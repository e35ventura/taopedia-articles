# Minimum Threshold

`MinimumThreshold` is a multisig pallet error raised when the approval threshold for a multisig
operation is set to less than 2. The API errors reference describes it as "Threshold must be 2 or
greater"
([Subtensor API Errors: MinimumThreshold](https://docs.learnbittensor.org/subtensor-api/errors#minimumthreshold)).

## What It Means

Bittensor multisig wallets are described as "M of N", where M is the threshold — the number of
signatories required to approve a call before it executes — and N is the total number of signatories
([Multisig Wallets](https://docs.learnbittensor.org/keys/multisig)).

`MinimumThreshold` fires when M is submitted as 1 or 0. The threshold must be 2 or greater, meaning
at least two co-signers must approve any multisig call
([Subtensor API Errors: MinimumThreshold](https://docs.learnbittensor.org/subtensor-api/errors#minimumthreshold),
[Multisig Wallets](https://docs.learnbittensor.org/keys/multisig)).

This is a threshold-value rejection, not proof that the signatories list is empty, that the
signatories list is longer than the threshold, or that the signatory list is out of order.

## Why It Appears

This error appears when a multisig call is submitted with a threshold below the documented minimum
of 2. The multisig documentation uses a "two of three" configuration as the illustrative example,
where 2 is the threshold and 3 is the total number of signatories
([Multisig Wallets](https://docs.learnbittensor.org/keys/multisig)).

The practical meaning is narrow: the threshold must be at least 2 before the multisig call can
succeed.

## Distinction from Too Few Signatories

`MinimumThreshold` and `TooFewSignatories` both block multisig calls on structural parameters, but
they check different values. `TooFewSignatories` fires when the signatories list does not contain
enough entries. `MinimumThreshold` fires when the threshold value itself is below 2, regardless of
how many signatories are listed
([Subtensor API Errors: TooFewSignatories](https://docs.learnbittensor.org/subtensor-api/errors#toofewsignatories),
[Multisig Wallets](https://docs.learnbittensor.org/keys/multisig)).

- **MinimumThreshold** — the threshold value M is less than 2.
- **TooFewSignatories** — the signatories list N has too few entries.

## Distinction from Too Many Signatories

`MinimumThreshold` and `TooManySignatories` both block multisig calls on signatory-structure
parameters. `TooManySignatories` fires when the signatories list exceeds the configured maximum.
`MinimumThreshold` fires when the threshold value is below the minimum of 2, independent of the
signatories list length
([Subtensor API Errors: TooManySignatories](https://docs.learnbittensor.org/subtensor-api/errors#toomanysignatories),
[Multisig Wallets](https://docs.learnbittensor.org/keys/multisig)).

- **MinimumThreshold** — the threshold value M is less than 2.
- **TooManySignatories** — the signatories list N exceeds the maximum.

## Reader Boundary

This page defines the meaning of the error label and the threshold minimum that raises it. It does
not report the current threshold set for any existing multisig on chain; that is live chain state
([Multisig Wallets](https://docs.learnbittensor.org/keys/multisig),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
