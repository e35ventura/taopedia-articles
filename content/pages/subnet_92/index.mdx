Subnet 92 is a Bittensor subnet slot that no longer has a registered identity returned by the Finney
identity query. The slot is active on the network with a small number of registered neurons, but the
on-chain identity fields — name, GitHub repository, project URL, description, and contact metadata —
are all absent.

The slot was previously associated with a project called TensorClaw, which described itself as a
decentralized LLM-inference subnet aggregating model-serving backends into a load-balanced API. The
GitHub repository previously linked to that identity, `tensorclaw/tensorclaw`, is no longer
accessible. Because neither the on-chain identity nor the associated codebase is currently
available, this article does not describe a technical mechanism, miner workflow, or validator
scoring process for the current operator.
