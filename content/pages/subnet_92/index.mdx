# Subnet 92: SN92

Bittensor Subnet 92 (netuid 92) was previously operated under the name TensorClaw. At that time the
on-chain identity listed [tensorclaw.ai](https://www.tensorclaw.ai) as the subnet URL and
[tensorclaw/tensorclaw](https://github.com/tensorclaw/tensorclaw) as the GitHub repository. The
subnet was described as a decentralized LLM-inference network that pooled multiple model-serving
backends behind a single load-balanced API.

The on-chain identity for SN92 has since been cleared. As shown on
[TaoStats](https://taostats.io/subnets/92), the slot now carries no registered name, description,
GitHub repository, or URL. The active-neuron count is 2.

## Previous Mechanism (TensorClaw)

While operating as TensorClaw, Subnet 92 rewarded miners for serving real LLM inference traffic
through a shared API endpoint. Validators sent live probes to measure miner responsiveness, and
miners earned scores based on a combination of availability metrics and the actual request and token
volume they handled over a rolling window. Validators who accurately tracked miner performance
earned dividends through [[Yuma Consensus]].

## On-Chain Identity

Live SN92 data is available on [TaoStats](https://taostats.io/subnets/92). The current on-chain
identity shows no registered name, description, GitHub repository, or URL. Only two neurons are
active. Readers seeking current operator information should consult TaoStats directly for the most
recent registration state.
