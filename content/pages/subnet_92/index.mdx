Subnet 92 is a Bittensor subnet slot that currently has no registered identity returned by the
Finney identity query. The live on-chain record does not list a subnet name, GitHub repository,
project URL, contact address, description, or Discord for this slot.

Because the live identity fields are absent, this page treats SN92 as an unknown identity record.
Readers should verify the live Finney identity before relying on any older project name, third-party
profile, or repository assumption for the slot.

## Current Status

For active subnet articles, Taopedia normally explains what miners produce, how validators evaluate
contributions, and which public repository or documentation defines the mechanism. Subnet 92 does
not currently expose that kind of source through its live identity fields, and its active neuron
count is very low.

Readers who need up-to-date information about Subnet 92 should consult the live on-chain record
directly.

## On-Chain Identity

Live SN92 data is available on [TaoStats](https://taostats.io/subnets/92). Readers can reproduce the
chain identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 92 --network finney`.
