Subnet 92 is a Bittensor subnet slot that has no registered on-chain identity. The live Finney
identity lookup returns no subnet name, GitHub repository, project URL, contact field, description,
or additional metadata for netuid 92.

The slot was previously associated with a project called TensorClaw, which registered an on-chain
identity describing a decentralized LLM-inference service, listed tensorclaw.ai as the subnet URL,
and linked to a GitHub repository at tensorclaw/tensorclaw. Both the on-chain identity and that
GitHub repository have since been removed. The subnet currently shows only two registered neurons.

Because no verifiable source currently describes the mechanism, operator, or public project for this
slot, this page treats SN92 as an unknown identity record. Readers should verify the live Finney
state before relying on any older project name or third-party description for the slot.

## Current Status

For active subnet articles, Taopedia normally explains what miners produce, how validators evaluate
that work, and which public source defines the mechanism. Subnet 92 does not currently expose that
kind of public source through its live identity state.

A future operator could register new identity metadata and publish project documentation for this
netuid. Until that happens, the slot should be treated as unoccupied from a public-participation
standpoint.

Subnet-specific miner and validator roles cannot be described reliably from the current state of

## On-Chain Identity

Live SN92 subnet data is available on [TaoStats](https://taostats.io/subnets/92). Readers can
reproduce the registered identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 92 --network finney`.

for netuid 92.
