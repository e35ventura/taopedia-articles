TensorClaw was the public project associated with Bittensor Subnet 92. The subnet's original
on-chain identity described it as a decentralized large language model inference subnet that
aggregated high-quality LLM API nodes — such as OpenAI, DeepSeek, Claude, and Llama — into a
unified, highly available, and load-balanced service, listing
[tensorclaw.ai](https://www.tensorclaw.ai) as the subnet URL and `tensorclaw/tensorclaw` as the
GitHub repository.

The Finney identity record for netuid 92 no longer returns a registered name, description, GitHub
URL, or website. The GitHub repository previously associated with the subnet returns a 404 response.
The subnet currently reports two active neurons, down from the 256 reported while TensorClaw was
operational.

## Historical Mechanism

TensorClaw's README described the subnet as pooling many model-serving backends behind a single API.
A "Business API" forwarded real user requests to participating miners and fed the resulting usage
back into the network's incentive scores, so miners who handled more real, high-quality traffic
earned a larger share of rewards.

The README described miners as connecting a model backend to the network and serving the inference
requests routed to them. To keep miners from claiming capacity they did not have, validators and the
request layer sent a short live prompt as a probe; a backend that failed to answer in time was
treated as offline, scored zero, and removed from the routing pool.

Validators scored miners and set weights on-chain. A miner's final score combined a small base
component — model availability, probe success, response time, and recent uptime — with a larger
business component derived from the real request and token volume the miner served over a rolling
window. Those weights then entered [[Yuma Consensus]] through the standard [[Mining and Validating]]
process.

## On-Chain Identity

Live SN92 data is available on [TaoStats](https://taostats.io/subnets/92). Readers can reproduce the
current identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 92 --network finney`.

The Finney identity currently reports no registered name, description, GitHub URL, or website for
netuid 92. The subnet reports two active neurons. The previously associated GitHub repository
(`tensorclaw/tensorclaw`) is no longer publicly accessible.
