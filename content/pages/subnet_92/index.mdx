wgmi is Bittensor Subnet 92. Its current on-chain identity is registered under the name wgmi and
does not include a public description, GitHub repository, website, or contact information. The
subnet currently seats three registered neurons.

Readers should treat Subnet 92 as an identity-labeled slot whose full protocol details are not yet
publicly documented through on-chain identity fields. If the identity is later updated with source
or URL information, the live Finney identity should be the first place to check.

## On-Chain Identity

Live SN92 data is available on [TaoStats](https://taostats.io/subnets/92). Readers can reproduce the
subnet's registered identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 92 --network finney`.

That Finney identity reports the subnet name as wgmi. It does not report a GitHub source, subnet
URL, description, or additional metadata.
