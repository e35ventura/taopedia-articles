# Subnet 92: wgmi

wgmi is Bittensor Subnet 92, registered on the Finney mainnet under the name wgmi — a phrase drawn
from crypto culture meaning "we're gonna make it." The subnet's on-chain identity currently lists no
GitHub repository, no public website, and no description, and the active neuron count is 3 as
recorded on [TaoStats](https://taostats.io/subnets/92).

Because no validator code, miner documentation, or operator website is publicly linked from the
on-chain identity, the subnet's incentive mechanism and participation requirements are not available
for independent review at this time.

## On-Chain Identity

Live SN92 data is available on [TaoStats](https://taostats.io/subnets/92). The Finney identity
registers the subnet name as wgmi with no GitHub, URL, or description fields set.
