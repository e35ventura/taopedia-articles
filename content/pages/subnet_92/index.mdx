Subnet 92 is a Bittensor subnet slot that currently has no registered identity returned by the
Finney identity query. The live identity lookup does not return a subnet name, GitHub repository,
project URL, contact field, description, or additional metadata for this slot.

This subnet was previously associated with the TensorClaw project — a decentralized LLM inference
network described in earlier on-chain records as aggregating model-serving backends into a
load-balanced API. That identity registration no longer appears in the live Finney chain state.
Because the current identity fields are empty, this page does not reproduce the prior project's
mechanism as current fact.

## Current Status

For active subnet articles, Taopedia normally describes what miners produce, how validators evaluate
that work, and which public repository or documentation defines the mechanism. Subnet 92 does not
currently expose a public source through its live identity state.

Readers should verify the slot's current registration before acting on any older third-party
descriptions. A fresh identity query can be run with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 92 --network finney`.
