Subnet 92 was formerly associated with TensorClaw, a decentralized LLM-inference subnet. The project
described aggregating LLM API backends from providers such as OpenAI, DeepSeek, Claude, and Llama
into a unified, load-balanced service, rewarding miners for handling real inference traffic.

The current on-chain identity for netuid 92 is blank — the Finney chain returns no registered name,
description, URL, or GitHub repository for this subnet. The GitHub repository that was listed in the
original identity (`tensorclaw/tensorclaw`) no longer exists. The subnet currently has two active
neurons, indicating it is dormant.

## What TensorClaw Provided

While active, TensorClaw described itself as a decentralized LLM inference network that pooled many
model-serving backends behind a single API. Miners connected to a central router and served
inference requests routed to them. Validators scored miners based on model availability, probe
success, response time, and the volume of real request traffic served over a rolling window.

The subnet positioned itself as infrastructure for high-availability LLM serving rather than a model
training or evaluation subnet.

## Current Status

Live SN92 data is available on [TaoStats](https://taostats.io/subnets/92). As of the current
on-chain query, netuid 92 has no registered identity and very few active participants. Any future
operator acquiring or reactivating this slot would reset the identity and mechanism from scratch.
