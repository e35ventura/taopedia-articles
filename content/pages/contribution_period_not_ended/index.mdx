# Contribution Period Not Ended

`ContributionPeriodNotEnded` is a crowdloan pallet error raised when an operation that requires the
contribution period to have concluded is attempted before that deadline has been reached. The API
docs describe it as "The crowdloan contribution period has not ended yet"
([Subtensor API Errors: ContributionPeriodNotEnded](https://docs.learnbittensor.org/subtensor-api/errors#contributionperiodnotended)).

## What It Means

Each [crowdloan](https://docs.learnbittensor.org/subnets/crowdloans) has a deadline — a block number
at which the contribution window closes. Operations that can only proceed once the contribution
window has closed are blocked while that deadline block has not yet been produced.
`ContributionPeriodNotEnded` is that deadline check — not a balance check, a contribution-amount
check, or a funding-cap check
([Subtensor API Errors: ContributionPeriodNotEnded](https://docs.learnbittensor.org/subtensor-api/errors#contributionperiodnotended)).

## Distinction from Contribution Period Ended

`ContributionPeriodNotEnded` and `ContributionPeriodEnded` are both crowdloan deadline errors, but
they block opposite operations. `ContributionPeriodEnded` fires when a contribution is attempted
after the deadline has passed. `ContributionPeriodNotEnded` fires when a post-period operation is
attempted before the deadline has been reached
([Subtensor API Errors: ContributionPeriodEnded](https://docs.learnbittensor.org/subtensor-api/errors#contributionperiodended),
[Subtensor API Errors: ContributionPeriodNotEnded](https://docs.learnbittensor.org/subtensor-api/errors#contributionperiodnotended)).

- **ContributionPeriodEnded** — the deadline has passed; new contributions are blocked.
- **ContributionPeriodNotEnded** — the deadline has not passed; post-period operations are blocked.

## Reader Boundary

This page defines the error label and the deadline check that raises it. It does not describe how
crowdloan deadlines are set or the specific operations that require the period to have concluded
([Subtensor API Errors: ContributionPeriodNotEnded](https://docs.learnbittensor.org/subtensor-api/errors#contributionperiodnotended),
[Crowdloans](https://docs.learnbittensor.org/subnets/crowdloans)).
