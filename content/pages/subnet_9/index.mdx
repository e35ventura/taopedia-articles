# Subnet 9: iota

iota is Bittensor Subnet 9 (SN9), operated by [Macrocosmos](https://www.macrocosmos.ai/). The subnet
implements IOTA — Incentivized Orchestrated Training Architecture — a framework for pretraining
large language models across a network of heterogeneous, unreliable, permissionless, and
token-incentivized machines. Rather than requiring a single operator to own a supercomputer, iota
distributes model layers across independent miners and orchestrates the data flow between them,
using token emissions to reward participants who do useful work. Macrocosmos provides a public
[dashboard](https://iota.macrocosmos.ai/dashboard/mainnet) showing live training metrics and network
state.

References: [macrocosm-os/iota (GitHub)](https://github.com/macrocosm-os/iota),
[iota.macrocosmos.ai](https://iota.macrocosmos.ai/),
[IOTA technical paper (arXiv)](https://arxiv.org/abs/2507.17766)

## How the Mechanism Works

iota uses a pipeline-parallel design in which a model is split into consecutive layer groups —
called pipeline stages — and each stage is assigned to a different set of miners. An orchestrator
distributes the data, passes activations forward through the pipeline, and coordinates a shared
storage layer where layer weights and intermediate activations are held between steps. Miners
process activations for their assigned stage and periodically merge weight updates using a variant
of Butterfly All-Reduce, a communication primitive that reduces inter-node traffic while keeping
weights synchronized.

Validators spot-check miner work throughout training to verify that miners computed activations
correctly and did not submit fraudulent updates. Only miners who pass these checks receive
emissions. This creates an economic incentive structure where honest computation is consistently
rewarded and shortcuts are penalized. Validator weight-sets flow into [[Yuma Consensus]], which
distributes per-block TAO emissions through [[Dynamic TAO]].

The full mechanism is documented in the
[IOTA technical paper](https://www.macrocosmos.ai/research/iota_primer.pdf) published by
Macrocosmos, and is also available on [arXiv](https://arxiv.org/abs/2507.17766).

References: [macrocosm-os/iota (GitHub)](https://github.com/macrocosm-os/iota),
[IOTA technical paper (arXiv)](https://arxiv.org/abs/2507.17766)

## Participating as a Miner

Miners on iota contribute GPU compute to one or more pipeline stages of the active training run.
Each miner registers on netuid 9, is assigned a layer segment by the orchestrator, and processes the
forward and backward passes for that segment as training data flows through the network. Earnings
are proportional to how many activations a miner successfully processes — miners who process more
activations in the training stage earn more of the emissions allocated to the subnet.

Because the network is permissionless, miners with consumer-grade hardware can participate. The
current training run targets a 1.5 billion parameter model with three pipeline stages, meaning the
compute load is divided into three segments that miners can cover without needing a single very
large GPU. Official miner documentation is maintained at
[docs.macrocosmos.ai](https://docs.macrocosmos.ai/subnets/subnet-9-pre-training/subnet-9-iota-mining-setup-guide).

References: [macrocosm-os/iota (GitHub)](https://github.com/macrocosm-os/iota),
[Macrocosmos miner docs](https://docs.macrocosmos.ai/subnets/subnet-9-pre-training/subnet-9-iota-mining-setup-guide)

## Participating as a Validator

Validators on iota run the spot-checking infrastructure that samples miner outputs, re-computes
expected activations, and flags miners whose work does not match. A validator must maintain reliable
uptime and connectivity to the orchestrator so it can participate in the continuous verification
cycle. Validators that submit honest weight-sets earn emissions through [[Yuma Consensus]].

Because validator spot-checks are the primary mechanism preventing miners from cheating, validator
quality directly affects the integrity of the trained model. Macrocosmos provides official validator
documentation at
[docs.macrocosmos.ai](https://docs.macrocosmos.ai/subnets/subnet-9-pre-training/subnet-9-validating).

References: [macrocosm-os/iota (GitHub)](https://github.com/macrocosm-os/iota),
[Macrocosmos validator docs](https://docs.macrocosmos.ai/subnets/subnet-9-pre-training/subnet-9-validating)
