Nodexo is Bittensor Subnet 106. Its on-chain identity describes the subnet as tokenized AI compute
and lists [nodexo.ai](https://nodexo.ai) as the project site. The operator, neuralinternet, also
operates Subnet 27 under the Nodexo name, where the stated focus is decentralized AI compute
infrastructure. SN106 carries the same branding with the description "tokenized ai compute,"
indicating the subnet is part of the same Nodexo compute ecosystem.

The on-chain GitHub field for SN106 points to neuralinternet/SN27, which does not currently resolve
to a public repository. Because no separate public documentation is available for SN106, the
mechanism details below are not verifiable from the subnet's own source code. Readers should check
the [TaoStats page for SN106](https://taostats.io/subnets/106) for current identity fields and any
updated GitHub links.

## How the Mechanism Works

Based on the on-chain description and the operator's other subnet, Nodexo SN106 is positioned as a
tokenized compute layer on Bittensor. In a compute subnet of this kind, miners typically contribute
hardware resources, validators benchmark or test that hardware, and the resulting scores determine
how emissions flow to participants via [[Yuma Consensus]].

The description "tokenized ai compute" suggests the subnet may bridge the Nodexo compute platform to
a token-denominated resource market, though the specific miner tasks, validator scoring logic, and
reward formula for SN106 are not publicly documented in a verifiable source at this time.
