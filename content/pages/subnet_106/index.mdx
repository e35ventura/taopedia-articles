# Subnet 106: Nodexo

Subnet 106 is registered on Finney under the name Nodexo, operated by NeuralInternet. Its on-chain
description is "tokenized ai compute." The subnet occupies a second Bittensor slot alongside
[Subnet 27](/subnet_27), which carries Nodexo's primary compute-subnet identity. Both slots share
the Nodexo brand and the [nodexo.ai](https://nodexo.ai) domain.

## How the Mechanism Works

The on-chain description positions SN106 as a compute resource subnet. In this class of subnet,
miners contribute compute capacity to the network and validators score the quality and availability
of those contributions. Weights derived from validator assessments flow into [[Yuma Consensus]],
which distributes emissions to miners in proportion to how useful their compute proved to be.

The specific scoring method, task format, and hardware requirements for SN106 are defined by the
NeuralInternet team. Because the registered GitHub field points to a repository that is not
currently public, the subnet's miner and validator tooling should be verified directly through the
operator's official channels.

## Participating as a Miner

Miners on SN106 register a hotkey under netuid 106 and contribute compute resources as defined by
NeuralInternet's validator software. Since the subnet shares a brand with SN27, miners already
familiar with the Nodexo compute model may find the requirements similar, though SN106 operates as a
distinct subnet with its own metagraph, emissions, and registration slots.

Prospective miners should consult the NeuralInternet Discord at
[discord.gg/fwjBwxUcdX](https://discord.gg/fwjBwxUcdX) for current setup instructions and any
hardware requirements specific to netuid 106.

## Participating as a Validator

Validators on SN106 run NeuralInternet's validator software, which sends scoring tasks to registered
miners and converts responses into weights submitted on-chain. Those weights are the input to
[[Yuma Consensus]] and directly determine how emissions flow to miners. Validators interested in
SN106 should confirm current requirements through the operator's Discord and official documentation
before registering.

## On-Chain Identity

Live on-chain data for SN106 is available at
[taostats.io/subnets/106](https://taostats.io/subnets/106). The current Finney identity registers
the subnet as Nodexo, with the description "tokenized ai compute" and the URL
[nodexo.ai](https://nodexo.ai).
