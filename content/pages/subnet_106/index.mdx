Nodexo is Bittensor Subnet 106. Its on-chain description is "tokenized ai compute," and the project
site is [nodexo.ai](https://nodexo.ai). The same team that operates Subnet 27 — also registered
under the Nodexo identity — controls this subnet. Both subnets share the same registered owner
coldkey and point to the same GitHub field, neuralinternet/SN27.

The subnet's stated purpose is to turn AI compute into a tokenized, incentivized commodity on
Bittensor. Miners contribute compute resources and validators evaluate those contributions. That
evaluation produces weights, and those weights determine rewards.

## How the Mechanism Works

Nodexo's compute-tokenization model follows the general Bittensor pattern: miners supply a resource,
validators measure it, and emissions reward the strongest suppliers. The on-chain description
positions the subnet as infrastructure — a network layer that makes GPU or CPU capacity available
and accountable through on-chain incentives.

Because the GitHub repository listed in the on-chain identity for SN106 does not resolve publicly,
this article describes the subnet from its registered on-chain identity rather than from a specific
codebase. Readers who need current scoring details or setup instructions should consult the
[Nodexo project site](https://nodexo.ai) or the community Discord.

## Participating as a Miner

Miners on Nodexo contribute compute to the network. The subnet's operator also runs Subnet 27 under
the same Nodexo brand, and the general participation model — connecting compute resources to the
Bittensor network and having those resources evaluated by validators — applies here. Prospective
miners should consult the current Nodexo documentation and community Discord for subnet-specific
registration and hardware requirements.

## Participating as a Validator

Validators assess the compute contributions made by miners and submit weights. Those weights flow
through [[Yuma Consensus]] to determine which miners receive emissions. As with miners, current
validator setup guidance lives in Nodexo's public documentation and Discord rather than in a
publicly accessible repository.

## On-Chain Identity

Live SN106 subnet data is available on [TaoStats](https://taostats.io/subnets/106). The Finney
identity for netuid 106 lists the registered subnet name as Nodexo, the description as "tokenized ai
compute," the project URL as nodexo.ai, and the Discord as the Nodexo community server. The listed
GitHub field points to neuralinternet/SN27 but does not currently resolve as a public repository.

The same registered owner coldkey (5E5Ctr2D9SjvLwNn45UNhBpjuQ7QWuinMqpAXY1ueRfJr5PT) controls both
this subnet and Subnet 27, confirming that both operate under the Nodexo umbrella. SN106 was
previously registered under the VoidAI identity before the current operator registered the Nodexo
identity.
