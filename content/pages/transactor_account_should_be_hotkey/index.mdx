# Transactor Account Should Be Hotkey

`TransactorAccountShouldBeHotKey` is a subtensor pallet error raised when a call that requires a
hotkey as the signing origin is submitted by an account that is not a hotkey. The API errors
reference describes it as "The hotkey is required to be the origin."
([Subtensor API Errors: TransactorAccountShouldBeHotKey](https://docs.learnbittensor.org/subtensor-api/errors#transactoraccountshouldbehotkey),
[Subtensor Standard Errors: TransactorAccountShouldBeHotKey](https://docs.learnbittensor.org/errors/subtensor#transactoraccountshouldbehotkey)).

## What It Means

Some subtensor extrinsics require the transaction to be signed by a hotkey account. When one of
those calls is submitted and the signing account is not a hotkey, the runtime raises
`TransactorAccountShouldBeHotKey`
([Subtensor API Errors: TransactorAccountShouldBeHotKey](https://docs.learnbittensor.org/subtensor-api/errors#transactoraccountshouldbehotkey)).

This is an origin-type check. It does not mean the hotkey account does not exist, or that a
coldkey-to-hotkey ownership mismatch was detected.

## Why It Appears

This error appears when a subtensor call that requires a hotkey origin is submitted with a signing
account that is not a hotkey
([Subtensor API Errors: TransactorAccountShouldBeHotKey](https://docs.learnbittensor.org/subtensor-api/errors#transactoraccountshouldbehotkey)).

## Distinction from Non Associated Coldkey

`TransactorAccountShouldBeHotKey` and `NonAssociatedColdKey` both block subtensor calls involving
hotkey-coldkey relationships, but they check different things. `NonAssociatedColdKey` fires when the
signing coldkey is not the owner of the targeted hotkey. `TransactorAccountShouldBeHotKey` fires
when the signing account itself is required to be a hotkey but is not
([Subtensor API Errors: NonAssociatedColdKey](https://docs.learnbittensor.org/subtensor-api/errors#nonassociatedcoldkey),
[Subtensor API Errors: TransactorAccountShouldBeHotKey](https://docs.learnbittensor.org/subtensor-api/errors#transactoraccountshouldbehotkey)).

- **TransactorAccountShouldBeHotKey** — signing account is not a hotkey.
- **NonAssociatedColdKey** — signing coldkey does not own the targeted hotkey.

## Distinction from Hotkey Account Not Exists

`TransactorAccountShouldBeHotKey` and `HotKeyAccountNotExists` both appear on paths that validate
hotkey accounts, but they describe different failures. `HotKeyAccountNotExists` fires when a call
references a hotkey that has no on-chain account. `TransactorAccountShouldBeHotKey` fires when the
signing account is not a hotkey
([Subtensor API Errors: HotKeyAccountNotExists](https://docs.learnbittensor.org/subtensor-api/errors#hotkeyaccountnotexists),
[Subtensor API Errors: TransactorAccountShouldBeHotKey](https://docs.learnbittensor.org/subtensor-api/errors#transactoraccountshouldbehotkey)).

- **TransactorAccountShouldBeHotKey** — signing account is not a hotkey.
- **HotKeyAccountNotExists** — the referenced hotkey account does not exist on chain.
