# Alpha Halving

An alpha halving is a subnet-scoped reduction in alpha-token emission. It applies the halving idea
to a subnet's own alpha supply, rather than to the network-wide TAO supply
([Glossary: Halving](https://docs.learnbittensor.org/resources/glossary#halving)).

The concept belongs to subnet tokenomics because alpha tokens are tied to individual subnets and
their emission flow ([Emissions](https://docs.learnbittensor.org/learn/emissions)).

## Supply-Threshold Context

A halving is a supply-threshold event: once the relevant token supply crosses the next threshold,
the emission rate is reduced. In the alpha-token case, the relevant supply is the alpha supply for a
single subnet ([Glossary: Halving](https://docs.learnbittensor.org/resources/glossary#halving)).

This makes alpha halving a supply-schedule concept, not a market signal or a claim about reward
quality. It explains why new alpha enters a subnet more slowly after the threshold is reached
([Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving)).

## Subnet Scope

Alpha halving is scoped to one subnet because each subnet has its own alpha token. The halving stage
of one subnet should therefore not be read as the halving stage of every other subnet
([Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets)).

That scope separates alpha halving from the TAO halving. TAO halving is network-scoped, while alpha
halving is tied to the supply path of a specific subnet token
([Glossary: Alpha Tokens](https://docs.learnbittensor.org/resources/glossary#alpha-tokens)).

## Emission Context

Emission describes the creation and allocation of new token rewards. Alpha halving changes the
alpha-token side of that flow by reducing how much new alpha is emitted for the affected subnet
([Emissions](https://docs.learnbittensor.org/learn/emissions)).

The important reader-facing point is the direction of the change: alpha halving slows future alpha
creation. It does not describe a one-time transfer, a staking action, or a separate valuation rule
([Glossary: Halving](https://docs.learnbittensor.org/resources/glossary#halving)).

## Alpha Token Context

Alpha tokens are subnet-specific assets. An alpha halving matters because it changes the emission
rate for that subnet's asset, not because it creates a new class of token
([Glossary: Alpha Tokens](https://docs.learnbittensor.org/resources/glossary#alpha-tokens)).

For readers, this keeps the vocabulary clear: alpha tokens name the subnet asset, while alpha
halving names a scheduled reduction in that asset's emission rate
([Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving)).

## Burn Context

Alpha halving and subnet stake burn are both supply-side ideas, but they operate differently. Alpha
halving slows future emission; subnet stake burn describes a reserve-and-burn flow that removes
alpha already in circulation
([Subnet Stake Burn](https://docs.learnbittensor.org/concepts/stake-burn)).

The two should not be treated as interchangeable. One changes the rate at which future alpha is
created, while the other changes an existing pool relationship
([Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving)).

## Coinbase Context

Alpha emission also appears in the block and epoch flow described by the coinbase documentation.
After an alpha halving, the affected subnet's alpha-emission input is lower, while the broader
emission process still handles reward flow
([Coinbase Flow](https://docs.learnbittensor.org/navigating-subtensor/emissions-coinbase)).

This makes coinbase context useful for placement, but it does not change the definition of alpha
halving. Alpha halving names the supply-threshold reduction; coinbase names part of the recurring
emission path ([Emissions](https://docs.learnbittensor.org/learn/emissions)).

## Reader Boundary

Alpha halving should be read as a concept-level article. It does not provide halving stages, exact
thresholds, dates, or subnet schedules
([Glossary: Halving](https://docs.learnbittensor.org/resources/glossary#halving)).

The stable article-level point is that a subnet's alpha-token emission rate can be reduced at supply
thresholds independently from the TAO halving and independently from other subnets
([Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets)).
