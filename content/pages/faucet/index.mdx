# Faucet

A faucet is a mechanism that hands out test TAO on Bittensor's test network so that developers can
experiment without spending real TAO. Official documentation describes the faucet as a way for new
participants to receive an initial amount of test TAO to start working on the test network.

References: [Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)

## Test TAO, Not Real Value

The TAO a faucet dispenses exists only on the test network and carries no mainnet value. Its purpose
is to let newcomers and builders obtain a small starting balance so they can try actions like
registration, staking, and running miners or validators in a safe environment before doing anything
with real funds on mainnet.

Reference: [Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)

## How It Worked

The documentation describes the faucet as dispensing test TAO in exchange for proof of work. A
requester performed computational work and received test funds in return, which kept the supply of
free test TAO bounded rather than unlimited on demand.

Reference: [btcli Reference](https://docs.learnbittensor.org/btcli)

## Current Status

The documentation notes that the faucet is currently disabled on the public test network. Because of
that, test TAO is obtained through other means, such as asking in the project's community channels,
and a developer running their own local staging chain can enable a faucet there for self-contained
testing. The takeaway is that a public, on-demand faucet is not the assumed path today.

Reference: [btcli Reference](https://docs.learnbittensor.org/btcli)

## Testnet and Mainnet Boundary

A faucet belongs to the test network only. On mainnet, TAO has real value and is not handed out by a
faucet; it is earned, transferred, or acquired. Keeping that boundary clear avoids treating test TAO
as if it were spendable network currency.

References: [Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks),
[TAO](https://docs.learnbittensor.org/resources/glossary#tao)

## Reader Boundary

This page defines the concept at a high level. It does not provide steps to obtain test TAO, and the
availability or method of doing so can change over time. For the current state of the faucet and how
to get test TAO, consult current Bittensor documentation and community resources.

Reference: [Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)
