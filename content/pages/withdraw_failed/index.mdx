# Withdraw Failed

`WithdrawFailed` is an EVM pallet error raised when the runtime cannot withdraw the fee required for
the requested operation. The API errors reference describes it as "Withdraw fee failed"
([Subtensor API Errors: WithdrawFailed](https://docs.learnbittensor.org/subtensor-api/errors#withdrawfailed)).

## What It Means

`WithdrawFailed` means the EVM call was blocked because the fee could not be withdrawn from the
account funding the operation
([Subtensor API Errors: WithdrawFailed](https://docs.learnbittensor.org/subtensor-api/errors#withdrawfailed)).

This is a fee withdrawal check. It does not mean the fee calculation overflowed.

## Why It Appears

This error appears when an EVM operation is processed but the step that withdraws the fee does not
succeed
([Subtensor API Errors: WithdrawFailed](https://docs.learnbittensor.org/subtensor-api/errors#withdrawfailed)).

## Distinction from Fee Overflow

`WithdrawFailed` is documented as "Withdraw fee failed." `FeeOverflow` is documented as "Calculating
total fee overflowed." Both are EVM pallet errors tied to the transaction fee, but their documented
conditions describe different stages: withdrawing the fee versus calculating it
([Subtensor API Errors: WithdrawFailed](https://docs.learnbittensor.org/subtensor-api/errors#withdrawfailed),
[Subtensor API Errors: FeeOverflow](https://docs.learnbittensor.org/subtensor-api/errors#feeoverflow)).

- **WithdrawFailed** -- the fee could not be withdrawn from the account.
- **FeeOverflow** -- the total fee calculation overflowed.

## Distinction from Balance Low

`WithdrawFailed` is documented as "Withdraw fee failed." `BalanceLow` is documented as "Not enough
balance to perform action." Both block an EVM operation related to funds, but their documented
conditions describe different problems
([Subtensor API Errors: WithdrawFailed](https://docs.learnbittensor.org/subtensor-api/errors#withdrawfailed),
[Subtensor API Errors: BalanceLow](https://docs.learnbittensor.org/subtensor-api/errors#balancelow)).

- **WithdrawFailed** -- the fee withdrawal step itself failed.
- **BalanceLow** -- the account does not have enough balance to perform the action.
