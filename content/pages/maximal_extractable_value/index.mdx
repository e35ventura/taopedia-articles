# Maximal Extractable Value (MEV)

Maximal extractable value, or MEV, is profit that can be gained by using transaction ordering or
pending transaction information. The official
[Glossary](https://docs.learnbittensor.org/resources/glossary#mev-maximal-extractable-value) defines
MEV as value extracted by reordering, inserting, or censoring transactions within a block.

## Transaction-Ordering Risk

MEV is easiest to understand as an ordering risk. If an observer can see a transaction before it is
included, that information may create an opportunity to place another transaction before, after, or
around it. The official glossary names front-running, sandwich attacks, and back-running as common
forms of MEV behavior.

This does not mean every pending transaction is attacked. The concept names the class of risk: a
party with useful timing or ordering information may try to turn that information into profit.

## Bittensor Context

In Bittensor, the official glossary connects MEV risk to staking and unstaking activity, where
pending transaction knowledge can affect token-price execution. The
[Price Protection](https://docs.learnbittensor.org/learn/price-protection) page describes the same
problem from the user's side: token prices can move while a transaction is pending, and those moves
can be exploited by sandwich attacks or other MEV behavior.

The important reader-facing point is the timing window. MEV risk appears before final execution,
when pending information and ordering choices can still matter.

## Relationship to MEV Shield

MEV and MEV Shield are related but not the same concept. MEV names the risk. The official
[MEV Shield](https://docs.learnbittensor.org/concepts/mev-shield/) page describes a Bittensor
security feature that keeps transaction details hidden until they are on-chain, reducing the
opportunity to profit from advance knowledge.

MEV Shield therefore addresses a visibility problem around pending transactions. It should not be
read as a guarantee that every transaction outcome is favorable or that all transaction risk has
been removed.

## Reader Boundary

MEV is not a fee or a general label for price movement. It is a specific transaction-ordering and
information-timing risk. Price protection and MEV Shield address related parts of that risk, but
each term names a different idea in the official documentation.
