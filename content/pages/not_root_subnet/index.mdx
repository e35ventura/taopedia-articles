# Not Root Subnet

`NotRootSubnet` is a subtensor pallet error. The API errors reference describes it as "Netuid does
not match for setting root network weights."
([Subtensor API Errors: NotRootSubnet](https://docs.learnbittensor.org/subtensor-api/errors#notrootsubnet)).

## What It Means

`NotRootSubnet` fires when a root network weight operation is submitted with a netuid that does not
match the expected root subnet netuid
([Subtensor API Errors: NotRootSubnet](https://docs.learnbittensor.org/subtensor-api/errors#notrootsubnet)).

This is a netuid mismatch specifically on the root-weight path. It does not, by itself, mean the
submitted subnet does not exist, or that the root network itself is absent from chain state.

## Why It Appears

This error appears when a call that sets root network weights is submitted with a netuid that does
not match for that operation
([Subtensor API Errors: NotRootSubnet](https://docs.learnbittensor.org/subtensor-api/errors#notrootsubnet)).

## Distinction from Subnet Not Exists

`SubnetNotExists` is documented as "Trying to perform action on non-existent subnet."
`NotRootSubnet` is documented as "Netuid does not match for setting root network weights." Both
involve a netuid that does not produce the expected result for an operation, but their documented
trigger conditions describe different problems
([Subtensor API Errors: SubnetNotExists](https://docs.learnbittensor.org/subtensor-api/errors#subnetnotexists),
[Subtensor API Errors: NotRootSubnet](https://docs.learnbittensor.org/subtensor-api/errors#notrootsubnet)).

- **NotRootSubnet** — netuid does not match for setting root network weights.
- **SubnetNotExists** — action attempted on a non-existent subnet.

## Distinction from Root Network Does Not Exist

`RootNetworkDoesNotExist` is documented as "The root network does not exist." `NotRootSubnet` is
documented as "Netuid does not match for setting root network weights." Both errors are associated
with the root network, but their documented conditions describe different problems
([Subtensor API Errors: RootNetworkDoesNotExist](https://docs.learnbittensor.org/subtensor-api/errors#rootnetworkdoesnotexist),
[Subtensor API Errors: NotRootSubnet](https://docs.learnbittensor.org/subtensor-api/errors#notrootsubnet)).

- **NotRootSubnet** — documented as a netuid mismatch for the root-weight operation.
- **RootNetworkDoesNotExist** — documented as the root network not existing.
