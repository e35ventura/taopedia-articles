# Objective Function

A subnet's objective function is the goal that the subnet is continuously optimizing for, through
its incentive mechanism. As with any machine learning model, a subnet has an objective function it
is continuously optimizing, and the rest of the subnet's design exists to push miner behavior toward
that goal rather than away from it.

References:
[Objective Function](https://docs.learnbittensor.org/resources/glossary#objective-function),
[Anatomy of an Incentive Mechanism](https://docs.learnbittensor.org/learn/anatomy-of-incentive-mechanism)

## Pursued Through the Incentive Mechanism

The objective function does not act on its own; it is pursued through the incentive mechanism, the
system that drives the behavior of subnet miners and governs consensus among subnet validators. The
mechanism is what turns an abstract goal into pressure on participants, rewarding work that moves
toward the objective and withholding reward from work that does not. The objective function is the
target, and the incentive mechanism is the means.

References:
[Incentive Mechanism](https://docs.learnbittensor.org/resources/glossary#incentive-mechanism),
[Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets)

## Task and Scoring Make It Concrete

Two parts of the incentive mechanism give the objective function a concrete shape. The subnet task
defines the work the subnet miners will perform, and the scoring model defines how those miners'
responses are evaluated, converting responses into numerical scores that capture the quality of
miner behavior. Together they translate the goal into a measurable target: the task says what to do,
and the scoring model says how well it was done relative to the objective.

References: [Subnet Task](https://docs.learnbittensor.org/resources/glossary#subnet-task),
[Subnet Scoring Model](https://docs.learnbittensor.org/resources/glossary#subnet-scoring-model)

## One Goal Per Subnet

The objective function is specific to a subnet. Because each subnet defines its own task and its own
scoring model inside its own incentive mechanism, each subnet is optimizing for its own goal rather
than a single network-wide one. That is why two subnets can run the same underlying machinery yet
reward entirely different behavior: the machinery is shared, but the objective each one points it at
is not.

References:
[Anatomy of an Incentive Mechanism](https://docs.learnbittensor.org/learn/anatomy-of-incentive-mechanism),
[Subnet Scoring Model](https://docs.learnbittensor.org/resources/glossary#subnet-scoring-model)

## Reader Boundary

This page defines the concept and does not state the exact objective of any particular subnet, since
each subnet sets its own and can change it. The durable point is structural: the objective function
is the goal a subnet continuously optimizes for, and it reaches that goal only through an incentive
mechanism whose task and scoring model express what the goal rewards.
