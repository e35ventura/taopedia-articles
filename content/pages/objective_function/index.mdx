# Objective Function

An objective function names the goal that a subnet continuously optimizes for through its incentive
mechanism. The official
[Glossary: Objective Function](https://docs.learnbittensor.org/resources/glossary#objective-function)
describes it as the goal a subnet is continuously optimizing for through its incentive mechanism,
and places it alongside loss function as part of subnet incentive vocabulary.

## Subnet Vocabulary

Objective function belongs to the vocabulary of subnet design and incentive mechanisms. The
[Glossary: Incentive Mechanism](https://docs.learnbittensor.org/resources/glossary#incentive-mechanism)
describes incentive mechanisms as systems that drive miner behavior and govern validator consensus.
[Understanding Incentive Mechanisms](https://docs.learnbittensor.org/learn/anatomy-of-incentive-mechanism)
places the task, protocol, and evaluation method together as the parts of that design.

Objective function names the goal side of that context. It is not a wallet term, a governance term,
or a token supply term.

## Relationship to Loss Function

Objective function and loss function are related terms in subnet prose. The
[Glossary: Loss Function](https://docs.learnbittensor.org/resources/glossary#loss-function)
describes incentive mechanisms as loss functions that guide subnet miners toward desirable outcomes.

Objective function emphasizes the goal the subnet pursues, while loss function emphasizes what
miners are steered to optimize toward. Both belong to the incentive-mechanism layer of subnet
vocabulary and are separate from miner registration, validator weights, or chain-level consensus.

## Subnet Task Context

[Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets) describes
subnets as markets where miners produce a digital commodity and validators measure the work. The
objective function names the goal the subnet pursues through its incentive rules in that context.

This keeps the term separate from the subnet task, which describes the work miners perform, and from
the incentive mechanism, which describes the rule system that drives behavior.

## Scope

Objective function is a concept term for the goal a subnet pursues through its incentive mechanism.
It does not name a live metric, a reward amount, or a validator recommendation.
