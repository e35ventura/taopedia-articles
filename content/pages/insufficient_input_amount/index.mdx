# Insufficient Input Amount

`InsufficientInputAmount` is a swap pallet error raised when the provided amount is not sufficient
for the swap. The API docs describe it as "The provided amount is insufficient for the swap"
([Subtensor API Errors: InsufficientInputAmount](https://docs.learnbittensor.org/subtensor-api/errors#insufficientinputamount)).

## What It Means

The swap pallet validates the input amount before executing a swap. When the amount provided by the
caller does not meet the swap's requirement, the operation is rejected with
`InsufficientInputAmount`. This is an input-amount rejection — not a pool-liquidity rejection and
not a price-limit rejection
([Subtensor API Errors: InsufficientInputAmount](https://docs.learnbittensor.org/subtensor-api/errors#insufficientinputamount)).

## Distinction from Insufficient Liquidity

`InsufficientInputAmount` and `InsufficientLiquidity` both block swap operations, but they reflect
different conditions. `InsufficientLiquidity` is raised when the pool does not have enough liquidity
to support the swap. `InsufficientInputAmount` is raised when the caller's provided input amount is
not sufficient, regardless of pool liquidity
([Subtensor API Errors: InsufficientLiquidity](https://docs.learnbittensor.org/subtensor-api/errors#insufficientliquidity),
[Subtensor API Errors: InsufficientInputAmount](https://docs.learnbittensor.org/subtensor-api/errors#insufficientinputamount)).

- **InsufficientLiquidity** — the pool lacks the liquidity to support the swap.
- **InsufficientInputAmount** — the caller's provided amount is insufficient for the swap.

## Distinction from Reserves Too Low

`InsufficientInputAmount` and `ReservesTooLow` both block swap operations, but at different checks.
`ReservesTooLow` is raised when the pool's output-side reserve is too thin for the operation.
`InsufficientInputAmount` is raised when the input amount provided by the caller is not sufficient
([Subtensor API Errors: ReservesTooLow](https://docs.learnbittensor.org/subtensor-api/errors#reservestoolow),
[Subtensor API Errors: InsufficientInputAmount](https://docs.learnbittensor.org/subtensor-api/errors#insufficientinputamount)).

- **ReservesTooLow** — the pool's output-side reserve is too thin.
- **InsufficientInputAmount** — the caller's provided input amount is not sufficient.

## Reader Boundary

This page defines the error label and the input-amount check it represents on the swap path. It does
not report minimum required amounts for any specific swap; those depend on current pool state
([Subtensor API Errors: InsufficientInputAmount](https://docs.learnbittensor.org/subtensor-api/errors#insufficientinputamount)).
