# Insufficient Input Amount

`InsufficientInputAmount` is an error raised when a swap cannot proceed because the provided input
amount is too small. The API errors reference describes it as "The provided amount is insufficient
for the swap."
([Subtensor API Errors: InsufficientInputAmount](https://docs.learnbittensor.org/subtensor-api/errors#insufficientinputamount)).

## What It Means

`InsufficientInputAmount` means the amount provided to the swap was not sufficient to complete the
requested exchange
([Subtensor API Errors: InsufficientInputAmount](https://docs.learnbittensor.org/subtensor-api/errors#insufficientinputamount)).

This is an input-side check. It does not mean the pool lacks reserves or that a slippage limit was
reached.

## Why It Appears

This error appears when a swap call is submitted with an input amount that is too small for the swap
to execute
([Subtensor API Errors: InsufficientInputAmount](https://docs.learnbittensor.org/subtensor-api/errors#insufficientinputamount)).

## Distinction from Reserves Too Low

`InsufficientInputAmount` is documented as "The provided amount is insufficient for the swap."
`ReservesTooLow` is documented as "Reserves too low for operation." Both block a swap operation, but
their documented conditions describe different problems
([Subtensor API Errors: InsufficientInputAmount](https://docs.learnbittensor.org/subtensor-api/errors#insufficientinputamount),
[Subtensor API Errors: ReservesTooLow](https://docs.learnbittensor.org/subtensor-api/errors#reservestoolow)).

- **InsufficientInputAmount** — the provided input amount is insufficient for the swap.
- **ReservesTooLow** — the pool reserves are too low for the operation.

## Distinction from Slippage Too High

`InsufficientInputAmount` is documented as "The provided amount is insufficient for the swap."
`SlippageTooHigh` is documented as "Slippage is too high." Both can block a swap-related call, but
their documented conditions describe different problems
([Subtensor API Errors: InsufficientInputAmount](https://docs.learnbittensor.org/subtensor-api/errors#insufficientinputamount),
[Subtensor API Errors: SlippageTooHigh](https://docs.learnbittensor.org/subtensor-api/errors#slippagetoohigh)).

- **InsufficientInputAmount** — the provided input amount is insufficient for the swap.
- **SlippageTooHigh** — the slippage on the swap is too high.
