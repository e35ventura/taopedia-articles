# Insufficient Input Amount

`InsufficientInputAmount` is a swap pallet error raised when the provided input amount is
insufficient for the swap operation
([Subtensor API Errors: InsufficientInputAmount](https://docs.learnbittensor.org/subtensor-api/errors#insufficientinputamount)).

## What It Means

When swapping between TAO and a subnet's alpha token, the input amount must be large enough for the
swap to produce a meaningful output. `InsufficientInputAmount` fires when the submitted input falls
below what the swap requires
([Subtensor API Errors: InsufficientInputAmount](https://docs.learnbittensor.org/subtensor-api/errors#insufficientinputamount)).

## Distinction from Insufficient Liquidity

`InsufficientInputAmount` fires when the caller's input is too low. `InsufficientLiquidity` fires
when the pool itself does not have enough liquidity to complete the swap regardless of the input
amount
([Subtensor API Errors: InsufficientInputAmount](https://docs.learnbittensor.org/subtensor-api/errors#insufficientinputamount),
[Subtensor API Errors: InsufficientLiquidity](https://docs.learnbittensor.org/subtensor-api/errors#insufficientliquidity)).

- **InsufficientInputAmount** — the caller did not provide enough input.
- **InsufficientLiquidity** — the pool does not have enough liquidity.

## Distinction from Fee Rate Too High

`InsufficientInputAmount` fires when the input amount itself is too low. `FeeRateTooHigh` fires when
the submitted fee rate exceeds the allowed maximum, regardless of the input amount
([Subtensor API Errors: InsufficientInputAmount](https://docs.learnbittensor.org/subtensor-api/errors#insufficientinputamount),
[Subtensor API Errors: FeeRateTooHigh](https://docs.learnbittensor.org/subtensor-api/errors#feeratetoohigh)).

- **InsufficientInputAmount** — the input amount is too low.
- **FeeRateTooHigh** — the fee rate exceeds the maximum.
