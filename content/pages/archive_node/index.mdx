# Archive Node

An archive node is a type of public Subtensor node that stores the entire blockchain history,
allowing for full data access and querying. The
[Glossary: Archive Node](https://docs.learnbittensor.org/resources/glossary#archive-node) entry
defines it this way and groups it with the other Subtensor node types in the
[Subtensor Nodes](https://docs.learnbittensor.org/subtensor-nodes) reference.

## What It Stores

The defining feature is complete history. An archive node retains the full chain state back to
genesis, so a query about an old block, a past balance, or a historical
[metagraph](https://docs.learnbittensor.org/resources/glossary#metagraph) snapshot can be answered
directly from the node rather than reconstructed
([Subtensor Nodes](https://docs.learnbittensor.org/subtensor-nodes)).

That full-history role makes archive nodes the data backbone other clients lean on when they need
information older than a lite node keeps.

## Distinction from Lite Node

A lite node stores only limited blockchain data and relies on archive nodes for full historical
data, while an archive node keeps everything. The two are the same kind of public Subtensor node
differing in how much history they retain
([Glossary: Lite Node](https://docs.learnbittensor.org/resources/glossary#lite-node)).

- **Archive node** — keeps the entire chain history for full querying.
- **Lite node** — keeps limited data and defers to archive nodes for older state.

## Why Full History Matters

Applications that read deep history — analytics dashboards, audits, or tools reconstructing past
subnet state — need a source that has not pruned older blocks. Archive nodes provide that source, so
a query for historical chain data resolves against retained state rather than failing for lack of it
([Managing Subtensor Connections](https://docs.learnbittensor.org/sdk/managing-subtensor-connections)).

For readers, choosing an archive endpoint matters when a task reaches beyond recent blocks; for
current-state reads, a lite node is usually sufficient and an archive node is not required
([Subtensor Nodes](https://docs.learnbittensor.org/subtensor-nodes)).
