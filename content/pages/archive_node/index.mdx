# Archive Node

An archive node is a type of public Subtensor node that stores the entire blockchain history for
full data access and querying. The official
[Glossary: Archive Node](https://docs.learnbittensor.org/resources/glossary#archive-node) defines it
in those terms, and the [Subtensor Node Basics](https://docs.learnbittensor.org/subtensor-nodes)
documentation places it alongside lite nodes as one of two public node types synchronized with the
Bittensor network.

## Public Subtensor Context

Archive nodes belong to public chain access, not local development blockchains. The
[Subtensor Node Basics](https://docs.learnbittensor.org/subtensor-nodes) documentation contrasts a
public Subtensor node with a local blockchain used for subnet development and testing. In that
reading, archive node names a public full-history role rather than a private staging chain.

A public Subtensor node can sync with the Bittensor mainchain or testchain. Archive node should be
read as network-access vocabulary rather than as a subnet participant role.

## Relationship to Lite Node

Archive nodes and lite nodes solve different storage problems. The
[Glossary: Lite Node](https://docs.learnbittensor.org/resources/glossary#lite-node) describes lite
nodes as storing limited blockchain data and relying on archive nodes when full historical access is
required. The archive node glossary entry, by contrast, stores the entire chain history.

The distinction is scope: archive node names the full-history public node type, while lite node
names the lighter public node type that depends on archive nodes for deep historical queries.

## Network Environment Boundary

Bittensor documentation separates mainnet, testnet, and localnet contexts. Archive node belongs to
public chain access for mainnet or testnet environments
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

An archive node should not be read as a local or testnet-only concept. It names a public Subtensor
node role that can connect to production or test chain environments.

## Scope

Archive node is a concept term for a public Subtensor node that retains the complete blockchain
history. It does not name a subnet role, a wallet type, or a development chain.
