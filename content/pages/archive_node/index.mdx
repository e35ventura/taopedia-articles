# Archive Node

An archive node is a node that keeps historical blockchain state rather than only the recent state
needed for ordinary operation. In Bittensor context, the term appears in official documentation for
node operation and chain data access.

References:
[Glossary: Archive Node](https://docs.learnbittensor.org/resources/glossary#archive-node),
[Subtensor Nodes](https://docs.learnbittensor.org/subtensor-nodes)

## Historical State

The main distinction is historical coverage. A node that retains archive state can support deeper
queries into older chain data, while lighter node configurations focus on more limited state. This
matters for tooling, analysis, and operations that need historical context rather than only current
chain information.

References:
[Glossary: Archive Node](https://docs.learnbittensor.org/resources/glossary#archive-node),
[Subtensor Nodes](https://docs.learnbittensor.org/subtensor-nodes)

## Reader Boundary

This page defines the term at a high level. It does not provide node setup steps, hardware sizing,
or current endpoint recommendations. Those operational details can change and should be checked in
current official node documentation.
