# Wallet Address

A wallet address is a public-key-derived identifier used as a TAO destination in Bittensor. The
official
[Glossary: Wallet Address](https://docs.learnbittensor.org/resources/glossary#wallet-address)
describes wallet addresses as public-key-derived values that identify destinations for TAO in the
Bittensor network.

## Address Context

A wallet address is address material, not the whole wallet. It gives a compact way to refer to a
destination account context, while the wallet itself can include broader key material and account
management concepts. This distinction keeps an address from being treated as a balance, a staking
position, or a complete set of wallet keys.

The glossary definition places wallet address in the destination-identification role, which is the
only role this article needs to explain.

## Public-Key Relationship

Wallet addresses are derived from public keys. The
[Glossary: Public Key](https://docs.learnbittensor.org/resources/glossary#public-key) describes a
public key as shareable material used for verification, encryption, and account reference. In this
context, the wallet address is the destination identifier derived from that public-key side of the
keypair vocabulary.

This does not mean a wallet address is the same thing as a private key. The
[Glossary: Private Key](https://docs.learnbittensor.org/resources/glossary#private-key) describes
private keys as protected signing material used to authorize transactions and operations.

## SS58 Representation

Bittensor wallet addresses are closely related to SS58 encoded values. The
[Glossary: SS58 Encoded](https://docs.learnbittensor.org/resources/glossary#ss58-encoded) describes
SS58 encoded values as compact representations of public-key-derived addresses used in Bittensor.
For readers, SS58 is the address-format vocabulary, while wallet address is the destination
identifier vocabulary.

Keeping those terms separate helps avoid treating every address-format detail as a wallet operation.

## Reader Boundary

Wallet address should not be read as a recovery phrase, a private key, a live balance, or proof that
a transaction occurred. It is a public-key-derived destination identifier. This article does not
describe how to create, store, recover, rotate, or use wallets.
