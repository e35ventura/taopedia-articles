# Contract Reverted

`ContractReverted` is a contracts pallet error raised when a contract finishes running but discards
its storage changes instead of keeping them. The API errors reference summarizes it as "The contract
ran to completion but decided to revert its storage changes"
([Subtensor API Errors: ContractReverted](https://docs.learnbittensor.org/subtensor-api/errors#contractreverted)).

## What It Means

`ContractReverted` does not mean the contract failed to start or disappeared from the chain. It
means execution reached the end of the contract call, but the contract chose not to keep the storage
changes from that run
([Subtensor API Errors: ContractReverted](https://docs.learnbittensor.org/subtensor-api/errors#contractreverted)).

The same docs note an important reader-facing distinction: this error is returned from extrinsics,
but direct or RPC calls can still return `Ok`, in which case the caller must inspect the returned
flags to see that a reversion happened
([Subtensor API Errors: ContractReverted](https://docs.learnbittensor.org/subtensor-api/errors#contractreverted)).

This is a reverted-after-execution outcome. It does not, by itself, mean the contract trapped during
execution, that the contract ran out of gas, or that the contract had already been terminated.

## Why It Appears

This error appears when a contracts operation runs to completion and then reverts its storage
changes instead of committing them
([Subtensor API Errors: ContractReverted](https://docs.learnbittensor.org/subtensor-api/errors#contractreverted)).

## Distinction from Contract Trapped

`ContractReverted` and `ContractTrapped` both stop a contracts operation from succeeding, but they
describe different outcomes. `ContractReverted` means execution reached completion and then reverted
its storage changes. `ContractTrapped` means the contract trapped during execution
([Subtensor API Errors: ContractReverted](https://docs.learnbittensor.org/subtensor-api/errors#contractreverted),
[Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped)).

- **ContractReverted** — execution completes, but the storage changes are discarded.
- **ContractTrapped** — execution traps before completing normally.

## Distinction from Out Of Gas

`ContractReverted` and `OutOfGas` both leave a contract call without the intended result, but they
fail for different reasons. `ContractReverted` means the contract completed and then reverted its
storage changes. `OutOfGas` means execution exhausted the gas limit before finishing
([Subtensor API Errors: ContractReverted](https://docs.learnbittensor.org/subtensor-api/errors#contractreverted),
[Subtensor API Errors: OutOfGas](https://docs.learnbittensor.org/subtensor-api/errors#outofgas)).

- **ContractReverted** — execution finishes, but the result is reverted.
- **OutOfGas** — execution cannot finish because the gas limit is exhausted.
