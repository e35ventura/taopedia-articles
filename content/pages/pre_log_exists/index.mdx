# Pre Log Exists

`PreLogExists` is an ethereum pallet error raised when a transact call cannot proceed because a
pre-log is already present. The API errors reference describes it as "Pre-log is present, therefore
transact is not allowed"
([Subtensor API Errors: PreLogExists](https://docs.learnbittensor.org/subtensor-api/errors#prelogexists)).

## What It Means

`PreLogExists` means the transact call was blocked because a pre-log entry was already present at
the time the call was submitted
([Subtensor API Errors: PreLogExists](https://docs.learnbittensor.org/subtensor-api/errors#prelogexists)).

This is a pre-log state check. It does not mean the origin lacks permission or that the account has
insufficient balance.

## Why It Appears

This error appears when a transact call is submitted while a pre-log entry is already present,
blocking the call from proceeding
([Subtensor API Errors: PreLogExists](https://docs.learnbittensor.org/subtensor-api/errors#prelogexists)).

## Distinction from Not Allowed

`PreLogExists` is documented as "Pre-log is present, therefore transact is not allowed."
`NotAllowed` is documented as "Origin is not allowed to perform the operation." Both block an
EVM-layer call, but their documented conditions describe different problems
([Subtensor API Errors: PreLogExists](https://docs.learnbittensor.org/subtensor-api/errors#prelogexists),
[Subtensor API Errors: NotAllowed](https://docs.learnbittensor.org/subtensor-api/errors#notallowed)).

- **PreLogExists** -- a pre-log entry is already present, blocking the transact call.
- **NotAllowed** -- the origin does not have permission for the EVM operation.

## Distinction from Balance Low

`PreLogExists` is documented as "Pre-log is present, therefore transact is not allowed."
`BalanceLow` is documented as "Not enough balance to perform action." Both block an EVM-layer
operation, but their documented conditions describe different problems
([Subtensor API Errors: PreLogExists](https://docs.learnbittensor.org/subtensor-api/errors#prelogexists),
[Subtensor API Errors: BalanceLow](https://docs.learnbittensor.org/subtensor-api/errors#balancelow)).

- **PreLogExists** -- a pre-log is already present when the transaction is submitted.
- **BalanceLow** -- the account does not have enough balance for the EVM action.
