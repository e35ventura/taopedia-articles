# Reentrance Denied

`ReentranceDenied` is a contracts pallet error raised when a call tries to invoke a contract that is
flagged as non-reentrant while that contract is already active in the current call chain. The API
errors reference summarizes it as a call that "tried to invoke a contract that is flagged as
non-reentrant"
([Subtensor API Errors: ReentranceDenied](https://docs.learnbittensor.org/subtensor-api/errors#reentrancedenied)).

## What It Means

Some contracts are marked non-reentrant so they cannot be entered again while a prior call to the
same contract is still active. `ReentranceDenied` means the runtime rejected a new invocation
because that reentrancy guard was triggered
([Subtensor API Errors: ReentranceDenied](https://docs.learnbittensor.org/subtensor-api/errors#reentrancedenied)).

This is a reentrancy-guard failure. It does not, by itself, mean nested call depth reached the
schedule limit, that a contract tried to terminate while still active, or that execution trapped for
another reason.

## Why It Appears

This error appears when a contracts call would re-enter a non-reentrant contract that is already
active in the ongoing call chain
([Subtensor API Errors: ReentranceDenied](https://docs.learnbittensor.org/subtensor-api/errors#reentrancedenied)).

## Distinction from Terminated While Reentrant

`ReentranceDenied` and `TerminatedWhileReentrant` both involve active contracts on the call stack,
but they stop different operations. `ReentranceDenied` is summarized as a call that tried to invoke
a non-reentrant contract while it was already active. `TerminatedWhileReentrant` is summarized as
"Termination of a contract is not allowed while the contract is already on the call stack"
([Subtensor API Errors: ReentranceDenied](https://docs.learnbittensor.org/subtensor-api/errors#reentrancedenied),
[Subtensor API Errors: TerminatedWhileReentrant](https://docs.learnbittensor.org/subtensor-api/errors#terminatedwhilereentrant)).

- **ReentranceDenied** — a non-reentrant contract was invoked while already active.
- **TerminatedWhileReentrant** — termination was attempted while the contract was still active.

## Distinction from Max Call Depth Reached

`ReentranceDenied` and `MaxCallDepthReached` both stop nested contract activity, but at different
checks. `MaxCallDepthReached` is summarized as a call denied because nested call depth reached the
schedule limit. `ReentranceDenied` is summarized as a call that tried to invoke a non-reentrant
contract while it was already active
([Subtensor API Errors: ReentranceDenied](https://docs.learnbittensor.org/subtensor-api/errors#reentrancedenied),
[Subtensor API Errors: MaxCallDepthReached](https://docs.learnbittensor.org/subtensor-api/errors#maxcalldepthreached)).

- **ReentranceDenied** — a non-reentrant contract was invoked while already active.
- **MaxCallDepthReached** — nested call depth reached the schedule limit.

## Distinction from Contract Trapped

`ReentranceDenied` and `ContractTrapped` both stop contract execution, but with different API
summaries. `ReentranceDenied` concerns the non-reentrant guard on an active contract.
`ContractTrapped` means contract execution trapped during the call
([Subtensor API Errors: ReentranceDenied](https://docs.learnbittensor.org/subtensor-api/errors#reentrancedenied),
[Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped)).

- **ReentranceDenied** — a non-reentrant contract was invoked while already active.
- **ContractTrapped** — execution trapped during the call.
