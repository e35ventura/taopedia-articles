# Initial Scaling Law Power

Initial Scaling Law Power is a subtensorModule runtime constant, listed in the chain's constants
metadata as initialScalingLawPower, with the value 50 and the summary "Initial scaling law power"
([Subtensor API Constants: initialScalingLawPower](https://docs.learnbittensor.org/subtensor-api/constants#initialscalinglawpower-u16)).
It supplies the default value a subnet's ScalingLawPower uses.

## What It Means

ScalingLawPower is held per subnet and sets the power a subnet applies in its scaling-law
calculation. Initial Scaling Law Power is the default this per-subnet value falls back to before a
different value applies for a subnet
([Subtensor API Constants: initialScalingLawPower](https://docs.learnbittensor.org/subtensor-api/constants#initialscalinglawpower-u16)).
The ScalingLawPower in force on a subnet such as netuid 1 is that subnet's own chain state and can
differ from this default.

## Distinction from Kappa and Rho

Initial Scaling Law Power is the default scaling law power, while initialKappa, valued at 32767, is
the consensus majority ratio used in consensus; initialBondsPenalty, valued at 65535, is the penalty
applied to bonds for out-of-consensus weights
([Subtensor API Constants: initialKappa](https://docs.learnbittensor.org/subtensor-api/constants#initialkappa-u16),
[Subtensor API Constants: initialBondsPenalty](https://docs.learnbittensor.org/subtensor-api/constants#initialbondspenalty-u16)).

## Reader Boundary

Initial Scaling Law Power is a default constant, not the live per-subnet ScalingLawPower, and it
reflects the current runtime configuration rather than a fixed protocol rule
([Subtensor API Constants: initialScalingLawPower](https://docs.learnbittensor.org/subtensor-api/constants#initialscalinglawpower-u16)).
