Liquidity is Bittensor Subnet 77, a subnet that channels rewards toward providing liquidity on
decentralized exchanges. Its on-chain description sums it up: supply liquidity on external chains
via Uniswap, and let any project be incentivized. The codebase for the subnet is the
`creativebuilds/sn77` repository.

## What Subnet 77 Rewards

Many token projects need deep, reliable liquidity on a decentralized exchange so that people can
trade them without large price swings. Subnet 77 turns that need into an incentive: it rewards
miners for supplying liquidity to Uniswap pools, and it lets the community steer where that
liquidity goes. Token holders vote on which pools should be favored, so any project can attract
liquidity by winning votes, and miners earn by providing liquidity to the pools the network has
chosen to back.

## Miner and Validator Roles

Miners are the liquidity providers. A miner adds liquidity to the Uniswap pools that the subnet
rewards and links its Bittensor identity to the external-chain address holding that position, so the
liquidity it supplies can be credited to it.

Validators turn the community's votes and the miners' positions into rewards. They tally the votes
that token holders cast for different pools, measure how much liquidity each miner has actually
provided to those pools, and set miner weights on subnet 77 accordingly, which is how reward flows
through [[Yuma Consensus]].

## On-Chain Identity

Live SN77 subnet data is available on [TaoStats](https://taostats.io/subnets/77), which identifies
the subnet as Liquidity. Readers can reproduce the subnet identity fields directly with the
Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 77 --network finney`. That Finney identity is the source of
truth for the subnet name and the GitHub repository associated with the subnet.
