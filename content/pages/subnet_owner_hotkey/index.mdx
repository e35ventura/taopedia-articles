# Subnet Owner Hotkey

Subnet owner hotkey is a per-subnet hyperparameter, listed in the documentation as
`SubnetOwnerHotkey`, that identifies which hotkey holds the subnet owner role on a netuid. The
reference describes it as changing the hotkey of the subnet owner on the subnet, with a default of
the hotkey that created the subnet
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

## What It Controls

The hyperparameter binds the owner role to a hotkey identity, not to emission percentages or
consensus rules. It decides which hotkey acts as the subnet owner for owner-only actions such as
hyperparameter updates and owner-cut receipt on the selected netuid
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters),
[Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets)).

It does not transfer coldkey funds by itself, register miners, or set validator weights. It only
points the owner role at a particular hotkey on the subnet's configuration table
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

The value is owner-settable per subnet, so netuid 1 can keep the creator hotkey while another netuid
points owner authority at a different hotkey, and the live identity is chain state rather than a
network constant
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

## Documented Default and Setter

The [Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)
reference states that the default is the hotkey of the account that created the subnet and marks the
permission required to change it as subnet owner
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

Because each subnet carries its own hyperparameters, the owner hotkey on one netuid can differ from
another subnet's owner identity
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

## Reading the Live Value for netuid 1

Subnet owner hotkey is per-subnet chain state, so any live claim is tied to a specific netuid. For
the documented example netuid 1 on Finney mainnet, the hotkey appears in that subnet's
hyperparameter table, which the reference describes under viewing a subnet's hyperparameters
([Subnet Hyperparameters: View hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters#view-hyperparameters)).
The infobox uses netuid 1 only as an example label; other subnets expose their own values
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

## Distinction from Subnet Creator

Subnet creator names who launched the subnet market. Subnet owner hotkey names which hotkey
currently holds the owner role on the netuid, which may differ after an owner hotkey change
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters),
[Create a Subnet](https://docs.learnbittensor.org/subnets/create-a-subnet)).

- **Subnet creator** — account that originally created the subnet market.
- **Subnet owner hotkey** — hotkey currently designated as subnet owner.
