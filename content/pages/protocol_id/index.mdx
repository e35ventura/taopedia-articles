# Protocol ID

Protocol ID is the swap pallet runtime constant listed in the chain constants metadata as
`protocolId`. The constants reference exposes it under `api.consts.swap.protocolId`
([Subtensor API Constants: protocolId](https://docs.learnbittensor.org/subtensor-api/constants#protocolid-u88)).

The current runtime wires this constant as `SwapProtocolId`, with the value `PalletId(*b"ten/swap")`
([runtime/src/lib.rs](https://github.com/opentensor/subtensor/blob/14bc6f9f964b9cc362e9635dd110a487fa5d15a0/runtime/src/lib.rs#L1130-L1140)).

## What It Means

This constant gives the swap pallet the pallet identifier it uses to derive its protocol account.
The current swap implementation defines `ProtocolId` as a required constant and derives the protocol
account with `T::ProtocolId::get().into_account_truncating()`
([pallet mod.rs](https://github.com/opentensor/subtensor/blob/14bc6f9f964b9cc362e9635dd110a487fa5d15a0/pallets/swap/src/pallet/mod.rs#L51-L53),
[pallet impls.rs](https://github.com/opentensor/subtensor/blob/14bc6f9f964b9cc362e9635dd110a487fa5d15a0/pallets/swap/src/pallet/impls.rs#L272-L277)).

For a reader, the narrow meaning is simple: `protocolId` is the identifier behind the swap pallet's
own derived account, not a trading parameter like fee rate, minimum reserve, or minimum liquidity
([Subtensor API Constants: protocolId](https://docs.learnbittensor.org/subtensor-api/constants#protocolid-u88)).

## Distinction from Minimum Liquidity

`protocolId` and `minimumLiquidity` are both swap constants, but they govern different things.
`protocolId` names the pallet identifier used to derive the protocol account. `minimumLiquidity`
names the floor on liquidity values accepted by the swap pallet
([Subtensor API Constants: protocolId](https://docs.learnbittensor.org/subtensor-api/constants#protocolid-u88),
[Subtensor API Constants: minimumLiquidity](https://docs.learnbittensor.org/subtensor-api/constants#minimumliquidity-u64)).

- **protocolId** — the swap pallet identifier used for account derivation.
- **minimumLiquidity** — the minimum liquidity floor for swap math inputs.

## Distinction from Minimum Reserve

`protocolId` and `minimumReserve` also belong to the swap pallet, but they describe different
concepts. `protocolId` is an identifier constant. `minimumReserve` is the minimum reserve floor for
TAO and alpha in the swap system
([Subtensor API Constants: protocolId](https://docs.learnbittensor.org/subtensor-api/constants#protocolid-u88),
[Subtensor API Constants: minimumReserve](https://docs.learnbittensor.org/subtensor-api/constants#minimumreserve-u64)).

- **protocolId** — the identifier behind the protocol account.
- **minimumReserve** — the documented reserve floor for TAO and alpha.

## Reader Boundary

This page defines the constant and the protocol-account derivation it supports. It does not report
the live balance of the derived account or every place that account may be referenced in swap
accounting
([Subtensor API Constants: protocolId](https://docs.learnbittensor.org/subtensor-api/constants#protocolid-u88),
[pallet impls.rs](https://github.com/opentensor/subtensor/blob/14bc6f9f964b9cc362e9635dd110a487fa5d15a0/pallets/swap/src/pallet/impls.rs#L272-L277)).
