# Consensus

Consensus is a per-miner value produced by Yuma Consensus as the stake-weighted median of the
weights that validators assign to that miner. It becomes the threshold against which validator
weights are clipped before miner ranks are calculated
([Glossary: Consensus](https://docs.learnbittensor.org/resources/glossary#consensus),
[Yuma Consensus](https://docs.learnbittensor.org/learn/yuma-consensus)).

The term belongs to the miner-evaluation side of consensus. It is a computed aggregate per miner,
not one validator's raw weight and not the overall Yuma Consensus algorithm itself
([Glossary: Consensus](https://docs.learnbittensor.org/resources/glossary#consensus)).

## What It Represents

For each miner, consensus is the weight level that the majority of validator stake supports. Rather
than averaging every validator's opinion, Yuma Consensus takes the stake-weighted median, so the
result reflects what most of the stake considers a fair evaluation of that miner
([Glossary: Consensus](https://docs.learnbittensor.org/resources/glossary#consensus),
[Yuma Consensus](https://docs.learnbittensor.org/learn/yuma-consensus)).

Using a stake-weighted median is what gives the value its manipulation resistance. A simple average
would let a minority-stake validator drag a miner's score with an extreme rating, but the median
reflects only weights backed by majority stake, so minority outliers do not move it
([Yuma Consensus](https://docs.learnbittensor.org/learn/yuma-consensus)).

As a metagraph property the consensus value is normalized to the range zero to one. Values near one
indicate strong validator agreement on a miner, while values near zero indicate weak agreement
([Glossary: Consensus](https://docs.learnbittensor.org/resources/glossary#consensus)).

## How It Is Used

The consensus value is the clipping threshold for validator weights. A validator's weight on a miner
is brought down to the consensus value whenever it exceeds it, so weight above the threshold earns
neither the miner nor the validator any reward for that excess
([Yuma Consensus](https://docs.learnbittensor.org/learn/yuma-consensus),
[Glossary: Consensus](https://docs.learnbittensor.org/resources/glossary#consensus)).

Miner ranks then build on these consensus-clipped weights, which is why consensus sits directly
upstream of rank and the resulting miner incentive
([Glossary: Rank](https://docs.learnbittensor.org/resources/glossary#rank),
[Yuma Consensus](https://docs.learnbittensor.org/learn/yuma-consensus)).

## Role of Kappa

Kappa is the hyperparameter that sets the majority stake ratio the consensus median requires. It
defines how much of the total stake must support a weight level for that level to become the
consensus value, so a higher kappa demands broader stake agreement
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters),
[Glossary: Consensus](https://docs.learnbittensor.org/resources/glossary#consensus)).

Examples tied to netuid 1 illustrate one subnet's miner-side consensus result. They should not be
read as representing production evaluation on another network
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

## Distinction from Rank

Consensus is the stake-weighted median threshold used to clip validator weights. Rank is the
downstream result built from the clipped weights, so consensus feeds rank rather than being the same
value ([Glossary: Consensus](https://docs.learnbittensor.org/resources/glossary#consensus),
[Glossary: Rank](https://docs.learnbittensor.org/resources/glossary#rank)).

- **Consensus** — stake-weighted median threshold that clips weights.
- **Rank** — the miner standing built from the consensus-clipped weights.

## Distinction from Validator Trust

Validator trust measures how well a validator's submitted weights aligned with consensus. Consensus
is the per-miner threshold itself, while validator trust is a per-validator measure derived from how
their weights compared to it
([Glossary: Consensus](https://docs.learnbittensor.org/resources/glossary#consensus),
[Validator Trust](https://docs.learnbittensor.org/resources/glossary#validator-trust)).

- **Consensus** — per-miner stake-weighted median threshold.
- **Validator trust** — per-validator alignment with that threshold.
