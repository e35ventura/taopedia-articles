Unknown is Bittensor Subnet 117. Its current on-chain identity points to the helionlink/Chi
codebase, whose README describes Chi as a vibe-codable Bittensor subnet template.

Unlike subnets with a public README that defines a specific service, commodity, or scoring target,
the public source currently linked from SN117 reads as a template for building a subnet. This
article therefore treats the chain identity and the linked codebase as the source of truth, and
avoids assigning SN117 a more specific purpose than the public materials support.

## What Unknown Provides

The linked Chi repository presents itself as a starting point for creating a Bittensor subnet rather
than as a finished public service with a detailed reward market. It includes a validator entry
point, Docker configuration, and knowledge files about subnet design patterns.

At the Taopedia article level, the safe description is narrow: SN117 currently exposes an on-chain
identity named Unknown, and the codebase named by that identity is a Bittensor subnet template. The
public README does not describe a specialized miner task, data product, compute market, or model
evaluation service.

## Miner and Validator Roles

Because the linked README is template-oriented, it does not define a concrete miner role for a
specific production commodity. It also does not publish a subnet-specific scoring target that miners
can optimize against.

Validators should therefore be understood only at the generic Bittensor level unless the subnet
owner publishes more specific documentation. In general, validators evaluate miner contributions and
set weights that flow through [[Yuma Consensus]], but SN117's currently linked public source does
not provide enough detail to describe a distinct scoring mechanism.

## On-Chain Identity

Live SN117 subnet data is available on [TaoStats](https://taostats.io/subnets/117), which identifies
the current netuid 117 page. Readers can reproduce the subnet identity fields directly with the
Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 117 --network finney`.

For the GitHub field, the Finney subnet identity for netuid 117 points to the helionlink/Chi
repository. That chain identity is the source of truth for the codebase named in this article.
