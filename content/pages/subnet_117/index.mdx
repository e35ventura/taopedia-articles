Subnet 117 is a Bittensor subnet slot whose live Finney identity currently lists the subnet name as
"Unknown." The same identity record points its GitHub field to the helionlink/Chi repository and
lists hello@helionlink.com as the contact address. The subnet URL and description fields are blank.

Because the registered project metadata is sparse, this page treats SN117 as an identity-status
article rather than as a full mechanism description. Readers should verify the live Finney identity
before relying on any older project name or third-party profile for the slot.

## Current Status

The registered Chi repository describes itself as a vibe-codable Bittensor subnet template. Its
README gives only a short description and minimal usage guidance, so it does not provide enough
public detail to describe a specific miner task, validator scoring method, or product surface for
SN117.

For active subnet articles, Taopedia normally explains what miners produce and how validators
evaluate that work. SN117's current public identity does not expose enough source material for that
kind of article. The useful current facts are the registered "Unknown" name, the helionlink/Chi
GitHub identity field, and the lack of a registered subnet URL or description.

The subnet-specific miner and validator roles cannot be described reliably from the currently

## On-Chain Identity

Live SN117 subnet data is available on [TaoStats](https://taostats.io/subnets/117). Readers can
reproduce the registered identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 117 --network finney`.

At the time this article was prepared, that Finney identity reported `subnet_name: Unknown`,
`github_repo: https://github.com/helionlink/Chi`, `subnet_contact: hello@helionlink.com`, and blank
subnet URL and description fields.
