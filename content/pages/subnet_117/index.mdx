Subnet 117 is registered on Finney with the subnet name Unknown. The live identity lists
https://github.com/helionlink/Chi as its GitHub source, with no subnet URL or public description
field.

That GitHub source redirects to the public Chi repository. Its README identifies Chi as a Bittensor
subnet template, and the public repository exposes a small validator script rather than a documented
application-specific task market.

## What Unknown Provides

Unknown currently provides a public reference point for the Chi subnet code named in its live
identity. The available repository material is minimal: the README describes Chi as a Bittensor
subnet template, and the validator source describes a simple validator that syncs the subnet
metagraph and assigns validator weight to UID 0 on the subnet tempo.

Because the live identity does not include a description or subnet URL, and the repository does not
document a custom scoring objective, the safest reading is that subnet 117 is publicly represented
by the Chi template-style code rather than by a documented production service.

## Miner and Validator Roles

The public sources checked for subnet 117 do not document a custom miner task. In Bittensor terms,
miners would normally compete for validator weight, but no Chi-specific miner objective is described
in the repository README.

The included validator source is intentionally minimal. It connects to the subnet, syncs the
metagraph, waits for the subnet tempo, and sets validator weight to UID 0. Those weights still enter
the usual [[Yuma Consensus]] flow, while the general miner and validator relationship is covered in
[[Mining and Validating]].

## On-Chain Identity

Readers can reproduce the live identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 117 --network finney`.

That Finney identity reports the subnet name as Unknown and the GitHub source as
https://github.com/helionlink/Chi. It does not report a subnet URL or description.
