# Network Registration Allowed

Network registration allowed is a per-subnet hyperparameter, listed in the documentation as
`NetworkRegistrationAllowed`, that once named whether neuron registration was permitted on a subnet.
The reference now states it is not used for neuron registration; admission is burn-based and always
open on ordinary subnets, with pricing governed by burn half life and burn increase mult instead
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

## What It Controlled

Under older models, the boolean flag could gate whether new neurons could register on a subnet at
all. That permission layer sat above registration pricing and UID capacity, deciding whether the
register path was open before burn cost or displacement rules applied
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters),
[Glossary: Register](https://docs.learnbittensor.org/resources/glossary#register)).

It did not set burn cost, immunity period, or max allowed UIDs. It only named whether registration
was allowed under the older gated model.

## Current Registration Economics

Official documentation states that neuron registration is burn-based and always open, with
continuous burn pricing replacing registration permission flags. Readers encountering network
registration allowed in older material should treat it as legacy vocabulary and verify live
registration economics through the current burn hyperparameters on the relevant netuid
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters),
[Understanding Neurons](https://docs.learnbittensor.org/learn/neurons),
[Miner registration](https://docs.learnbittensor.org/miners#miner-registration)).

## Documented Type and Default

The [Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)
reference lists `NetworkRegistrationAllowed` as a `Bool` with a default of false and marks the
permission required to set it as subnet owner
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

## Distinction from Registration Allowed

Registration allowed is the live vocabulary readers may still see in subnet configuration
discussions. Network registration allowed is the hyperparameter-table name for the older
gated-registration flag that documentation now marks as unused for neuron admission
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

- **Network registration allowed** — legacy hyperparameter flag for gated registration.
- **Current registration** — burn-based, always-open admission on ordinary subnets.
