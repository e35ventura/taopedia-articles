# Non Zero Ref Count

`NonZeroRefCount` is a system pallet error raised when an account purge is attempted while the
account still has a non-zero reference count
([Subtensor API Errors: NonZeroRefCount](https://docs.learnbittensor.org/subtensor-api/errors#nonzerorefcount)).

## What It Means

The system pallet tracks a reference count per account. `NonZeroRefCount` fires when a purge is
attempted on an account whose reference count is above zero, meaning the account cannot be removed
yet
([Subtensor API Errors: NonZeroRefCount](https://docs.learnbittensor.org/subtensor-api/errors#nonzerorefcount)).

## Distinction from Call Filtered

`NonZeroRefCount` blocks an account-level purge because of a non-zero reference count.
`CallFiltered` blocks a dispatch-level call because the runtime filter rejects it for the current
origin
([Subtensor API Errors: NonZeroRefCount](https://docs.learnbittensor.org/subtensor-api/errors#nonzerorefcount),
[Subtensor API Errors: CallFiltered](https://docs.learnbittensor.org/subtensor-api/errors#callfiltered)).

- **NonZeroRefCount** — a non-zero reference count prevents the purge.
- **CallFiltered** — the runtime filter blocks the call.

## Distinction from Multi Block Migrations Ongoing

`NonZeroRefCount` blocks an account purge at the reference-count check.
`MultiBlockMigrationsOngoing` blocks a runtime upgrade at the migration check
([Subtensor API Errors: NonZeroRefCount](https://docs.learnbittensor.org/subtensor-api/errors#nonzerorefcount),
[Subtensor API Errors: MultiBlockMigrationsOngoing](https://docs.learnbittensor.org/subtensor-api/errors#multiblockmigrationsongoing)).

- **NonZeroRefCount** — reference count prevents account purge.
- **MultiBlockMigrationsOngoing** — migration prevents runtime upgrade.

## Reader Boundary

This page defines the error label and the zero-ref-count guard on the account purge path. It does
not report the current reference count for a specific account
([Subtensor API Errors: NonZeroRefCount](https://docs.learnbittensor.org/subtensor-api/errors#nonzerorefcount)).
