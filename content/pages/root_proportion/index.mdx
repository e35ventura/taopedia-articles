# Root Proportion

Root proportion is a Bittensor tokenomics measure for a single subnet: the relative weight of TAO
staked to validators through the root subnet, rather than through that subnet's alpha-token side
([Glossary: Root Proportion](https://docs.learnbittensor.org/resources/glossary#root-proportion)).

The term is useful when a reader needs to distinguish Root-side TAO stake from the subnet's own
alpha-token context.

## Core Idea

Root proportion describes how much of a subnet's dividend context is attributed to TAO staked
through Root. A higher value points toward a larger root-staker portion, while a lower value points
toward the subnet's alpha-token side.

The measure is subnet-specific. It does not describe the whole Bittensor network at once, and it
does not rank validators, miners, or subnet quality.

References:
[Glossary: Root Proportion](https://docs.learnbittensor.org/resources/glossary#root-proportion),
[Emission](https://docs.learnbittensor.org/learn/emissions)

## Range Interpretation

The glossary places root proportion on a zero-to-one range. That makes the term a proportion rather
than a raw TAO amount, raw alpha amount, or full dividend total
([Glossary: Root Proportion](https://docs.learnbittensor.org/resources/glossary#root-proportion)).

For concept use, the endpoints describe which side dominates the subnet's dividend context. A value
near the root side points toward TAO staked through Root carrying more of the dividend proportion; a
value near the other side points toward the subnet's alpha-stake context carrying more of it. The
article should avoid treating the proportion alone as a complete reward calculation.

That range framing also keeps the unit clear. Root proportion is not itself denominated in TAO,
alpha, or RAO. It is a relative measure that needs the relevant subnet and dividend context before
it can be interpreted.

## Root Subnet Link

The [Root Subnet](https://docs.learnbittensor.org/resources/glossary#root-subnetsubnet-zero), also
called Subnet Zero, is the staking environment where TAO holders can stake in a subnet-agnostic way.
Root proportion connects that root staking side back to a particular subnet's dividend split.

Root Subnet names the staking environment, while root proportion names the subnet-level dividend
measure.

References:
[Glossary: Root Subnet/Subnet Zero](https://docs.learnbittensor.org/resources/glossary#root-subnetsubnet-zero),
[Glossary: Root Proportion](https://docs.learnbittensor.org/resources/glossary#root-proportion)

Root staker and root proportion describe different layers of the same Root Subnet setting. A root
staker is the TAO holder using the Root Subnet staking path, while root proportion is a subnet-level
measure for the dividend context tied to that side
([Glossary: Root Staker](https://docs.learnbittensor.org/resources/glossary#root-staker),
[Glossary: Root Proportion](https://docs.learnbittensor.org/resources/glossary#root-proportion)).

The distinction matters because a role term should not be read as a metric. Root staker identifies
who is staking through Root. Root proportion identifies how the root side appears in one subnet's
dividend proportion.

## Dividend Reading

Root proportion sits on a range from 0 to 1 and represents the proportion of dividends going to root
stakers. In the broader [Emission](https://docs.learnbittensor.org/learn/emissions) model, Bittensor
emissions can involve both TAO stakers on Root and alpha stakers on mining subnets.

In that setting, root proportion is a reading of the split between those sides. It is not a price
quote, a staking instruction, or a total-emission amount.

References:
[Glossary: Root Proportion](https://docs.learnbittensor.org/resources/glossary#root-proportion),
[Emission](https://docs.learnbittensor.org/learn/emissions)

Root proportion is easiest to read beside the alpha side of subnet staking. The Root side concerns
TAO staked through Root, while the subnet-local side concerns alpha-token context in the subnet
economy ([Emission](https://docs.learnbittensor.org/learn/emissions),
[Glossary: Root Proportion](https://docs.learnbittensor.org/resources/glossary#root-proportion)).

This contrast prevents the measure from being flattened into a generic stake label. A root
proportion statement should say that it is about the Root side of a subnet's dividend context, not
about all stake, all emissions, or all validator activity.

## Not the Same as TAO Weight

Root proportion is related to TAO weight, but the terms answer different questions. TAO weight is
the parameter for how TAO stake contributes relative to alpha stake
([Glossary: TAO Weight](https://docs.learnbittensor.org/resources/glossary#tao-weight)). Root
proportion instead describes how much of one subnet's dividend context is attributed to root-staked
TAO.

The same caveat applies to nearby staking terms: root proportion is not validator stake weight,
alpha-token issuance by itself, or a general reward label. It is the root side of a subnet's
dividend proportion.

References:
[Glossary: Root Proportion](https://docs.learnbittensor.org/resources/glossary#root-proportion),
[Glossary: TAO Weight](https://docs.learnbittensor.org/resources/glossary#tao-weight)

## Reading Boundary

Root claims are related because they concern dividends earned through Root Subnet staking, including
Keep and Swap handling for processed dividends. Root proportion is still a separate measure: it
describes the root side of a subnet's dividend proportion, while root claim type describes how
processed dividends are handled
([Root Claim overview](https://docs.learnbittensor.org/staking-and-delegation/root-claims),
[Glossary: Root Proportion](https://docs.learnbittensor.org/resources/glossary#root-proportion)).

That boundary keeps the timing and outcome language separate. Root proportion helps interpret a
subnet-level dividend split; a root claim event and its Keep or Swap setting describe what happens
when accumulated root-claim dividends are processed.

The glossary supports the core definition, range, and root-staker dividend context for root
proportion. More specific statements about a subnet's exact value, timing, or observed dividend
result need a source for that subnet and observation
([Glossary: Root Proportion](https://docs.learnbittensor.org/resources/glossary#root-proportion),
[Emission](https://docs.learnbittensor.org/learn/emissions)).

This is the main reading limit for the term. Root proportion can explain the category of a
subnet-level measure, but it should not be used by itself as a price quote, validator assessment, or
complete emission report.
