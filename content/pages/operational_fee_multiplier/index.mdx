# Operational Fee Multiplier

Operational fee multiplier is a transaction payment runtime constant, listed in the Subtensor
constants reference as operationalFeeMultiplier. Its current value is 5, and the reference describes
it as a fee multiplier used by Operational extrinsics to compute a virtual tip that boosts priority
([Subtensor API Constants: operationalFeeMultiplier](https://docs.learnbittensor.org/subtensor-api/constants#operationalfeemultiplier-u8)).
The Subtensor runtime wires the same value into the transaction payment pallet configuration
([runtime/src/lib.rs](https://github.com/opentensor/subtensor/blob/14bc6f9f964b9cc362e9635dd110a487fa5d15a0/runtime/src/lib.rs#L528-L540)).

## What It Means

Operational extrinsics are treated differently from normal extrinsics in priority calculation. The
constants reference says the multiplier is applied to the final fee to obtain a virtual tip, which
is then added during regular priority calculation
([Subtensor API Constants: operationalFeeMultiplier](https://docs.learnbittensor.org/subtensor-api/constants#operationalfeemultiplier-u8)).

For a reader, the important point is that operational fee multiplier affects transaction ordering
priority. It does not mean Operational extrinsics are free, nor does it make every Operational
extrinsic execute before every Normal extrinsic in all circumstances.

## Distinction from Regular Tip

Operational fee multiplier and a regular transaction tip both affect priority, but they enter from
different places. A regular tip is supplied with the transaction. Operational fee multiplier is a
runtime constant that computes an additional virtual tip for Operational extrinsics
([Subtensor API Constants: operationalFeeMultiplier](https://docs.learnbittensor.org/subtensor-api/constants#operationalfeemultiplier-u8)).

- **Operational fee multiplier** - runtime multiplier used for Operational extrinsic priority.
- **Regular tip** - user-supplied priority component included with a transaction.

## Reader Boundary

This page defines the current operationalFeeMultiplier constant. It does not estimate the exact fee
for a specific transaction, list which calls are Operational, or predict the final ordering of a
live mempool
([Subtensor API Constants: operationalFeeMultiplier](https://docs.learnbittensor.org/subtensor-api/constants#operationalfeemultiplier-u8),
[Subtensor API Runtime Calls](https://docs.learnbittensor.org/subtensor-api/runtime)).
