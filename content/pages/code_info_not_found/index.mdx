# Code Info Not Found

`CodeInfoNotFound` is a contracts pallet error raised when no code info exists at the supplied code
hash. The API errors reference summarizes it as "No code info could be found at the supplied code
hash"
([Subtensor API Errors: CodeInfoNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codeinfonotfound)).

## What It Means

Subtensor includes a contracts pallet for on-chain smart contracts. Stored contract code has
associated code info that tracks metadata such as whether the code is referenced by live contracts.
`CodeInfoNotFound` means the runtime could not find that code-info record at the supplied hash, so
the operation cannot continue
([Subtensor API Errors: CodeInfoNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codeinfonotfound)).

This is a code-info lookup failure. It does not, by itself, mean no bytecode exists at the hash,
that stored code is still referenced by a live contract, or that supplied instantiate code exceeded
the schedule size limit.

## Why It Appears

This error appears when a contracts operation names a code hash whose code-info record is not
present in storage
([Subtensor API Errors: CodeInfoNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codeinfonotfound)).

## Distinction from Code Not Found

`CodeInfoNotFound` and `CodeNotFound` both involve a missing record at a code hash, but the API
summaries name different missing data. `CodeInfoNotFound` is summarized as "No code info could be
found at the supplied code hash." `CodeNotFound` is summarized as "No code could be found at the
supplied code hash."
([Subtensor API Errors: CodeInfoNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codeinfonotfound),
[Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound)).

- **CodeInfoNotFound** — no code-info record exists at the supplied hash.
- **CodeNotFound** — no code exists at the supplied hash.

## Distinction from Code In Use

`CodeInfoNotFound` and `CodeInUse` both arise on paths that consult stored code metadata, but they
reject different problems. `CodeInfoNotFound` means the code-info record itself is missing.
`CodeInUse` is summarized as "Code removal was denied because the code is still in use by at least
one contract."
([Subtensor API Errors: CodeInfoNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codeinfonotfound),
[Subtensor API Errors: CodeInUse](https://docs.learnbittensor.org/subtensor-api/errors#codeinuse)).

- **CodeInfoNotFound** — no code-info record exists at the supplied hash.
- **CodeInUse** — the code exists but is still referenced by at least one contract.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not report whether
bytecode or code info is stored for a specific hash on a network
([Subtensor API Errors: CodeInfoNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codeinfonotfound),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
