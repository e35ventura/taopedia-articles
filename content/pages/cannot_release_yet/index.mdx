# Cannot Release Yet

`CannotReleaseYet` is a safe-mode pallet error raised when a deposit release is attempted but the
deposit cannot be released yet. The API errors reference describes it as "This deposit cannot be
released yet"
([Subtensor API Errors: CannotReleaseYet](https://docs.learnbittensor.org/subtensor-api/errors#cannotreleaseyet)).

## What It Means

`releaseDeposit` is the documented safe-mode extrinsic for reclaiming a deposit
([Subtensor API Extrinsics: releaseDeposit](https://docs.learnbittensor.org/subtensor-api/extrinsics#releasedeposit-account-accountid-block-u32)).
`CannotReleaseYet` fires on that release path when the runtime rejects the release because the
deposit is not yet eligible
([Subtensor API Errors: CannotReleaseYet](https://docs.learnbittensor.org/subtensor-api/errors#cannotreleaseyet)).

## Why It Appears

This error appears when `releaseDeposit` is called before the configured release conditions are
satisfied for the supplied account and block
([Subtensor API Errors: CannotReleaseYet](https://docs.learnbittensor.org/subtensor-api/errors#cannotreleaseyet),
[Subtensor API Extrinsics: releaseDeposit](https://docs.learnbittensor.org/subtensor-api/extrinsics#releasedeposit-account-accountid-block-u32)).

## Distinction from No Deposit

`CannotReleaseYet` and `NoDeposit` are separate safe-mode errors with different API summaries.
`NoDeposit` is documented as "There is no balance reserved." `CannotReleaseYet` is documented as
"This deposit cannot be released yet"
([Subtensor API Errors: NoDeposit](https://docs.learnbittensor.org/subtensor-api/errors#nodeposit),
[Subtensor API Errors: CannotReleaseYet](https://docs.learnbittensor.org/subtensor-api/errors#cannotreleaseyet)).

- **NoDeposit** — no reserved balance is recorded for the release lookup.
- **CannotReleaseYet** — a release was attempted but is not yet allowed.

## Distinction from Not Configured

`CannotReleaseYet` and `NotConfigured` both appear on the `releaseDeposit` path, but they name
different failures. `NotConfigured` means the pallet functionality is disabled by configuration.
`CannotReleaseYet` means a deposit cannot be released yet
([Subtensor API Errors: NotConfigured](https://docs.learnbittensor.org/subtensor-api/errors#notconfigured),
[Subtensor API Errors: CannotReleaseYet](https://docs.learnbittensor.org/subtensor-api/errors#cannotreleaseyet)).

- **NotConfigured** — required configuration is absent; the operation is disabled.
- **CannotReleaseYet** — release is configured but not yet allowed for this deposit.

## Reader Boundary

This page defines the meaning of the error label and the release timing check that raises it. It
does not report the current safe-mode release delay configuration or the current block number on
chain; those are live chain state
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
