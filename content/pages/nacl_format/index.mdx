# NaCl Format

NaCl Format is Bittensor wallet-file terminology for a secure encryption format based on the
[NaCl library](https://nacl.cr.yp.to/). The official
[NaCl Format glossary](https://docs.learnbittensor.org/resources/glossary#nacl-format) describes it
as the format used when improving security for legacy Bittensor wallets.

## Format Context

NaCl is not a Bittensor network role, subnet role, or asset type. In Taopedia context, the term is
best read as encryption-format vocabulary. It names the security format referenced by Bittensor
documentation, not a separate wallet role or address format.

## Wallet Context

Bittensor wallet documentation separates wallet roles, public address material, and private signing
material. NaCl Format belongs to the file-protection side of that vocabulary: it concerns how legacy
wallet material is protected, while articles such as [[wallets|Wallets]] and
[[eddsa_cryptographic_keypairs|EdDSA Cryptographic Keypairs]] describe adjacent wallet concepts.

## Reading the Term

This article is a concept boundary. It does not describe how to create, migrate, recover, store, or
operate a wallet. For a reader, the important point is that NaCl Format names an encryption format
used in Bittensor wallet security context.
