# NaCl Format

NaCl Format is Bittensor wallet-file terminology for a secure encryption format. The official
[NaCl Format glossary](https://docs.learnbittensor.org/resources/glossary#nacl-format) describes it
as a format that uses the NaCl library and is used when improving security for legacy Bittensor
wallets.

## Format Context

NaCl Format is not a Bittensor network role, subnet role, asset type, or address format. In Taopedia
context, the term is best read as encryption-format vocabulary for wallet-file protection.

## Wallet Context

Bittensor documentation treats wallets and keys as the surrounding context for wallet-file security.
NaCl Format sits beside that vocabulary as a file-protection term: it concerns the format used for
legacy wallet security, not a new wallet category.

## Legacy Wallet Security

The official glossary describes NaCl Format in the context of updating legacy Bittensor wallets.
That wording is important: the term points to a security format around stored wallet material, not
to a change in the wallet's on-chain identity. A wallet can still be understood through its coldkey,
hotkey, public address, balances, stake, and transaction history while the local file format
describes how sensitive material is protected on disk.

Reference: [Glossary: NaCl Format](https://docs.learnbittensor.org/resources/glossary#nacl-format)

## File Protection Boundary

NaCl Format is best read as an at-rest protection concept. The wallet documentation explains that a
Bittensor wallet is used to prove identity, sign transactions, access TAO, and manage stake, while
the private key remains the closely held secret behind those actions. A wallet-file encryption
format helps name how local wallet material is stored, but it does not make a public key private or
make an exposed recovery phrase safe.

References: [Bittensor wallet documentation](https://docs.learnbittensor.org/keys/wallets),
[Handle your Seed Phrase/Mnemonic Securely](https://docs.learnbittensor.org/keys/handle-seed-phrase)

## Relationship to Seed Phrases

Seed phrases and wallet-file formats answer different questions. A seed phrase is recovery material
for a wallet's cryptographic key pair; losing it can mean losing access, and leaking it can give
someone else control. NaCl Format instead names an encryption-format vocabulary item for wallet
files. Treating those as separate concepts avoids implying that a better local file format replaces
the need for careful recovery-phrase handling.

Reference:
[Handle your Seed Phrase/Mnemonic Securely](https://docs.learnbittensor.org/keys/handle-seed-phrase)

## Local Storage Context

The term also belongs near local wallet vocabulary. A local wallet is created and used on a user's
machine, so wallet-file protection concerns local storage and local software behavior. That does not
make NaCl Format a subnet feature, validator feature, staking feature, or transaction rule. It is a
wallet-security detail that becomes relevant when a reader is comparing stored wallet material,
recovery material, and on-chain wallet records.

References: [Bittensor wallet documentation](https://docs.learnbittensor.org/keys/wallets),
[Glossary: Local Wallet](https://docs.learnbittensor.org/resources/glossary#local-wallet)

## What the Term Does Not Claim

NaCl Format should not be read as a promise that a wallet is safe in every operating environment.
The wallet docs distinguish stored keys, wallet applications, hardware wallets, and signing
workflows because risk depends on how and where private material is handled. The term is useful for
describing a legacy wallet-file security format, but it does not replace coldkey hygiene,
seed-phrase backups, hardware-wallet choices, or proxy-based operational separation.

References: [Bittensor wallet documentation](https://docs.learnbittensor.org/keys/wallets),
[Handle your Seed Phrase/Mnemonic Securely](https://docs.learnbittensor.org/keys/handle-seed-phrase)

## Reading the Term

This article is a concept boundary. It does not provide wallet handling steps. For a reader, the
important point is that NaCl Format names an encryption format used in Bittensor wallet security
context.

Use the term when the question is about the format of protected local wallet material. Use other
wallet vocabulary when the question is about addresses, balances, signing authority, recovery
phrases, hotkey activity, or coldkey ownership. That separation keeps a narrow security-format term
from becoming a catch-all description for wallet control.
