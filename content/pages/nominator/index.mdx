# Nominator

A nominator is a staking participant in Bittensor delegation context. Official Bittensor
documentation uses nominator and delegation terms when explaining how TAO can be associated with
validators.

References: [Glossary: Nominator](https://docs.learnbittensor.org/resources/glossary#nominator),
[Staking and Delegation](https://docs.learnbittensor.org/staking-and-delegation/delegation)

## Delegation Context

The term belongs to staking rather than mining or subnet task execution. A nominator participates in
delegation by associating TAO with a validator context. This makes the term part of Bittensor's
staking vocabulary.

References: [Glossary: Delegation](https://docs.learnbittensor.org/resources/glossary#delegation),
[Glossary: Delegate Stake](https://docs.learnbittensor.org/resources/glossary#delegate-stake)

## Reader Boundary

This page defines the term. It does not recommend validators, report current returns, list live
stake, or describe a specific staking action. Readers should use current official staking
documentation for security-sensitive staking actions.
