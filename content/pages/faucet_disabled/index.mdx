# Faucet Disabled

`FaucetDisabled` is a documented Subtensor standard error raised by the faucet extrinsic when faucet
execution is not available. The standard-errors reference describes it as "Faucet is disabled"
([Subtensor Standard Errors](https://docs.learnbittensor.org/errors/subtensor#faucetdisabled)).

## What It Means

The Subtensor `faucet` extrinsic is explicitly described in source comments as a testing facility
path. In its dispatch implementation, the fallback branch returns `FaucetDisabled` when faucet
execution is not available on that runtime path
([Subtensor source: dispatches.rs](https://github.com/opentensor/subtensor/blob/main/pallets/subtensor/src/macros/dispatches.rs)).

This is an availability rejection for faucet execution, not a signature-validation failure and not a
staking balance failure.

## Why It Appears

This error appears when a caller submits the `faucet` extrinsic to a runtime path where faucet
execution does not proceed and the dispatch returns `FaucetDisabled` instead. In practice, this
indicates faucet access is not active for that execution context
([Subtensor source: dispatches.rs](https://github.com/opentensor/subtensor/blob/main/pallets/subtensor/src/macros/dispatches.rs)).

When debugging, separate this from unrelated wallet errors on other extrinsics. For example,
`NotEnoughBalanceToStake` concerns staking funding checks, while `FaucetDisabled` concerns faucet
availability on the faucet call itself
([Subtensor Standard Errors: NotEnoughBalanceToStake](https://docs.learnbittensor.org/errors/subtensor#notenoughbalancetostake),
[Subtensor Standard Errors: FaucetDisabled](https://docs.learnbittensor.org/errors/subtensor#faucetdisabled)).

## Distinction from Not Enough Balance To Stake

`FaucetDisabled` and `NotEnoughBalanceToStake` both involve wallet outcomes, but on different
mechanisms. `FaucetDisabled` is a faucet-availability rejection. `NotEnoughBalanceToStake` is a
staking amount check on stake-related calls
([Subtensor Standard Errors: FaucetDisabled](https://docs.learnbittensor.org/errors/subtensor#faucetdisabled),
[Subtensor Standard Errors: NotEnoughBalanceToStake](https://docs.learnbittensor.org/errors/subtensor#notenoughbalancetostake)).

- **FaucetDisabled** — faucet execution is unavailable.
- **NotEnoughBalanceToStake** — coldkey balance is insufficient for a stake request.

## Distinction from Bad Origin

`FaucetDisabled` and `BadOrigin` are both dispatch failures, but they represent different
conditions. `FaucetDisabled` is about faucet availability. `BadOrigin` indicates an origin-type
mismatch for an extrinsic's origin requirements
([Subtensor Standard Errors: FaucetDisabled](https://docs.learnbittensor.org/errors/subtensor#faucetdisabled),
[Subtensor Standard Errors: BadOrigin](https://docs.learnbittensor.org/errors/subtensor#badorigin)).

- **FaucetDisabled** — faucet is not available on that execution path.
- **BadOrigin** — caller origin type does not satisfy extrinsic requirements.

## Reader Boundary

This page defines the meaning of the error label and the faucet dispatch branch that raises it. It
does not describe faucet economics or broader token distribution policy beyond this runtime error
condition
([Subtensor source: dispatches.rs](https://github.com/opentensor/subtensor/blob/main/pallets/subtensor/src/macros/dispatches.rs)).
