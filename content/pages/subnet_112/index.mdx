minotaur is Bittensor Subnet 112. Its on-chain identity registers the subnet as a distributed DEX
aggregator and swap-intent solver engine.

## What minotaur Provides

The registered identity describes minotaur as a "distributed DEX aggregator and swap intent solver
engine" — finding and executing efficient routes for token swaps across decentralized exchanges.
Miners compete to solve swap intents, and the network rewards the strongest solutions. The
registered project website is [minotaursubnet.com](https://minotaursubnet.com) and the codebase is
the [subnet112/minotaur_subnet](https://github.com/subnet112/minotaur_subnet) repository, which
defines the task in more detail than the on-chain identity alone.

## Miner and Validator Roles

Subnet 112 operates under the standard Bittensor two-role structure. Miners supply a capability to
the network, and validators evaluate those contributions and set weights. Reward distribution
follows [[Yuma Consensus]].

## On-Chain Identity

The live Finney identity for netuid 112 registers the subnet name as minotaur, with the description
"Distributed DEX aggregator and swap intent solver engine." The registered project website is
[minotaursubnet.com](https://minotaursubnet.com) and the GitHub repository is
[subnet112/minotaur_subnet](https://github.com/subnet112/minotaur_subnet). Live subnet data is
available on [TaoStats](https://taostats.io/subnets/112).
