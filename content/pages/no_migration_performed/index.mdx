# No Migration Performed

`NoMigrationPerformed` is a contracts pallet error returned when a migrate operation runs but the
runtime performs no migration. The API errors reference summarizes it as "Migrate dispatch call was
attempted but no migration was performed"
([Subtensor API Errors: NoMigrationPerformed](https://docs.learnbittensor.org/subtensor-api/errors#nomigrationperformed)).

## What It Means

Subtensor includes a contracts pallet for on-chain smart contracts. The runtime can run migrations
that update stored contract state when a migrate operation is submitted. `NoMigrationPerformed`
means the migrate path completed without applying any migration work
([Subtensor API Errors: NoMigrationPerformed](https://docs.learnbittensor.org/subtensor-api/errors#nomigrationperformed)).

This is a no-op migration outcome. It does not, by itself, mean a migration is still pending, that
no contract exists at the targeted address, or that no code exists at a supplied hash.

## Why It Appears

This error appears when a contracts migrate operation is submitted but the runtime has no migration
to perform at that point
([Subtensor API Errors: NoMigrationPerformed](https://docs.learnbittensor.org/subtensor-api/errors#nomigrationperformed)).

## Distinction from Migration In Progress

`NoMigrationPerformed` and `MigrationInProgress` both involve contracts migrations, but at different
stages. `NoMigrationPerformed` means a migrate call did not perform any migration.
`MigrationInProgress` is summarized as "A pending migration needs to complete before the extrinsic
can be called."
([Subtensor API Errors: NoMigrationPerformed](https://docs.learnbittensor.org/subtensor-api/errors#nomigrationperformed),
[Subtensor API Errors: MigrationInProgress](https://docs.learnbittensor.org/subtensor-api/errors#migrationinprogress)).

- **NoMigrationPerformed** — a migrate call did not perform any migration.
- **MigrationInProgress** — a pending migration still needs to complete.

## Distinction from Contract Not Found

`NoMigrationPerformed` and `ContractNotFound` are different contracts pallet errors with different
API summaries. `NoMigrationPerformed` means a migrate call performed no migration.
`ContractNotFound` is summarized as "Contract not found at the specified address."
([Subtensor API Errors: NoMigrationPerformed](https://docs.learnbittensor.org/subtensor-api/errors#nomigrationperformed),
[Subtensor API Errors: ContractNotFound](https://docs.learnbittensor.org/subtensor-api/errors#contractnotfound)).

- **NoMigrationPerformed** — a migrate call did not perform any migration.
- **ContractNotFound** — no live contract exists at the targeted address.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not report whether
a migrate operation is needed on a network or diagnose why no migration was performed there
([Subtensor API Errors: NoMigrationPerformed](https://docs.learnbittensor.org/subtensor-api/errors#nomigrationperformed),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
