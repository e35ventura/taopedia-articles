# Metagraph

The metagraph is Bittensor's structured view of state for a selected subnet. The official glossary
defines it as a data structure containing comprehensive information about a subnet's neurons and
notes that it helps calculate emissions.

References: [Glossary: Metagraph](https://docs.learnbittensor.org/resources/glossary#metagraph),
[The Subnet Metagraph](https://docs.learnbittensor.org/subnets/metagraph)

## Subnet Selector

A metagraph is read for a specific subnet. The subnet metagraph documentation uses netuid 1 as an
example subnet selector, then describes the resulting metagraph as a snapshot of that subnet's state
at a particular block. In practice, the reader first chooses the subnet context, then reads the
metagraph for that context.

Reference: [The Subnet Metagraph](https://docs.learnbittensor.org/subnets/metagraph)

## Snapshot, Not Live Feed

A metagraph represents chain state at the block height it was synced from. The Bittensor Python API
documentation describes sync behavior for refreshing the object from chain data. That distinction
matters because a local metagraph view can become stale as later blocks are produced.

References: [The Subnet Metagraph](https://docs.learnbittensor.org/subnets/metagraph),
[bittensor.core.metagraph](https://docs.learnbittensor.org/python-api/html/autoapi/bittensor/core/metagraph/)

## What the Term Covers

Official references describe the metagraph as carrying subnet state used by validators, miners, and
tooling. It is the place readers encounter values such as stake-related state, weights, ranks,
trust, consensus, incentives, dividends, emissions, activity state, and bonds for the selected
subnet context. Those values are chain-derived state, not editorial ratings.

References: [The Subnet Metagraph](https://docs.learnbittensor.org/subnets/metagraph),
[Understanding Neurons](https://docs.learnbittensor.org/learn/neurons),
[bittensor.core.metagraph](https://docs.learnbittensor.org/python-api/html/autoapi/bittensor/core/metagraph/)

## Consensus Context

The metagraph sits near Bittensor's incentive layer because validator weights and resulting
consensus-related values are part of the subnet state readers inspect. Yuma Consensus explains how
validator evaluations are aggregated into miner incentives and validator dividends; the metagraph is
one of the structured views where those subnet-level values can be observed.

References: [Yuma Consensus](https://docs.learnbittensor.org/yuma-consensus/),
[Glossary: Metagraph](https://docs.learnbittensor.org/resources/glossary#metagraph)

## Reader Boundary

This page defines the term. It does not report current subnet membership, current stake, current
emissions, wallet ownership, or any live identity fields. Those values change with chain state and
should be checked with official tooling for the relevant netuid.
