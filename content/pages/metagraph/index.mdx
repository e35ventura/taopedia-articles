# Metagraph

A metagraph is the data structure that describes the state of a Bittensor subnet. The
[Glossary](https://docs.learnbittensor.org/resources/glossary#metagraph) describes it as a structure
containing comprehensive information about the current state of a subnet, including detailed
information on all the nodes (neurons) such as subnet validator stakes and subnet weights.

## What It Describes

The [Subnet Metagraph](https://docs.learnbittensor.org/subnets/metagraph) reference describes the
metagraph as the per-subnet view of its neurons and their associated values, indexed by UID. The
[Glossary](https://docs.learnbittensor.org/resources/glossary#metagraph) ties this to subnet
validator stakes and subnet weights, so the metagraph is best read as the structure that organizes a
subnet's participant values rather than as a separate role or token.

## Relationship to Neurons

Each entry in a metagraph corresponds to a neuron — a subnet miner or subnet validator — identified
by its UID. The [Understanding Neurons](https://docs.learnbittensor.org/learn/neurons) reference
describes neurons as the nodes that occupy a subnet, and the
[Subnet Metagraph](https://docs.learnbittensor.org/subnets/metagraph) reference places those neurons
and their values inside the metagraph structure.

## Syncing

The [Subnet Metagraph](https://docs.learnbittensor.org/subnets/metagraph) reference and the
Bittensor SDK
[metagraph module](https://docs.learnbittensor.org/python-api/html/autoapi/bittensor/core/metagraph/)
describe syncing as the step that updates a metagraph's values to match the network, optionally at a
chosen block. They also describe a lighter sync mode that omits weights and bonds. These references,
not this article, are the source for exact fields and access patterns.

## Reader Boundary

This article defines the metagraph concept. It does not report a specific subnet's values, count its
neurons, state any stake or weight figure, or describe current network state. Readers should use the
Bittensor SDK or official subnet references for live values.
