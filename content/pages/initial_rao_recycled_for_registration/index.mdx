# Initial Rao Recycled For Registration

Initial Rao Recycled For Registration is a subtensorModule runtime constant, listed in the chain's
constants metadata as initialRAORecycledForRegistration, with the value 0 and the summary "Initial
RAO Recycled"
([Subtensor API Constants: initialRAORecycledForRegistration](https://docs.learnbittensor.org/subtensor-api/constants#initialraorecycledforregistration-u64)).
It supplies the default value a subnet's RAORecycledForRegistration uses.

## What It Means

RAORecycledForRegistration is held per subnet and records the amount of RAO recycled toward
registration on a subnet. Initial Rao Recycled For Registration is the default this per-subnet value
falls back to before a different value applies for a subnet
([Subtensor API Constants: initialRAORecycledForRegistration](https://docs.learnbittensor.org/subtensor-api/constants#initialraorecycledforregistration-u64)).
The RAORecycledForRegistration in force on a subnet such as netuid 1 is that subnet's own chain
state and can differ from this default.

## Distinction from Burn and Difficulty

Initial Rao Recycled For Registration is the default recycled-RAO amount, while initialBurn, valued
at 100000000, is the registration burn cost; initialDifficulty, valued at 10000000, is the
registration difficulty
([Subtensor API Constants: initialBurn](https://docs.learnbittensor.org/subtensor-api/constants#initialburn-u64),
[Subtensor API Constants: initialDifficulty](https://docs.learnbittensor.org/subtensor-api/constants#initialdifficulty-u64)).

## Reader Boundary

Initial Rao Recycled For Registration is a default constant, not the live per-subnet
RAORecycledForRegistration, and it reflects the current runtime configuration rather than a fixed
protocol rule
([Subtensor API Constants: initialRAORecycledForRegistration](https://docs.learnbittensor.org/subtensor-api/constants#initialraorecycledforregistration-u64)).
