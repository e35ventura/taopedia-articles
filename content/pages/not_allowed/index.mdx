# Not Allowed

`NotAllowed` is an EVM pallet error raised when the origin address is not permitted to perform the
requested operation. The API errors reference describes it as "Origin is not allowed to perform the
operation"
([Subtensor API Errors: NotAllowed](https://docs.learnbittensor.org/subtensor-api/errors#notallowed)).

## What It Means

`NotAllowed` means the EVM call was blocked because the origin address does not have permission to
perform the requested operation
([Subtensor API Errors: NotAllowed](https://docs.learnbittensor.org/subtensor-api/errors#notallowed)).

This is an origin permission check. It does not mean the account lacks funds.

## Why It Appears

This error appears when an EVM call is submitted from an origin address that is not permitted for
that operation
([Subtensor API Errors: NotAllowed](https://docs.learnbittensor.org/subtensor-api/errors#notallowed)).

## Distinction from Create Origin Not Allowed

`NotAllowed` is documented as "Origin is not allowed to perform the operation."
`CreateOriginNotAllowed` is documented as "Address not allowed to deploy contracts either via CREATE
or CALL(CREATE)." Both block an EVM call due to an origin permission check, but their documented
conditions describe different operations
([Subtensor API Errors: NotAllowed](https://docs.learnbittensor.org/subtensor-api/errors#notallowed),
[Subtensor API Errors: CreateOriginNotAllowed](https://docs.learnbittensor.org/subtensor-api/errors#createoriginnotallowed)).

- **NotAllowed** -- the origin is not permitted for the requested EVM operation.
- **CreateOriginNotAllowed** -- the address is not permitted to deploy contracts via CREATE or
  CALL(CREATE).

## Distinction from Balance Low

`NotAllowed` is documented as "Origin is not allowed to perform the operation." `BalanceLow` is
documented as "Not enough balance to perform action." Both block an EVM operation, but their
documented conditions describe different problems
([Subtensor API Errors: NotAllowed](https://docs.learnbittensor.org/subtensor-api/errors#notallowed),
[Subtensor API Errors: BalanceLow](https://docs.learnbittensor.org/subtensor-api/errors#balancelow)).

- **NotAllowed** -- the origin does not have permission for the operation.
- **BalanceLow** -- the account does not have enough balance for the operation.
