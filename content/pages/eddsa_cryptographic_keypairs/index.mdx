# EdDSA Cryptographic Keypairs

EdDSA cryptographic keypairs refer to the public and private key pairs generated with EdDSA, the
signature algorithm named in Bittensor wallet-key terminology. The official
[Glossary](https://docs.learnbittensor.org/resources/glossary#eddsa-cryptographic-keypairs)
describes EdDSA as the algorithm used to generate public and private key pairs for Bittensor
coldkeys and hotkeys.

## Keypair Context

A keypair has two sides: a public side that can be shared for identification or verification, and a
private side that must remain protected. The
[Public Key glossary](https://docs.learnbittensor.org/resources/glossary#public-key) describes the
public key as shareable material used for verification, encryption, and account reference. The
[Private Key glossary](https://docs.learnbittensor.org/resources/glossary#private-key) describes the
private key as the protected component used to authorize activity.

## Wallet-Key Context

In Bittensor, EdDSA keypairs sit under the wallet-key vocabulary rather than naming a separate
network role or asset. The glossary connects EdDSA key generation with coldkeys and hotkeys, while
separate articles can explain those wallet-key roles in more detail.

## Reading the Term

This article is a concept boundary. It does not describe how to create, store, recover, rotate, or
use keys. For Taopedia readers, the useful point is that EdDSA names the cryptographic method behind
the public/private keypair terminology used in Bittensor.

## Relationship to Public Key

EdDSA cryptographic keypairs and public keys are related but different parts of Bittensor wallet-key
vocabulary. An EdDSA cryptographic keypair is the public and private key pair generated using the
EdDSA signature algorithm, while a public key is the shareable half of that pair used for
verification, encryption, and account reference. The
[Glossary: EdDSA Cryptographic Keypairs](https://docs.learnbittensor.org/resources/glossary#eddsa-cryptographic-keypairs)
describes EdDSA as the algorithm that generates both sides of the keypair, and the
[Glossary: Public Key](https://docs.learnbittensor.org/resources/glossary#public-key) describes the
public key as the shareable component derived from that keypair.

For readers, EdDSA keypairs name the complete public/private pair and the algorithm used to generate
it, while public key names the specific shareable half used for identification and verification.

References:
[Glossary: EdDSA Cryptographic Keypairs](https://docs.learnbittensor.org/resources/glossary#eddsa-cryptographic-keypairs),
[Glossary: Public Key](https://docs.learnbittensor.org/resources/glossary#public-key)

## Relationship to Private Key

EdDSA cryptographic keypairs and private keys are related but different parts of Bittensor
wallet-key vocabulary. An EdDSA cryptographic keypair is the public and private key pair generated
using EdDSA, while a private key is the protected half of that pair used to authorize operations and
prove control. The
[Glossary: EdDSA Cryptographic Keypairs](https://docs.learnbittensor.org/resources/glossary#eddsa-cryptographic-keypairs)
describes EdDSA as generating the complete keypair for Bittensor coldkeys and hotkeys, and the
[Glossary: Private Key](https://docs.learnbittensor.org/resources/glossary#private-key) describes
the private key as the sensitive component that must remain protected.

For readers, EdDSA keypairs name the algorithm and the complete pair structure, while private key
names the specific protected half that signs transactions and authorizes wallet operations.

References:
[Glossary: EdDSA Cryptographic Keypairs](https://docs.learnbittensor.org/resources/glossary#eddsa-cryptographic-keypairs),
[Glossary: Private Key](https://docs.learnbittensor.org/resources/glossary#private-key)

## Relationship to Coldkeys

EdDSA cryptographic keypairs and coldkeys are related but different scopes in Bittensor wallet
vocabulary. An EdDSA cryptographic keypair describes the public and private key pair generated using
the EdDSA algorithm, while a coldkey is the security-sensitive Bittensor wallet key that controls
TAO balances and owns hotkeys, generated using that EdDSA algorithm. The
[Glossary: EdDSA Cryptographic Keypairs](https://docs.learnbittensor.org/resources/glossary#eddsa-cryptographic-keypairs)
identifies EdDSA as the algorithm used to generate public and private key pairs for Bittensor
coldkeys and hotkeys, and the
[Wallets, Coldkeys and Hotkeys](https://docs.learnbittensor.org/keys/wallets) documentation
describes the coldkey as the custody anchor that holds funds and stake.

For readers, EdDSA keypairs name the cryptographic method and key-pair structure, while coldkey
names the specific wallet-role key generated using that method and positioned as the
financial-control anchor.

References:
[Glossary: EdDSA Cryptographic Keypairs](https://docs.learnbittensor.org/resources/glossary#eddsa-cryptographic-keypairs),
[Wallets, Coldkeys and Hotkeys](https://docs.learnbittensor.org/keys/wallets)
