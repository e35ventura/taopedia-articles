# Encrypting the Hotkey

Encrypting the hotkey refers to protecting a Bittensor hotkey with encryption in wallet context.
Official Bittensor documentation discusses hotkeys as operational keys and treats wallet key
material as security-sensitive.

References:
[Glossary: Encrypting the Hotkey](https://docs.learnbittensor.org/resources/glossary#encrypting-the-hotkey),
[Working with Keys](https://docs.learnbittensor.org/keys/working-with-keys)

## Wallet Security Context

A hotkey is used for day-to-day Bittensor actions, so protecting it matters even when a coldkey is
kept separate. Encryption is part of reducing exposure of locally stored key material and belongs to
the broader wallet-security model.

References: [Glossary: Hotkey](https://docs.learnbittensor.org/resources/glossary#hotkey),
[Wallets](https://docs.learnbittensor.org/keys/wallets)

## Reader Boundary

This page defines the term. It does not ask readers to enter a password, expose a key, or follow a
specific wallet action. Readers should use current official wallet documentation for
security-sensitive wallet actions.
