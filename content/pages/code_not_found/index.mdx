# Code Not Found

`CodeNotFound` is a contracts pallet error raised when no code exists at the supplied code hash. The
API errors reference summarizes it as "No code could be found at the supplied code hash"
([Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound)).

## What It Means

Bittensor runs an Ethereum-compatible execution layer on Subtensor for smart contracts
([Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials)). `CodeNotFound`
means the contracts runtime could not find bytecode at the code hash named in the call
([Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound)).

This is a code-hash lookup failure. It does not, by itself, mean execution trapped during the call
or that the executed contract exhausted its gas limit.

## Why It Appears

This error appears when a contracts call names a code hash that the runtime does not have stored
([Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound)).

## Distinction from Contract Trapped

`CodeNotFound` and `ContractTrapped` are different contracts pallet errors with different API
summaries. `CodeNotFound` is summarized as "No code could be found at the supplied code hash."
`ContractTrapped` is summarized as "Contract trapped during execution."
([Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped),
[Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound)).

- **CodeNotFound** — no code at the supplied code hash.
- **ContractTrapped** — contract trapped during execution.

## Distinction from Code Too Large

`CodeNotFound` and `CodeTooLarge` both involve contract code, but at different checks.
`CodeTooLarge` is summarized as "The code supplied to `instantiate_with_code` exceeds the limit
specified in the current schedule." `CodeNotFound` is summarized as "No code could be found at the
supplied code hash."
([Subtensor API Errors: CodeTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#codetoolarge),
[Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound)).

- **CodeNotFound** — no code at the supplied code hash.
- **CodeTooLarge** — supplied instantiate code exceeds the current schedule limit.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not report which
code hashes exist on a live network
([Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
