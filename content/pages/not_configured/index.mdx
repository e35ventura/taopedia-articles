# Not Configured

`NotConfigured` is a safe-mode pallet error raised when a call requires a network-configured
parameter that has not been set. The API errors reference describes it as "This functionality of the
pallet is disabled by the configuration"
([Subtensor API Errors: NotConfigured](https://docs.learnbittensor.org/subtensor-api/errors#notconfigured)).

## What It Means

The safe-mode pallet exposes deposit operations that depend on network-level configuration values.
When a required parameter is absent, the corresponding operation is disabled and raises
`NotConfigured`
([Subtensor API Errors: NotConfigured](https://docs.learnbittensor.org/subtensor-api/errors#notconfigured),
[Subtensor API Extrinsics: safeMode](https://docs.learnbittensor.org/subtensor-api/extrinsics#safemode)).

Documented safe-mode calls include `enter`, `extend`, and `releaseDeposit`
([Subtensor API Extrinsics: safeMode](https://docs.learnbittensor.org/subtensor-api/extrinsics#safemode)).

## Why It Appears

This error appears when a caller attempts a safe-mode operation that the network has not enabled
through configuration. If the network does not set the parameter a call requires, that call fails
immediately with `NotConfigured`
([Subtensor API Errors: NotConfigured](https://docs.learnbittensor.org/subtensor-api/errors#notconfigured)).

## Distinction from Cannot Release Yet

`NotConfigured` and `CannotReleaseYet` both appear on the `releaseDeposit` path, but they name
different failures. `NotConfigured` means the pallet functionality is disabled by configuration.
`CannotReleaseYet` means a deposit cannot be released yet
([Subtensor API Errors: NotConfigured](https://docs.learnbittensor.org/subtensor-api/errors#notconfigured),
[Subtensor API Errors: CannotReleaseYet](https://docs.learnbittensor.org/subtensor-api/errors#cannotreleaseyet)).

- **NotConfigured** — required configuration is absent; the operation is disabled.
- **CannotReleaseYet** — release is configured but not yet allowed for this deposit.

## Distinction from No Deposit

`NotConfigured` and `NoDeposit` are separate safe-mode errors with different API summaries.
`NoDeposit` is documented as "There is no balance reserved." `NotConfigured` is documented as
functionality disabled by configuration
([Subtensor API Errors: NoDeposit](https://docs.learnbittensor.org/subtensor-api/errors#nodeposit),
[Subtensor API Errors: NotConfigured](https://docs.learnbittensor.org/subtensor-api/errors#notconfigured)).

- **NoDeposit** — no reserved balance is recorded for the release lookup.
- **NotConfigured** — the call is disabled because required configuration is absent.

## Reader Boundary

This page defines the meaning of the error label and the configuration presence checks that raise
it. It does not report whether the network has configured deposit amounts or a release delay; those
are live chain state
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
