# Delegate Dependency Not Found

`DelegateDependencyNotFound` is a contracts pallet error raised when the requested delegate
dependency is not present in the contract's stored list. The API errors reference summarizes it as
"The dependency was not found in the contract's delegate dependencies"
([Subtensor API Errors: DelegateDependencyNotFound](https://docs.learnbittensor.org/subtensor-api/errors#delegatedependencynotfound)).

## What It Means

Bittensor supports an Ethereum-compatible smart-contract environment on Subtensor
([Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials)). In that setting, a
contract keeps a stored list of delegate dependencies on other code hashes it may call through
delegation. `DelegateDependencyNotFound` means the named dependency is not in that list, so an
operation that requires it cannot proceed
([Subtensor API Errors: DelegateDependencyNotFound](https://docs.learnbittensor.org/subtensor-api/errors#delegatedependencynotfound)).

This is a missing-dependency rejection. It does not mean the contract already depends on the same
dependency, that the contract has reached the maximum number of dependencies, or that the submitted
code hash is the contract's own code hash.

## Why It Appears

This error appears when a contracts operation references a delegate dependency that is not stored
for that contract
([Subtensor API Errors: DelegateDependencyNotFound](https://docs.learnbittensor.org/subtensor-api/errors#delegatedependencynotfound)).

## Distinction from Delegate Dependency Already Exists

`DelegateDependencyNotFound` and `DelegateDependencyAlreadyExists` point in opposite directions.
`DelegateDependencyNotFound` means the named dependency is absent from the contract's stored list.
`DelegateDependencyAlreadyExists` is summarized as "The contract already depends on the given
delegate dependency."
([Subtensor API Errors: DelegateDependencyNotFound](https://docs.learnbittensor.org/subtensor-api/errors#delegatedependencynotfound),
[Subtensor API Errors: DelegateDependencyAlreadyExists](https://docs.learnbittensor.org/subtensor-api/errors#delegatedependencyalreadyexists)).

- **DelegateDependencyNotFound** — the dependency is not present.
- **DelegateDependencyAlreadyExists** — the dependency is already present.

## Distinction from Max Delegate Dependencies Reached

`DelegateDependencyNotFound` and `MaxDelegateDependenciesReached` involve delegate dependencies at
different stages. `DelegateDependencyNotFound` blocks an operation because a named dependency is
missing from storage. `MaxDelegateDependenciesReached` is summarized as "The contract has reached
its maximum number of delegate dependencies."
([Subtensor API Errors: DelegateDependencyNotFound](https://docs.learnbittensor.org/subtensor-api/errors#delegatedependencynotfound),
[Subtensor API Errors: MaxDelegateDependenciesReached](https://docs.learnbittensor.org/subtensor-api/errors#maxdelegatedependenciesreached)).

- **DelegateDependencyNotFound** — the requested dependency is not stored.
- **MaxDelegateDependenciesReached** — the contract has no room for another dependency.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not report the
delegate dependencies stored for a specific contract on a network or describe how a contract should
redesign its dependency structure
([Subtensor API Errors: DelegateDependencyNotFound](https://docs.learnbittensor.org/subtensor-api/errors#delegatedependencynotfound),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
