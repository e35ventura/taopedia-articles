# Subnet 6: Numinous

Numinous is Bittensor Subnet 6. The on-chain identity describes it as "a forecasting protocol whose
goal is to aggregate agents into superhuman LLM forecasters," and the official repository explains
that the subnet evaluates miner-submitted forecasting agents through validator-run sandboxes.

References: [numinouslabs/numinous (GitHub)](https://github.com/numinouslabs/numinous),
[taostats.io/subnets/6](https://taostats.io/subnets/6)

## What Numinous Provides

According to the official repository, Numinous is organized around a fixed cycle of code submission,
sandbox execution, event resolution, and weight setting. Miners submit Python agents, validators
execute those agents inside isolated sandboxes, and resolved events are used to score forecast
quality with the Brier score before weights are set on-chain.

The repository also describes a gateway proxy that lets agents reach approved external services
without exposing validator credentials directly to miner code. In the project documentation, this
source-controlled and visible execution model is presented as a core part of the subnet's
discoverability and composability goals.

References: [numinouslabs/numinous (GitHub)](https://github.com/numinouslabs/numinous)

## Miner and Validator Roles

Numinous follows the standard Bittensor subnet structure. Miners provide forecasting agents, while
validators run the infrastructure that executes those agents, evaluates the resulting forecasts, and
sets weights. Those validator-set weights then flow into [[Yuma Consensus]], which determines how
subnet performance affects emissions under [[Dynamic TAO]].

References: [numinouslabs/numinous (GitHub)](https://github.com/numinouslabs/numinous)

## On-Chain Identity

The live on-chain identity for netuid 6 lists the subnet name as Numinous. Its GitHub repository
field points to `https://github.com/numinouslabs/numinous`, its project URL field points to
`https://numinouslabs.io/`, and its Discord field is `amedeo_ma`. The on-chain description says
"Numinous is a forecasting protocol whose goal is to aggregate agents into superhuman LLM
forecasters." The `additional` field is blank. The subnet currently has **256 neurons**.
