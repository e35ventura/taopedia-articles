# State Change Denied

`StateChangeDenied` is a contracts pallet error raised when a contract tries to invoke a
state-modifying API while running in read-only mode. The API errors reference summarizes it as "A
contract attempted to invoke a state modifying API while being in read-only mode"
([Subtensor API Errors: StateChangeDenied](https://docs.learnbittensor.org/subtensor-api/errors#statechangedenied)).

## What It Means

Some contracts calls run under a read-only restriction. `StateChangeDenied` means the contract then
tried to use an API that would modify state, so the runtime rejected that operation
([Subtensor API Errors: StateChangeDenied](https://docs.learnbittensor.org/subtensor-api/errors#statechangedenied)).

This is a read-only mode guard. It does not, by itself, mean the output buffer was too small, that
the call exceeded a value-size limit, or that too many topics were supplied for an event deposit.

## Why It Appears

This error appears when a contracts call reaches a state-modifying API while the contract is being
handled as read-only
([Subtensor API Errors: StateChangeDenied](https://docs.learnbittensor.org/subtensor-api/errors#statechangedenied)).

## Distinction from Output Buffer Too Small

`StateChangeDenied` and `OutputBufferTooSmall` can both stop a contracts call, but they fail for
different reasons. `StateChangeDenied` rejects a state-modifying API call in read-only mode.
`OutputBufferTooSmall` rejects a call because the caller-supplied output buffer is too small
([Subtensor API Errors: StateChangeDenied](https://docs.learnbittensor.org/subtensor-api/errors#statechangedenied),
[Subtensor API Errors: OutputBufferTooSmall](https://docs.learnbittensor.org/subtensor-api/errors#outputbuffertoosmall)).

- **StateChangeDenied** — a state-changing API was attempted in read-only mode.
- **OutputBufferTooSmall** — the caller-supplied output buffer is too small.

## Distinction from Value Too Large

`StateChangeDenied` and `ValueTooLarge` both reject contracts operations, but they check different
conditions. `StateChangeDenied` blocks a state-changing API in read-only mode. `ValueTooLarge`
blocks a value that exceeds the runtime's configured maximum size
([Subtensor API Errors: StateChangeDenied](https://docs.learnbittensor.org/subtensor-api/errors#statechangedenied),
[Subtensor API Errors: ValueTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#valuetoolarge)).

- **StateChangeDenied** — the operation violates a read-only restriction.
- **ValueTooLarge** — the value exceeds the configured size limit.
