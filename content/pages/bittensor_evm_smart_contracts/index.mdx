# Bittensor EVM Smart Contracts

Bittensor EVM smart contracts are Ethereum Virtual Machine-compatible contracts executed on the
Bittensor blockchain. The official
[Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials) overview describes a
full EVM runtime operating as an application layer on top of Subtensor.

## What the EVM Layer Provides

The EVM layer lets developers deploy many EVM-compatible smart contracts on Subtensor, interact with
contracts already deployed there, and use standard Ethereum JSON-RPC methods. This makes the feature
a compatibility layer for smart-contract execution, not a replacement for Bittensor's subnet or
consensus systems.

Reference: [Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials)

## Bittensor Rather Than Ethereum

The official overview emphasizes that Bittensor EVM smart contracts execute on the Bittensor
blockchain, not on the Ethereum blockchain. The EVM compatibility describes the contract runtime and
interface style; the underlying chain context remains Subtensor.

Reference: [Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials)

## Address Context

The same source distinguishes Bittensor's SS58-style addresses from Ethereum-style H160 addresses.
That distinction matters because address formats can be translated for display, but the signing
authority for one address format is not automatically the signing authority for the other. Readers
should treat the EVM layer as a bridge between interface models, not as a collapse of the two
account systems into one.

Reference: [Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials)

## Relationship to Subtensor

Subtensor remains the Bittensor blockchain underneath the EVM application layer. EVM contracts are
part of how applications can run on Bittensor, while consensus, subnets, emissions, and validator
behavior remain Bittensor protocol concepts. This distinction helps keep smart-contract
compatibility separate from the broader subnet economy.

Reference: [Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials)

## Careful Interpretation

This article is a conceptual overview, not a deployment guide or operational page. The official EVM
documentation includes tutorials and examples for specific workflows, but Taopedia readers should
separate those operational details from the core idea: Bittensor can execute EVM-compatible smart
contracts on Subtensor.

Reference: [Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials)
