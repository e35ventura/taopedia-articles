# Scheduled Call Not Found

`NotFound` is a scheduler pallet error raised when the runtime cannot find the scheduled call being
referenced. The API errors reference summarizes it as "Cannot find the scheduled call"
([Subtensor API Errors: NotFound](https://docs.learnbittensor.org/subtensor-api/errors#notfound)).

## What It Means

Subtensor uses the scheduler pallet to queue calls for dispatch at a specified future block.
Scheduler operations such as cancel or reschedule first look up an existing scheduled call.
`NotFound` means that lookup did not find a matching entry, so the operation cannot proceed
([Subtensor API Errors: NotFound](https://docs.learnbittensor.org/subtensor-api/errors#notfound)).

This is a scheduled-call lookup failure. It does not, by itself, mean the scheduler failed to queue
a new call, that the submitted target block is in the past, or that a reschedule would leave the
call at the same block.

## Why It Appears

This error appears when a scheduler operation names a scheduled call that is not present in
scheduler storage
([Subtensor API Errors: NotFound](https://docs.learnbittensor.org/subtensor-api/errors#notfound)).

## Distinction from Failed To Schedule

`NotFound` and `FailedToSchedule` both stop scheduler operations, but with different API summaries.
`NotFound` is summarized as "Cannot find the scheduled call." `FailedToSchedule` is summarized as
"Failed to schedule a call."
([Subtensor API Errors: NotFound](https://docs.learnbittensor.org/subtensor-api/errors#notfound),
[Subtensor API Errors: FailedToSchedule](https://docs.learnbittensor.org/subtensor-api/errors#failedtoschedule)).

- **NotFound** — the referenced scheduled call was not found.
- **FailedToSchedule** — the scheduler failed to schedule the call.

## Distinction from Reschedule No Change

`NotFound` and `RescheduleNoChange` both block scheduler paths that act on an existing scheduled
call, but on different checks. `NotFound` means the scheduled call is missing from storage.
`RescheduleNoChange` is summarized as "Reschedule failed because it does not change scheduled time."
([Subtensor API Errors: NotFound](https://docs.learnbittensor.org/subtensor-api/errors#notfound),
[Subtensor API Errors: RescheduleNoChange](https://docs.learnbittensor.org/subtensor-api/errors#reschedulenochange)).

- **NotFound** — the referenced scheduled call was not found.
- **RescheduleNoChange** — the reschedule would not change the scheduled time.

## Reader Boundary

This page defines the meaning of the scheduler `NotFound` error label from the API reference. It
does not list which scheduled calls are currently stored on a network
([Subtensor API Errors: NotFound](https://docs.learnbittensor.org/subtensor-api/errors#notfound),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
