# Random Subject Too Long

`RandomSubjectTooLong` is a contracts pallet error raised when a randomness request uses a subject
that is longer than the runtime allows. The API errors reference summarizes it as "The subject
passed to `seal_random` exceeds the limit"
([Subtensor API Errors: RandomSubjectTooLong](https://docs.learnbittensor.org/subtensor-api/errors#randomsubjecttoolong)).

## What It Means

Some contracts requests for randomness include a subject so the request can be identified or varied.
`RandomSubjectTooLong` means that subject is longer than the runtime permits, so the randomness
request is rejected
([Subtensor API Errors: RandomSubjectTooLong](https://docs.learnbittensor.org/subtensor-api/errors#randomsubjecttoolong)).

This is a subject-length limit failure. It does not, by itself, mean the caller supplied too many
event topics, that a contract value exceeded the runtime's maximum size, or that a caller-provided
output buffer was too small.

## Why It Appears

This error appears when a contracts randomness request supplies a subject that is longer than the
allowed limit
([Subtensor API Errors: RandomSubjectTooLong](https://docs.learnbittensor.org/subtensor-api/errors#randomsubjecttoolong)).

## Distinction from Too Many Topics

`RandomSubjectTooLong` and `TooManyTopics` both reject oversized inputs, but they apply to different
parts of a contracts call. `RandomSubjectTooLong` rejects a randomness request because its subject
is too long. `TooManyTopics` rejects an event deposit because it includes more topics than the
runtime allows
([Subtensor API Errors: RandomSubjectTooLong](https://docs.learnbittensor.org/subtensor-api/errors#randomsubjecttoolong),
[Subtensor API Errors: TooManyTopics](https://docs.learnbittensor.org/subtensor-api/errors#toomanytopics)).

- **RandomSubjectTooLong** — the randomness subject exceeds its length limit.
- **TooManyTopics** — the event deposit includes too many topics.

## Distinction from Value Too Large

`RandomSubjectTooLong` and `ValueTooLarge` both describe limit checks, but they name different
inputs. `RandomSubjectTooLong` is about the subject supplied with a randomness request.
`ValueTooLarge` is about a contracts value whose size exceeds the runtime's configured maximum
([Subtensor API Errors: RandomSubjectTooLong](https://docs.learnbittensor.org/subtensor-api/errors#randomsubjecttoolong),
[Subtensor API Errors: ValueTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#valuetoolarge)).

- **RandomSubjectTooLong** — the randomness subject is too long.
- **ValueTooLarge** — the value itself exceeds the configured size limit.
