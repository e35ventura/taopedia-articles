# Gas Limit Too Low

`GasLimitTooLow` is an EVM pallet error raised when the submitted gas limit is below the required
minimum. The API errors reference summarizes it as "Gas limit is too low"
([Subtensor API Errors: GasLimitTooLow](https://docs.learnbittensor.org/subtensor-api/errors#gaslimittoolow)).

## What It Means

Bittensor's EVM layer executes Ethereum-compatible transactions on Subtensor and validates gas
parameters before running the call. `GasLimitTooLow` means the submitted gas limit is under the
runtime floor for that transaction, so the EVM path rejects the call before execution proceeds
([Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials),
[Subtensor API Errors: GasLimitTooLow](https://docs.learnbittensor.org/subtensor-api/errors#gaslimittoolow)).

This is a gas-limit floor rejection. It does not, by itself, mean the gas limit exceeded the
maximum, that the gas price was too low, or that fee conversion overflowed.

## Why It Appears

This error appears when an EVM transaction or contract call names a gas limit below what the runtime
requires for that submission. The practical meaning is narrow: raise the gas limit to at least the
required minimum before resubmitting the same call
([Subtensor API Errors: GasLimitTooLow](https://docs.learnbittensor.org/subtensor-api/errors#gaslimittoolow),
[Token Bridging](https://docs.learnbittensor.org/evm-tutorials/bridge-vtao)).

## Distinction from Gas Limit Too High

`GasLimitTooLow` and `GasLimitTooHigh` both reject EVM gas-limit parameters, but on opposite bounds.
`GasLimitTooLow` means the submitted limit is below the required minimum. `GasLimitTooHigh` means
the submitted limit exceeds the runtime maximum
([Subtensor API Errors: GasLimitTooHigh](https://docs.learnbittensor.org/subtensor-api/errors#gaslimittoohigh),
[Subtensor API Errors: GasLimitTooLow](https://docs.learnbittensor.org/subtensor-api/errors#gaslimittoolow)).

- **GasLimitTooLow** — the submitted gas limit is below the required minimum.
- **GasLimitTooHigh** — the submitted gas limit exceeds the allowed maximum.

## Distinction from Gas Price Too Low

`GasLimitTooLow` and `GasPriceTooLow` both block EVM transaction submission, but they reject
different parameters. `GasLimitTooLow` means the gas limit field is below the runtime minimum.
`GasPriceTooLow` means the gas price field is below the required floor
([Subtensor API Errors: GasPriceTooLow](https://docs.learnbittensor.org/subtensor-api/errors#gaspricetoolow),
[Subtensor API Errors: GasLimitTooLow](https://docs.learnbittensor.org/subtensor-api/errors#gaslimittoolow)).

- **GasLimitTooLow** — the submitted gas limit is below the required minimum.
- **GasPriceTooLow** — the submitted gas price is below the required minimum.

## Reader Boundary

This page defines the meaning of the error label and the gas-limit floor check it represents on EVM
paths. It does not report the live minimum gas limit configured on a network or estimate gas for a
specific contract call; those depend on runtime settings and call parameters at submission time
([Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
