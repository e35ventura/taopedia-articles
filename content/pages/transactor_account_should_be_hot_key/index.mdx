# Transactor Account Should Be Hot Key

`TransactorAccountShouldBeHotKey` is a subtensor pallet error. The API errors reference describes it
as "The hotkey is required to be the origin."
([Subtensor API Errors: TransactorAccountShouldBeHotKey](https://docs.learnbittensor.org/subtensor-api/errors#transactoraccountshouldbehotkey)).

## What It Means

Some subtensor operations require the hotkey itself to be the calling account.
`TransactorAccountShouldBeHotKey` fires when such an operation is called by an account that is not
the hotkey
([Subtensor API Errors: TransactorAccountShouldBeHotKey](https://docs.learnbittensor.org/subtensor-api/errors#transactoraccountshouldbehotkey)).

This is a hotkey-origin rejection. It does not, by itself, mean the coldkey was not associated with
the hotkey, that the caller was not a subnet owner, or that the operation was rate-limited.

## Why It Appears

This error appears when an operation that requires the hotkey as origin is submitted by a different
account
([Subtensor API Errors: TransactorAccountShouldBeHotKey](https://docs.learnbittensor.org/subtensor-api/errors#transactoraccountshouldbehotkey)).

## Distinction from Non Associated Cold Key

`NonAssociatedColdKey` is documented as "Request to stake, unstake or subscribe is made by a coldkey
that is not associated with the hotkey account." `TransactorAccountShouldBeHotKey` is documented as
"The hotkey is required to be the origin." Both are origin checks, but one rejects an unassociated
coldkey while the other rejects any account that is not the hotkey itself
([Subtensor API Errors: TransactorAccountShouldBeHotKey](https://docs.learnbittensor.org/subtensor-api/errors#transactoraccountshouldbehotkey),
[Subtensor API Errors: NonAssociatedColdKey](https://docs.learnbittensor.org/subtensor-api/errors#nonassociatedcoldkey)).

- **TransactorAccountShouldBeHotKey** — the caller is not the hotkey.
- **NonAssociatedColdKey** — the caller's coldkey is not linked to the hotkey.

## Distinction from Not Subnet Owner

`NotSubnetOwner` is documented as "Not a subnet owner." `TransactorAccountShouldBeHotKey` is
documented as "The hotkey is required to be the origin." Both are identity checks, but one checks
subnet ownership while the other checks whether the caller is the hotkey
([Subtensor API Errors: TransactorAccountShouldBeHotKey](https://docs.learnbittensor.org/subtensor-api/errors#transactoraccountshouldbehotkey),
[Subtensor API Errors: NotSubnetOwner](https://docs.learnbittensor.org/subtensor-api/errors#notsubnetowner)).

- **TransactorAccountShouldBeHotKey** — the caller is not the hotkey.
- **NotSubnetOwner** — the caller is not the subnet owner.
