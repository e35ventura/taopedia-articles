# Sub Network Does Not Exist

`SubNetworkDoesNotExist` is a subtensor pallet error raised when the specified subnet cannot be
found. The standard-errors reference describes it as "The specified subnet does not exist"
([Subtensor Standard Errors: SubNetworkDoesNotExist](https://docs.learnbittensor.org/errors/subtensor#subnetworkdoesnotexist)).

## What It Means

`SubNetworkDoesNotExist` means the call was blocked because the netuid provided does not correspond
to any subnet present in chain state
([Subtensor Standard Errors: SubNetworkDoesNotExist](https://docs.learnbittensor.org/errors/subtensor#subnetworkdoesnotexist)).

This is a subnet existence check. It does not mean the caller lacks permission to act on the subnet.

## Why It Appears

This error appears when a subtensor call is submitted with a netuid that does not correspond to an
existing subnet
([Subtensor Standard Errors: SubNetworkDoesNotExist](https://docs.learnbittensor.org/errors/subtensor#subnetworkdoesnotexist)).

## Distinction from Subnet Not Exists

`SubNetworkDoesNotExist` is documented as "The specified subnet does not exist." `SubnetNotExists`
is documented as "Trying to perform action on non-existent subnet." Both are raised when a netuid
does not match an existing subnet, but their documented descriptions describe the condition
differently
([Subtensor Standard Errors: SubNetworkDoesNotExist](https://docs.learnbittensor.org/errors/subtensor#subnetworkdoesnotexist),
[Subtensor API Errors: SubnetNotExists](https://docs.learnbittensor.org/subtensor-api/errors#subnetnotexists)).

- **SubNetworkDoesNotExist** -- the specified subnet does not exist.
- **SubnetNotExists** -- an action was attempted on a non-existent subnet.

## Distinction from Root Network Does Not Exist

`SubNetworkDoesNotExist` is documented as "The specified subnet does not exist."
`RootNetworkDoesNotExist` is documented as "The root network does not exist." Both involve a subnet
that cannot be found, but their documented conditions describe different targets
([Subtensor Standard Errors: SubNetworkDoesNotExist](https://docs.learnbittensor.org/errors/subtensor#subnetworkdoesnotexist),
[Subtensor API Errors: RootNetworkDoesNotExist](https://docs.learnbittensor.org/subtensor-api/errors#rootnetworkdoesnotexist)).

- **SubNetworkDoesNotExist** -- the specified subnet does not exist.
- **RootNetworkDoesNotExist** -- the root network does not exist.
