# Proxy Deposit Base

Proxy deposit base is a proxy pallet runtime constant, listed in the Subtensor constants reference
as proxyDepositBase with a value of 60000000. The proxy pallet defines it as the base amount of
currency reserved for creating a proxy, held for the storage item that keeps an account's proxy list
([Subtensor API Constants: proxyDepositBase](https://docs.learnbittensor.org/subtensor-api/constants#proxydepositbase-u64)).
The Subtensor runtime sets this constant as ProxyDepositBase and wires it into the proxy pallet
configuration
([runtime/src/lib.rs](https://github.com/opentensor/subtensor/blob/main/runtime/src/lib.rs)).

## What It Means

When an account registers its first proxy, the runtime reserves a deposit so the on-chain proxy list
is backed by locked balance rather than created for free. Proxy deposit base is the fixed part of
that reserve: it is charged once for the storage item that holds the account's proxy list, separate
from the per-proxy amount added for each delegate
([Subtensor API Constants: proxyDepositBase](https://docs.learnbittensor.org/subtensor-api/constants#proxydepositbase-u64),
[frame/proxy pallet](https://github.com/paritytech/polkadot-sdk/blob/master/substrate/frame/proxy/src/lib.rs)).

The value is denominated in the base unit of the balance (RAO), so 60000000 is 0.06 TAO given TAO's
nine decimal places. The deposit is reserved, not spent, and is returned when the proxy entries it
backs are removed.

## Why It Matters

Reserving a base deposit ties proxy creation to locked balance, which discourages an account from
opening proxy storage it does not intend to use. Together with the per-proxy factor, the base sets
the total reserve for a proxy list as base plus factor times the number of proxies, so the reserved
balance scales with how many delegates an account holds
([frame/proxy pallet](https://github.com/paritytech/polkadot-sdk/blob/master/substrate/frame/proxy/src/lib.rs),
[Subtensor API Constants: proxyDepositBase](https://docs.learnbittensor.org/subtensor-api/constants#proxydepositbase-u64)).

## Distinction from Proxy Deposit Factor

Proxy deposit base is the fixed reserve charged once for holding a proxy list; proxy deposit factor
is the amount added per proxy delegate. The base prices the list's existence and the factor prices
each entry, so the full proxy deposit is the base plus the factor for every proxy
([Subtensor API Constants: proxyDepositBase](https://docs.learnbittensor.org/subtensor-api/constants#proxydepositbase-u64),
[Subtensor API Constants: proxyDepositFactor](https://docs.learnbittensor.org/subtensor-api/constants#proxydepositfactor-u64)).

- **Proxy deposit base**: fixed reserve charged once for the proxy list.
- **Proxy deposit factor**: reserve added per proxy delegate.

## Distinction from Announcement Deposit Base

Proxy deposit base reserves balance for holding an account's proxy list. Announcement deposit base
reserves balance for creating a time-delayed announcement, which is a separate storage item and a
separate deposit from the proxy list itself
([Subtensor API Constants: proxyDepositBase](https://docs.learnbittensor.org/subtensor-api/constants#proxydepositbase-u64),
[Subtensor API Constants: announcementDepositBase](https://docs.learnbittensor.org/subtensor-api/constants#announcementdepositbase-u64)).

- **Proxy deposit base**: base reserve for the proxy list.
- **Announcement deposit base**: base reserve for the announcement store.

## Reader Boundary

This page defines the base component of the proxy deposit. It does not price the full deposit for a
given account, report a specific account's reserved balance, or describe the individual proxy types
an account can assign
([Subtensor API Constants: proxyDepositBase](https://docs.learnbittensor.org/subtensor-api/constants#proxydepositbase-u64)).
