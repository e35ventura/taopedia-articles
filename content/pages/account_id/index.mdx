# Account ID

Account ID is Bittensor wallet-key vocabulary for account-reference material. The
[Glossary: Account ID](https://docs.learnbittensor.org/resources/glossary#account-id) names the term
directly, and the [Working with Keys](https://docs.learnbittensor.org/keys/working-with-keys) guide
shows `accountId` stored alongside `publicKey` and `ss58Address` in a wallet's public key file.

## What It Represents

Account ID belongs to the public reference side of wallet identity, not the private signing side.
The wallet-file example in
[Working with Keys](https://docs.learnbittensor.org/keys/working-with-keys) presents `accountId`
with other shareable reference fields while secret fields stay absent from the public file. That
keeps account-reference vocabulary separate from private-key or mnemonic vocabulary
([Glossary: Account ID](https://docs.learnbittensor.org/resources/glossary#account-id),
[Working with Keys](https://docs.learnbittensor.org/keys/working-with-keys)).

Readers should treat account ID as account-reference terminology rather than as transfer
instructions, custody proof, or a subnet role. It helps identify which account records refer to, but
it does not by itself authorize stake movement, transfers, or subnet operations
([Glossary: Account ID](https://docs.learnbittensor.org/resources/glossary#account-id),
[Glossary: Private Key](https://docs.learnbittensor.org/resources/glossary#private-key)).

## Distinction from Wallet Address

A wallet address is the public destination identifier used for sending and receiving TAO. Account ID
names account-reference material, while wallet-address vocabulary names the destination role that
other participants use when they send funds
([Glossary: Wallet Address](https://docs.learnbittensor.org/resources/glossary#wallet-address),
[Glossary: Account ID](https://docs.learnbittensor.org/resources/glossary#account-id)).

- **Account ID** — account-reference material.
- **Wallet address** — public destination identifier for TAO transfers.

## Distinction from Public Key

Public key names the shareable cryptographic side of a keypair used for verification and account
reference. Account ID is the account-reference field recorded alongside that public key in wallet
materials, so one names the cryptographic pair side and the other names the account identifier in
reference context
([Glossary: Public Key](https://docs.learnbittensor.org/resources/glossary#public-key),
[Working with Keys](https://docs.learnbittensor.org/keys/working-with-keys),
[Glossary: Account ID](https://docs.learnbittensor.org/resources/glossary#account-id)).

- **Public key** — shareable cryptographic key material.
- **Account ID** — account-reference identifier recorded alongside it.

## Distinction from SS58 Encoded

SS58 encoded names the compact display format for public-key-derived native Bittensor addresses.
Account ID is account-reference vocabulary rather than address-format vocabulary, so SS58 answers
how a native address is presented while account ID answers which account reference is being named
([Glossary: SS58 Encoded](https://docs.learnbittensor.org/resources/glossary#ss58-encoded),
[Glossary: Account ID](https://docs.learnbittensor.org/resources/glossary#account-id)).

- **SS58 encoded** — compact address display format.
- **Account ID** — account-reference identifier.

## Reader Boundary

Account ID should not be read as a private key, a mnemonic, a transfer action, or a subnet role. It
names public account-reference material in wallet-key context
([Glossary: Account ID](https://docs.learnbittensor.org/resources/glossary#account-id)).
