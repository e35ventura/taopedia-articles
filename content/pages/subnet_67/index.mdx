Harnyx is Bittensor Subnet 67, a subnet for deep research. It treats research not as a single
reasoning step but as a workflow — decomposing a question, retrieving sources, ranking and
cross-checking them, and synthesizing an answer — and turns that workflow into an open competition.
Miners build the research agents, validators run and score them, and the network returns answers
with traceable provenance. The incentive-mechanism code is maintained in the
[harnyx/harnyx](https://github.com/harnyx/harnyx) repository.

## What the Subnet Produces

The subnet's output is researched answers to standalone queries. According to the repository, the
platform builds tasks by generating research-style questions and, for each one, a stronger reference
answer using a more expensive model than a typical miner would run. The questions are deliberately
mixed across factual recall, explanation, comparison, and synthesis, so a miner needs genuine search
and reasoning behavior rather than memorized responses. The premise the project states is that
better research harnesses compound faster than better models alone.

## Miner and Validator Roles

Miners submit Python agents that answer a query under a tight tool budget. The agent is the
deliverable: a miner improves by building a workflow that produces better-researched answers within
the allowed cost.

Validators run each agent in a sandboxed container against the task set and score its answer against
the reference. The repository describes scoring by pairwise comparison against the reference answer,
judged twice with the order swapped to reduce bias, with ties broken in favor of lower tool cost.
Rather than simply crowning the top score in a batch, the subnet keeps an incumbent "champion" and
only replaces it when a challenger clearly beats it under a defined rule. Those validator scores
become the weights that feed into [[Yuma Consensus]], which converts them into the incentive split
across miners and validators.

## On-Chain Identity

Live SN67 data, including metagraph state and alpha token pool information, is available on
[TaoStats](https://taostats.io/subnets/67). Readers can reproduce the subnet's registered identity
fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 67 --network finney`.

The Finney subnet identity for netuid 67 points to the
[harnyx/harnyx](https://github.com/harnyx/harnyx) repository, which is the source of truth for the
task, scoring, and champion-selection process described above.
