# Non-fast Blocks

Non-fast blocks describe ordinary block timing in contrast with fast blocks. Official Bittensor
documentation uses the term in local development context, where fast blocks are a development-only
configuration for accelerated block production.

References:
[Glossary: Non-fast blocks](https://docs.learnbittensor.org/resources/glossary#non-fast-blocks),
[Glossary: Fast blocks](https://docs.learnbittensor.org/resources/glossary#fast-blocks)

## Local Development Context

The term is most useful when comparing local testing modes. Fast blocks shorten feedback loops in a
local chain, while non-fast blocks describe the non-accelerated timing side of that distinction.
Both terms belong to development context rather than a separate public network role.

References:
[Glossary: Non-fast blocks](https://docs.learnbittensor.org/resources/glossary#non-fast-blocks),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)

## Reader Boundary

This page defines the term. It does not describe live mainnet timing, a subnet mechanism, or a node
setup procedure. Readers should use current official local development documentation when they need
environment-specific setup details.
