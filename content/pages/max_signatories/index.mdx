# Max Signatories

Max signatories is a multisig pallet runtime constant, listed in the chain's constants metadata as
maxSignatories, with the value 100 and the summary "The maximum amount of signatories allowed in the
multisig"
([Subtensor API Constants: maxSignatories](https://docs.learnbittensor.org/subtensor-api/constants#maxsignatories-u32)).
The runtime sets this bound directly
([runtime/src/lib.rs](https://github.com/opentensor/subtensor/blob/14bc6f9f964b9cc362e9635dd110a487fa5d15a0/runtime/src/lib.rs#L558)).

## What It Means

A multisig operation requires a list of signatory accounts that must approve the call before it
executes. The `maxSignatories` constant caps that list at 100 entries. When a multisig call submits
a signatory list longer than 100, the runtime rejects it with `TooManySignatories` before any
approval logic runs
([Subtensor API Errors: TooManySignatories](https://docs.learnbittensor.org/subtensor-api/errors#toomanysignatories)).
