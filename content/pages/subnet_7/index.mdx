# Subnet 7: Allways

Allways is Bittensor Subnet 7 (SN7), operated by [entrius](https://github.com/entrius/allways). It
implements a universal transaction layer that enables trustless native asset swaps across
independent blockchains without wrapping or bridging. Assets move natively on their home chains; the
subnet provides the verification and enforcement layer above them. The protocol is currently live
with BTC ↔ TAO and is designed to extend to any verifiable asset pair.

References: [entrius/allways (GitHub)](https://github.com/entrius/allways),
[all-ways.io](https://all-ways.io/)

## How the Mechanism Works

Allways coordinates four components to execute trustless swaps:
[entrius/allways architecture (GitHub)](https://github.com/entrius/allways#architecture)

Miners post exchange rate pairs and lock collateral backing those rates. When a user submits a swap
order, a miner fulfills it by executing native on-chain transactions on both sides of the pair.
Validators then independently monitor the transactions miners claim to have executed, verify the
on-chain state of both assets, and vote on whether each swap outcome is valid. A smart contract
holds miner collateral, manages the swap lifecycle from posting through settlement, and applies
slashing to miners whose claimed fulfillments are rejected by validator consensus. A CLI tool
provides the user-facing interface for posting rate pairs, depositing collateral, and executing
swaps.

Because validators verify native on-chain transactions independently of the miners, the protocol
requires no trusted custodian. Incorrect or fraudulent fulfillments are slashed from miner
collateral, aligning miner incentives with honest execution. Validator scores flow into
[[Yuma Consensus]], which translates them into per-block emissions.

## Participating as a Miner

Miners on Allways act as liquidity providers and order fulfillers. They register a hotkey on SN7,
set up the Allways software with access to both a TAO wallet and a Bitcoin node, then post exchange
rate pairs and lock collateral via the `alw` CLI. When a swap order arrives that matches their
posted rate, their node executes the native transactions on both chains and reports the outcome to
the subnet.

Rewards are earned on every accurately fulfilled swap. Collateral is slashed when validators reject
a claimed fulfillment, so miners must maintain reliable connections to both chains, price their
rates conservatively, and keep their nodes online continuously.

Reference: [entrius/allways (GitHub)](https://github.com/entrius/allways#getting-started)

## Participating as a Validator

Validators on Allways watch miner rate commitments and independently verify native transaction
outcomes on both chains for every claimed fulfillment. They register a hotkey on SN7, run the
Allways validator software, and submit weight scores based on whether miner-reported swap outcomes
match verified on-chain state. The Allways documentation recommends that validators run their own
Subtensor lite node to reduce latency and ensure independent chain access. Validator scores feed
into [[Yuma Consensus]] to determine per-block miner emissions.

Reference:
[entrius/allways validator docs (GitHub)](https://github.com/entrius/allways#running-a-local-subtensor-lite-node-validators)
