# Subnet 7: Allways

Allways is Bittensor Subnet 7. The live on-chain identity lists the subnet name as Allways and
describes it as a "universal transaction layer." The project's official repository describes Allways
as a system for trustless native transactions across independent assets and says it is currently
live with BTC ↔ TAO.

References: [entrius/allways (GitHub)](https://github.com/entrius/allways),
[all-ways.io](https://all-ways.io/)

## What Allways Provides

According to the official repository, Allways is built around a miner-validator structure with a
smart contract layer. The README says miners complete transactions, validators independently verify
the results, and a smart contract enforces outcomes through collateral and slashing.

The same source says the protocol is designed for native transactions across independent assets
rather than a wrapped-asset model. Its high-level architecture section lists four public components:

- **Miners:** post exchange rate pairs and collateral, then fulfill swap orders.
- **Validators:** monitor swaps, verify on-chain transactions, and vote on outcomes.
- **Smart contract:** manages collateral, the swap lifecycle, and validator voting.
- **CLI:** the user-facing interface for posting pairs, managing collateral, and executing swaps.

Reference: [entrius/allways (GitHub)](https://github.com/entrius/allways)

## Miner and Validator Roles

Allways follows the standard Bittensor subnet pattern. Miners provide the work described by the
subnet, and validators evaluate miner performance and set weights. Those validator assessments feed
into [[Yuma Consensus]], which determines how subnet emissions are distributed.

References: [entrius/allways (GitHub)](https://github.com/entrius/allways), [[Yuma Consensus]]
