# Subnet 7: Allways

Allways is Bittensor Subnet 7 (SN7), operated by [entrius](https://github.com/entrius/allways). It
implements a universal transaction layer that enables trustless native asset swaps across
independent blockchains without wrapping or bridging. Assets move natively on their home chains; the
subnet provides the verification and enforcement layer above them. The protocol is currently live
with BTC ↔ TAO and is designed to extend to any verifiable asset pair.

References: [entrius/allways (GitHub)](https://github.com/entrius/allways),
[all-ways.io](https://all-ways.io/)

## How the Mechanism Works

Allways operates through four coordinated components:

- **Miners** post exchange rate pairs and lock collateral against those rates. When a user submits a
  swap order, a miner fulfills it by executing the native on-chain transactions on both sides.
- **Validators** independently monitor the transactions miners claim to have executed. They verify
  the on-chain state of both assets, then vote on whether each swap outcome is valid.
- **Smart Contract** holds miner collateral, manages the swap lifecycle (posted → matched → verified
  → settled), and applies slashing to miners whose claimed fulfillments are rejected by validator
  consensus.
- **CLI** (`alw`) provides the user-facing interface for posting rate pairs, depositing collateral,
  and executing swaps.

Because validators verify native on-chain transactions independently of the miners, the protocol
requires no trusted custodian. Incorrect or fraudulent fulfillments are slashed from miner
collateral, aligning miner incentives with honest execution. Validator scores flow into
[[Yuma Consensus]], which translates them into per-block emissions.

References: [entrius/allways architecture (GitHub)](https://github.com/entrius/allways#architecture)

## Participating as a Miner

Miners provide liquidity and order fulfillment. They register a hotkey on SN7, install the Allways
repo (Python 3.10+, Docker, and Docker Compose are required), and run the miner container with their
wallet and Bitcoin node configuration. Once running, miners post exchange rate pairs and lock
collateral via the `alw` CLI.

Miners earn rewards by fulfilling swap orders accurately. Collateral is slashed when validators
reject a claimed fulfillment, so miners must maintain reliable connections to both chains and price
their rates conservatively.

References: [entrius/allways (GitHub)](https://github.com/entrius/allways#getting-started)

## Participating as a Validator

Validators monitor miner rate commitments and verify native transaction outcomes on both chains.
They register a hotkey on SN7, configure their wallet and network settings, and run the validator
container. Validators read miner rate commitments approximately every three minutes and stream
contract events every block. The Allways documentation recommends that each validator run its own
Subtensor lite node to reduce latency and avoid congesting the public Finney endpoint.

References:
[entrius/allways validator storage (GitHub)](https://github.com/entrius/allways#validator-storage-layout),
[lite-node setup (GitHub)](https://github.com/entrius/allways#running-a-local-subtensor-lite-node-validators)
