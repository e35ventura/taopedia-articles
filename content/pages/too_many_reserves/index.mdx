# Too Many Reserves

`TooManyReserves` is a balances pallet error raised when placing a new named reserve on an account
would exceed the configured maximum number of named reserves. The API docs describe it as "Number of
named reserves exceed `MaxReserves`"
([Subtensor API Errors: TooManyReserves](https://docs.learnbittensor.org/subtensor-api/errors#toomanyreserves)).

## What It Means

Each account may hold a limited number of named reserves at the same time. `TooManyReserves` fires
when a pallet attempts to add a named reserve to an account that already has the maximum number
([Subtensor API Errors: TooManyReserves](https://docs.learnbittensor.org/subtensor-api/errors#toomanyreserves)).

## Why It Appears

This error appears when a pallet tries to place a named reserve on an account and the insertion
fails because the account's named-reserve list has reached `MaxReserves`
([Subtensor API Errors: TooManyReserves](https://docs.learnbittensor.org/subtensor-api/errors#toomanyreserves)).

## Distinction from Too Many Holds

`TooManyReserves` and `TooManyHolds` both block pallet-initiated balance operations, but they apply
to different balance mechanisms. `TooManyReserves` fires when the named-reserve count is exceeded.
`TooManyHolds` fires when the holds count is exceeded
([Subtensor API Errors: TooManyHolds](https://docs.learnbittensor.org/subtensor-api/errors#toomanyholds)).

- **TooManyReserves** — named-reserve count is at the limit.
- **TooManyHolds** — holds count is at the limit.

## Distinction from Too Many Freezes

`TooManyReserves` and `TooManyFreezes` both block pallet-initiated balance operations, but they
apply to different balance mechanisms. `TooManyReserves` fires when the named-reserve count is
exceeded. `TooManyFreezes` fires when the freeze count is exceeded
([Subtensor API Errors: TooManyFreezes](https://docs.learnbittensor.org/subtensor-api/errors#toomanyfreezes)).

- **TooManyReserves** — named-reserve count is at the limit.
- **TooManyFreezes** — freeze count is at the limit.

## Reader Boundary

This page defines the meaning of the error label and the named-reserve count check that raises it.
It does not report the current number of named reserves on any account; that is live chain state
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
