# Issuance Deactivated

`IssuanceDeactivated` is a balances pallet error raised when a balances issuance modification is
attempted while issuance is already deactivated. The API errors reference documents this error on
the issuance path
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

## What It Means

The balances pallet tracks the total issuance of the chain's native token. When issuance is
deactivated, certain modifications to the total supply are blocked. `IssuanceDeactivated` fires when
such a modification is attempted while issuance is in the deactivated state
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

This is a not-deactivated rejection, not proof that the account lacked balance, that the existential
deposit was not met, or that liquidity restrictions blocked the operation.

## Why It Appears

This error appears when a balances issuance modification is submitted and issuance is currently
deactivated, so the pallet rejects the request
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

## Distinction from Insufficient Balance

`IssuanceDeactivated` and `InsufficientBalance` are both balances-pallet errors that block a balance
operation, but they fire at different checks. `IssuanceDeactivated` fires when issuance is
deactivated. `InsufficientBalance` fires when the account's balance is too low
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated),
[Subtensor API Errors: InsufficientBalance](https://docs.learnbittensor.org/subtensor-api/errors#insufficientbalance)).

- **IssuanceDeactivated** — issuance is currently deactivated.
- **InsufficientBalance** — the account balance is too low.

## Distinction from Delta Zero

`IssuanceDeactivated` and `DeltaZero` are both balances-pallet errors that block a balance
operation, but they fire at different checks. `IssuanceDeactivated` fires when issuance is
deactivated. `DeltaZero` fires when the submitted delta amount is zero
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated),
[Subtensor API Errors: DeltaZero](https://docs.learnbittensor.org/subtensor-api/errors#deltazero)).

- **IssuanceDeactivated** — issuance is currently deactivated.
- **DeltaZero** — the submitted delta amount is zero.

## Reader Boundary

This page defines the meaning of the error label and the not-deactivated guard it represents on the
issuance path. It does not report whether issuance is currently activated, describe the governance
process that toggles issuance, or list the extrinsics that modify total supply
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).
