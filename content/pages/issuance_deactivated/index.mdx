# Issuance Deactivated

`IssuanceDeactivated` is a balances pallet error fired when an operation that modifies total
issuance is rejected because issuance tracking is deactivated. The API docs describe it as "The
issuance cannot be modified since it is already deactivated"
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

## What It Means

This error is an issuance-state rejection. The account's balance level and the submitted amount are
not the cause; the cause is the deactivated state of the pallet's issuance tracking
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

## Why It Appears

This error appears when an operation that would change the total issuance is submitted while the
balances pallet's issuance tracking is in a deactivated state
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

## Distinction from Insufficient Balance

`IssuanceDeactivated` and `InsufficientBalance` are both balances pallet errors, but they represent
different checks. `InsufficientBalance` fires when an account's balance is too low to send value.
`IssuanceDeactivated` fires when the issuance tracking is deactivated
([Subtensor API Errors: InsufficientBalance](https://docs.learnbittensor.org/subtensor-api/errors#insufficientbalance),
[Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

- **InsufficientBalance** — account balance is too low to send value.
- **IssuanceDeactivated** — issuance tracking is deactivated; modification is blocked.

## Distinction from Delta Zero

`IssuanceDeactivated` and `DeltaZero` are both balances pallet errors, but they represent different
conditions. `DeltaZero` fires when a submitted delta is zero. `IssuanceDeactivated` fires when
issuance tracking is deactivated
([Subtensor API Errors: DeltaZero](https://docs.learnbittensor.org/subtensor-api/errors#deltazero),
[Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

- **DeltaZero** — the submitted delta is zero.
- **IssuanceDeactivated** — issuance tracking is deactivated.

## Reader Boundary

This page defines the meaning of `IssuanceDeactivated` and the issuance-state check it represents.
It does not describe how to enable or disable issuance tracking, report the current issuance state,
or list the extrinsics that modify issuance
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
