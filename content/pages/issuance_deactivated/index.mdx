# Issuance Deactivated

`IssuanceDeactivated` is a balances pallet error raised when code attempts to modify the total
issuance after it has already been deactivated. The API errors reference describes it as "The
issuance cannot be modified since it is already deactivated."
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

## What It Means

The balances pallet tracks total issuance — the circulating supply of the native token. When
issuance accounting is deactivated, the pallet blocks any further modifications to that total.
`IssuanceDeactivated` fires when a modification is attempted against the total issuance in that
deactivated state
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

This is a deactivation-state rejection on the issuance accounting path. It does not mean a transfer
failed because of insufficient balance, that a liquidity restriction blocked a spend, or that a
vesting schedule conflict was detected.

## Why It Appears

This error appears when an operation on the balances pallet attempts to adjust the total issuance
value and the issuance accounting is already in the deactivated state
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

## Distinction from Liquidity Restrictions

`IssuanceDeactivated` and `LiquidityRestrictions` both block balance operations in the balances
pallet, but they fire on different paths. `LiquidityRestrictions` fires when a spend or transfer is
blocked by a lock or restriction on an individual account. `IssuanceDeactivated` fires when an
operation tries to change the total issuance and that accounting has been deactivated
([Subtensor API Errors: LiquidityRestrictions](https://docs.learnbittensor.org/subtensor-api/errors#liquidityrestrictions),
[Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

- **IssuanceDeactivated** — total-issuance modification blocked because issuance is deactivated.
- **LiquidityRestrictions** — account-level spend blocked by a lock or restriction.

## Distinction from Insufficient Balance

`IssuanceDeactivated` and `InsufficientBalance` both appear on the balances pallet, but they block
different things. `InsufficientBalance` fires when an individual account does not have enough free
balance for the requested amount. `IssuanceDeactivated` fires when the total-issuance accounting
itself is in a deactivated state and cannot be modified
([Subtensor API Errors: InsufficientBalance](https://docs.learnbittensor.org/subtensor-api/errors#insufficientbalance),
[Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

- **IssuanceDeactivated** — supply-level accounting is deactivated; modification is rejected.
- **InsufficientBalance** — account-level free balance is too low for the operation.
