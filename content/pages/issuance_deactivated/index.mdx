# Issuance Deactivated

`IssuanceDeactivated` is a balances pallet error raised when a total-supply modification is
attempted while issuance is in the deactivated state
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

## What It Means

The balances pallet tracks the total supply of the chain's native token. When issuance is
deactivated, the pallet blocks operations that would modify the total supply — such as minting or
burning — until issuance is reactivated. This guard protects against supply changes during windows
where the chain has intentionally frozen issuance
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

## Distinction from Insufficient Balance

`IssuanceDeactivated` fires on the total-supply path when the chain has frozen issuance.
`InsufficientBalance` fires on the account path when the sender's balance is too low to cover the
transfer
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated),
[Subtensor API Errors: InsufficientBalance](https://docs.learnbittensor.org/subtensor-api/errors#insufficientbalance)).

- **IssuanceDeactivated** — the chain's total supply is frozen.
- **InsufficientBalance** — the sender's account balance is too low.

## Distinction from Delta Zero

`IssuanceDeactivated` fires when the chain has deactivated issuance entirely, regardless of the
submitted amount. `DeltaZero` fires when the submitted delta amount is zero, making the operation a
no-op
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated),
[Subtensor API Errors: DeltaZero](https://docs.learnbittensor.org/subtensor-api/errors#deltazero)).

- **IssuanceDeactivated** — issuance is frozen at the chain level.
- **DeltaZero** — the submitted amount is zero.

## Reader Boundary

This page defines the error label and the not-deactivated guard on the total-supply path. It does
not report whether issuance is currently activated or describe the governance flow that toggles it
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).
