# Issuance Deactivated

`IssuanceDeactivated` is a balances pallet error raised when an issuance modification is rejected
because issuance is already deactivated. The API errors reference describes it as "The issuance
cannot be modified since it is already deactivated"
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

## What It Means

`IssuanceDeactivated` means the balances pallet rejected an issuance modification because issuance
is already in a deactivated state
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

## Why It Appears

This error appears when a call that would modify issuance is submitted while issuance is already
deactivated
([Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

## Distinction from Insufficient Balance

`IssuanceDeactivated` and `InsufficientBalance` are separate balances pallet errors with different
API summaries. `InsufficientBalance` is documented as "Balance too low to send value."
`IssuanceDeactivated` is documented as "The issuance cannot be modified since it is already
deactivated"
([Subtensor API Errors: InsufficientBalance](https://docs.learnbittensor.org/subtensor-api/errors#insufficientbalance),
[Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

- **InsufficientBalance** — balance too low to send value.
- **IssuanceDeactivated** — issuance cannot be modified because it is already deactivated.

## Distinction from Delta Zero

`IssuanceDeactivated` and `DeltaZero` are separate balances pallet errors with different API
summaries. `DeltaZero` is documented as "The delta cannot be zero." `IssuanceDeactivated` is
documented as "The issuance cannot be modified since it is already deactivated"
([Subtensor API Errors: DeltaZero](https://docs.learnbittensor.org/subtensor-api/errors#deltazero),
[Subtensor API Errors: IssuanceDeactivated](https://docs.learnbittensor.org/subtensor-api/errors#issuancedeactivated)).

- **DeltaZero** — the delta cannot be zero.
- **IssuanceDeactivated** — issuance cannot be modified because it is already deactivated.
