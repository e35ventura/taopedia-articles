# Block

A block is a unit of data in the Bittensor blockchain. The
[Glossary](https://docs.learnbittensor.org/resources/glossary#block) describes a block as containing
a collection of transactions and a unique identifier called a block hash.

## Chain Timing Context

The glossary states that Bittensor processes one block every 12 seconds. The
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks) reference also
lists block processing for mainnet and testnet as one block every 12 seconds, while separating those
network contexts from localnet behavior.

## Emission Cadence Context

Each block is also the per-step interval at which emission injection happens. The
[Emission](https://docs.learnbittensor.org/learn/emissions) documentation describes injection as new
liquidity flowing into each subnet's pools every block, while distribution to participants is a
separate step that follows. For readers, this keeps the block as the per-step unit of the emission
process rather than only a unit of data: injection is paced by the block, and the later distribution
step is grouped across many blocks.

References: [Emission](https://docs.learnbittensor.org/learn/emissions)

## Reader Boundary

This article defines the term at a high level. It does not describe transaction submission, endpoint
details, current chain height, or any specific block record. Readers should use official network
references for network-specific timing context.
