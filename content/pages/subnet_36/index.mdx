Eirel is Bittensor Subnet 36, described in its Finney identity as an execution layer for multimodal
AI workflows. The GitHub repository listed in the subnet's Finney identity is
[RendixNetwork/eirel-ai](https://github.com/RendixNetwork/eirel-ai).

## What Eirel Provides

The Eirel README describes an owner control plane for the EIREL Bittensor subnet. Its
responsibilities include miner submissions, runtime deployments, evaluation orchestration, score
aggregation, and chain publication.

At the article level, Eirel is best understood as a workflow-execution subnet. Miners submit agents
that can be evaluated on structured tasks, validators run the judging side of the evaluation
process, and aggregated results are converted into subnet weights for [[Yuma Consensus]].

## Miner and Validator Roles

Miners provide agents that can be deployed into the subnet runtime and evaluated on task families.
The README describes the launch family as `general_chat`, a multi-turn assistant workflow backed by
owner-routed tools such as web search, URL fetch, a Python sandbox, and retrieval over per-run
document corpora.

Validators evaluate miner outputs. The README describes validators as claiming evaluation tasks,
invoking miners through the subnet infrastructure, judging results locally, and submitting those
results for aggregation. Operators should treat the repository as the source of truth for current
participant guidance.

## On-Chain Identity

Live SN36 data is available on [TaoStats](https://taostats.io/subnets/36). Readers can also
reproduce the chain identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 36 --network finney`.

That Finney identity reports the subnet name as Eirel, the subnet URL as eirel.ai, and the GitHub
repo as RendixNetwork/eirel-ai.
