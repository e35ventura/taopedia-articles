# Minimum Period

Minimum period is a timestamp pallet runtime constant, listed in the Subtensor constants reference
as minimumPeriod. Its current value is 6000, and the reference describes it as the minimum period
between blocks
([Subtensor API Constants: minimumPeriod](https://docs.learnbittensor.org/subtensor-api/constants#minimumperiod-u64)).
The Subtensor runtime wires the timestamp pallet minimum period as half of the runtime slot duration
([runtime/src/lib.rs](https://github.com/opentensor/subtensor/blob/14bc6f9f964b9cc362e9635dd110a487fa5d15a0/runtime/src/lib.rs#L408-L413)).

## What It Means

The value is expressed in milliseconds, so 6000 means six seconds. The constants reference warns
that minimum period is different from the expected period supplied by block production, and that the
chosen consensus system uses it to determine a sensible block time
([Subtensor API Constants: minimumPeriod](https://docs.learnbittensor.org/subtensor-api/constants#minimumperiod-u64)).

For readers, minimum period is best treated as the timestamp pallet's lower timing component rather
than as the whole block-production schedule. It helps explain why timing constants may appear in
related pairs instead of all naming the same interval.

## Distinction from Slot Duration

Minimum period and slot duration are related, but they name different timing constants. Minimum
period is the timestamp pallet value, currently 6000 milliseconds. Slot duration is the Aura pallet
value, currently 12000 milliseconds, and the constants reference describes it as the duration Aura
should run with
([Subtensor API Constants: minimumPeriod](https://docs.learnbittensor.org/subtensor-api/constants#minimumperiod-u64),
[Subtensor API Constants: slotDuration](https://docs.learnbittensor.org/subtensor-api/constants#slotduration-u64)).

- **Minimum period** - timestamp pallet minimum interval.
- **Slot duration** - Aura slot timing value.

## Reader Boundary

This page defines the current minimumPeriod constant. It does not report live block production
performance, promise that every observed block interval equals exactly six seconds, or replace
separate block-window constants such as blockHashCount
([Subtensor API Constants: minimumPeriod](https://docs.learnbittensor.org/subtensor-api/constants#minimumperiod-u64),
[Subtensor API Constants: blockHashCount](https://docs.learnbittensor.org/subtensor-api/constants#blockhashcount-u32)).
