# Hot Key Already Delegate

`HotKeyAlreadyDelegate` is a subtensor pallet error. The API errors reference describes it as "The
hotkey is attempting to become a delegate when the hotkey is already a delegate."
([Subtensor API Errors: HotKeyAlreadyDelegate](https://docs.learnbittensor.org/subtensor-api/errors#hotkeyalreadydelegate)).

## What It Means

A delegate is a validator that accepts staked TAO from delegators. Once a hotkey has registered as a
delegate, it cannot register again. `HotKeyAlreadyDelegate` fires when a second registration is
attempted for a hotkey that is already a delegate
([Subtensor API Errors: HotKeyAlreadyDelegate](https://docs.learnbittensor.org/subtensor-api/errors#hotkeyalreadydelegate)).

This is an already-delegate rejection. It does not, by itself, mean the hotkey was not registered in
any subnet, that the delegate take was out of range, or that the registration was rate-limited.

## Why It Appears

This error appears when a delegate registration call is submitted for a hotkey that is already
registered as a delegate
([Subtensor API Errors: HotKeyAlreadyDelegate](https://docs.learnbittensor.org/subtensor-api/errors#hotkeyalreadydelegate)).

## Distinction from Delegate Take Too High

`DelegateTakeTooHigh` is documented as "Delegate take is too high." `HotKeyAlreadyDelegate` is
documented as "The hotkey is attempting to become a delegate when the hotkey is already a delegate."
Both involve delegate operations, but their documented triggers describe different problems
([Subtensor API Errors: HotKeyAlreadyDelegate](https://docs.learnbittensor.org/subtensor-api/errors#hotkeyalreadydelegate),
[Subtensor API Errors: DelegateTakeTooHigh](https://docs.learnbittensor.org/subtensor-api/errors#delegatetaketoohigh)).

- **HotKeyAlreadyDelegate** — the hotkey is already a delegate.
- **DelegateTakeTooHigh** — the delegate commission take is above the maximum.

## Distinction from Delegate Tx Rate Limit Exceeded

`DelegateTxRateLimitExceeded` is documented as "A transactor exceeded the rate limit for delegate
transaction." `HotKeyAlreadyDelegate` is documented as "The hotkey is attempting to become a
delegate when the hotkey is already a delegate." Both involve delegate operations, but one is a
duplicate-registration rejection and the other is a pacing rejection
([Subtensor API Errors: HotKeyAlreadyDelegate](https://docs.learnbittensor.org/subtensor-api/errors#hotkeyalreadydelegate),
[Subtensor API Errors: DelegateTxRateLimitExceeded](https://docs.learnbittensor.org/subtensor-api/errors#delegatetxratelimitexceeded)).

- **HotKeyAlreadyDelegate** — the hotkey is already a delegate.
- **DelegateTxRateLimitExceeded** — the delegate transaction was rate-limited.
