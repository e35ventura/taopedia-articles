# Min Burn

Min burn is a per-subnet hyperparameter that sets the lower bound on the dynamic TAO burn required
to register a neuron on a subnet. Official documentation describes it as the lower bound for the
dynamic TAO burn required for neuron registration on the subnet, so it is the floor the registration
cost does not fall below.

References: [Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)

## What It Controls

The hyperparameter floors the registration burn. Registering a neuron requires burning TAO, and min
burn is the least that amount can be on the subnet. Because the cost cannot drop below it, regist
remains a baseline cost even when few neurons are registering, rather than approaching free.

Reference: [Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)

## A Dynamic Cost Within Bounds

The registration burn is dynamic. The documentation describes it as moving between this lower bound
and an upper bound: the cost rises as registrations occur and eases back during quieter periods,
while staying inside that band. Min burn anchors the bottom of the range, so the burn settles toward
it, but not below it, when demand is low.

Reference: [Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)

## Default and Setting

The documentation lists a default of 0.0005 TAO and marks the parameter as owner-settable, so a
subnet owner can adjust the floor for their subnet. The value in force is per-subnet chain state and
can differ from the default, so the real floor should be read for the subnet in question.

Reference: [Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)

## Subnet Context

Min burn is one of the subnet hyperparameters, the on-chain state variables that configure a single
subnet, for example netuid 1. Because each subnet carries its own hyperparameters, the registration
burn floor is defined per subnet and applies only to registration on that subnet.

References:
[Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters),
[Register](https://docs.learnbittensor.org/resources/glossary#register)

## Reader Boundary

This page defines the concept at a high level. It does not report the min burn value set on any
particular subnet or the current registration cost. Those are live chain state and should be checked
for the relevant netuid. The default of 0.0005 TAO is the documented value, and the parameter is
owner-settable per subnet.

Reference: [Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)
