# Maximum Supply

Maximum supply is the fixed ceiling on how much TAO can ever exist. Official documentation states
that TAO has a hard cap of 21 million, similar to Bitcoin's maximum supply. Issuance can approach
this ceiling over time but cannot exceed it.

References: [Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving)

## The 21 Million Cap

The cap is a protocol-level maximum: across the network's whole lifetime, the total amount of TAO is
bounded at 21 million. This is the total ceiling, which is different from how much TAO is in
circulation at any given moment. The circulating amount changes continuously, while the cap stays
fixed.

References: [Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving)

## Halving by Supply, Not Blocks

Bittensor approaches the cap through halvings, but the documentation notes a key difference from
Bitcoin: rather than halving on block numbers, Bittensor halves the emission rate when total
issuance reaches supply thresholds. Each time a threshold is crossed, the rate at which new TAO is
created is cut in half, so issuance slows as the total climbs toward 21 million.

References: [Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving),
[Emission](https://docs.learnbittensor.org/learn/emissions)

## Recycling Delays the Approach

Because halvings are tied to supply rather than time, their timing is not fixed. The documentation
explains that recycled TAO, such as TAO consumed by registration, is removed from circulation and
returned toward the emission pool, which pushes back the next supply threshold. More recycling
therefore extends the time until the next halving, so the exact dates are dynamic.

References: [Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving),
[Emission](https://docs.learnbittensor.org/learn/emissions)

## Cap, Issuance, and Recycling Context

Maximum supply is easiest to read when the fixed ceiling is separated from the moving quantities
that approach it. The halving documentation supplies the 21 million TAO cap and the supply-threshold
halving rule, while the emissions material explains the ongoing creation and recycling context that
affects how fast the network moves toward the next threshold
([Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving),
[Emission](https://docs.learnbittensor.org/learn/emissions)).

| Reading item      | What it explains                                      | What it does not supply              |
| ----------------- | ----------------------------------------------------- | ------------------------------------ |
| Maximum supply    | The lifetime TAO ceiling of 21 million                | A current circulating supply figure  |
| Total issuance    | Progress toward the next supply threshold             | A fixed calendar date for a halving  |
| Emission rate     | How quickly new TAO enters the system after a halving | The total cap itself                 |
| Recycled TAO      | Supply returned toward the emission pool              | New TAO above the maximum supply     |
| Registration burn | One source of TAO recycling described by the docs     | A permanent reduction in the cap     |
| Halving threshold | The supply point where emission rate changes          | A block-height schedule              |
| Live supply data  | The current point on the issuance path                | A replacement for the protocol limit |
| Circulating TAO   | The amount presently moving outside the cap concept   | The lifetime issuance ceiling        |
| Next-halving view | A projection from current issuance and recycling      | A promise that timing is fixed       |

That separation keeps the 21 million figure from being confused with a live measurement. The cap is
the upper bound across TAO's lifetime; live supply readings describe where issuance currently sits
inside that bound ([Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving),
[Glossary: Maximum Supply](https://docs.learnbittensor.org/resources/glossary#maximum-supply)).

Issuance explains movement toward the cap, not a change to the cap. When a halving threshold is
reached, the emission rate changes, so later TAO enters more slowly while the maximum remains 21
million ([Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving),
[Emission](https://docs.learnbittensor.org/learn/emissions)).

Recycling changes timing by moving consumed TAO back toward the emission pool. That makes the path
to the next threshold responsive to network activity, because recycled TAO can delay when total
issuance reaches the next halving point
([Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving)).

Circulating supply belongs in the same reading path but answers a different question. It is a
snapshot-like live figure, while maximum supply is the protocol ceiling used to interpret all such
snapshots ([Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving),
[Glossary: Maximum Supply](https://docs.learnbittensor.org/resources/glossary#maximum-supply)).

Recycled TAO also should not be read as a second issuance channel above the cap. The halving
documentation describes recycling as returning consumed TAO toward future emission, so the useful
reader distinction is between newly emitted TAO, recycled TAO, and the unchanged lifetime maximum
([Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving),
[Emission](https://docs.learnbittensor.org/learn/emissions)).

For readers, the practical order is to identify the fixed maximum, then read current issuance,
recycling, and emission-rate context as moving parts beneath that ceiling. That order preserves the
hard-cap idea while leaving live supply and next-halving timing to current data sources.

## Why the Cap Matters

A fixed ceiling makes TAO's long-run total predictable even though the pace of issuance is dynamic.
Readers can treat the 21 million figure as the upper bound on TAO that will ever exist, while
treating the timing of how quickly issuance approaches it as variable and dependent on network
activity rather than a fixed calendar.

Reference: [Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving)

## Reader Boundary

This page defines the concept at a high level. It does not report the current circulating supply,
the date of the next halving, or current recycling rates, which are live chain state and change over
time. The 21 million figure is the fixed protocol maximum; live figures should be read from current
Bittensor sources.

Reference: [Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving)
