# Initial Kappa

Initial Kappa is a subtensorModule runtime constant, listed in the chain's constants metadata as
initialKappa, with the value 32767 and the summary "Kappa constant"
([Subtensor API Constants: initialKappa](https://docs.learnbittensor.org/subtensor-api/constants#initialkappa-u16)).
It supplies the default value a subnet's Kappa uses.

## What It Means

Kappa is held per subnet and sets the consensus majority ratio a subnet uses when computing
consensus. Initial Kappa is the default this per-subnet value falls back to before a different value
applies for a subnet
([Subtensor API Constants: initialKappa](https://docs.learnbittensor.org/subtensor-api/constants#initialkappa-u16)).
The Kappa in force on a subnet such as netuid 1 is that subnet's own chain state and can differ from
this default.

## Distinction from Bonds Penalty and Bonds Moving Average

Initial Kappa is the default consensus majority ratio, while initialBondsPenalty, valued at 65535,
is the penalty applied to bonds for out-of-consensus weights; initialBondsMovingAverage, valued at
900000, is the smoothing applied to validator-miner bonds
([Subtensor API Constants: initialBondsPenalty](https://docs.learnbittensor.org/subtensor-api/constants#initialbondspenalty-u16),
[Subtensor API Constants: initialBondsMovingAverage](https://docs.learnbittensor.org/subtensor-api/constants#initialbondsmovingaverage-u64)).

## Reader Boundary

Initial Kappa is a default constant, not the live per-subnet Kappa, and it reflects the current
runtime configuration rather than a fixed protocol rule
([Subtensor API Constants: initialKappa](https://docs.learnbittensor.org/subtensor-api/constants#initialkappa-u16)).
