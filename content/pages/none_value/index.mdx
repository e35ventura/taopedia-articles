# None Value

`NoneValue` is a drand pallet error raised when a value is retrieved as `None` because no value was
previously set
([Subtensor API Errors: NoneValue](https://docs.learnbittensor.org/subtensor-api/errors#nonevalue)).

## What It Means

The drand pallet stores values as part of its randomness tracking. `NoneValue` fires when a drand
operation tries to read one of those values and finds nothing has been set yet
([Subtensor API Errors: NoneValue](https://docs.learnbittensor.org/subtensor-api/errors#nonevalue)).

## Distinction from Invalid Round Number

`NoneValue` fires when a stored value is missing entirely. `InvalidRoundNumber` fires when the round
number was retrieved but did not increment as expected
([Subtensor API Errors: NoneValue](https://docs.learnbittensor.org/subtensor-api/errors#nonevalue),
[Subtensor API Errors: InvalidRoundNumber](https://docs.learnbittensor.org/subtensor-api/errors#invalidroundnumber)).

- **NoneValue** — no value was previously set.
- **InvalidRoundNumber** — the round number exists but did not increment.

## Distinction from Pulse Verification Error

`NoneValue` fires when a stored value is missing. `PulseVerificationError` fires when a randomness
pulse was submitted but could not be verified
([Subtensor API Errors: NoneValue](https://docs.learnbittensor.org/subtensor-api/errors#nonevalue),
[Subtensor API Errors: PulseVerificationError](https://docs.learnbittensor.org/subtensor-api/errors#pulseverificationerror)).

- **NoneValue** — no stored value to read.
- **PulseVerificationError** — a pulse was submitted but failed verification.
