# Private Key

A private key is the protected side of a cryptographic keypair in Bittensor wallet-key terminology.
The official [Glossary: Private Key](https://docs.learnbittensor.org/resources/glossary#private-key)
describes it as the private component used to secure and authorize transactions and operations
within the Bittensor network.

## Keypair Context

Private keys are read together with public keys. The
[Glossary: Public Key](https://docs.learnbittensor.org/resources/glossary#public-key) describes the
public side as shareable material used for verification, encryption, and account reference. The
private side is the protected counterpart used for authorization.

This distinction keeps private key from being treated as shareable address material. It is part of
the same cryptographic keypair vocabulary, but it has a different role from public identification
material.

## Wallet-Key Context

In Bittensor, private keys belong to wallet-key terminology rather than naming a separate network
role or token. The
[Glossary: EdDSA Cryptographic Keypairs](https://docs.learnbittensor.org/resources/glossary#eddsa-cryptographic-keypairs)
connects public and private key pairs with coldkeys and hotkeys, which are Bittensor wallet-key
roles.

For readers, the useful point is structural: a private key is part of the wallet-key system used to
authorize activity, not a staking position, subnet role, or balance.

## Relationship to Wallet Addresses

Wallet addresses are related but not identical. The
[Glossary: Wallet Address](https://docs.learnbittensor.org/resources/glossary#wallet-address)
describes a wallet address as a public-key-derived identifier used as a TAO destination. Private key
material is not the same as that destination identifier.

This means private key is the protected signing concept, while wallet address and SS58 encoded
describe public-key-derived destination context.

## Reader Boundary

Private key should not be read as a public key, a wallet address, a recovery phrase, or a complete
wallet by itself. It is protected signing material that must remain confidential. This article does
not describe how to create, store, recover, rotate, or use wallet keys.
