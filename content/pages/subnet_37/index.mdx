Aurelius is Bittensor Subnet 37, a subnet for moral-reasoning alignment. Its on-chain identity
describes the project as decentralized alignment of artificial intelligence and lists
[Aurelius-Protocol/Aurelius-Protocol](https://github.com/Aurelius-Protocol/Aurelius-Protocol) as the
subnet's GitHub repository.

## What Aurelius Provides

The Aurelius README describes a subnet where miners submit structured ethical-dilemma scenarios and
validators evaluate accepted scenarios through generative-agent simulations. The resulting
transcripts are intended to create training data for improving large language models on moral
reasoning benchmarks.

In Bittensor terms, Aurelius turns alignment data generation into a competitive subnet task. Miners
propose useful moral-reasoning scenarios, validators score those submissions, and the resulting
weights feed into [[Yuma Consensus]].

## Miner and Validator Roles

Miners provide scenario submissions for moral-reasoning evaluation. Strong submissions describe a
clear ethical tension and give validators material that can produce useful simulation transcripts.

Validators evaluate submitted scenarios and determine which miner work is accepted and scored. The
repository describes validator scoring as a staged process that includes quality checks and
simulation of accepted scenarios. Operators should treat the repository as the source of truth for
current participant guidance.

## On-Chain Identity

Live SN37 data is available on [TaoStats](https://taostats.io/subnets/37). Readers can also
reproduce the chain identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 37 --network finney`.

That Finney identity reports the subnet name as Aurelius, the subnet URL as aureliusaligned.ai, and
the GitHub repo as Aurelius-Protocol/Aurelius-Protocol.
