Finetuning is Bittensor Subnet 37, an LLM finetuning subnet owned by Macrocosmos. Where pretraining
produces a raw foundation model, finetuning is the step that adapts a model to a task and gives it
the behavior needed for real use; Subnet 37 focuses that work on reasoning models. It is positioned
as one layer of a larger Macrocosmos stack: a model can be pretrained on Subnet 9 (also run by
Macrocosmos) and then brought to Subnet 37 for finetuning.

## What the Subnet Produces

The subnet's output is finetuned model weights, selected by competition. Rather than scoring a live
service, Subnet 37 runs a continuous benchmarking competition in which miners submit trained models
and the best model in each competition is rewarded. Because the target keeps moving as stronger
models appear, the competition format keeps pressure on miners to improve rather than to defend a
fixed result.

A single subnet can host more than one competition at a time. Each competition defines its own model
and tokenizer specifications, sequence lengths, and evaluation tasks, and it can weight and
normalize multiple tasks together. The repository also notes support for validator-funded public
competitions and user-defined competitions, so the set of things being optimized can change over
time.

## Miner and Validator Roles

Miners train models and publish them to Hugging Face, committing the metadata needed to locate and
identify each submission to the Bittensor chain. Validators read that metadata, download the models,
and evaluate them against the competition's tasks, awarding the top-performing model in each
competition. Evaluation runs are logged publicly so results can be inspected.

According to the repository, validators draw evaluation data from Subnet 1 because its data quality
is higher than the synthetic data the subnet previously used, and hash-based synchronization is used
to keep evaluation fair across validators. The resulting validator scores become the weights that
feed into [[Yuma Consensus]], which converts them into the incentive split across miners and
validators.

## On-Chain Identity

Live SN37 data, including metagraph state and alpha token pool information, is available on
[TaoStats](https://taostats.io/subnets/37). Readers can reproduce the subnet's registered identity
fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 37 --network finney`.

The subnet's open-source codebase (macrocosm-os/finetuning) is the source of truth for the
competition format and evaluation process described above.
