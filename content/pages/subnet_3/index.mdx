# Subnet 3: Deprecated

Subnet 3 (netuid 3) is a deprecated slot on the Bittensor network. The on-chain identity registers
the subnet as "deprecated" with no active operator, no public GitHub repository, and no live
website. The slot continues to exist on-chain and retains a residual alpha-token pool, but there is
no functioning miner or validator codebase associated with it.

On-chain data is verifiable via [taostats.io/subnets/3](https://taostats.io/subnets/3).

## How the Mechanism Works

Because no active codebase or operator is registered for Subnet 3, the subnet does not run a
meaningful incentive mechanism. Registered neurons on this slot receive no meaningful task
assignments or scoring, and the slot does not contribute to the broader [[Yuma Consensus]] weight
aggregation in any productive way.

The [[Dynamic TAO]] pricing mechanism still tracks an alpha-token pool for SN3, since the pool
exists on-chain independently of whether the subnet is actively operated.

## Participating as a Miner

Subnet 3 has no active validator codebase or task specification. There is no practical path to
earning emissions by mining on this subnet.

## Participating as a Validator

Subnet 3 has no active validator software or scoring specification. Staking on this subnet does not
confer any validation responsibilities or meaningful emission exposure.
