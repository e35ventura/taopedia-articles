# Subnet 3: Deprecated

Subnet 3 (netuid 3) is a deprecated Bittensor subnet. It has no active operator, no functional
GitHub repository, and no website. The on-chain identity fields — name, GitHub, and URL — all
contain placeholder values, indicating the original project either never launched or was abandoned
after initial registration.

Despite its inactive status, the subnet retains a registered slot on the Bittensor network and holds
a pool of alpha tokens. On-chain data for the subnet is viewable at
[taostats.io/subnets/3](https://taostats.io/subnets/3).

## How the Mechanism Works

No mechanism is in operation. The subnet was registered but the operator did not deploy active miner
or validator code. The slot exists on-chain but emits no meaningful incentive structure.

References: [taostats.io/subnets/3](https://taostats.io/subnets/3)

## Participating as a Miner

There is no active mining task for Subnet 3. The subnet has no validator software or scoring
protocol deployed by an operator.

## Participating as a Validator

There is no active validation protocol for Subnet 3. Validators registering on this subnet would
find no scoring mechanism to participate in.

## On-Chain Identity

The registered owner coldkey is `5FUJoAsY5TWfs1FGFtscC5QUuarJMCWYwYzEftyGAeH7pUqK`. The subnet holds
256 registered neuron slots. Full on-chain data — including pool balances, emission history, and
registered neurons — is available at [taostats.io/subnets/3](https://taostats.io/subnets/3).
