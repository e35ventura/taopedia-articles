# Subnet 3: Deprecated

Subnet 3 (netuid 3) is a retired subnet on the Bittensor network. It has been formally
decommissioned and its on-chain identity now carries placeholder values with no active operator,
GitHub repository, or website. The subnet continues to occupy a slot on the chain with 256
registered neurons but runs no meaningful workload.

References: [taostats.io/subnets/3](https://taostats.io/subnets/3)

## How the Mechanism Works

No active mechanism is defined for Subnet 3. The subnet was retired and its original incentive
design is no longer in operation. Registered neurons receive no meaningful emissions, and there is
no scoring logic actively running.

## Participating as a Miner

Subnet 3 is not open for new participation. Because no active task or scoring mechanism exists,
registering a hotkey on this subnet would yield no rewards. Prospective miners should look to active
subnets on the Bittensor network instead.

## Participating as a Validator

No validator logic is deployed on Subnet 3. Validators cannot meaningfully score miners on a subnet
with no active mechanism, and no weights are being set that would influence emissions through
[[Yuma Consensus]].
