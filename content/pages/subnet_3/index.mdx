# Subnet 3: Deprecated

Subnet 3 (netuid 3) is a slot on the Bittensor network whose on-chain identity description reads
"deprecated." The registered GitHub and URL fields both contain generic placeholder values rather
than active resources. No public codebase or documentation is available through those registered
identifiers.

The subnet's alpha-token pool continues to exist on-chain. Pool state, the registered owner coldkey,
and current neuron count are verifiable via [taostats.io/subnets/3](https://taostats.io/subnets/3).

## Netuid 3 Identifies the Subnet On-Chain

Bittensor assigns every subnet a unique numeric identifier called a netuid, and Subnet 3 is the
subnet registered at netuid 3
([Glossary: Netuid](https://docs.learnbittensor.org/resources/glossary#netuid)). The
[Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets) reference
explains that each subnet runs its own incentive mechanism while sharing the same underlying
Subtensor chain, so the netuid is the stable handle that distinguishes Subnet 3 from every other
subnet.

For a reader, this means "Subnet 3" and "netuid 3" refer to the same on-chain slot. A claim about
Subnet 3 should be tied to that netuid rather than to the registered name alone, because the name
field can be changed on-chain while the netuid stays fixed.

## Miner and Validator Roles

Subnet 3 operates under the standard Bittensor two-role structure. Miners supply the subnet's
capability and validators evaluate those contributions and set weights. Reward distribution follows
[Yuma Consensus](https://docs.learnbittensor.org/learn/yuma-consensus).

## Distinction from Yuma Consensus

Subnet 3 is a deprecated netuid slot whose Finney identity lists placeholder GitHub and URL fields
and no active public codebase. That deprecated-slot vocabulary names the current registered state at
netuid 3, not the on-chain step that turns validator weight submissions into emission shares each
tempo ([Subnet 3 on TaoStats](https://taostats.io/subnets/3),
[Yuma Consensus](https://docs.learnbittensor.org/learn/yuma-consensus)).

Yuma Consensus is the on-chain mechanism that runs at the epoch boundary on the selected netuid. It
reads the weight matrix from eligible validators, applies clipping and bonding, and converts the
result into miner incentives and validator dividend shares
([Yuma Consensus](https://docs.learnbittensor.org/learn/yuma-consensus),
[Emission](https://docs.learnbittensor.org/learn/emissions)).

Earlier sections describe placeholder identity fields and the absence of a published mechanism.
Those identity facts do not settle emissions themselves. Yuma still aggregates any validator weight
signals on netuid 3 rather than defining what deprecated means on chain
([Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets)).

The registered deprecated state therefore sits upstream of settlement. Yuma still credits emissions
from included validator weights on netuid 3 once the tempo closes
([Subnet 3 on TaoStats](https://taostats.io/subnets/3),
[Emission](https://docs.learnbittensor.org/learn/emissions)).

Readers should treat Subnet 3 as a deprecated on-chain slot at netuid 3, and Yuma Consensus as the
recurring mechanism that allocates rewards from validator weights each tempo.

- **Subnet 3** — deprecated on-chain identity at netuid 3.
- **Yuma Consensus** — epoch-boundary settlement from validator weights to emission shares on a task
  subnet
  ([Yuma Consensus: Validator emissions](https://docs.learnbittensor.org/learn/yuma-consensus#validator-emissions)).

## Reader Boundary

Subnet 3 should not be read as generic Bittensor subnet documentation, confirmation that the subnet
has a published, working mechanism, or a substitute for the subnet's own primary sources. It names
the on-chain subnet slot registered at netuid 3; see this article's On-Chain Identity section for
its current registered fields
([Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets),
[Glossary: Netuid](https://docs.learnbittensor.org/resources/glossary#netuid)).
