# No Chain Extension

`NoChainExtension` is a contracts pallet error raised when a contract tries to use a chain extension
that the network does not provide. The API errors reference summarizes it as "The chain does not
provide a chain extension. Calling the chain extension results in this error"
([Subtensor API Errors: NoChainExtension](https://docs.learnbittensor.org/subtensor-api/errors#nochainextension)).

## What It Means

Some contracts depend on a chain extension to reach functionality provided by the network outside
the contract itself. `NoChainExtension` means that expected extension is not available on the
current chain, so the contract operation is rejected
([Subtensor API Errors: NoChainExtension](https://docs.learnbittensor.org/subtensor-api/errors#nochainextension)).

This is a chain-extension availability failure. It does not, by itself, mean contract code was
invalid, that execution exhausted its gas limit, or that the caller supplied too many event topics.

## Why It Appears

This error appears when a contracts operation tries to use a chain extension on a network that does
not provide that extension
([Subtensor API Errors: NoChainExtension](https://docs.learnbittensor.org/subtensor-api/errors#nochainextension)).

## Distinction from Code Rejected

`NoChainExtension` and `CodeRejected` can both stop a contracts workflow, but they fail at different
points. `NoChainExtension` means the network does not provide the extension the contract tries to
use. `CodeRejected` is the contracts-pallet error for code that is invalid during validation
([Subtensor API Errors: NoChainExtension](https://docs.learnbittensor.org/subtensor-api/errors#nochainextension),
[Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

- **NoChainExtension** — the network does not provide the needed chain extension.
- **CodeRejected** — the contract code is rejected as invalid during validation.

## Distinction from Contract Trapped

`NoChainExtension` and `ContractTrapped` both stop a contracts operation, but they describe
different outcomes. `NoChainExtension` means the required chain extension is unavailable on the
network. `ContractTrapped` means the contract trapped during execution
([Subtensor API Errors: NoChainExtension](https://docs.learnbittensor.org/subtensor-api/errors#nochainextension),
[Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped)).

- **NoChainExtension** — the network feature the contract expects is unavailable.
- **ContractTrapped** — execution reaches the contract and then traps.
