# First Emission Block Number Already Set

`FirstEmissionBlockNumberAlreadySet` means a `start_call` reached the first-emission-block check
while that value was already stored for the targeted netuid. The standard-errors reference describes
it as "First emission block number already set"
([Subtensor Standard Errors](https://docs.learnbittensor.org/errors/subtensor#firstemissionblocknumberalreadyset)).

## What It Means

The `start_call` extrinsic is how a subnet owner activates a newly registered subnet
([Create a Subnet](https://docs.learnbittensor.org/subnets/create-a-subnet)). On that path, the
runtime checks whether `FirstEmissionBlockNumber` is already present for the submitted netuid and
returns `FirstEmissionBlockNumberAlreadySet` when it is
([Subtensor Standard Errors](https://docs.learnbittensor.org/errors/subtensor#firstemissionblocknumberalreadyset)).

This is a duplicate-call guard on `start_call`. The failure means the first emission block number
for that netuid is already recorded, so the chain rejects another activation attempt on the same
subnet.

## Why It Appears

This error appears when a wallet or automation submits `start_call` on a netuid whose
`FirstEmissionBlockNumber` entry is already populated. That commonly happens when a client retries
an activation that already succeeded or when a script does not check whether the value was written
on a prior call
([Subtensor Standard Errors](https://docs.learnbittensor.org/errors/subtensor#firstemissionblocknumberalreadyset)).

When debugging `start_call` failures, rule out earlier gates on the same extrinsic first.
`SubnetNotExists` means the netuid has no subnet record. `BadOrigin` and `NotSubnetOwner` mean the
signer lacks subnet-owner permission. `NeedWaitingMoreBlocksToStarCall` means the call arrived
before the required waiting period after registration
([Subtensor Standard Errors: SubnetNotExists](https://docs.learnbittensor.org/errors/subtensor#subnetnotexists),
[Subtensor Standard Errors: BadOrigin](https://docs.learnbittensor.org/errors/subtensor#badorigin),
[Subtensor Standard Errors: NotSubnetOwner](https://docs.learnbittensor.org/errors/subtensor#notsubnetowner),
[Subtensor Standard Errors: NeedWaitingMoreBlocksToStarCall](https://docs.learnbittensor.org/errors/subtensor#needwaitingmoreblockstostarcall)).

The practical meaning is narrow: the first emission block number is already set for the netuid.

## Distinction from Need Waiting More Blocks To Start Call

`FirstEmissionBlockNumberAlreadySet` and `NeedWaitingMoreBlocksToStarCall` both appear on
`start_call`, but they reject different conditions. `NeedWaitingMoreBlocksToStarCall` means the
caller must wait for more blocks before the start call is accepted.
`FirstEmissionBlockNumberAlreadySet` means the first emission block number is already stored, so the
activation step cannot run again
([Subtensor Standard Errors: NeedWaitingMoreBlocksToStarCall](https://docs.learnbittensor.org/errors/subtensor#needwaitingmoreblockstostarcall)).

- **NeedWaitingMoreBlocksToStarCall** — the start call arrived too soon after registration.
- **FirstEmissionBlockNumberAlreadySet** — the first emission block number is already set.

## Distinction from Subnet Not Exists

`FirstEmissionBlockNumberAlreadySet` and `SubnetNotExists` both appear when `start_call` names a
problematic netuid, but they reject different problems. `SubnetNotExists` means the targeted subnet
is absent from chain state. `FirstEmissionBlockNumberAlreadySet` means the subnet exists and already
has a stored first emission block number
([Subtensor Standard Errors: SubnetNotExists](https://docs.learnbittensor.org/errors/subtensor#subnetnotexists)).

- **SubnetNotExists** — the targeted subnet does not exist.
- **FirstEmissionBlockNumberAlreadySet** — the first emission block number is already set.

## Reader Boundary

This page defines the meaning of the error label and the duplicate `start_call` guard it represents.
It does not report whether a particular netuid has a stored first emission block number or what
value was written; those are live chain-state questions for the selected netuid
([Subtensor Standard Errors](https://docs.learnbittensor.org/errors/subtensor#firstemissionblocknumberalreadyset),
[Create a Subnet](https://docs.learnbittensor.org/subnets/create-a-subnet)).
