# Delta Zero

`DeltaZero` is a balances pallet error raised when a balances operation is submitted with a zero
delta amount. The API errors reference documents this error on the balances operation path
([Subtensor API Errors: DeltaZero](https://docs.learnbittensor.org/subtensor-api/errors#deltazero)).

## What It Means

Some balances operations accept a delta amount that specifies how much balance to add or remove.
`DeltaZero` fires when that delta is zero, meaning the operation would have no effect on the
account's balance
([Subtensor API Errors: DeltaZero](https://docs.learnbittensor.org/subtensor-api/errors#deltazero)).

This is a non-zero-delta rejection, not proof that the account lacked balance, that the existential
deposit was not met, or that liquidity restrictions blocked the operation.

## Why It Appears

This error appears when a balances operation is submitted with a delta of zero and the pallet
rejects the no-op request
([Subtensor API Errors: DeltaZero](https://docs.learnbittensor.org/subtensor-api/errors#deltazero)).

## Distinction from Insufficient Balance

`DeltaZero` and `InsufficientBalance` are both balances-pallet errors that block a balance
operation, but they fire at different checks. `DeltaZero` fires when the delta amount is zero.
`InsufficientBalance` fires when the account's balance is too low to cover the requested amount
([Subtensor API Errors: DeltaZero](https://docs.learnbittensor.org/subtensor-api/errors#deltazero),
[Subtensor API Errors: InsufficientBalance](https://docs.learnbittensor.org/subtensor-api/errors#insufficientbalance)).

- **DeltaZero** — the submitted delta amount is zero.
- **InsufficientBalance** — the account balance is too low.

## Distinction from Existential Deposit

`DeltaZero` and `ExistentialDeposit` are both balances-pallet errors that block a balance operation,
but they fire at different checks. `DeltaZero` fires when the delta amount is zero.
`ExistentialDeposit` fires when the transfer amount is below the minimum required to keep the
destination account alive
([Subtensor API Errors: DeltaZero](https://docs.learnbittensor.org/subtensor-api/errors#deltazero),
[Subtensor API Errors: ExistentialDeposit](https://docs.learnbittensor.org/subtensor-api/errors#existentialdeposit)).

- **DeltaZero** — the submitted delta amount is zero.
- **ExistentialDeposit** — the transfer amount is below the existential deposit.

## Reader Boundary

This page defines the meaning of the error label and the non-zero-delta guard it represents on the
balances operation path. It does not report the account's current balance, list the extrinsics that
accept a delta amount, or describe the full balances pallet configuration
([Subtensor API Errors: DeltaZero](https://docs.learnbittensor.org/subtensor-api/errors#deltazero)).
