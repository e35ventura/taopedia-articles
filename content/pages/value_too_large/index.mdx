# Value Too Large

`ValueTooLarge` is a contracts pallet error raised when a contracts operation exceeds the runtime's
configured maximum value size. The API errors reference summarizes it as "The size defined in
`T::MaxValueSize` was exceeded"
([Subtensor API Errors: ValueTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#valuetoolarge)).

## What It Means

Some contracts-pallet operations need the supplied or produced value to fit within the runtime's
allowed size boundary. `ValueTooLarge` means that size boundary was exceeded, so the operation
cannot continue
([Subtensor API Errors: ValueTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#valuetoolarge)).

This is a value-size limit failure. It does not, by itself, mean the uploaded contract code was too
large or that the caller only provided too little output-buffer space.

## Why It Appears

This error appears when a contracts operation tries to work with a value whose size is above the
runtime's configured maximum
([Subtensor API Errors: ValueTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#valuetoolarge)).

## Distinction from Code Too Large

`ValueTooLarge` and `CodeTooLarge` both describe size checks, but they apply to different things.
`ValueTooLarge` rejects an oversized value. `CodeTooLarge` rejects oversized contract code
([Subtensor API Errors: ValueTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#valuetoolarge),
[Subtensor API Errors: CodeTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#codetoolarge)).

- **ValueTooLarge** — the value size exceeds the configured limit.
- **CodeTooLarge** — the contract code size exceeds the configured limit.

## Distinction from Output Buffer Too Small

`ValueTooLarge` and `OutputBufferTooSmall` fail on opposite sides of a size boundary.
`ValueTooLarge` means the value itself is too large for the runtime's configured maximum.
`OutputBufferTooSmall` means the caller-supplied output buffer is too small for the contract API
call
([Subtensor API Errors: ValueTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#valuetoolarge),
[Subtensor API Errors: OutputBufferTooSmall](https://docs.learnbittensor.org/subtensor-api/errors#outputbuffertoosmall)).

- **ValueTooLarge** — the value exceeds the runtime's value-size limit.
- **OutputBufferTooSmall** — the buffer supplied by the caller is too small.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not report the live
size limit configured on any particular network
([Subtensor API Errors: ValueTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#valuetoolarge),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
