# Seed Phrase

A seed phrase is the human-readable word sequence that can recover access to Bittensor wallet key
material. The official
[Glossary: Seed Phrase](https://docs.learnbittensor.org/resources/glossary#seed-phrase) describes it
as a series of words generated with a wallet's cryptographic key pair and used to recover the
coldkey private key offline.

## Wallet Recovery Context

Seed-phrase vocabulary belongs to wallet security rather than to subnet participation roles. The
[Glossary: Mnemonic](https://docs.learnbittensor.org/resources/glossary#mnemonic) uses overlapping
language, describing a mnemonic as a word sequence used to regenerate keys and restore coldkeys and
hotkeys.

For readers, seed phrase emphasizes the recovery-words form of that secret, while mnemonic names the
same recovery concept in Bittensor key vocabulary.

References: [Wallets](https://docs.learnbittensor.org/keys/wallets),
[Working with Keys](https://docs.learnbittensor.org/keys/working-with-keys)

## Recovery Material Boundary

A seed phrase is recovery material, not a public wallet address or ordinary account label. The
glossary ties it to restoring coldkey private-key access, while the wallet documentation separates
wallet identity from the software used to view or manage it
([Glossary: Seed Phrase](https://docs.learnbittensor.org/resources/glossary#seed-phrase),
[Wallets](https://docs.learnbittensor.org/keys/wallets)).

That boundary keeps the term in custody context. Sharing a seed phrase should be understood as
exposing recovery authority over the protected wallet material, not as sharing a harmless
identifier.

## Coldkey and Hotkey Boundary

A seed phrase is most closely tied to coldkey recovery in official prose. The glossary definition
focuses on recovering the coldkey private key, which is the ownership root for TAO and stake in
Bittensor wallet design. Hotkeys remain operational keys controlled by that ownership context.

Seed phrase is concept vocabulary for the recovery-words role in wallet design. It does not name a
display format, a key management standard, or a backup schedule. Those questions belong to the
wallet's own key security context.

## Generated With the Wallet Key Pair

The [Glossary: Seed Phrase](https://docs.learnbittensor.org/resources/glossary#seed-phrase) and
[Wallets](https://docs.learnbittensor.org/keys/wallets) documentation describe the seed phrase as
words generated together with the wallet's cryptographic key pair. Official prose treats it as a
human-usable way to save that key access offline and later import the wallet into software or
hardware wallet applications.

The phrase belongs to creation output rather than to an optional display label. The wallet
documentation describes the series as at least twelve words tied to recovering protected coldkey
material.

The same wallet guidance also treats importing that phrase as the path to rebuild local key access
after separation from the original install.

References: [Glossary: Seed Phrase](https://docs.learnbittensor.org/resources/glossary#seed-phrase),
[Wallets](https://docs.learnbittensor.org/keys/wallets)

## Shown Once at Creation

Wallet setup documentation places the mnemonic in a one-time disclosure step. The
[Working with Keys](https://docs.learnbittensor.org/keys/working-with-keys) page notes that the
secret phrase is shown only once, while ordinary coldkey keyfiles omit it because of the higher
security bar around that material.

A wallet password can encrypt local files, but official recovery prose states that the mnemonic is
needed when password access or the original machine is gone. The same guidance warns that anyone
with the phrase can recreate the related key authority.

Each created coldkey or hotkey receives its own unique phrase at generation time, so recovery
language should name which key role the words belong to rather than assuming one phrase covers every
operational key in the wallet.

References: [Working with Keys](https://docs.learnbittensor.org/keys/working-with-keys),
[Glossary: Mnemonic](https://docs.learnbittensor.org/resources/glossary#mnemonic)

## Loss Versus Leak

The [Handle Seed Phrase](https://docs.learnbittensor.org/keys/handle-seed-phrase) page separates two
seed-phrase failure modes: losing the secret and leaking it to another party. Loss can leave the
coldkey's TAO, stake, and related permissions unreachable; leak gives someone else the ability to
recreate that recovery authority.

Official guidance treats a leak as a case where coldkey rotation should be considered, while loss
points to permanent recovery failure unless another valid backup exists. Both modes belong in
custody reading rather than in subnet or staking outcome prose.

The same page also states that whoever holds the seed phrase has full control over the wallet. That
claim is why the term should stay in backup and disclosure discussions instead of ordinary public
wallet metadata.

References: [Handle Seed Phrase](https://docs.learnbittensor.org/keys/handle-seed-phrase),
[Glossary: Coldkey](https://docs.learnbittensor.org/resources/glossary#coldkey)

## Relationship to Bittensor Wallet

A Bittensor wallet is the identity and ownership container for keys and stake, while a seed phrase
is one form of offline backup for that ownership material. The
[Glossary: Bittensor Wallet](https://docs.learnbittensor.org/resources/glossary#bittensor-wallet)
describes the wallet as the network identity container, and seed phrase names the recovery words
that can restore that container's key access if needed.

## Reader Boundary

Seed phrase should not be read as a public identifier, a validator label, or a transferable token.
It is secret recovery material. The term names the recovery-word concept inside Bittensor wallet
design, not a balance, a role, or a network address.
