# Gas Price Too Low

`GasPriceTooLow` is an EVM pallet error raised when the submitted gas price is below the required
minimum. The API errors reference summarizes it as "Gas price is too low"
([Subtensor API Errors: GasPriceTooLow](https://docs.learnbittensor.org/subtensor-api/errors#gaspricetoolow)).

## What It Means

Bittensor's EVM layer executes Ethereum-compatible transactions on Subtensor and validates gas
parameters before running the call. `GasPriceTooLow` means the submitted gas price is under the
runtime floor for that transaction, so the EVM path rejects the call before execution proceeds
([Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials),
[Subtensor API Errors: GasPriceTooLow](https://docs.learnbittensor.org/subtensor-api/errors#gaspricetoolow)).

This is a gas-price floor rejection. It does not, by itself, mean the gas limit was too low, that
the gas limit exceeded the maximum, or that fee conversion overflowed.

## Why It Appears

This error appears when an EVM transaction names a gas price below what the runtime requires. The
practical meaning is narrow: raise the gas price to at least the required minimum before
resubmitting the same call
([Subtensor API Errors: GasPriceTooLow](https://docs.learnbittensor.org/subtensor-api/errors#gaspricetoolow),
[Token Bridging](https://docs.learnbittensor.org/evm-tutorials/bridge-vtao)).

## Distinction from Gas Limit Too Low

`GasPriceTooLow` and `GasLimitTooLow` both block EVM transaction submission, but they reject
different parameters. `GasLimitTooLow` means the gas limit field is below the runtime minimum.
`GasPriceTooLow` means the gas price field is below the required floor
([Subtensor API Errors: GasLimitTooLow](https://docs.learnbittensor.org/subtensor-api/errors#gaslimittoolow),
[Subtensor API Errors: GasPriceTooLow](https://docs.learnbittensor.org/subtensor-api/errors#gaspricetoolow)).

- **GasPriceTooLow** — the submitted gas price is below the required minimum.
- **GasLimitTooLow** — the submitted gas limit is below the required minimum.

## Distinction from Gas Limit Too High

`GasPriceTooLow` and `GasLimitTooHigh` both block EVM transaction submission, but on different
parameters and bounds. `GasLimitTooHigh` rejects a gas limit that exceeds the allowed maximum.
`GasPriceTooLow` rejects a gas price that falls below the required minimum
([Subtensor API Errors: GasLimitTooHigh](https://docs.learnbittensor.org/subtensor-api/errors#gaslimittoohigh),
[Subtensor API Errors: GasPriceTooLow](https://docs.learnbittensor.org/subtensor-api/errors#gaspricetoolow)).

- **GasPriceTooLow** — the submitted gas price is below the required minimum.
- **GasLimitTooHigh** — the submitted gas limit exceeds the allowed maximum.

## Reader Boundary

This page defines the meaning of the error label and the gas-price floor check it represents on EVM
paths. It does not report the live minimum gas price configured on a network; that depends on
runtime settings at submission time
([Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
