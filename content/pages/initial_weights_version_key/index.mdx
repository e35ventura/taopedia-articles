# Initial Weights Version Key

Initial Weights Version Key is a subtensorModule runtime constant, listed in the chain's constants
metadata as initialWeightsVersionKey, with the value 0 and the summary "Initial weights version key"
([Subtensor API Constants: initialWeightsVersionKey](https://docs.learnbittensor.org/subtensor-api/constants#initialweightsversionkey-u64)).
It supplies the default value a subnet's WeightsVersionKey uses.

## What It Means

WeightsVersionKey is held per subnet and sets the version key a validator's weight submission must
match for the subnet to accept it. Initial Weights Version Key is the default this per-subnet value
falls back to before a different value applies for a subnet
([Subtensor API Constants: initialWeightsVersionKey](https://docs.learnbittensor.org/subtensor-api/constants#initialweightsversionkey-u64)).
The WeightsVersionKey in force on a subnet such as netuid 1 is that subnet's own chain state and can
differ from this default.

## Distinction from Kappa and Bonds Penalty

Initial Weights Version Key is the default weights version key, while initialKappa, valued at 32767,
is the consensus majority ratio used in consensus; initialBondsPenalty, valued at 65535, is the
penalty applied to bonds for out-of-consensus weights
([Subtensor API Constants: initialKappa](https://docs.learnbittensor.org/subtensor-api/constants#initialkappa-u16),
[Subtensor API Constants: initialBondsPenalty](https://docs.learnbittensor.org/subtensor-api/constants#initialbondspenalty-u16)).

## Reader Boundary

Initial Weights Version Key is a default constant, not the live per-subnet WeightsVersionKey, and it
reflects the current runtime configuration rather than a fixed protocol rule
([Subtensor API Constants: initialWeightsVersionKey](https://docs.learnbittensor.org/subtensor-api/constants#initialweightsversionkey-u64)).
