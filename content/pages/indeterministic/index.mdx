# Indeterministic

`Indeterministic` is a contracts pallet error raised when non-deterministic code is used in a
context where it is not permitted. The API errors reference summarizes it as "An indeterministic
code was used in a context where this is not permitted"
([Subtensor API Errors: Indeterministic](https://docs.learnbittensor.org/subtensor-api/errors#indeterministic)).

## What It Means

Subtensor includes a contracts pallet for on-chain smart contracts. Some contracts paths require
code whose outcome is fully determined by its inputs so validators can reach the same result.
`Indeterministic` means the runtime detected code that does not meet that requirement in a context
where only deterministic code is allowed, so the operation is rejected
([Subtensor API Errors: Indeterministic](https://docs.learnbittensor.org/subtensor-api/errors#indeterministic)).

This is a determinism rejection. It does not, by itself, mean no code exists at a supplied hash,
that supplied instantiate code exceeded the schedule size limit, or that no live contract exists at
the targeted address.

## Why It Appears

This error appears when a contracts operation uses code the runtime treats as indeterministic in a
context that permits only deterministic code
([Subtensor API Errors: Indeterministic](https://docs.learnbittensor.org/subtensor-api/errors#indeterministic)).

## Distinction from Code Not Found

`Indeterministic` and `CodeNotFound` both involve contract code, but the API summaries name
different problems. `Indeterministic` means non-deterministic code was used where it is not
permitted. `CodeNotFound` is summarized as "No code could be found at the supplied code hash."
([Subtensor API Errors: Indeterministic](https://docs.learnbittensor.org/subtensor-api/errors#indeterministic),
[Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound)).

- **Indeterministic** — non-deterministic code was used where it is not permitted.
- **CodeNotFound** — no code exists at the supplied hash.

## Distinction from Code Too Large

`Indeterministic` and `CodeTooLarge` both reject contract code on different checks.
`Indeterministic` concerns whether the code is permitted in a determinism-required context.
`CodeTooLarge` is summarized as "The code supplied to `instantiate_with_code` exceeds the limit
specified in the current schedule."
([Subtensor API Errors: Indeterministic](https://docs.learnbittensor.org/subtensor-api/errors#indeterministic),
[Subtensor API Errors: CodeTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#codetoolarge)).

- **Indeterministic** — non-deterministic code was used where it is not permitted.
- **CodeTooLarge** — supplied instantiate code exceeds the schedule size limit.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not inspect whether
a specific code hash is deterministic on a network or redesign contract code for determinism
([Subtensor API Errors: Indeterministic](https://docs.learnbittensor.org/subtensor-api/errors#indeterministic),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
