Hippius is Bittensor Subnet 75. Its on-chain description presents it as a blockchain-backed cloud
offering storage, virtual machines, and apps, and the project site is
[hippius.com](https://hippius.com). The subnet's aim is to provide cloud-style infrastructure — file
storage and compute — without a single central provider, by rewarding a network of miners for
supplying that capacity and validators for confirming it is delivered reliably. The codebase for the
subnet is the `thenervelab/thebrain` repository.

## What Hippius Rewards

Hippius pays for two kinds of real infrastructure. The first is storage: miners contribute disk
capacity and hold users' files on a distributed file system, keeping copies replicated so data stays
available even if individual nodes go offline. The second is compute: other miners run virtual
machines, providing on-demand processing — including GPU capacity — that applications can use.

The reward follows dependable service rather than mere participation. Nodes that genuinely hold the
data they claim and keep their compute available earn rewards, while unreliable or dishonest nodes
can be penalized and removed. A marketplace ties this together, matching the storage and compute
that miners supply with the users and applications that need it.

## Miner and Validator Roles

Miners come in two main types. Storage miners run distributed file-storage nodes and are responsible
for keeping files intact, available, and properly replicated. Compute miners act as hosts for
virtual machines, managing the execution of workloads and the resources behind them. In both cases a
registered hotkey on netuid 75 is what ties a miner's contribution back to them.

Validators verify that this infrastructure is real and healthy. They check that stored files remain
available and correctly replicated, confirm that compute resources are performing, monitor usage
across the network, and coordinate where data and tasks should sit. From those checks they reward
reliable nodes and set weights on the network, which is how reward flows through [[Yuma Consensus]].
At the article level the split is straightforward: miners supply storage and compute, while
validators confirm the service is delivered and weight each miner accordingly.

## On-Chain Identity

Live SN75 subnet data is available on [TaoStats](https://taostats.io/subnets/75), which identifies
the subnet as Hippius. Readers can reproduce the subnet identity fields directly with the Bittensor
CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 75 --network finney`. That Finney identity is the source of
truth for the subnet name and the GitHub repository associated with the subnet.
