gm is Bittensor Subnet 28. The subnet's Finney chain identity registers the name "gm" — a shorthand
familiar in crypto communities for "good morning" — but includes no GitHub repository, no website,
and no description. The [TaoStats explorer](https://taostats.io/subnets/28) is the primary public
window into the subnet's live on-chain state.

## How the Mechanism Works

Subnet 28 participates in the standard Bittensor emission model: miners earn alpha token rewards by
satisfying validator queries, and validators assign scores that feed into [[Yuma Consensus]] to
determine each miner's share of block emissions. Because the subnet operator has not published a
public codebase or technical specification, the specific miner task, scoring function, and
validation methodology are not publicly documented.

## Participating as a Miner

No public setup guide exists for Subnet 28. Prospective miners would need to contact the subnet
operator directly to learn about required hardware, software dependencies, and expected task
behavior. The on-chain owner coldkey is `5CA6rwAytZvvyZhLYEzo79627QEV422Q8kD51DEnTaRQxm45`, which
can be used to identify the operator on TaoStats.

## Participating as a Validator

Validators on Subnet 28 are responsible for scoring miner responses and submitting weights that flow
through [[Yuma Consensus]] to set emissions. As with mining, no public validator documentation is
available. Interested parties should monitor TaoStats for registration activity or reach out to the
operator coldkey directly.

Subnet 28 is registered on the Bittensor Finney network under the name "gm". The owner coldkey is
