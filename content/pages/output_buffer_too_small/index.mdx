# Output Buffer Too Small

`OutputBufferTooSmall` is a contracts pallet error raised when a contracts API call receives an
output buffer that is too small. The API errors reference summarizes it as "The output buffer
supplied to a contract API call was too small"
([Subtensor API Errors: OutputBufferTooSmall](https://docs.learnbittensor.org/subtensor-api/errors#outputbuffertoosmall)).

## What It Means

Some contracts API calls need enough output-buffer space to return their result.
`OutputBufferTooSmall` means the caller-supplied buffer did not provide enough room, so the call
cannot complete as requested
([Subtensor API Errors: OutputBufferTooSmall](https://docs.learnbittensor.org/subtensor-api/errors#outputbuffertoosmall)).

This is an output-buffer size failure. It does not, by itself, mean the value exceeded the runtime's
maximum size, that too many topics were supplied for an event deposit, or that a transfer failed.

## Why It Appears

This error appears when a contracts API call supplies an output buffer that is smaller than the call
needs
([Subtensor API Errors: OutputBufferTooSmall](https://docs.learnbittensor.org/subtensor-api/errors#outputbuffertoosmall)).

## Distinction from Value Too Large

`OutputBufferTooSmall` and `ValueTooLarge` both involve size limits, but they fail on different
boundaries. `OutputBufferTooSmall` means the caller-supplied output buffer is too small.
`ValueTooLarge` means the value itself exceeds the runtime's configured maximum size
([Subtensor API Errors: OutputBufferTooSmall](https://docs.learnbittensor.org/subtensor-api/errors#outputbuffertoosmall),
[Subtensor API Errors: ValueTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#valuetoolarge)).

- **OutputBufferTooSmall** — the output buffer is too small for the call.
- **ValueTooLarge** — the value itself exceeds the runtime limit.

## Distinction from Too Many Topics

`OutputBufferTooSmall` and `TooManyTopics` both stop contracts operations, but they check different
inputs. `OutputBufferTooSmall` checks the size of the output buffer supplied by the caller.
`TooManyTopics` checks how many topics were supplied for an event deposit
([Subtensor API Errors: OutputBufferTooSmall](https://docs.learnbittensor.org/subtensor-api/errors#outputbuffertoosmall),
[Subtensor API Errors: TooManyTopics](https://docs.learnbittensor.org/subtensor-api/errors#toomanytopics)).

- **OutputBufferTooSmall** — the caller-supplied output buffer is too small.
- **TooManyTopics** — too many topics were supplied for the event deposit.
