Subtensor nodes are infrastructure for Bittensor's blockchain layer. The official
[Subtensor Node Basics](https://docs.learnbittensor.org/subtensor-nodes/) guide describes a public
subtensor node as an internet-connected computer synchronized with the Bittensor blockchain
database.

A subtensor node is not the same thing as a subnet miner or validator. The same official guide
distinguishes subtensor nodes from Bittensor neurons: neurons operate inside subnets, while
subtensor nodes provide access to blockchain state.

## Role in Bittensor

Subtensor nodes sit below subnet activity. They help software connect to chain state, while subnet
miners and validators perform the incentive-specific work described in [[Mining and Validating]].

The official guide also separates public subtensor nodes from local development chains. Public nodes
connect to a Bittensor network, while local chains are isolated environments for development and
testing.

## Node Types

Bittensor documentation names two public subtensor node types: lite nodes and archive nodes. A lite
node is the lighter access option, while an archive node is intended for historical chain data and
explorer-style use cases.

The important distinction for Taopedia readers is scope: both are blockchain access nodes, not
subnet task definitions and not miner or validator roles.
