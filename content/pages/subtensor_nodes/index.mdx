Subtensor nodes are Bittensor blockchain nodes. The official
[Subtensor Node Basics](https://docs.learnbittensor.org/subtensor-nodes/) guide describes a public
subtensor node as an internet-connected computer synchronized with the Bittensor blockchain
database.

## What They Provide

A subtensor node gives software an access point to a Bittensor network's blockchain data. This is
different from a local blockchain, which the same official guide describes as a development
environment rather than a public network node.

At the article level, the distinction is simple: a subtensor node belongs to the blockchain access
layer. It is not a subnet description or a step-by-step operations guide.

## Reader Context

Readers will usually encounter subtensor nodes when documentation discusses connecting software to
Bittensor. For current node types and requirements, the official node documentation is the source of
truth.
