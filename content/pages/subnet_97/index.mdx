Albedo is Bittensor Subnet 97, a subnet that runs an ongoing "king-of-the-hill" contest to improve
AI models on software-engineering tasks. Its on-chain description is "Alchemical intelligence," and
the project publishes a live dashboard at
[us-east-1.hippius.com/albedo](https://us-east-1.hippius.com/albedo/index.html). The codebase for
the subnet is the `unarbos/albedo` repository.

## What Albedo Rewards

At any moment one model holds the title of "king." Miners submit challenger models that try to
unseat it, and the subnet rewards a challenger that proves it is better than the current king. The
two models are compared head-to-head on a fixed set of software-engineering coding problems, and the
winner of that comparison becomes the new king. Because the title only changes when a challenger
genuinely outperforms the incumbent, reward concentrates on models that push the current best
forward.

A second purpose runs alongside the contest. Every head-to-head comparison is published in full —
not just the final verdict, but the step-by-step record of how each model approached the problems.
These published traces are openly available for anyone to download and use as training data, so the
subnet doubles as a continuously growing dataset for distilling better coding models, with no wallet
or registration required to read it.

## Miner and Validator Roles

Miners are the challengers. A miner trains a model that it believes can beat the reigning king,
uploads it, and registers the submission on-chain so validators know to evaluate it. The interesting
work is in producing a model that actually improves on the incumbent rather than merely matching it.

Validators run the contest. They watch for new challenger submissions, fetch the current king and
the challenger, and stage the head-to-head duel on the shared set of coding tasks. The two models'
answers are compared by a panel of language-model judges, and a challenger takes the throne only if
that panel finds it genuinely better. Validators then record the outcome, publish the full duel
traces, and set weights on the network accordingly, which is how reward flows through
[[Yuma Consensus]]. At the article level the split is straightforward: miners supply challenger
models, while validators run the duels, decide the winner, and weight the network.

## On-Chain Identity

Live SN97 subnet data is available on [TaoStats](https://taostats.io/subnets/97), which identifies
the subnet as Albedo. Readers can reproduce the subnet identity fields directly with the Bittensor
CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 97 --network finney`. That Finney identity is the source of
truth for the subnet name and the GitHub repository associated with the subnet.
