# Unverified Pulse

`UnverifiedPulse` is a drand pallet error raised when a submitted randomness pulse is invalid
([Subtensor API Errors: UnverifiedPulse](https://docs.learnbittensor.org/subtensor-api/errors#unverifiedpulse)).

## What It Means

The drand pallet processes randomness pulses as part of its distributed randomness tracking.
`UnverifiedPulse` fires when a submitted pulse is deemed invalid
([Subtensor API Errors: UnverifiedPulse](https://docs.learnbittensor.org/subtensor-api/errors#unverifiedpulse)).

## Distinction from Pulse Verification Error

`UnverifiedPulse` fires when the pulse itself is invalid. `PulseVerificationError` fires when the
pulse could not be verified — the verification step failed rather than the pulse being rejected as
invalid
([Subtensor API Errors: UnverifiedPulse](https://docs.learnbittensor.org/subtensor-api/errors#unverifiedpulse),
[Subtensor API Errors: PulseVerificationError](https://docs.learnbittensor.org/subtensor-api/errors#pulseverificationerror)).

- **UnverifiedPulse** — the pulse is invalid.
- **PulseVerificationError** — the pulse could not be verified.

## Distinction from None Value

`UnverifiedPulse` fires when a submitted pulse fails validation. `NoneValue` fires when a stored
value is missing because nothing was previously set
([Subtensor API Errors: UnverifiedPulse](https://docs.learnbittensor.org/subtensor-api/errors#unverifiedpulse),
[Subtensor API Errors: NoneValue](https://docs.learnbittensor.org/subtensor-api/errors#nonevalue)).

- **UnverifiedPulse** — a submitted pulse is invalid.
- **NoneValue** — no stored value was previously set.
