# Add Stake Burn Rate Limit Exceeded

`AddStakeBurnRateLimitExceeded` is a subtensor pallet error raised when an add-stake-and-burn
operation is attempted more frequently than its rate limit allows. The API errors reference
describes it as `"Add stake and burn" exceeded the operation rate limit`
([Subtensor API Errors: AddStakeBurnRateLimitExceeded](https://docs.learnbittensor.org/subtensor-api/errors#addstakeburnratelimitexceeded),
[Subtensor Standard Errors: AddStakeBurnRateLimitExceeded](https://docs.learnbittensor.org/errors/subtensor#addstakeburnratelimitexceeded)).

## What It Means

`AddStakeBurnRateLimitExceeded` means the add-stake-and-burn call was submitted too soon after a
previous one. The standard-errors reference notes the caller should try again in the next tempo
([Subtensor Standard Errors: AddStakeBurnRateLimitExceeded](https://docs.learnbittensor.org/errors/subtensor#addstakeburnratelimitexceeded)).

This is a rate-pacing check. It does not mean the account lacks funds or that the subnet is
unavailable.

## Why It Appears

This error appears when an add-stake-and-burn operation is submitted before the operation rate limit
for that account has cleared
([Subtensor API Errors: AddStakeBurnRateLimitExceeded](https://docs.learnbittensor.org/subtensor-api/errors#addstakeburnratelimitexceeded)).

## Distinction from Staking Operation Rate Limit Exceeded

`AddStakeBurnRateLimitExceeded` is documented as
`"Add stake and burn" exceeded the operation rate limit.` `StakingOperationRateLimitExceeded` is
documented as "Attempting staking operations too frequently." Both block a staking-related call due
to a rate limit, but their documented conditions describe different limits
([Subtensor API Errors: AddStakeBurnRateLimitExceeded](https://docs.learnbittensor.org/subtensor-api/errors#addstakeburnratelimitexceeded),
[Subtensor Standard Errors: StakingOperationRateLimitExceeded](https://docs.learnbittensor.org/errors/subtensor#stakingoperationratelimitexceeded)).

- **AddStakeBurnRateLimitExceeded** — the stake-burn operation exceeded its rate limit.
- **StakingOperationRateLimitExceeded** — a staking operation was attempted too frequently under the
  per-subnet staking cooldown.

## Distinction from Staking Rate Limit Exceeded

`AddStakeBurnRateLimitExceeded` is documented as
`"Add stake and burn" exceeded the operation rate limit.` `StakingRateLimitExceeded` is documented
as "Staking rate limit exceeded." Both block a staking call due to a rate limit, but their
documented conditions describe different limits
([Subtensor API Errors: AddStakeBurnRateLimitExceeded](https://docs.learnbittensor.org/subtensor-api/errors#addstakeburnratelimitexceeded),
[Subtensor Standard Errors: StakingRateLimitExceeded](https://docs.learnbittensor.org/errors/subtensor#stakingratelimitexceeded)).

- **AddStakeBurnRateLimitExceeded** — the stake-burn operation exceeded its rate limit.
- **StakingRateLimitExceeded** — a staking or unstaking call was retried before the per-account
  staking cooldown cleared.
