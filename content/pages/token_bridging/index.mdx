# Token Bridging

Token bridging in Bittensor is the concept of moving TAO between Substrate-style (SS58) wallets and
Ethereum-style (H160) wallets on the Bittensor chain, and of bridging the EVM representation of TAO
to other EVM-compatible chains. The official
[Token Bridging](https://docs.learnbittensor.org/evm-tutorials/bridge-vtao) documentation frames
this as two related ideas: transferring the same TAO between account formats, and using vTAO as a
cross-chain bridge token.

In Taopedia terms, token bridging names a capability, not a wallet type or a subnet role. It belongs
alongside the [H160 address](https://docs.learnbittensor.org/evm-tutorials/convert-h160-to-ss58)
concept because bridging is what makes TAO usable inside Bittensor's EVM layer.

## Transferring Between Account Formats

TAO is the native token of the Bittensor network. The
[Token Bridging](https://docs.learnbittensor.org/evm-tutorials/bridge-vtao) documentation explains
that TAO is normally held in Substrate-style, SS58-format wallets, which are used to execute
Subtensor blockchain operations through the Bittensor Python SDK and BTCLI.

When TAO is moved to an Ethereum-style H160 wallet, it can be used in Bittensor's EVM layer. The
documentation emphasizes that this is the same token, just represented in a different account
format. The value does not change when TAO moves between SS58 and H160 — only the address format and
the set of available operations change.

For readers, the concept is that token bridging connects two account contexts for the same asset.
SS58 wallets access Substrate-side operations, while H160 wallets access EVM-side operations. The
bridge is the conceptual link between those two representations of TAO.

References: [Token Bridging](https://docs.learnbittensor.org/evm-tutorials/bridge-vtao)

## vTAO

vTAO is the liquid-staked TAO token on the Subtensor EVM. The
[Token Bridging](https://docs.learnbittensor.org/evm-tutorials/bridge-vtao) documentation describes
vTAO as minted by depositing TAO into a staking contract, with the resulting vTAO later redeemable
for an amount of TAO that depends on the exchange rate.

For readers, vTAO is the EVM-chain representation of staked TAO. A holder's vTAO balance stays the
same, while the underlying TAO locked in the staking contract grows with staking rewards. vTAO can
be bridged between supported EVM chains, which is the cross-chain side of token bridging.

References: [Token Bridging](https://docs.learnbittensor.org/evm-tutorials/bridge-vtao)

## Relationship to H160 Address

Token bridging and the H160 address are related because H160 is the destination account format for
Substrate-to-EVM transfers. The
[Token Bridging](https://docs.learnbittensor.org/evm-tutorials/bridge-vtao) documentation describes
moving TAO into Ethereum-style H160 wallets to use it in the EVM layer.

For readers, the H160 address names the EVM-side account format, while token bridging names the
capability of moving TAO into that format. The two concepts work together — the address is the
destination, and the bridge is how TAO reaches it — but they are not the same idea.

References: [Token Bridging](https://docs.learnbittensor.org/evm-tutorials/bridge-vtao),
[H160 Address](https://docs.learnbittensor.org/evm-tutorials/convert-h160-to-ss58)

## Relationship to Bittensor EVM Smart Contracts

Token bridging is what makes TAO usable inside Bittensor's EVM smart-contract layer. The
[Token Bridging](https://docs.learnbittensor.org/evm-tutorials/bridge-vtao) documentation notes that
Bittensor EVM smart contracts are executed solely on the Bittensor blockchain, not on the Ethereum
blockchain.

For readers, this keeps the EVM concept scoped to Bittensor. Token bridging moves TAO into the H160
account format so it can interact with Bittensor's own EVM contracts. The bridge does not send TAO
to Ethereum; it changes the account representation so the same token can participate in Bittensor's
EVM environment.

References: [Token Bridging](https://docs.learnbittensor.org/evm-tutorials/bridge-vtao),
[Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials)

## Reader Boundary

This article defines token bridging and vTAO as concepts. It does not describe bridging steps,
wallet-setup procedures, exchange rates, tool-specific instructions, or supported chain lists.
Readers should use the official Bittensor EVM documentation for operational detail and current
bridge parameters.
