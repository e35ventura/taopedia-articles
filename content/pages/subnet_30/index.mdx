Endure Network is Bittensor Subnet 30. Its on-chain identity registers the subnet name as Endure
Network, describes it as the risk intelligence network, and lists
[endure.network](https://endure.network) as the subnet URL. The on-chain record does not list a
public GitHub repository; the operator organization on GitHub is
[endure-network](https://github.com/endure-network).

## How the Mechanism Works

The Endure Network website describes the subnet as a competitive market for DeFi risk parameters.
Miners are independent analysts who submit risk intelligence — specifically loan-to-value
recommendations, interest rate curves, and liquidation thresholds — for DeFi lending markets.
Validators score those submissions against what actually happened in the market after each epoch:
whether the submitted parameters correctly predicted market behavior and whether recommended
thresholds would have been safe and capital-efficient.

Emissions track performance directly. Miners whose models align with real outcomes earn a larger
share; miners whose models diverge lose share immediately. The website frames this as continuous
scoring rather than periodic reviews, and notes that diverse methodologies across many miners make
the network more adaptive when any single model breaks down.

Subnet consensus produces a risk-intelligence output that Endure routes into products. The first
product built on the network is Forge, described as a lending market that uses Endure's consensus
parameters as its live risk inputs. Forge provides the subnet with real demand data and a proving
ground where miner quality is tested against actual deployed capital.

## Participating as a Miner

Miners on Endure compete by submitting risk-parameter sets for DeFi lending markets. The website
describes the miner task as producing LTV recommendations, interest rate curves, and liquidation
thresholds. Each submission is evaluated after the relevant market outcomes can be observed. Miners
should consult the [endure-network](https://github.com/endure-network) organization on GitHub for
current miner documentation before registering a hotkey.

## Participating as a Validator

Validators score miner submissions against real market outcomes each epoch. The website describes
the scoring axis as whether a model correctly predicted market behavior and whether its recommended
parameters would have been safe and efficient for deployed capital. Validators then set on-chain
weights through [[Yuma Consensus]], directing emissions toward the miners whose risk models most
consistently matched observed outcomes.

## On-Chain Identity

Live SN30 data is available on [TaoStats](https://taostats.io/subnets/30). The Finney identity
reports the subnet name as Endure Network, the description as "The risk intelligence network," and
the subnet URL as endure.network. The GitHub field in the on-chain record is currently blank; the
operator organization is [endure-network](https://github.com/endure-network) on GitHub.
