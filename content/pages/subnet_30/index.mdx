Endure Network is Bittensor Subnet 30. Its live Finney identity registers the subnet name as Endure
Network, describes the project as "the risk intelligence network," and lists
[endure.network](https://endure.network) as the subnet URL. The identity does not currently include
a public GitHub repository, Discord server, or description beyond the one-line tagline.

Because the registered identity does not publish a source repository or detailed project
documentation, this article describes the subnet's known on-chain identity rather than a
reproducible miner task, validator scoring function, or setup process.

## Current Status

For active subnet articles, Taopedia normally describes what miners produce, how validators evaluate
that work, and which public repository defines the mechanism. Subnet 30's current identity provides
a project name and URL but does not link a GitHub source. Readers who want to participate should
consult the live Finney identity and any documentation published at endure.network before relying on
third-party descriptions.

The registered identity state is the useful current fact: netuid 30 is named Endure Network, its
stated purpose is risk intelligence, and its public presence is at endure.network.

## On-Chain Identity

Live SN30 data, including metagraph state and alpha token pool information, is available on
[TaoStats](https://taostats.io/subnets/30). Readers can reproduce the subnet's registered identity
fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 30 --network finney`.

That Finney identity reports the subnet name as Endure Network, the description as "The risk
intelligence network," the subnet URL as endure.network, and blank values for GitHub, contact,
Discord, and additional metadata.
