Endure Network is Bittensor Subnet 30. Its on-chain identity registers the subnet name as Endure
Network, describes the subnet as "the risk intelligence network," and lists
[endure.network](https://endure.network) as the subnet URL. The live identity does not register a
public GitHub repository.

## How the Mechanism Works

Endure turns financial risk analysis into a competitive, continuously scored network task. According
to the [Endure website](https://endure.network), miners are independent analysts who submit risk
parameters — LTV ratios, interest rate curves, and liquidation thresholds — for financial markets.
Each epoch, validators score submissions by measuring them against what actually happened in the
market: did the model predict behavior correctly, and were the parameters safe and efficient?

Emissions follow scoring directly. Top-performing miners earn a larger share; poor performers lose
share immediately. The website describes this as accuracy winning over tenure: "No contracts, no
reputation moats."

The first product built on Endure is Forge, a Bittensor-native money market where users can borrow
TAO against alpha token collateral. Forge provides live demand and real outcome data that feeds back
into miner scoring, and 60% of all Forge revenue is used to buy back the subnet's alpha token
according to the website.

## Participating as a Miner

Miners on Endure compete as risk analysts. The website describes miner work as submitting risk
parameters — specifically LTV recommendations, interest curves, and liquidation thresholds — for
inclusion in the network's consensus output. Because submissions are scored against real market
outcomes each epoch, miners must develop models that accurately predict market behavior rather than
models that merely pass fixed benchmarks. Diverse methodologies across the miner set are described
as a design goal so that the network adapts when any single model breaks.

Operators should consult the Endure website and any published documentation for current
participation requirements.

## Participating as a Validator

Validators score miner submissions against real outcomes. The website describes the scoring process
as measuring each submission against what actually happened — whether predictions were accurate and
whether proposed parameters were safe and capital-efficient. Validators reach agreement on those
scores and set weights on the network through [[Yuma Consensus]], which converts them into the
incentive split across miners.

Operators should consult the Endure website for current validator setup requirements.

## On-Chain Identity

Live SN30 data is available on [TaoStats](https://taostats.io/subnets/30). Readers can reproduce the
subnet's registered identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 30 --network finney`.

That Finney identity reports the subnet name as Endure Network, the subnet description as "the risk
intelligence network," the subnet URL as endure.network, and no registered GitHub repository.
