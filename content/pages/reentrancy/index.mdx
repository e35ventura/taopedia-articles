# Reentrancy

`Reentrancy` is an EVM pallet error raised when reentrancy is detected during EVM transaction
execution. The API errors reference describes it as "EVM reentrancy detected"
([Subtensor API Errors: Reentrancy](https://docs.learnbittensor.org/subtensor-api/errors#reentrancy)).

## What It Means

`Reentrancy` means the EVM call was blocked because the runtime detected a reentrancy condition
during execution
([Subtensor API Errors: Reentrancy](https://docs.learnbittensor.org/subtensor-api/errors#reentrancy)).

This is an EVM reentrancy guard. It does not mean the origin lacks permission to perform the
operation.

## Why It Appears

This error appears when an EVM transaction triggers the reentrancy detection check in the EVM pallet
([Subtensor API Errors: Reentrancy](https://docs.learnbittensor.org/subtensor-api/errors#reentrancy)).

## Distinction from Reentrance Denied

`Reentrancy` is documented as "EVM reentrancy detected." `ReentranceDenied` is documented as "Call
attempted on non-reentrant contract." Both block a call due to reentrancy detection, but their
documented descriptions place them in different pallets
([Subtensor API Errors: Reentrancy](https://docs.learnbittensor.org/subtensor-api/errors#reentrancy),
[Subtensor API Errors: ReentranceDenied](https://docs.learnbittensor.org/subtensor-api/errors#reentrancedenied)).

- **Reentrancy** -- EVM reentrancy detected in the EVM pallet.
- **ReentranceDenied** -- a non-reentrant contract invocation was blocked in the contracts pallet.

## Distinction from Not Allowed

`Reentrancy` is documented as "EVM reentrancy detected." `NotAllowed` is documented as "Origin not
allowed to perform operation." Both block an EVM call, but their documented conditions describe
different problems
([Subtensor API Errors: Reentrancy](https://docs.learnbittensor.org/subtensor-api/errors#reentrancy),
[Subtensor API Errors: NotAllowed](https://docs.learnbittensor.org/subtensor-api/errors#notallowed)).

- **Reentrancy** -- the call is blocked due to reentrancy detection.
- **NotAllowed** -- the origin address is not permitted for the operation.
