# Too Many Topics

`TooManyTopics` is a contracts pallet error raised when a contracts event deposit includes more
topics than the runtime allows. The API errors reference summarizes it as "The amount of topics
passed to `seal_deposit_events` exceeds the limit"
([Subtensor API Errors: TooManyTopics](https://docs.learnbittensor.org/subtensor-api/errors#toomanytopics)).

## What It Means

Some contracts operations can attach topics when depositing events. `TooManyTopics` means that the
supplied topic count is above the runtime's allowed limit, so the event deposit cannot proceed
([Subtensor API Errors: TooManyTopics](https://docs.learnbittensor.org/subtensor-api/errors#toomanytopics)).

This is a topic-count limit failure. It does not, by itself, mean the output buffer was too small,
that a value exceeded the runtime's size limit, or that a transfer failed.

## Why It Appears

This error appears when a contracts event deposit supplies more topics than the runtime permits
([Subtensor API Errors: TooManyTopics](https://docs.learnbittensor.org/subtensor-api/errors#toomanytopics)).

## Distinction from Output Buffer Too Small

`TooManyTopics` and `OutputBufferTooSmall` both stop a contracts call for size-related reasons, but
they check different boundaries. `TooManyTopics` rejects an event deposit because the topic count is
too high. `OutputBufferTooSmall` rejects a call because the caller-provided output buffer is too
small
([Subtensor API Errors: TooManyTopics](https://docs.learnbittensor.org/subtensor-api/errors#toomanytopics),
[Subtensor API Errors: OutputBufferTooSmall](https://docs.learnbittensor.org/subtensor-api/errors#outputbuffertoosmall)).

- **TooManyTopics** — too many topics were supplied for the event deposit.
- **OutputBufferTooSmall** — the caller-provided output buffer is too small.

## Distinction from Value Too Large

`TooManyTopics` and `ValueTooLarge` both describe runtime limit checks, but they apply to different
inputs. `TooManyTopics` checks how many topics were supplied for the event deposit. `ValueTooLarge`
checks whether a value exceeds the runtime's configured maximum size
([Subtensor API Errors: TooManyTopics](https://docs.learnbittensor.org/subtensor-api/errors#toomanytopics),
[Subtensor API Errors: ValueTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#valuetoolarge)).

- **TooManyTopics** — the topic count exceeds the allowed limit.
- **ValueTooLarge** — the value size exceeds the allowed limit.
