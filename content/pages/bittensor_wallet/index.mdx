# Bittensor Wallet

A Bittensor wallet is the key-management context used for Bittensor network actions. Official
Bittensor documentation describes wallets as the way users manage the keys needed to interact with
the network.

References:
[Glossary: Bittensor Wallet](https://docs.learnbittensor.org/resources/glossary#bittensor-wallet),
[Wallets](https://docs.learnbittensor.org/keys/wallets)

## Key-Management Context

The wallet is not just a display name or account label. It is where Bittensor key material is
managed, protected, and used for actions that require authorization. This is why wallet articles
often discuss local wallet files, external wallets, recovery phrases, and key security together.

References: [Wallets](https://docs.learnbittensor.org/keys/wallets),
[Working with Keys](https://docs.learnbittensor.org/keys/working-with-keys)

## Security Context

Wallet security matters because access to wallet key material controls what actions can be
authorized. Protecting wallet files, recovery material, and signing access is part of protecting the
user's Bittensor activity.

Reference: [Working with Keys](https://docs.learnbittensor.org/keys/working-with-keys)

## Reader Boundary

This page defines the term. It does not ask readers to enter keys, expose recovery phrases, or use a
specific wallet provider. Readers should use current official wallet documentation for
security-sensitive wallet actions.
