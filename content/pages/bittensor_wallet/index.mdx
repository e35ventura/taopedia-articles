# Bittensor Wallet

A Bittensor wallet manages the keys used to prove identity, sign transactions, access TAO, and
participate in staking-related actions. Official Bittensor documentation describes wallets as the
main way users organize the keys needed to interact with the network.

References:
[Glossary: Bittensor Wallet](https://docs.learnbittensor.org/resources/glossary#bittensor-wallet),
[Wallets](https://docs.learnbittensor.org/keys/wallets)

## Coldkey and Hotkey Structure

Bittensor wallets use a coldkey and hotkey structure. The coldkey is the higher-value key associated
with ownership and funds, while the hotkey is used for operational network actions. This split lets
users separate long-term custody from day-to-day activity.

References: [Wallets](https://docs.learnbittensor.org/keys/wallets),
[Working with Keys](https://docs.learnbittensor.org/keys/working-with-keys)

## What the Wallet Does

The wallet is not only a folder or display name. It is the structure a user relies on when signing
transactions, authorizing Bittensor actions, managing TAO access, and connecting wallet identity to
network participation. Local wallets, external wallets, and recovery phrases are different parts of
that broader wallet-security picture.

Reference: [Wallets](https://docs.learnbittensor.org/keys/wallets)

## Security Context

Wallet security matters because anyone with access to sensitive wallet material can affect the
actions authorized by those keys. Recovery phrases, wallet files, passwords, and signing access
should be handled as sensitive material. Current official wallet documentation should be used for
live wallet actions because wallet tooling and safety guidance can change.

References: [Working with Keys](https://docs.learnbittensor.org/keys/working-with-keys),
[Glossary: Mnemonic](https://docs.learnbittensor.org/resources/glossary#mnemonic)
