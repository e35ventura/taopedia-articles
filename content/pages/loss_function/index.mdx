# Loss Function

In machine learning, a loss function is a mathematical function that measures the difference between
a model's predicted output and the ground truth. In Bittensor, incentive mechanisms act as loss
functions that steer subnet miners toward desirable outcomes
([Glossary: Loss Function](https://docs.learnbittensor.org/resources/glossary#loss-function)).

## What It Represents

A loss function turns "how wrong was this output" into a number a system can minimize: the smaller
the loss, the closer a prediction sits to the target the designer wants
([Glossary: Loss Function](https://docs.learnbittensor.org/resources/glossary#loss-function)).

Bittensor reuses that idea at the network level. Rather than training a single model, a subnet's
incentive mechanism rewards miners whose work scores well and penalizes work that does not, so the
mechanism plays the role a loss function plays in ordinary training: it defines what "good" means
and pushes participants toward it
([Glossary: Loss Function](https://docs.learnbittensor.org/resources/glossary#loss-function),
[Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets)).

The evaluation details live in the subnet's scoring model, the component of an incentive mechanism
that defines how miner responses are assessed. The loss-function framing is the intuition behind
that scoring: it measures distance from the subnet's goal so emission can flow toward the miners
that close it
([Glossary: Subnet scoring model](https://docs.learnbittensor.org/resources/glossary#subnet-scoring-model)).

## Distinction from Objective Function

A loss function and an objective function are closely related and easy to confuse: one measures
error, the other names the goal. The objective function is the outcome a subnet is continuously
optimizing for through its incentive mechanism, while the loss-function view describes how that
mechanism measures and penalizes distance from the objective so miners are steered toward it
([Glossary: Objective Function](https://docs.learnbittensor.org/resources/glossary#objective-function),
[Glossary: Loss Function](https://docs.learnbittensor.org/resources/glossary#loss-function)).

- **Loss function** — measures how far miner output is from the desired result.
- **Objective function** — the goal the subnet optimizes for through its incentive mechanism.

## Reader Boundary

Loss function is a conceptual framing rather than a single on-chain parameter. The actual evaluation
for any subnet lives in that subnet's incentive mechanism and scoring model, which decide what is
measured and how it maps to rewards
([Glossary: Incentive Mechanism](https://docs.learnbittensor.org/resources/glossary#incentive-mechanism),
[Glossary: Subnet scoring model](https://docs.learnbittensor.org/resources/glossary#subnet-scoring-model)).
