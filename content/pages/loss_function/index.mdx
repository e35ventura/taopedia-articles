# Loss Function

A loss function names the optimization target that a subnet's incentive mechanism steers miners
toward. The official
[Glossary: Loss Function](https://docs.learnbittensor.org/resources/glossary#loss-function)
describes incentive mechanisms as loss functions that guide subnet miners toward desirable outcomes,
drawing on the machine-learning sense of a function that measures how far output is from a desired
result.

## Subnet Vocabulary

Loss function belongs to the vocabulary of subnet design rather than to wallet, governance, or
network infrastructure terms. The
[Glossary: Incentive Mechanism](https://docs.learnbittensor.org/resources/glossary#incentive-mechanism)
describes incentive mechanisms as systems that drive miner behavior and govern validator consensus.
[Understanding Incentive Mechanisms](https://docs.learnbittensor.org/learn/anatomy-of-incentive-mechanism)
places the subnet task, protocol, and evaluation method together as parts of that design.

Loss function names the optimization target inside that context. It is not a reward payout, a
validator score, or a subnet task description on its own.

## Relationship to Objective Function

Loss function and objective function are related terms in subnet prose.
[Glossary: Objective Function](https://docs.learnbittensor.org/resources/glossary#objective-function)
describes the goal a subnet continuously optimizes for through its incentive mechanism.

Loss function names what miners are steered to optimize, while objective function names the goal the
subnet pursues. Both terms belong to the incentive-mechanism layer of subnet vocabulary and are
separate from miner registration, wallet ownership, or chain-level consensus.

## Miner and Validator Context

Loss-function language applies to how subnet evaluation targets are named and communicated.
[Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets) describes
subnets as markets where miners produce a digital commodity and validators measure the work. Loss
function names the target that shapes what kind of work is rewarded within that evaluation context.

This keeps the term separate from the roles themselves: miner and validator name participation
roles, while loss function names how the incentive target is framed.

## Scope

Loss function is a concept term for how subnet incentive rules name an optimization target. It does
not report live scores, recommend specific validators, or describe reward amounts.
