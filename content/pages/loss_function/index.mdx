# Loss Function

In machine learning, a loss function is a mathematical function that measures the difference between
a predicted output and the ground truth. The
[Glossary: Loss Function](https://docs.learnbittensor.org/resources/glossary#loss-function) entry
adds the Bittensor framing: a subnet's incentive mechanism acts as a loss function that steers
subnet miners toward desirable outcomes.

## The Machine-Learning Idea

A loss function gives a model a single number describing how wrong its current output is. Training
then aims to reduce that number, so the loss is the signal that tells the system whether it is
improving. A smaller loss means predictions sit closer to the known correct answers
([Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets)).

The concept matters because it turns a vague goal — "be more accurate" — into a measurable quantity
that can be optimized.

## How Bittensor Uses the Idea

Bittensor reframes this at the network level. Instead of one model minimizing its own loss, a
subnet's incentive mechanism plays the role of the loss function for the whole subnet: it scores
miner outputs against what the subnet considers desirable and rewards the miners that come closest
([Anatomy of Incentive Mechanism](https://docs.learnbittensor.org/learn/anatomy-of-incentive-mechanism)).

In that sense, miners across a subnet are collectively driven down a loss surface defined by the
incentive mechanism, with rewards flowing to the outputs that reduce the measured gap.

## Distinction from Objective Function

A loss function measures error to be minimized, while an objective function names the goal a subnet
is optimizing for. The objective sets the target; the loss measures distance from it. They are two
sides of the same optimization, not the same thing
([Glossary: Objective Function](https://docs.learnbittensor.org/resources/glossary#objective-function)).

- **Loss function** — the measured gap between output and ground truth.
- **Objective function** — the goal the subnet is optimizing toward.

## Why It Matters

Reading incentive mechanisms as loss functions explains why subnet rewards behave the way they do.
The mechanism is not paying for activity in the abstract; it is paying down a measured gap between
miner output and a desired result, the same way training reduces loss
([Anatomy of Incentive Mechanism](https://docs.learnbittensor.org/learn/anatomy-of-incentive-mechanism)).

For readers, this is why a subnet's scoring choices matter so much: they define the loss, and the
loss defines what miners are pushed to produce.
