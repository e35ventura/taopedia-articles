# Loss Function

A loss function names the optimization target that a subnet's incentive mechanism steers miners
toward. The official
[Glossary: Loss Function](https://docs.learnbittensor.org/resources/glossary#loss-function)
describes incentive mechanisms as loss functions that guide subnet miners toward desirable outcomes,
drawing on the machine-learning sense of a function that measures how far output is from a desired
result.

## Subnet Vocabulary

Loss function belongs to the vocabulary of subnet design, alongside incentive mechanism and
objective function. The
[Glossary: Incentive Mechanism](https://docs.learnbittensor.org/resources/glossary#incentive-mechanism)
defines incentive mechanisms as systems that drive miner behavior and govern validator consensus.

Loss function names the optimization target inside that context. It is not a reward payout, a
validator score, or a subnet task description on its own. The
[Glossary: Subnet Task](https://docs.learnbittensor.org/resources/glossary#subnet-task) names the
work miners perform, while loss function names the target those miners are steered toward.

## Relationship to Objective Function

Loss function and objective function are related terms in subnet design prose.
[Glossary: Objective Function](https://docs.learnbittensor.org/resources/glossary#objective-function)
describes the goal a subnet continuously optimizes for through its incentive mechanism.

Loss function emphasizes what miners are steered to optimize toward, while objective function
emphasizes the goal the subnet pursues. Both belong to the incentive-mechanism layer of subnet
vocabulary and are separate from miner registration, token balances, or chain-level governance.

## Miner and Validator Context

Loss-function language applies to how subnet evaluation targets are named and communicated.
[Glossary: Subnet Miner](https://docs.learnbittensor.org/resources/glossary#subnet-miner) and
[Glossary: Subnet Validator](https://docs.learnbittensor.org/resources/glossary#subnet-validator)
name participation roles. Loss function names the target that shapes what kind of work is rewarded
within the evaluation context those roles operate in.

This keeps the term separate from the roles themselves. Miner and validator name who participates,
while loss function names how the incentive target is framed.

## Scope

Loss function is a concept term for how subnet incentive rules name an optimization target. It does
not report live scores, recommend specific validators, or describe reward amounts.
