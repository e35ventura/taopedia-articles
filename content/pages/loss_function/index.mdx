# Loss Function

Loss function is a machine-learning term for measuring how far an output is from the desired answer.
The official [Glossary](https://docs.learnbittensor.org/resources/glossary#loss-function) applies
the term to Bittensor by saying that incentive mechanisms act as loss functions that steer subnet
miners toward desirable outcomes.

## Bittensor Use

In Bittensor writing, loss function is best read as a design analogy. It explains that a subnet's
incentive mechanism points miner work toward what the subnet wants to produce. The term helps
describe the direction of the desired outcome without turning that outcome into a universal rule for
all subnets.

Reference:
[Glossary: Loss Function](https://docs.learnbittensor.org/resources/glossary#loss-function)

## Reader Boundary

This article defines the term at a glossary level. It does not describe a live subnet rule, an exact
equation, or any one subnet's full design. Specific subnet behavior belongs in that subnet's own
references.
