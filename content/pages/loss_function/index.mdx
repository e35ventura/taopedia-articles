# Loss Function

A loss function is a machine-learning idea that Bittensor reuses to describe how a subnet rewards
work. The official [Glossary](https://docs.learnbittensor.org/resources/glossary#loss-function)
defines it as a mathematical function that measures the difference between a predicted output and
the ground truth, and notes that in Bittensor an incentive mechanism acts as a loss function that
steers subnet miners toward desirable outcomes.

## What a Loss Function Measures

In ordinary machine learning, a loss function gives a single number for how far a model's output is
from the intended result, and training works to make that number smaller. The
[Glossary](https://docs.learnbittensor.org/resources/glossary#loss-function) frames the concept this
way: it is the measure of difference between prediction and ground truth, not the model or the data
itself.

## Loss Functions in Bittensor

The Bittensor-specific point is that a subnet's incentive mechanism plays the role of a loss
function. Instead of a single model minimizing its own error, the network rewards miners whose work
moves toward the outcome the subnet wants. The
[Anatomy of an Incentive Mechanism](https://docs.learnbittensor.org/learn/anatomy-of-incentive-mechanism)
documentation describes how a subnet defines and scores that desired behavior, and
[Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets) explains that
each subnet sets its own task and scoring.

## Relationship to the Objective Function

A loss function and an objective function are related but not identical. The
[Glossary](https://docs.learnbittensor.org/resources/glossary#objective-function) describes the
objective function as the goal a subnet is continuously optimizing for through its incentive
mechanism, while the loss function is the measure of difference that scoring uses to move toward
that goal. In short, the objective function names the target, and the loss function names how
distance from the target is measured.

## Reader Boundary

A loss function is a conceptual description, not a fixed formula for every subnet or a live value to
read from the chain. Each subnet defines its own scoring, so the exact loss a subnet uses lives in
that subnet's documentation and implementation. Taopedia's role is to explain what the term means
and how Bittensor applies it, not to specify any single subnet's scoring rule.
