# Bittensor Platform Components

Bittensor is made of several recurring pieces
([Introduction to Bittensor](https://docs.learnbittensor.org/learn/introduction)).

Its main pieces include subnets, miners, validators, TAO, emissions, and tools. The
[Introduction to Bittensor](https://docs.learnbittensor.org/learn/introduction) describes the
network at a high level, while
[Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets) explains how
subnets create specialized markets for digital work.

The components are easiest to read as layers. Subnets define work markets, miners produce work,
validators evaluate it, and TAO plus subnet alpha connect evaluation to tokenomics.

## Subnets

Subnets are the work markets inside Bittensor. The
[Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets) documentation
describes each subnet as a market for a particular digital commodity.

This makes subnets the place where the network specializes. One subnet can focus on a different kind
of work than another subnet, while both remain part of Bittensor.

## Miner and Validator Roles

Miners and validators are the core work-and-evaluation roles. The
[Introduction to Bittensor](https://docs.learnbittensor.org/learn/introduction) describes miners as
supplying useful work and validators as evaluating that work.

Together, those roles make subnet markets measurable. Miners create outputs, and validators provide
the evaluations that connect those outputs to rewards.

## Incentive Mechanisms

Each subnet needs a way to evaluate work. The
[Understanding Incentive Mechanisms](https://docs.learnbittensor.org/learn/anatomy-of-incentive-mechanism)
documentation explains how incentive mechanisms connect miner behavior, validator evaluation, and
reward outcomes.

This component explains why subnets can differ. A subnet's incentive mechanism determines what kind
of work is rewarded and how quality is measured.

## TAO and Emissions

TAO is the network token, and emissions are the reward flow. The
[Emission](https://docs.learnbittensor.org/learn/emissions) documentation describes newly created
TAO and subnet-specific alpha tokens in the emission process.

This tokenomics layer connects evaluated work to economic outcomes. TAO is network-scoped, while
alpha tokens are subnet-specific under Dynamic TAO.

## Tools and Interfaces

Bittensor tools provide ways to interact with the network. The
[Bittensor Tools](https://docs.learnbittensor.org/concepts/tools) documentation groups tools and
libraries used around Bittensor development and operation.

Tools are not the same as the platform concepts themselves. They are interfaces around subnets,
roles, and tokenomics.

## How The Pieces Fit Together

The [Introduction to Bittensor](https://docs.learnbittensor.org/learn/introduction) and
[Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets) documentation
present Bittensor as a network of specialized subnet markets.

In that structure, subnets define the market, miners supply work, validators evaluate work,
incentive mechanisms define reward logic, and emissions connect the evaluated work to TAO and subnet
alpha.

## Term Placement

Platform components is an overview phrase. It groups the concepts a reader needs before looking at
more specific articles such as subnets, incentives, TAO, emissions, or tools
([Introduction to Bittensor](https://docs.learnbittensor.org/learn/introduction)).

Those specific articles explain each component in more detail. This page explains how the components
relate.
