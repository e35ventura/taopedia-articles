# Storage Deposit Not Enough Funds

`StorageDepositNotEnoughFunds` is a contracts pallet error raised when the origin does not have
enough balance to pay the required storage deposits. The API errors reference summarizes it as
"Origin doesn't have enough balance to pay the required storage deposits"
([Subtensor API Errors: StorageDepositNotEnoughFunds](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositnotenoughfunds)).

## What It Means

Subtensor includes a contracts pallet for on-chain smart contracts. Some contracts operations
require the origin to reserve balance as a storage deposit when new contract storage is created.
`StorageDepositNotEnoughFunds` means the origin's available balance is too low to cover that
required deposit, so the runtime rejects the operation
([Subtensor API Errors: StorageDepositNotEnoughFunds](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositnotenoughfunds)).

This is a storage-deposit funding rejection. It does not, by itself, mean more storage was created
than the deposit limit allows, that no contract exists at the targeted address, or that no code
exists at a supplied hash.

## Why It Appears

This error appears when a contracts operation requires storage deposits the origin cannot fund from
its current balance
([Subtensor API Errors: StorageDepositNotEnoughFunds](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositnotenoughfunds)).

## Distinction from Storage Deposit Limit Exhausted

`StorageDepositNotEnoughFunds` and `StorageDepositLimitExhausted` both involve contracts storage
deposits, but the API summaries name different problems. `StorageDepositNotEnoughFunds` means the
origin cannot pay the required deposits. `StorageDepositLimitExhausted` is summarized as "More
storage was created than allowed by the storage deposit limit."
([Subtensor API Errors: StorageDepositNotEnoughFunds](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositnotenoughfunds),
[Subtensor API Errors: StorageDepositLimitExhausted](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositlimitexhausted)).

- **StorageDepositNotEnoughFunds** — the origin cannot fund the required storage deposits.
- **StorageDepositLimitExhausted** — more storage was created than the deposit limit allows.

## Distinction from Contract Not Found

`StorageDepositNotEnoughFunds` and `ContractNotFound` are different contracts pallet errors with
different API summaries. `StorageDepositNotEnoughFunds` means the origin cannot pay required storage
deposits. `ContractNotFound` is summarized as "Contract not found at the specified address."
([Subtensor API Errors: StorageDepositNotEnoughFunds](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositnotenoughfunds),
[Subtensor API Errors: ContractNotFound](https://docs.learnbittensor.org/subtensor-api/errors#contractnotfound)).

- **StorageDepositNotEnoughFunds** — the origin cannot fund the required storage deposits.
- **ContractNotFound** — no live contract exists at the targeted address.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not report the
storage deposit required for a specific operation on a network or calculate an origin's available
balance
([Subtensor API Errors: StorageDepositNotEnoughFunds](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositnotenoughfunds),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
