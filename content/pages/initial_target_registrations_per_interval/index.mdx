# Initial Target Registrations Per Interval

Initial Target Registrations Per Interval is a subtensorModule runtime constant, listed in the
chain's constants metadata as initialTargetRegistrationsPerInterval, with the value 2 and the
summary "Initial target registrations per interval"
([Subtensor API Constants: initialTargetRegistrationsPerInterval](https://docs.learnbittensor.org/subtensor-api/constants#initialtargetregistrationsperinterval-u16)).
It supplies the default value a subnet's TargetRegistrationsPerInterval uses.

## What It Means

TargetRegistrationsPerInterval is held per subnet and sets the number of registrations per interval
a subnet's difficulty and burn adjustment aims for. Initial Target Registrations Per Interval is the
default this per-subnet value falls back to before a different value applies for a subnet
([Subtensor API Constants: initialTargetRegistrationsPerInterval](https://docs.learnbittensor.org/subtensor-api/constants#initialtargetregistrationsperinterval-u16)).
The TargetRegistrationsPerInterval in force on a subnet such as netuid 1 is that subnet's own chain
state and can differ from this default.

## Distinction from Adjustment Interval and Max Per Block

Initial Target Registrations Per Interval is the default target registrations per interval, while
initialAdjustmentInterval, valued at 100, is the number of blocks between adjustments;
initialMaxRegistrationsPerBlock, valued at 1, is the per-block registration cap
([Subtensor API Constants: initialAdjustmentInterval](https://docs.learnbittensor.org/subtensor-api/constants#initialadjustmentinterval-u16),
[Subtensor API Constants: initialMaxRegistrationsPerBlock](https://docs.learnbittensor.org/subtensor-api/constants#initialmaxregistrationsperblock-u16)).

## Reader Boundary

Initial Target Registrations Per Interval is a default constant, not the live per-subnet
TargetRegistrationsPerInterval, and it reflects the current runtime configuration rather than a
fixed protocol rule
([Subtensor API Constants: initialTargetRegistrationsPerInterval](https://docs.learnbittensor.org/subtensor-api/constants#initialtargetregistrationsperinterval-u16)).
