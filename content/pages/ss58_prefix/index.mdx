# SS58 Prefix

SS58 prefix is a system runtime constant, listed in the Subtensor constants reference as ss58Prefix.
Its current value is 42, and the reference describes it as the chain's designated SS58 prefix
([Subtensor API Constants: ss58Prefix](https://docs.learnbittensor.org/subtensor-api/constants#ss58prefix-u16)).
The Subtensor runtime defines the same value and wires it into the system pallet configuration as
the chain identifier used by the runtime
([runtime/src/lib.rs](https://github.com/opentensor/subtensor/blob/14bc6f9f964b9cc362e9635dd110a487fa5d15a0/runtime/src/lib.rs#L258-L270),
[runtime/src/lib.rs](https://github.com/opentensor/subtensor/blob/14bc6f9f964b9cc362e9635dd110a487fa5d15a0/runtime/src/lib.rs#L337-L338)).

## What It Means

SS58 is the encoding format for public-key-derived Bittensor wallet addresses
([Glossary: SS58 Encoded](https://docs.learnbittensor.org/resources/glossary#ss58-encoded)). The
SS58 prefix is the chain-side number used as part of that address encoding context. It helps
identify which chain format an SS58-encoded address belongs to, while the key material still
determines who can sign for the account.

For a reader, the important boundary is that ss58Prefix is an address-format constant. It does not
name a wallet, coldkey, hotkey, balance, or ownership relationship by itself
([Subtensor API Constants: ss58Prefix](https://docs.learnbittensor.org/subtensor-api/constants#ss58prefix-u16),
[Wallets, Coldkeys, and Hotkeys](https://docs.learnbittensor.org/keys/coldkey-hotkey-security)).

## Distinction from SS58 Encoded

SS58 prefix and SS58 encoded are related, but they are not the same idea. SS58 prefix is the numeric
system constant, currently 42. SS58 encoded describes the address encoding format used for Bittensor
wallet addresses
([Subtensor API Constants: ss58Prefix](https://docs.learnbittensor.org/subtensor-api/constants#ss58prefix-u16),
[Glossary: SS58 Encoded](https://docs.learnbittensor.org/resources/glossary#ss58-encoded)).

- **SS58 prefix** - the chain prefix value used in address encoding.
- **SS58 encoded** - the address format that represents public-key-derived wallet addresses.

## Distinction from H160 Address

SS58 prefix belongs to native Subtensor address encoding. H160 address belongs to the Ethereum-style
address format used by Bittensor EVM wallets. The H160 conversion guide explains how users can
convert between H160 and SS58 representations, but conversion is about address representation rather
than proving native signing authority
([Convert H160 to SS58](https://docs.learnbittensor.org/evm-tutorials/convert-h160-to-ss58),
[Glossary: SS58 Encoded](https://docs.learnbittensor.org/resources/glossary#ss58-encoded)).

## Reader Boundary

This page defines the current ss58Prefix runtime constant. It does not validate a specific address,
convert an H160 address, or prove that a user controls a coldkey or hotkey. Those actions depend on
the relevant wallet keys and signing context, not on the prefix value alone
([Subtensor API Constants: ss58Prefix](https://docs.learnbittensor.org/subtensor-api/constants#ss58prefix-u16),
[Convert H160 to SS58](https://docs.learnbittensor.org/evm-tutorials/convert-h160-to-ss58)).
