Nodexo is Bittensor Subnet 27, a decentralized GPU compute marketplace operated by NeuralInternet.
Previously known as NI Compute, the subnet enables GPU owners to contribute hardware to a shared
pool and earn rewards, while clients can rent on-demand GPU instances through the NeuralInternet
cloud platform. The GitHub repository listed in the subnet's Finney identity is
[neuralinternet/compute-subnet](https://github.com/neuralinternet/compute-subnet).

## What the Subnet Produces

Nodexo's output is verified, on-demand GPU compute. The subnet connects GPU owners — called miners —
with clients who need compute capacity, all coordinated through a permissionless, on-chain incentive
layer. A community-maintained description of the subnet, reproduced in the
[SubnetAlpha listing](https://subnetalpha.ai/subnet/nodexo/), describes Nodexo as "decentralizing
computing resources by combining siloed pools of compute on a blockchain to be validated and
accessed trustlessly."

The subnet accepts a range of hardware tiers. High-end cards such as H100s and A100s earn higher
performance scores, but the incentive design is open to any GPU owner. The subnet explicitly
discourages container-based rental platforms; its documentation recommends dedicated bare-metal
hardware or reputable GPU-cloud providers that grant direct hardware access.

The NeuralInternet organization also maintains a public open-metrics repository,
[neuralinternet/SN27-opencompute](https://github.com/neuralinternet/SN27-opencompute), which
provides monitoring dashboards and analytics tooling for the subnet's performance data.

## Miner and Validator Roles

Miners contribute GPU hardware by running the subnet's miner process, which registers the hardware
with the network and exposes it for validator benchmarking and client allocation. When a validator
runs a Proof-of-GPU challenge, the miner responds with benchmark results that demonstrate its
hardware's actual compute throughput. Stronger hardware that answers challenges reliably earns a
higher score and, through [[Yuma Consensus]], a larger share of subnet emissions.

Validators run the benchmarking side of the subnet. They cycle through registered miners, issue GPU
performance tests measuring real compute output such as TFLOPS, and compute a score for each miner
based on the results. Those scores are committed as weight vectors to the Bittensor chain and feed
into [[Yuma Consensus]] to determine emission allocation. Validators also handle job allocation when
clients request compute capacity, routing requests to miners whose hardware has passed recent
benchmarks.

## On-Chain Identity

Live SN27 data, including metagraph state, neuron registrations, and alpha token pool information,
is available on [TaoStats](https://taostats.io/subnets/27). Readers can reproduce the subnet's
registered identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 27 --network finney`.

The Finney subnet identity for netuid 27 registers the subnet under the name Nodexo, lists the
GitHub repository as
[neuralinternet/compute-subnet](https://github.com/neuralinternet/compute-subnet), and records the
owner coldkey as `5CopvHeTZHNy6RMztuRFvViwwZbsZaVkJPA9zmRRnPAna73M`.
