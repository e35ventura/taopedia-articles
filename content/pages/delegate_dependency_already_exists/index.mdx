# Delegate Dependency Already Exists

`DelegateDependencyAlreadyExists` is a contracts pallet error raised when a contract already depends
on the same delegate dependency. The API errors reference summarizes it as "The contract already
depends on the given delegate dependency"
([Subtensor API Errors: DelegateDependencyAlreadyExists](https://docs.learnbittensor.org/subtensor-api/errors#delegatedependencyalreadyexists)).

## What It Means

Bittensor supports an Ethereum-compatible smart-contract environment on Subtensor
([Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials)). In that setting, a
delegate dependency is part of the contract's stored dependency list.
`DelegateDependencyAlreadyExists` means the requested dependency is already present, so the same
dependency cannot be added again
([Subtensor API Errors: DelegateDependencyAlreadyExists](https://docs.learnbittensor.org/subtensor-api/errors#delegatedependencyalreadyexists)).

This is a duplicate-entry rejection. It does not mean the contract has already reached the maximum
number of dependencies, and it does not mean the dependency is missing when a removal is attempted.

## Why It Appears

This error appears when a contracts operation tries to add a delegate dependency that is already in
the contract's dependency set
([Subtensor API Errors: DelegateDependencyAlreadyExists](https://docs.learnbittensor.org/subtensor-api/errors#delegatedependencyalreadyexists)).

## Distinction from Max Delegate Dependencies Reached

`DelegateDependencyAlreadyExists` and `MaxDelegateDependenciesReached` both block adding delegate
dependencies, but they reject different problems. `DelegateDependencyAlreadyExists` means the same
dependency is being added again. `MaxDelegateDependenciesReached` means the contract has already
filled the runtime's allowed dependency count
([Subtensor API Errors: DelegateDependencyAlreadyExists](https://docs.learnbittensor.org/subtensor-api/errors#delegatedependencyalreadyexists),
[Subtensor API Errors: MaxDelegateDependenciesReached](https://docs.learnbittensor.org/subtensor-api/errors#maxdelegatedependenciesreached)).

- **DelegateDependencyAlreadyExists** — the submitted dependency is already stored.
- **MaxDelegateDependenciesReached** — the contract has no room for another dependency.

## Distinction from Delegate Dependency Not Found

`DelegateDependencyAlreadyExists` and `DelegateDependencyNotFound` point in opposite directions.
`DelegateDependencyAlreadyExists` blocks adding a dependency that is already present.
`DelegateDependencyNotFound` means the named dependency is not present in the contract's stored
dependency list
([Subtensor API Errors: DelegateDependencyAlreadyExists](https://docs.learnbittensor.org/subtensor-api/errors#delegatedependencyalreadyexists),
[Subtensor API Errors: DelegateDependencyNotFound](https://docs.learnbittensor.org/subtensor-api/errors#delegatedependencynotfound)).

- **DelegateDependencyAlreadyExists** — the dependency is already present.
- **DelegateDependencyNotFound** — the dependency is not present.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not document the
live dependency count limit on a network or describe how a contract should redesign its dependency
structure
([Subtensor API Errors: DelegateDependencyAlreadyExists](https://docs.learnbittensor.org/subtensor-api/errors#delegatedependencyalreadyexists),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
