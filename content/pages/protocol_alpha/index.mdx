# Protocol Alpha

Protocol alpha refers to alpha-token context inside Bittensor tokenomics. Official Bittensor
documentation describes alpha tokens as subnet-related assets in the Dynamic TAO model.

References:
[Glossary: Protocol Alpha](https://docs.learnbittensor.org/resources/glossary#protocol-alpha),
[Emission](https://docs.bittensor.com/emissions)

## Tokenomics Context

The term belongs to subnet tokenomics rather than wallet custody or miner work. It helps distinguish
subnet-level alpha-token accounting from network-level TAO accounting when reading about Dynamic TAO
and emissions.

References:
[Glossary: Protocol Alpha](https://docs.learnbittensor.org/resources/glossary#protocol-alpha),
[Emission](https://docs.bittensor.com/emissions)

## Reader Boundary

This page defines the term at a high level. It does not report live alpha balances, subnet prices,
or investment recommendations. Readers should use current official tokenomics references when they
need exact network values.
