# Lite Node

A lite node is a type of public Subtensor node that stores limited blockchain data and relies on
archive nodes for full historical access. The official
[Glossary: Lite Node](https://docs.learnbittensor.org/resources/glossary#lite-node) defines it in
those terms, and the [Subtensor Node Basics](https://docs.learnbittensor.org/subtensor-nodes)
documentation places it alongside archive nodes as one of two public node types synchronized with
the Bittensor network.

## Public Subtensor Context

Lite nodes belong to public chain access, not local development blockchains. The
[Subtensor Node Basics](https://docs.learnbittensor.org/subtensor-nodes) documentation contrasts a
public Subtensor node with a local blockchain used for subnet incentive development and testing. In
that reading, lite node names a public synchronization role rather than a private staging chain.

The same documentation also notes that a public Subtensor node can sync with the Bittensor mainchain
or testchain. Taopedia readers should treat lite node as network-access vocabulary, not as a subnet
participant role.

## Relationship to Archive Node

Archive nodes and lite nodes solve different storage problems. The
[Glossary: Archive Node](https://docs.learnbittensor.org/resources/glossary#archive-node) describes
archive nodes as storing the entire blockchain history for full data access and querying. The lite
node glossary entry, by contrast, keeps only limited data and depends on archive nodes when full
historical access is required.

For readers, the distinction is scope: lite node names the lighter public node type, while archive
node names the full-history public node type.

## Neuron Boundary

A Subtensor node is not a Bittensor neuron. The
[Subtensor Node Basics](https://docs.learnbittensor.org/subtensor-nodes) documentation states that a
Subtensor node differs from a neuron, which is a subnet validator or subnet miner inside a subnet
and does not contain the blockchain database. Lite node therefore belongs to chain-access
vocabulary, not to subnet miner or subnet validator role labels.

## Reader Boundary

Lite node should not be read as a setup guide, endpoint recommendation, or storage-size quote. This
article defines the term at a reference level. Operational node configuration, sync mode details,
and current infrastructure choices belong in the official Subtensor node documentation.
