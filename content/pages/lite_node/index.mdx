# Lite Node

A lite node describes a lighter Bittensor node context with more limited chain state than an archive
node. Official Bittensor documentation uses node terms when explaining access to Subtensor chain
data.

References: [Glossary: Lite Node](https://docs.learnbittensor.org/resources/glossary#lite-node),
[Subtensor Nodes](https://docs.learnbittensor.org/subtensor-nodes)

## Chain State Scope

The useful distinction is state scope. Archive node context emphasizes historical chain state, while
lite node context emphasizes lighter chain access. This makes the term relevant when discussing what
kind of chain data a node context can support.

References: [Glossary: Lite Node](https://docs.learnbittensor.org/resources/glossary#lite-node),
[Glossary: Archive Node](https://docs.learnbittensor.org/resources/glossary#archive-node)

## Reader Boundary

This page defines the term. It does not recommend a node type, endpoint, or hardware profile.
Readers should use current official node documentation when they need operational details.
