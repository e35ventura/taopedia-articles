# Lite Node

A lite node is a type of public Subtensor node that stores limited blockchain data and relies on
archive nodes for full historical access. The official
[Glossary: Lite Node](https://docs.learnbittensor.org/resources/glossary#lite-node) defines it in
those terms, and the [Subtensor Node Basics](https://docs.learnbittensor.org/subtensor-nodes)
documentation places it alongside archive nodes as one of two public node types synchronized with
the Bittensor network.

## Public Subtensor Context

Lite nodes belong to public chain access, not local development blockchains. The
[Subtensor Node Basics](https://docs.learnbittensor.org/subtensor-nodes) documentation contrasts a
public Subtensor node with a local blockchain used for subnet development and testing. In that
reading, lite node names a public synchronization role rather than a private staging chain.

A public Subtensor node can sync with the Bittensor mainchain or testchain. Lite node should be read
as network-access vocabulary, not as a subnet participant role.

## Relationship to Archive Node

Archive nodes and lite nodes solve different storage problems. The
[Glossary: Archive Node](https://docs.learnbittensor.org/resources/glossary#archive-node) describes
archive nodes as storing the entire blockchain history for full data access and querying. The lite
node glossary entry, by contrast, keeps only limited data and depends on archive nodes when full
historical access is required.

The distinction is scope: lite node names the lighter public node type, while archive node names the
full-history public node type.

## Network Environment Boundary

Bittensor documentation separates mainnet, testnet, and localnet contexts. Lite node belongs to
public chain access for mainnet or testnet environments
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

A lite node should not be read as a local or testnet-only concept. It names a public Subtensor node
role that can connect to production or test chain environments.

## Scope

Lite node is a concept term for a public Subtensor node with limited historical storage. It does not
name a subnet role, a wallet type, or a development chain.
