# Lite Node

A lite node is a type of public Subtensor node that stores limited blockchain data and relies on
archive nodes for full historical data. The
[Glossary: Lite Node](https://docs.learnbittensor.org/resources/glossary#lite-node) entry defines it
this way and lists it among the Subtensor node types in the
[Subtensor Nodes](https://docs.learnbittensor.org/subtensor-nodes) reference.

## What It Stores

A lite node keeps a reduced view of chain state rather than the complete history. It can serve
current and recent data efficiently, but for queries that reach further back it depends on an
archive node that has retained the older blocks
([Subtensor Nodes](https://docs.learnbittensor.org/subtensor-nodes)).

That reduced footprint is the point: a lite node uses less storage and is cheaper to run, which
suits clients that mostly need present-state reads.

## Distinction from Archive Node

An archive node stores the entire chain history for full querying, while a lite node stores only
limited data and defers to archive nodes for full historical access. They are the same kind of
public Subtensor node differing in retained history
([Glossary: Archive Node](https://docs.learnbittensor.org/resources/glossary#archive-node)).

- **Lite node** — limited data, low footprint, relies on archive nodes for history.
- **Archive node** — full history, larger footprint, answers deep historical queries.

## Why Use a Lite Node

Most interactions — reading the current
[metagraph](https://docs.learnbittensor.org/resources/glossary#metagraph), checking a present
balance, or submitting a transaction — only need recent state. A lite node covers those at lower
cost, leaving archive nodes for the smaller set of tasks that genuinely need deep history
([Managing Subtensor Connections](https://docs.learnbittensor.org/sdk/managing-subtensor-connections)).

For readers, the choice is a trade-off: a lite node is lighter and sufficient for current-state
work, while a task that queries old blocks should point at an archive endpoint instead
([Subtensor Nodes](https://docs.learnbittensor.org/subtensor-nodes)).
