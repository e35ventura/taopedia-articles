# Bittensor Wallets

A Bittensor wallet represents a user or entity’s identity and signing authority on the network. It
stores cryptographic keys used to access TAO, delegate stake, and authorize operations.

- A wallet contains or references two key roles: a security-critical coldkey, and one or more
  operational hotkeys.
- Wallet operations include creating/importing keys, viewing balances, staking/unstaking, and
  registering participants.

References: [Wallets (learnbittensor.org)](https://docs.learnbittensor.org/keys/wallets),
[BTCLI Reference](https://docs.learnbittensor.org/btcli)

## What a wallet does

- Proves identity for transactions and on-chain actions.
- Controls TAO and stake (via the coldkey) and runs roles like miners/validators (via hotkeys).
- Interfaces with CLI (`btcli`) or SDKs to manage keys and send transactions.

## Managing a wallet (conceptual)

- Create or import a wallet using the CLI or SDK.
- Securely store the seed phrase (mnemonic) offline.
- Generate a hotkey for operational roles.

## Security guidelines

- Keep seed phrases private and offline.
- Verify you are using official documentation and released binaries.
- Use hardware-backed or dedicated secure storage for the coldkey if possible.

## Relationship to Autostaking

Wallets and autostaking address different parts of how miner emissions flow after being distributed.
A wallet is the container for a coldkey-hotkey pair and the associated balances and subnet
registrations those keys control. Autostaking is a feature that automatically stakes a miner's
emission rewards to a chosen validator rather than requiring the miner to initiate a separate
staking action after each emission cycle. The
[Wallets, Coldkeys and Hotkeys](https://docs.learnbittensor.org/keys/wallets) documentation covers
wallet and key structure, and the
[Autostaking](https://docs.learnbittensor.org/staking-and-delegation/autostaking) documentation
describes how earned emissions are routed without manual intervention.

Autostaking uses the hotkey registered with a subnet to determine where emissions are automatically
directed. A wallet holds those hotkeys and the coldkey that controls them. Without a properly
configured wallet and hotkey, autostaking has no key context to route emissions through. The wallet
provides the key structure; autostaking defines the routing behavior for what that key earns. A
miner who relies on autostaking still needs their hotkey to be registered in their wallet — the
wallet is the foundation, autostaking is the emission-routing behavior layered on top of it.

References: [Wallets, Coldkeys and Hotkeys](https://docs.learnbittensor.org/keys/wallets),
[Autostaking](https://docs.learnbittensor.org/staking-and-delegation/autostaking)
