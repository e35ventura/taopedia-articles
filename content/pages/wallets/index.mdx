# Bittensor Wallets

A Bittensor wallet represents a user or entity’s identity and signing authority on the network. It
stores cryptographic keys used to access TAO, delegate stake, and authorize operations.

- A wallet contains or references two key roles: a security-critical coldkey, and one or more
  operational hotkeys.
- Wallet operations include creating/importing keys, viewing balances, staking/unstaking, and
  registering participants.

References: [Wallets (learnbittensor.org)](https://docs.learnbittensor.org/keys/wallets),
[BTCLI Reference](https://docs.learnbittensor.org/btcli)

## What a wallet does

- Proves identity for transactions and on-chain actions.
- Controls TAO and stake (via the coldkey) and runs roles like miners/validators (via hotkeys).
- Interfaces with CLI (`btcli`) or SDKs to manage keys and send transactions.

## Managing a wallet (conceptual)

- Create or import a wallet using the CLI or SDK.
- Securely store the seed phrase (mnemonic) offline.
- Generate a hotkey for operational roles.

## Security guidelines

- Keep seed phrases private and offline.
- Verify you are using official documentation and released binaries.
- Use hardware-backed or dedicated secure storage for the coldkey if possible.

## Relationship to Coldkeys

Wallets and coldkeys are related but different scopes in Bittensor wallet vocabulary. A wallet is
the overall cryptographic identity that holds keys used to access TAO and sign transactions, while a
coldkey is the specific security-sensitive key within that wallet that controls TAO balances and
owns hotkeys. The [Wallets, Coldkeys and Hotkeys](https://docs.learnbittensor.org/keys/wallets)
documentation describes the wallet as containing or referencing both a coldkey and one or more
hotkeys, positioning the coldkey as the custody anchor and the wallet as the broader identity
structure.

For readers, the wallet names the complete identity framework, while the coldkey names the
high-security key component that should be protected offline and controls financial operations.

Reference: [Wallets, Coldkeys and Hotkeys](https://docs.learnbittensor.org/keys/wallets)

## Relationship to Hotkeys

Wallets and hotkeys are related but different parts of Bittensor wallet vocabulary. A wallet is the
cryptographic identity structure that proves control and signs transactions, while a hotkey is the
operational key within that wallet used for day-to-day network activities like registering on
subnets and submitting weights. The
[Wallets, Coldkeys and Hotkeys](https://docs.learnbittensor.org/keys/wallets) documentation
describes wallets as containing a coldkey and one or more hotkeys, where the coldkey handles
financial operations and the hotkeys handle operational roles.

For readers, the wallet names the overall identity and signing authority, while hotkeys name the
operational-level keys designed to run on internet-exposed nodes without risking the coldkey or TAO
balances.

Reference: [Wallets, Coldkeys and Hotkeys](https://docs.learnbittensor.org/keys/wallets)
