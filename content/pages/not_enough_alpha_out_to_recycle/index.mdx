# Not Enough Alpha Out To Recycle

`NotEnoughAlphaOutToRecycle` is a subtensor pallet error raised when a recycle operation cannot
proceed because the target subnet does not have enough AlphaOut. The API errors reference describes
it as "Not enough AlphaOut on the subnet to recycle"
([Subtensor API Errors: NotEnoughAlphaOutToRecycle](https://docs.learnbittensor.org/subtensor-api/errors#notenoughalphaouttorecycle)).

## What It Means

`NotEnoughAlphaOutToRecycle` means the recycle call was blocked because the subnet's AlphaOut was
below what is needed for the operation
([Subtensor API Errors: NotEnoughAlphaOutToRecycle](https://docs.learnbittensor.org/subtensor-api/errors#notenoughalphaouttorecycle)).

This is a subnet AlphaOut check. It does not mean the caller lacks funds or that the subnet does not
exist.

## Why It Appears

This error appears when a recycle_alpha call is submitted targeting a subnet whose AlphaOut is
insufficient for the recycling operation
([Subtensor API Errors: NotEnoughAlphaOutToRecycle](https://docs.learnbittensor.org/subtensor-api/errors#notenoughalphaouttorecycle)).

## Distinction from Cannot Burn Or Recycle On Root Subnet

`NotEnoughAlphaOutToRecycle` is documented as "Not enough AlphaOut on the subnet to recycle."
`CannotBurnOrRecycleOnRootSubnet` is documented as "Cannot burn/recycle TAO from root subnet." Both
block a recycle operation, but their documented conditions describe different problems
([Subtensor API Errors: NotEnoughAlphaOutToRecycle](https://docs.learnbittensor.org/subtensor-api/errors#notenoughalphaouttorecycle),
[Subtensor API Errors: CannotBurnOrRecycleOnRootSubnet](https://docs.learnbittensor.org/subtensor-api/errors#cannotburnorrecycleonrootsubnet)).

- **NotEnoughAlphaOutToRecycle** — the subnet's AlphaOut is too low for the recycle operation.
- **CannotBurnOrRecycleOnRootSubnet** — burn and recycle calls are not supported on the root subnet.

## Distinction from Reserves Too Low

`NotEnoughAlphaOutToRecycle` is documented as "Not enough AlphaOut on the subnet to recycle."
`ReservesTooLow` is documented as "Reserves too low for operation." Both block an operation due to
insufficient subnet resources, but their documented conditions describe different operations
([Subtensor API Errors: NotEnoughAlphaOutToRecycle](https://docs.learnbittensor.org/subtensor-api/errors#notenoughalphaouttorecycle),
[Subtensor API Errors: ReservesTooLow](https://docs.learnbittensor.org/subtensor-api/errors#reservestoolow)).

- **NotEnoughAlphaOutToRecycle** — subnet AlphaOut is insufficient for a recycle call.
- **ReservesTooLow** — pool reserves are too low for a swap operation.
