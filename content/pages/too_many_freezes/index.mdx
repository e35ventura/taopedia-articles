# Too Many Freezes

`TooManyFreezes` is a balances pallet error raised when placing a new balance freeze on an account
would exceed the maximum number of freezes the runtime allows. The API docs describe it as "Number
of freezes exceed `MaxFreezes`"
([Subtensor API Errors: TooManyFreezes](https://docs.learnbittensor.org/subtensor-api/errors#toomanyfreezes)).

## What It Means

Each account may have a limited number of balance freezes active at the same time. `TooManyFreezes`
fires when a pallet attempts to place a new freeze on an account that already has the maximum number
of freezes
([Subtensor API Errors: TooManyFreezes](https://docs.learnbittensor.org/subtensor-api/errors#toomanyfreezes)).

## Why It Appears

This error appears when a pallet tries to set or update a freeze on an account and the insertion
fails because the account's freeze list has reached `MaxFreezes`
([Subtensor API Errors: TooManyFreezes](https://docs.learnbittensor.org/subtensor-api/errors#toomanyfreezes)).

## Distinction from Too Many Holds

`TooManyFreezes` and `TooManyHolds` both fire when a per-account balance tracking list is full, but
they track different things. `TooManyHolds` fires when the hold list is full. `TooManyFreezes` fires
when the freeze list is full
([Subtensor API Errors: TooManyHolds](https://docs.learnbittensor.org/subtensor-api/errors#toomanyholds)).

- **TooManyHolds** — hold list is full; new hold cannot be placed.
- **TooManyFreezes** — freeze list is full; new freeze cannot be placed.

## Distinction from Too Many Reserves

`TooManyFreezes` and `TooManyReserves` both block pallet-initiated balance operations, but they
apply to different balance mechanisms. `TooManyReserves` fires when the named-reserve count is
exceeded. `TooManyFreezes` fires when the freeze count is exceeded
([Subtensor API Errors: TooManyReserves](https://docs.learnbittensor.org/subtensor-api/errors#toomanyreserves)).

- **TooManyReserves** — named-reserve count is at the limit.
- **TooManyFreezes** — freeze count is at the limit.

## Reader Boundary

This page defines the meaning of the error label and the freeze-count check that raises it. It does
not report the current number of active freezes on any account; that is live chain state
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
