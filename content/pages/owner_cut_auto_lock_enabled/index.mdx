# Owner Cut Auto Lock Enabled

Owner cut auto lock enabled is a per-subnet hyperparameter, listed in the documentation as
`OwnerCutAutoLockEnabled`, that decides whether the subnet owner's emission cut is automatically
locked each epoch. The reference describes it as controlling auto-locking of the distribution cut,
with a default of false so the cut is ordinarily received as free stake unless the flag is enabled
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

## What It Controls

The hyperparameter governs what happens to the owner cut after it is distributed, not whether the
cut is paid. When
[owner cut enabled](https://docs.learnbittensor.org/subnets/subnet-hyperparameters#ownercutenabled)
is true and this flag is true, the owner's distribution cut is added to the owner's conviction lock
each epoch, topping up an existing lock or creating a new one targeting the owner hotkey. When this
flag is false, the cut arrives as free stake with no auto-locking
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

It does not set the owner-cut percentage or change Yuma Consensus settlement. It only decides
whether the owner's received cut is immediately subject to conviction locking on the selected netuid
([Yuma Consensus](https://docs.learnbittensor.org/learn/yuma-consensus),
[Emission](https://docs.learnbittensor.org/learn/emissions)).

The flag is owner-tunable per subnet and is exposed in the canonical hyperparameter API, so netuid 1
can keep the default while another netuid auto-locks owner cuts, and the live value is chain state
rather than a network constant
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

## Documented Type and Default

The [Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)
reference lists `OwnerCutAutoLockEnabled` as a `Bool` with a default of false and marks the
permission required to change it as subnet owner
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

Because each subnet carries its own hyperparameters, the auto-lock gate on one netuid can differ
from the documented default and from the flag on another subnet
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

## Reading the Live Value for netuid 1

Owner cut auto lock enabled is per-subnet chain state, so any live claim is tied to a specific
netuid. For the documented example netuid 1 on Finney mainnet, the flag appears in that subnet's
hyperparameter table, which the reference describes under viewing a subnet's hyperparameters
([Subnet Hyperparameters: View hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters#view-hyperparameters)).
The infobox uses netuid 1 only as an example label; other subnets expose their own values
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

## Distinction from Owner Cut Enabled

Owner cut enabled decides whether the owner receives a cut of emissions at all. Owner cut auto lock
enabled decides whether that received cut is automatically conviction-locked each epoch
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

- **Owner cut enabled** — whether the owner cut is distributed.
- **Owner cut auto lock enabled** — whether the distributed cut is auto-locked.
