Tag101 is Bittensor Subnet 101, a subnet focused on a single task: attaching short descriptive
labels to X posts. As the repository puts it, Tag101 models a decentralized tagging network where
miners transform social media posts into concise, structured labels. The incentive-mechanism code is
maintained in the [tag101-ai/tag101](https://github.com/tag101-ai/tag101) repository.

## What the Subnet Produces

The subnet's output is structured label sets for X posts. Validators maintain a pool of posts drawn
from a publicly disclosed whitelist of accounts — the initial whitelist focuses on AI-related
accounts — and distribute each post to miners as a tagging task. Miners return a small set of short
labels identifying the key entities, topics, events, or meanings in each post.

Labels are evaluated on how well they reflect the consensus across all miners' submissions for the
same post, how relevant and correctly formatted they are, and how distinct they are from the miner's
own other labels for the same task. A miner's overall score for a task is the average of its
individual label scores.

## Miner and Validator Roles

Miners produce label sets for each post they receive. A miner competes by returning labels that
align with how other miners read the same post, correctly formatted and covering distinct aspects of
the content rather than repeating the same concept.

Validators distribute posts to miners, score the returned labels, and publish weights on chain.
Those validator scores feed into [[Yuma Consensus]], which converts them into the incentive split
across miners and validators.

## On-Chain Identity

Live SN101 data, including metagraph state and alpha token pool information, is available on
[TaoStats](https://taostats.io/subnets/101). Readers can reproduce the subnet's registered identity
fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 101 --network finney`.

The Finney subnet identity for netuid 101 reports the subnet name as Tag101, the on-chain
description as "Tag101 is a Bittensor subnet for decentralized social post tagging", the GitHub
repository as [tag101-ai/tag101](https://github.com/tag101-ai/tag101), and the Discord handle as
Tag101.
