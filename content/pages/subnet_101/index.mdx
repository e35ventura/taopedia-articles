Tag101 is Bittensor Subnet 101. Its on-chain identity names the subnet Tag101, describes it as "a
Bittensor subnet for decentralized social post tagging", and lists
[tag101-ai/tag101](https://github.com/tag101-ai/tag101) as the registered GitHub repository.

## How the Mechanism Works

Validators draw X (Twitter) posts from a publicly disclosed account whitelist and distribute them to
miners as individual tagging tasks. Each miner returns a small set of short labels identifying the
entities, topics, and meanings present in each post.

Labels are scored on three criteria documented in the tag101 README: how closely they align with the
consensus across all miners' submissions for the same post, how relevant and well-formed they are,
and how distinct they are from the miner's other labels for the same task. A miner's score for a
task is the average of its individual label scores. Validators aggregate per-task scores into
relative miner weights and publish those weights on chain, which feeds into [[Yuma Consensus]].

## On-Chain Identity

Live SN101 subnet data, including metagraph state and alpha token pool information, is available on
[TaoStats](https://taostats.io/subnets/101). The registered Finney identity for netuid 101 records
the subnet name as Tag101, the on-chain description as "Tag101 is a Bittensor subnet for
decentralized social post tagging", the GitHub repository as
[tag101-ai/tag101](https://github.com/tag101-ai/tag101), and the Discord handle as Tag101.
