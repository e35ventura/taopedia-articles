Tag101 is Bittensor Subnet 101, described in its on-chain identity as a Bittensor subnet for
decentralized social post tagging. In plain terms, the subnet turns X post labeling into a network
service: miners tag posts with short descriptive labels, and validators score how well those labels
capture what each post is about.

## What Tag101 Provides

The on-chain identity for netuid 101 names the subnet Tag101 and links to the
[tag101-ai/tag101](https://github.com/tag101-ai/tag101) repository as its codebase. The subnet's
output is a pool of labeled X posts. Validators draw posts from a publicly disclosed account
whitelist and distribute them to miners as tagging tasks. Miners return short labels per post that
identify the key entities, topics, and meanings present in the content.

This places Tag101 in the data-labeling layer of the ecosystem. Its value proposition is structured
annotation: instead of a single operator producing labels, a competitive pool of miners produces
them, and the network's incentives push that pool toward accurate, well-formed tags.

## Miner and Validator Roles

The two roles follow the standard Bittensor split between producing a labeled output and scoring it.
Miners produce the output — they return label sets for each X post they receive. Validators provide
the evaluation — they score the labels miners submit and decide how much each set is worth.

Validator scores become weights, and those weights feed into [[Yuma Consensus]], which converts the
evaluations into the incentive split across miners and validators. Operators should consult the
[tag101-ai/tag101 repository](https://github.com/tag101-ai/tag101) for current task specifications
and scoring details.

## On-Chain Identity

Live SN101 subnet data is available on [TaoStats](https://taostats.io/subnets/101). Readers can
reproduce the subnet identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 101 --network finney`.

The Finney identity for netuid 101 publishes the subnet name as Tag101, the on-chain description as
"Tag101 is a Bittensor subnet for decentralized social post tagging", the GitHub repository as
[tag101-ai/tag101](https://github.com/tag101-ai/tag101), and the Discord handle as Tag101.
