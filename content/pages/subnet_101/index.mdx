Tag101 is Bittensor Subnet 101, a network for decentralized social post tagging.

## How the Mechanism Works

The [Tag101 README](https://github.com/tag101-ai/tag101) describes a subnet where validators
retrieve X (Twitter) posts from a centralized database that draws on a disclosed whitelist of
accounts. Each post is distributed to miners as an independent tagging task.

Miners return a set of structured tags per post identifying entities, topics, events, or contextual
meanings. Each tag is scored across three components: consensus alignment with other miners'
submissions, validity as a relevant and well-formed label for the original post, and diversity
relative to the miner's other submitted tags. A miner's task score is the average of its tag scores.
Validator scoreboards aggregate per-task scores over time to produce the relative miner weights
submitted on-chain.

## On-Chain Identity

Live SN101 data is available on [TaoStats](https://taostats.io/subnets/101). The Finney identity for
Subnet 101 records the name as Tag101, the description as "Tag101 is a Bittensor subnet for
decentralized social post tagging", the GitHub repository as
[tag101-ai/tag101](https://github.com/tag101-ai/tag101), and the Discord as Tag101.
