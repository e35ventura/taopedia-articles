Tag101 is Bittensor Subnet 101, a decentralized semantic tagging network. Its on-chain description
says the subnet transforms Twitter/X posts into concise, structured tags, with the
[tag101-ai/tag101](https://github.com/tag101-ai/tag101) repository as the canonical codebase and
[tag101.ai](http://tag101.ai) as the project website.

The subnet treats unstructured social content as a data source and turns it into structured semantic
signals. Those signals can serve downstream AI systems that need real-time indexing, topic tracking,
or cleaner context for inference. Rather than relying on a single tagging model, Tag101 distributes
the tagging task across competing miners and evaluates quality through network consensus.

## How the Mechanism Works

Each task on Tag101 is a Twitter/X post drawn from a curated whitelist of accounts. Validators
distribute posts to miners, and each miner returns a small set of tags that identify the key
entities, topics, events, or contextual meanings in the post.

Each submitted tag is scored on three components combined into a single tag score:

**Consensus score (60% weight):** Tags are embedded and clustered across all miner submissions. A
tag's consensus score reflects how closely it aligns with the dominant interpretation — measured by
cluster support and centroid proximity. Tags that converge with the semantic center of the leading
cluster score highest.

**Validity score (40% weight, multiplied by diversity):** Validity captures content relevance and
format correctness. The raw value is mapped to discrete tiers (0, 0.3, 0.6, or 1.0) to keep scores
stable and filter tags that are irrelevant, malformed, or outside the expected format.

**Diversity score (multiplier on validity):** Diversity penalizes near-duplicate tags within the
same miner's submission. Tags that are sufficiently distinct from a miner's other tags receive full
credit; those that are too similar receive none, with linear decay in between. This prevents miners
from padding submissions with semantically identical variations.

A miner's task score is the average of its individual tag scores across its submission. Validators
aggregate task-level scores across multiple tasks to build a scoreboard and convert recent
performance into weights via [[Yuma Consensus]].

The initial topic season focuses on AI-related accounts, giving validators a consistent domain for
calibrating quality. The whitelist is updated as new topic seasons are introduced.

## Participating as a Miner

Miners register on SN101 and receive post distribution tasks from validators. For each post, a miner
produces a small set of tags — aiming for relevance, non-redundancy, and correct format.

The reference miner in the Tag101 repository calls the OpenAI API to generate tags from post
content. Operators who want to register as miners should consult the current repository for runtime
requirements, environment variables, and registration steps, as those details change with releases.

Tag101 competes on tagging quality over many tasks, so miners benefit from producing tags that are
semantically grounded in the post, aligned with the likely consensus, and distinct from one another
within each submission.

## Participating as a Validator

Validators distribute tagging tasks and score miner submissions. Scoring involves retrieving posts
from the centralized Tag101 database via API, sending them to registered miners, collecting returned
tags, embedding them, clustering the submissions, and computing the consensus, validity, and
diversity components for each tag.

Validators maintain a scoreboard that aggregates task-level miner scores over time and converts
recent performance into subnet weights. Those weights are submitted on-chain and processed through
[[Yuma Consensus]] to determine token emissions. Operators who want to run a validator should
consult the current repository for API access, scoring runtime, and validator registration guidance.
