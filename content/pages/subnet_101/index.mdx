Tag101 (SN101) is a Bittensor subnet that produces structured semantic tags from X (formerly
Twitter) posts. Miners label posts distributed by validators, and the network scores those labels
against a shared consensus formed across the full miner pool.

## How the Mechanism Works

Validators pull posts from a centralized Tag101 database and send each one to registered miners as a
tagging task. For each post, a miner returns a small set of tags identifying the key entities,
topics, events, or contextual meanings in the content.

Each submitted tag is evaluated on three combined dimensions. Consensus alignment, weighted at 60
percent, measures how closely a tag matches the dominant interpretation across all miner
submissions, determined by embedding and clustering the full tag pool. Validity, weighted at 40
percent, captures whether a tag is relevant to the post and meets basic formatting requirements,
mapped to discrete quality tiers. A diversity factor adjusts the validity score to penalize
near-duplicate tags within a single miner's submission, so miners gain nothing from padding a set
with semantically identical variations.

A miner's task score is the average of its individual tag scores. Scores accumulated across many
tasks are converted into on-chain weights via [[Yuma Consensus]], which determines emissions.

The initial topic season focuses on AI-related accounts, giving validators a consistent domain for
evaluating quality. The account whitelist can be updated as new topic seasons are introduced.

## Participating as a Miner

Miners register on SN101 and receive tagging tasks from validators. For each post, a miner produces
tags that are relevant to the content, correctly formatted, and semantically varied within the
submission. The reference implementation in the
[tag101-ai/tag101](https://github.com/tag101-ai/tag101) repository generates tags using the OpenAI
API. Operators should consult the repository for current registration and runtime requirements, as
details change with releases.

## Participating as a Validator

Validators retrieve posts from the Tag101 database via its API, distribute them to registered
miners, collect the returned tags, embed and cluster the submissions, and compute per-tag scores.
Aggregated miner scores are submitted on-chain as weights. Operators should consult the repository
for API access requirements and validator setup details.

## On-Chain Identity

Live SN101 data is available on [TaoStats](https://taostats.io/subnets/101). The Finney on-chain
identity reports the subnet name as Tag101, GitHub repository as
[tag101-ai/tag101](https://github.com/tag101-ai/tag101), website as [tag101.ai](http://tag101.ai),
Discord contact as Tag101, and description as "Tag101 is a Bittensor subnet for decentralized social
post tagging."
