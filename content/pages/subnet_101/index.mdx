Tag101 is Bittensor Subnet 101 (SN101). The subnet rewards miners for producing accurate semantic
labels for X (Twitter) posts.

## How the Mechanism Works

Validators draw posts from a publicly disclosed whitelist of X accounts and distribute them to
miners as independent tagging tasks. Each miner returns a set of short tags identifying the
entities, topics, and meanings present in the post.

Submitted tags are scored on three criteria documented in the
[tag101-ai/tag101](https://github.com/tag101-ai/tag101) README. The consensus score measures how
closely a tag aligns with the dominant interpretation across all miner submissions. The validity
score measures whether a tag is relevant to the post and follows the expected format. The diversity
score measures how distinct a tag is from the miner's other tags for the same task.

A miner's score for a task is the average of its individual tag scores. Validators aggregate
per-task scores into relative miner weights and publish those weights on chain, feeding into
[[Yuma Consensus]].

## On-Chain Identity

The registered Finney identity for netuid 101 records the name as Tag101, the description as "Tag101
is a Bittensor subnet for decentralized social post tagging", the GitHub repository as
[tag101-ai/tag101](https://github.com/tag101-ai/tag101), and the Discord handle as Tag101.

Live chain state for SN101 is available on [TaoStats](https://taostats.io/subnets/101).
