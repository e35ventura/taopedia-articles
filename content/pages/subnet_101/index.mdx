Tag101 (Subnet 101) is a Bittensor subnet for decentralized semantic tagging of social media posts.

## How the Mechanism Works

Validators pull individual X (formerly Twitter) posts from a centralized Tag101 database and
distribute them to miners as tasks. Posts are sourced from a publicly disclosed whitelist of
accounts. Each miner returns a short set of tags that identify the main topics, entities, and events
in the post.

Tags are evaluated on three dimensions. The consensus score reflects how closely a tag aligns with
the dominant interpretation across all miner submissions. The validity score checks content
relevance and basic formatting. The diversity score penalizes tags that are semantically similar to
the miner's own other submissions. These three scores combine into a per-tag score; the miner's task
score is the average across submitted tags. Validators aggregate task scores over time to set
on-chain weights.

## On-Chain Identity

The Finney identity for netuid 101 names the subnet Tag101. The on-chain description reads: "Tag101
is a Bittensor subnet for decentralized social post tagging." The registered repository is
[tag101-ai/tag101](https://github.com/tag101-ai/tag101) and the Discord contact is Tag101. Live data
is available on [TaoStats](https://taostats.io/subnets/101).
