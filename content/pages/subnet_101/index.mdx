Tag101 is a Bittensor subnet for decentralized social post tagging.

## How the Mechanism Works

The [tag101-ai/tag101 GitHub repository](https://github.com/tag101-ai/tag101) documents the
mechanism in its README. Validators retrieve X (formerly Twitter) posts from a centralized database
sourced from a disclosed whitelist of accounts and distribute each post to miners as an independent
tagging task. The initial whitelist focuses on AI-related accounts.

Miners return a small set of semantic tags per post. Each tag is scored on three dimensions
described in the README: a consensus score that measures alignment with the dominant semantic
interpretation formed across all miner submissions, a validity score that evaluates content
relevance and formatting mapped into four discrete tiers, and a diversity score that penalizes
redundancy within a single miner's tag set for the same task. A miner's final task score is the
average of its individual tag scores. Aggregated scores feed into validator weight calculations,
which flow into [[Yuma Consensus]].
