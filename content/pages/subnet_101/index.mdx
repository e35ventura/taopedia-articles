Tag101 is Bittensor Subnet 101. Its on-chain identity describes the subnet as a network for
decentralized social post tagging and lists [tag101-ai/tag101](https://github.com/tag101-ai/tag101)
as the GitHub repository.

## What Tag101 Does

The [Tag101 README](https://github.com/tag101-ai/tag101) describes the subnet as a decentralized
semantic tagging network. Miners receive Twitter/X posts sourced from a validator-managed database
and return a small set of descriptive tags for each post. The README describes three scoring
dimensions: consensus alignment with other miners' submissions, content validity relative to the
source post, and diversity within the miner's own tag set.

According to the README, tasks are sourced from a centralized database of Twitter/X posts collected
from a publicly disclosed whitelist of accounts. The initial phase focuses on AI-related accounts.
The whitelist is designed to be updated over time to expand into additional topic domains.

## Miner and Validator Roles

The README describes miners as receiving a post and returning a small set of tags. Each submitted
tag receives an individual score combining the three properties above; the miner's reward is
computed from its overall scored tag submissions.

Validators retrieve posts from a central database via API and distribute each post to miners as an
independent tagging task. Validators collect miner tag submissions, score them, and submit the
resulting weights on-chain. Operators should consult the
[tag101-ai/tag101 repository](https://github.com/tag101-ai/tag101) for current participant guidance.

## On-Chain Identity

Live SN101 data is available on [TaoStats](https://taostats.io/subnets/101). Readers can also
reproduce the chain identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 101 --network finney`.

That Finney identity reports the subnet name as Tag101, the description as "Tag101 is a Bittensor
subnet for decentralized social post tagging", the Discord contact as Tag101, and the GitHub
repository as tag101-ai/tag101.
