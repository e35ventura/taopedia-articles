Tag101 is Bittensor Subnet 101. The on-chain identity for netuid 101 now returns a registered name,
description, GitHub repository, and Discord handle.

## What Tag101 Does

Tag101 is described on-chain as a network for decentralized social post tagging. Participants label
posts from X and the network rewards label quality.

## Miner and Validator Roles

The general [[Mining and Validating]] pattern applies: miners compete for incentive and validators
submit weights that feed into [[Yuma Consensus]].

## On-Chain Identity

Live SN101 subnet data is available on [TaoStats](https://taostats.io/subnets/101). The Finney
identity for netuid 101 registers the name Tag101, the description "Tag101 is a Bittensor subnet for
decentralized social post tagging", the GitHub repository
[tag101-ai/tag101](https://github.com/tag101-ai/tag101), and the Discord handle Tag101.
