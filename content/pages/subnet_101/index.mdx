Subnet 101 operates on the Bittensor Finney mainnet under the registered identity Tag101. The
on-chain description reads: "Tag101 is a Bittensor subnet for decentralized social post tagging."
The registered Discord handle is Tag101.

The subnet's source code is listed on-chain at
[tag101-ai/tag101](https://github.com/tag101-ai/tag101). The on-chain URL field (http://tag101.ai)
redirects to that repository.
