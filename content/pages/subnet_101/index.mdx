Tag101 is Bittensor Subnet 101. Its on-chain identity describes it as a decentralized social post
tagging subnet and lists [tag101-ai/tag101](https://github.com/tag101-ai/tag101) as the project
codebase.

## How the Mechanism Works

According to the Tag101 README, miners receive Twitter / X posts as tasks and return a small set of
semantic tags identifying key entities, topics, events, or contextual meanings within each post.
Tasks are sourced from a centralized database of posts drawn from a disclosed whitelist of accounts,
initially focused on AI-related accounts.

Tags are scored using a weighted formula: 60 percent weight on a consensus score and 40 percent
weight on a combined validity and diversity score. The consensus score reflects how closely a tag
aligns with the semantic cluster formed by all miners' submissions. The validity score measures
content relevance and format correctness. The diversity score rewards tags that are distinct within
a miner's own submission set.

## On-Chain Identity

The live Finney identity for Subnet 101 lists the subnet name as Tag101, the GitHub repository as
[tag101-ai/tag101](https://github.com/tag101-ai/tag101), the Discord as Tag101, and the on-chain
description as "Tag101 is a Bittensor subnet for decentralized social post tagging." Live subnet
data is available on [TaoStats](https://taostats.io/subnets/101).
