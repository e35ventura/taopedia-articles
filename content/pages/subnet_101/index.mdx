Tag101 (Subnet 101) is a Bittensor subnet for decentralized social post tagging.

## How the Mechanism Works

Miners receive X (formerly Twitter) posts drawn from a centralized database sourced from a publicly
disclosed whitelist of accounts, as documented in the
[tag101-ai/tag101](https://github.com/tag101-ai/tag101) repository. Each miner returns a set of
short tags identifying the key entities, topics, and meanings present in the post.

Validators score miner tags on three dimensions: consensus (how closely a tag aligns with the
semantic cluster of submissions from other miners), validity (relevance to the source post and
correct format), and diversity (non-redundancy within the miner's own tag set). Per-tag scores
combine into a per-task score for each miner, which feeds into [[Yuma Consensus]] as weights.
