Tag101 is Bittensor Subnet 101. Miners earn rewards by generating structured tags for X (Twitter)
posts, and validators score those tags against the consensus formed across the miner network. The
incentive-mechanism code is published at [tag101-ai/tag101](https://github.com/tag101-ai/tag101).

## How the Mechanism Works

Validators pull posts from a centralized Tag101 database and distribute each one to miners as a
task. Miners return a short set of tags that identify the main topics, entities, and events in the
post.

Each tag is scored on three properties: how closely it matches what other miners submitted, how
relevant it is to the original post, and how distinct it is from the miner's other submitted tags.
The per-tag scores combine into a task score for each miner, which validators use to set on-chain
weights through [[Yuma Consensus]].

The post database draws from a publicly disclosed whitelist of accounts. The initial topic season
focused on AI-related accounts as a consistent domain for evaluating miner output.

## On-Chain Identity

The Finney identity for netuid 101 names the subnet Tag101. The on-chain description reads: "Tag101
is a Bittensor subnet for decentralized social post tagging." The registered repository is
[tag101-ai/tag101](https://github.com/tag101-ai/tag101) and the Discord contact is Tag101. Live data
is available on [TaoStats](https://taostats.io/subnets/101).
