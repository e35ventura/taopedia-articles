Tag101 is a Bittensor subnet for decentralized social post tagging.

## How the Mechanism Works

Validators pull posts from X (formerly Twitter) via the Tag101 API and distribute them to miners as
independent tagging tasks. Each miner returns a small set of semantic tags for each post. Tags are
scored on three dimensions: consensus alignment with the dominant interpretation across all miner
submissions, validity against the source post's content, and diversity within a single miner's tag
set. A miner's final task score is the average of its individual tag scores.

The initial topic season draws from AI-related accounts. The source whitelist can be updated over
time as new topic seasons are introduced.
