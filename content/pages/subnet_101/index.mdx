Tag101 is Bittensor Subnet 101. Its on-chain identity describes the subnet as a Bittensor subnet for
decentralized social post tagging, lists [tag101.ai](http://tag101.ai) as the subnet URL, and lists
[tag101-ai/tag101](https://github.com/tag101-ai/tag101) as the subnet's GitHub repository.

## What Tag101 Provides

The tag101-ai/tag101 README describes a tagging network built around X (formerly Twitter) posts.
Validators draw posts from a centralized database sourced from a curated whitelist of accounts and
distribute each post to miners as an independent task. The initial season focuses on AI-related
accounts, with the whitelist able to expand to new topic seasons over time.

Miners return a small set of short tags per post. According to the README, each tag is scored on
three criteria: how closely it aligns with the consensus interpretation across all miner submissions
for the same post, how relevant and correctly formatted it is, and how distinct it is from the
miner's other tags for the same post. A miner's task score is the average of its individual tag
scores. Validators aggregate task-level scores into per-miner weights and publish those weights on
chain, feeding into [[Yuma Consensus]].

## On-Chain Identity

The registered Finney identity for netuid 101 records the name as Tag101, the description as "Tag101
is a Bittensor subnet for decentralized social post tagging", the GitHub repository as
[tag101-ai/tag101](https://github.com/tag101-ai/tag101), and the Discord handle as Tag101.

Live chain state for SN101 is available on [TaoStats](https://taostats.io/subnets/101).
