Tag101 is Bittensor Subnet 101, a network for decentralized semantic tagging of social media posts.

## How the Mechanism Works

The [tag101-ai/tag101 repository](https://github.com/tag101-ai/tag101) describes a system built
around X (formerly Twitter) posts. Validators retrieve posts from a centralized database sourced
from a curated whitelist of accounts and distribute them to miners as individual tagging tasks.
Miners return a small set of semantic tags per post. Validators score each submitted tag on three
dimensions and aggregate those scores into per-miner weights that feed into [[Yuma Consensus]].

The initial task season focuses on AI-related accounts. The whitelist may expand to new topic
domains over time.

## Participating as a Miner

Miners receive X posts from validators and return short semantic tags that capture key entities,
topics, events, or contextual meanings. Each submitted tag is scored independently on three
dimensions described in the README:

- **Consensus**: tags are embedded and clustered across all miner submissions; higher scores go to
  tags that align with the dominant semantic interpretation.
- **Validity**: tags are evaluated for content relevance and basic formatting, mapped to one of four
  discrete tiers.
- **Diversity**: tags that are too similar to the miner's other tags for the same task receive lower
  scores.

A miner's final score for a task is the average of its individual tag scores. The repository is the
current source of truth for operator guidance.
