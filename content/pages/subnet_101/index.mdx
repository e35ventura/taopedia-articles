Tag101 (SN101) is a Bittensor subnet that produces structured semantic tags from X (formerly
Twitter) posts through a decentralized miner network.

## How the Mechanism Works

Validators retrieve posts from a centralized Tag101 database and send each one to registered miners
as a tagging task. Miners return a small set of tags identifying the key entities, topics, events,
or meanings within the post.

Each returned tag is scored on three combined dimensions. Consensus alignment, weighted at 60
percent, measures how closely a tag matches the dominant interpretation across all miner
submissions. The network determines this by embedding all submitted tags and clustering them, then
rewarding tags that land near the center of the strongest cluster. Validity, weighted at 40 percent,
captures whether a tag is relevant to the post and meets basic formatting requirements; validity
scores are expressed as one of four discrete tiers rather than a continuous number to keep scores
stable. A diversity factor adjusts the validity component to penalize near-duplicate tags within a
single miner's submission, so repeating the same idea with slightly different wording provides no
scoring advantage.

A miner's task score is the average across its individual tag scores. Over time, validator
scoreboards aggregate scores across many tasks and convert them into on-chain miner weights through
[[Yuma Consensus]], which determines emissions.

The initial topic season focuses on AI-related accounts, giving validators a consistent domain for
evaluating tag quality. The whitelist of source accounts can be updated as new topic seasons are
introduced.

## Participating as a Miner

Miners register on SN101 and receive tagging tasks distributed by validators. For each post, a miner
produces tags that are relevant to the content, correctly formatted, and semantically distinct from
one another to avoid diversity penalties. The reference implementation is published in the
[tag101-ai/tag101](https://github.com/tag101-ai/tag101) repository. Operators should consult that
repository for current registration and runtime requirements.

## Participating as a Validator

Validators retrieve posts from the Tag101 database via its API and distribute them to miners. After
collecting submissions, validators embed and cluster the tags, compute per-tag scores, and aggregate
miner performance into on-chain weights. Operators should consult the
[tag101-ai/tag101](https://github.com/tag101-ai/tag101) repository for API access requirements and
validator setup details.

## On-Chain Identity

Live SN101 data is available on [TaoStats](https://taostats.io/subnets/101). The Finney on-chain
identity reports the subnet name as Tag101, GitHub repository as
[tag101-ai/tag101](https://github.com/tag101-ai/tag101), Discord contact as Tag101, and description
as "Tag101 is a Bittensor subnet for decentralized social post tagging."
