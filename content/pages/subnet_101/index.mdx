Tag101 is Bittensor Subnet 101. Its on-chain identity describes the subnet as a Bittensor subnet for
decentralized social post tagging, lists tag101.ai as the subnet URL, and lists
[tag101-ai/tag101](https://github.com/tag101-ai/tag101) as the subnet's GitHub repository.

## What Tag101 Provides

The Tag101 README describes a decentralized semantic tagging network for X (formerly Twitter) posts.
Validators retrieve posts from a centralized database of X posts collected from a curated whitelist
of accounts and distribute them to miners as individual tagging tasks. Miners return a small set of
tags per post. Validators score the submissions and set weights on-chain through [[Yuma Consensus]].

The README describes the initial task season as focused on AI-related accounts, forming a consistent
topic domain for evaluating miner behavior. The whitelist may expand to new topic domains over time.

References: [tag101-ai/tag101 (GitHub)](https://github.com/tag101-ai/tag101)

## Miner and Validator Roles

The README describes miners as receiving X posts from validators and returning short semantic tags
that identify key entities, topics, events, or contextual meanings in each post. Miner performance
depends on producing tags that are consistent with the network's semantic consensus, relevant to the
post content, and distinct from one another within each submission.

Validators score each submitted tag on three dimensions described in the README:

- **Consensus**: tags are embedded and clustered across all miner submissions; a tag scores higher
  when it aligns with the dominant interpretation of the post.
- **Validity**: tags are evaluated for content relevance and basic formatting; the raw score maps to
  one of four discrete tiers.
- **Diversity**: tags are penalized when they are semantically similar to the miner's other tags for
  the same task.

The combined per-tag score is a weighted sum of the three components. A miner's final score for a
task is the average over its submitted tags. Operators should treat the repository as the source of
truth for current participant guidance.

References: [tag101-ai/tag101 (GitHub)](https://github.com/tag101-ai/tag101)
