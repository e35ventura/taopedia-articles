# Subnet 101: Tag101

Tag101 is Bittensor Subnet 101.

## How the Mechanism Works

The [tag101-ai/tag101 repository](https://github.com/tag101-ai/tag101) describes a system for
semantic tagging of X (formerly Twitter) posts. Validators retrieve posts from a centralized
database built from a publicly disclosed whitelist of accounts and distribute each post to miners as
an independent tagging task. The initial whitelist focuses on AI-related accounts and may expand to
additional topic domains in future seasons.

Miners return a small set of short semantic tags that identify key entities, topics, events, or
contextual meanings within each post. Each submitted tag is scored on three dimensions: a consensus
score that measures alignment with the dominant interpretation formed by clustering all miners'
submissions, a validity score that evaluates content relevance and formatting mapped into four
discrete tiers, and a diversity score that penalizes tags too similar to the miner's other
submissions for the same task. A miner's final task score averages its individual tag scores.
Validators aggregate task-level scores over time and convert them into relative miner weights that
feed into [[Yuma Consensus]].

## On-Chain Identity

The on-chain identity for netuid 101 registers the name Tag101, the description "Tag101 is a
Bittensor subnet for decentralized social post tagging", and the Discord handle Tag101. The GitHub
repository is [tag101-ai/tag101](https://github.com/tag101-ai/tag101). Live SN101 data is available
on [TaoStats](https://taostats.io/subnets/101).
