# Subnet 101: Tag101

Tag101 is Bittensor Subnet 101, a subnet focused on a single task: attaching short descriptive
labels to X posts. As the repository puts it, Tag101 models a decentralized tagging network where
miners transform social media posts into concise, structured labels. The incentive-mechanism code is
maintained in the [tag101-ai/tag101](https://github.com/tag101-ai/tag101) repository.

## How the Mechanism Works

Validators retrieve X posts from a centralized database built from a publicly disclosed whitelist of
accounts and send each post to miners as a tagging task. The initial whitelist covers AI-related
accounts. Miners return a small set of short labels that identify the key entities, topics, events,
or meanings in each post.

Each label a miner submits receives a score combining three components. The consensus component
rewards labels that align with the dominant interpretation formed by clustering all miners'
submissions for the same post. The validity component evaluates whether the label is relevant to the
post and correctly formatted, mapping to one of four discrete tiers. The diversity component
penalizes labels that are too similar to a miner's own other labels for the same task. A miner's
final score for each task is the average of its individual label scores. Validators aggregate those
scores and convert them into relative miner weights that feed into [[Yuma Consensus]].

## On-Chain Identity

The on-chain identity for netuid 101 registers the name Tag101, the description "Tag101 is a
Bittensor subnet for decentralized social post tagging", and the Discord handle Tag101. The GitHub
repository is [tag101-ai/tag101](https://github.com/tag101-ai/tag101). Live SN101 data is available
on [TaoStats](https://taostats.io/subnets/101).
