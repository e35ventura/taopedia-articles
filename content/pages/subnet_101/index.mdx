Tag101 is Bittensor Subnet 101 (SN101), a decentralized network for tagging social media posts. Its
on-chain description registers the subnet as "a Bittensor subnet for decentralized social post
tagging." The codebase is at [tag101-ai/tag101](https://github.com/tag101-ai/tag101).

## How the Mechanism Works

The [Tag101 README](https://github.com/tag101-ai/tag101) describes the tagging workflow. Validators
select posts from a curated database of X accounts. Each post is distributed to miners as an
independent tagging task. Each miner returns a small set of semantic tags for that post.

Tags are scored on three criteria. Consensus alignment measures how closely a tag matches the
network's shared interpretation of the post. Validity measures whether the tag is relevant to the
source post and meets basic formatting requirements. Diversity measures how distinct the tag is from
the miner's other submissions for the same task. The README specifies the final tag score as 60%
consensus and 40% from validity multiplied by diversity.

Validators aggregate per-tag scores into a per-miner task score, then submit the resulting weights
to [[Yuma Consensus]] at epoch boundaries.
