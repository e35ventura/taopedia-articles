Tag101 is Bittensor Subnet 101. Its on-chain description reads "Tag101 is a Bittensor subnet for
decentralized social post tagging," the registered GitHub repository is
[tag101-ai/tag101](https://github.com/tag101-ai/tag101), and the Discord contact is Tag101.

## How the Mechanism Works

The Tag101 README describes the subnet as a decentralized semantic tagging network. Validators
retrieve X (formerly Twitter) posts from a centralized Tag101 database and distribute each post to
miners as an independent tagging task. Posts are sourced from a publicly disclosed whitelist of
accounts, initially focused on AI-related content.

Each miner returns a small set of tags that identify key entities, topics, events, or contextual
meanings within the post. Tags are evaluated on three dimensions: a consensus score that reflects
alignment with the dominant interpretation across all miner submissions, a validity score that
measures relevance to the original post and basic formatting, and a diversity score that reduces
credit for tags semantically similar to the miner's other submissions. A per-tag score averages
these components, and the miner's task score is the average of its per-tag scores. Validators
aggregate task scores over multiple rounds to set on-chain weights.
