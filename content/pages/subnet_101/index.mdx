Tag101 is Bittensor Subnet 101. The network rewards participants for tagging X posts.

## What Tag101 Produces

Tag101 creates a shared pool of labeled X posts drawn from a publicly disclosed list of accounts.
Participants compete to produce accurate and distinctive label sets for each post, and the network
distributes rewards based on how well each participant's labels reflect the broader consensus.

The registered GitHub repository is [tag101-ai/tag101](https://github.com/tag101-ai/tag101).

## On-Chain Identity

The Finney identity for netuid 101 records the subnet name as Tag101, the description "Tag101 is a
Bittensor subnet for decentralized social post tagging", and the Discord handle Tag101. Live subnet
data is available on [TaoStats](https://taostats.io/subnets/101).
