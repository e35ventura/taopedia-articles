# Mainchain

Mainchain is the primary Bittensor network used for production purposes. It is the production
network context within Bittensor's broader set of network environments
([Glossary: Mainchain](https://docs.learnbittensor.org/resources/glossary#mainchain),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

## Network Role

Bittensor network vocabulary separates mainnet, testnet, and localnet environments
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)). Mainchain
belongs to the production side of that vocabulary, while testnet and localnet describe
non-production environments.

That makes Mainchain an environment label. It tells readers that the subject belongs to production
Bittensor network context rather than to a test or isolated development environment.

## Subtensor Relationship

Subtensor is Bittensor's layer-one blockchain and system of record
([Glossary: Subtensor](https://docs.learnbittensor.org/resources/glossary#subtensor)). Mainchain is
related to Subtensor because it names the production network context in which that chain layer is
used.

The distinction keeps the terms from collapsing into one another. Subtensor names the chain layer;
Mainchain names the production network setting around that layer.

## Public Access Context

Public Subtensor names publicly reachable access to the Subtensor layer
([Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)).
Mainchain and Public Subtensor therefore sit near each other, but they answer different questions.

Mainchain identifies the production network context. Public Subtensor identifies public access to
the chain layer in that broader context.

## Local Blockchain Contrast

A local blockchain is a private Bittensor chain used for development and testing
([Glossary: Local Blockchain](https://docs.learnbittensor.org/resources/glossary#local-blockchain)).
Mainchain is the opposite kind of environment label: it refers to the primary production network.

This contrast is important when reading examples. A local blockchain example can show how a concept
works in isolation, but it is not a Mainchain example.

## Coinbase Context

Coinbase is a per-block protocol mechanism involved in emission processing
([Coinbase Implementation](https://docs.learnbittensor.org/navigating-subtensor/emissions-coinbase)).
Mainchain is not the coinbase mechanism itself. It is the production network context where Bittensor
protocol mechanisms operate in production.

Keeping the terms separate helps avoid mixing environment vocabulary with mechanism vocabulary.
Mainchain names where production blocks belong; coinbase names one protocol routine associated with
block and emission processing.

## Reader Boundary

Mainchain does not name every Bittensor environment, every public endpoint, or every Subtensor
mechanism. It names the primary production network context
([Glossary: Mainchain](https://docs.learnbittensor.org/resources/glossary#mainchain)).

When the focus is a non-production environment, localnet or testnet is more precise. When the focus
is the chain layer, Subtensor is more precise. When the focus is public access to that layer, Public
Subtensor is more precise.
