# Mainchain

Mainchain is the glossary term for the primary Bittensor blockchain network. The official glossary
describes it as the primary Bittensor network used for production purposes
([Glossary: Mainchain](https://docs.learnbittensor.org/resources/glossary#mainchain),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

The term is network-context vocabulary. It identifies the production network context, while
localnet, testnet, Subtensor, and public access surfaces describe neighboring but different parts of
the Bittensor system.

## Production Network Context

The [Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks) reference
lists mainnet alongside testnet and localnet. Mainchain belongs to the primary production side of
that vocabulary, while testnet and localnet name separate non-production or development contexts.

This distinction keeps Mainchain from becoming a loose synonym for every Bittensor environment. A
claim about the production network should not automatically be read as a claim about a local chain
or a test network.

## Chain-Layer Boundary

Mainchain names the primary network context. Subtensor names Bittensor's layer 1 blockchain and
system of record for transactions and rankings
([Glossary: Mainchain](https://docs.learnbittensor.org/resources/glossary#mainchain),
[Glossary: Subtensor](https://docs.learnbittensor.org/resources/glossary#subtensor)).

The two terms often appear together because production Bittensor activity is recorded through the
Subtensor chain layer. They still answer different questions: Mainchain tells readers which network
context is being discussed; Subtensor tells readers which chain layer records Bittensor activity.

## Bittensor Networks Scope

Bittensor Networks is the broader environment label. It includes mainnet, testnet, and localnet
contexts, while Mainchain points to the production side of that set
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks),
[Glossary: Mainchain](https://docs.learnbittensor.org/resources/glossary#mainchain)).

That scope matters when comparing examples. Localnet can be useful for isolated development, and
testnet can be useful for shared testing, but neither provides production chain history. Mainchain
language should stay attached to the production network context.

## Public Access Boundary

Public Subtensor is related to Mainchain, but it is not the same term. Public Subtensor refers to
publicly reachable access to the Subtensor chain layer
([Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor),
[Glossary: Mainchain](https://docs.learnbittensor.org/resources/glossary#mainchain)).

Mainchain names the primary network context. Public Subtensor names an access surface for the chain
layer. The distinction prevents access-path language from being mistaken for the network context
itself.

## Local and Test Boundary

Mainchain and local blockchain name different sides of Bittensor network context. Local blockchain
describes a private chain used for development and testing
([Glossary: Local Blockchain](https://docs.learnbittensor.org/resources/glossary#local-blockchain),
[Glossary: Mainchain](https://docs.learnbittensor.org/resources/glossary#mainchain)).

The Bittensor introduction also describes subnet development as moving from localnet to testnet and
then mainnet
([Introduction to Bittensor: Subnet development](https://docs.learnbittensor.org/learn/introduction#subnet-development)).

In that sequence, Mainchain belongs to the final production context. A localnet or testnet example
can explain development behavior, but it should not be treated as production evidence. A Mainchain
example places activity on the production network without proving the quality, outcome, or future
behavior of the subnet or action being discussed.

## Reader Boundary

Mainchain does not name endpoint status, a connection guide, local development behavior, a subnet
quality claim, or every detail of the Subtensor layer
([Glossary: Mainchain](https://docs.learnbittensor.org/resources/glossary#mainchain),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

Keeping that boundary preserves the term's narrower meaning. Mainchain identifies the primary
Bittensor network context, while Subtensor, Public Subtensor, local blockchain, testnet, and
subnet-development references describe neighboring parts of the system.
