# Initial Bonds Penalty

Initial Bonds Penalty is a subtensorModule runtime constant, listed in the chain's constants
metadata as initialBondsPenalty, with the value 65535 and the summary "Initial bonds penalty"
([Subtensor API Constants: initialBondsPenalty](https://docs.learnbittensor.org/subtensor-api/constants#initialbondspenalty-u16)).
It supplies the default value a subnet's BondsPenalty uses.

## What It Means

BondsPenalty is held per subnet and sets the magnitude of the penalty applied to validator bonds
when weights fall outside the subnet consensus benchmark. Initial Bonds Penalty is the default this
per-subnet value falls back to before a different value applies for a subnet
([Subtensor API Constants: initialBondsPenalty](https://docs.learnbittensor.org/subtensor-api/constants#initialbondspenalty-u16)).
The BondsPenalty in force on a subnet such as netuid 1 is that subnet's own chain state and can
differ from this default.

## Distinction from Bonds Moving Average and Kappa

Initial Bonds Penalty is the default bonds penalty, while initialBondsMovingAverage, valued at
900000, is the smoothing applied to validator-miner bonds; initialKappa, valued at 32767, is the
consensus majority ratio used in consensus
([Subtensor API Constants: initialBondsMovingAverage](https://docs.learnbittensor.org/subtensor-api/constants#initialbondsmovingaverage-u64),
[Subtensor API Constants: initialKappa](https://docs.learnbittensor.org/subtensor-api/constants#initialkappa-u16)).

## Reader Boundary

Initial Bonds Penalty is a default constant, not the live per-subnet BondsPenalty, and it reflects
the current runtime configuration rather than a fixed protocol rule
([Subtensor API Constants: initialBondsPenalty](https://docs.learnbittensor.org/subtensor-api/constants#initialbondspenalty-u16)).
