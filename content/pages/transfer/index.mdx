# Transfer

A transfer is Bittensor terminology for sending TAO from one wallet address to another. The official
[Transfer glossary](https://docs.learnbittensor.org/resources/glossary#transfer) describes it as the
process of sending TAO tokens between wallet addresses in the Bittensor network.

## Address Context

Transfers rely on wallet addresses as destinations. The
[Wallet Address glossary](https://docs.learnbittensor.org/resources/glossary#wallet-address)
describes a wallet address as a public-key-derived identifier used as a TAO destination.

## Wallet Context

In Taopedia prose, transfer should be read as wallet-movement vocabulary. It is not a staking
position, subnet role, or live balance claim. It also does not describe the protected key material
that authorizes account activity.

## Reading the Term

This article is a concept boundary. It does not provide transaction steps or wallet operation
guidance. For a reader, the useful point is that transfer names TAO movement between Bittensor
wallet addresses.

## State-Changing Transaction Context

Sending TAO between wallet addresses is a state-changing chain action rather than a passive read.
The [Transaction Fees](https://docs.learnbittensor.org/learn/fees) documentation separates free
chain reads from state-changing actions that the runtime must process, which is the context in which
wallet transfers are submitted on chain.

## Relationship to Wallet Address

Transfer and wallet address are related but different parts of Bittensor wallet vocabulary. A wallet
address is the public-key-derived identifier used as a TAO destination, while transfer names the act
of sending TAO between those addresses. The
[Glossary: Wallet Address](https://docs.learnbittensor.org/resources/glossary#wallet-address)
describes a wallet address as a unique identifier derived from a public key, and the
[Glossary: Transfer](https://docs.learnbittensor.org/resources/glossary#transfer) describes transfer
as sending TAO tokens between wallet addresses.

For readers, wallet address names the destination identifier, while transfer names the movement
between those identifiers.

References:
[Glossary: Wallet Address](https://docs.learnbittensor.org/resources/glossary#wallet-address),
[Glossary: Transfer](https://docs.learnbittensor.org/resources/glossary#transfer)

## Relationship to TAO

Transfer and TAO are related but different parts of Bittensor token vocabulary. TAO is the network
incentive token, while transfer names the wallet-to-wallet movement of that token between addresses.
The [Glossary: TAO](https://docs.learnbittensor.org/resources/glossary#tao) describes TAO as the
token used to incentivize subnet activity, and the
[Glossary: Transfer](https://docs.learnbittensor.org/resources/glossary#transfer) describes transfer
as sending TAO tokens between wallet addresses.

For readers, TAO names the asset being moved, while transfer names the wallet movement action for
that asset.

References: [Glossary: TAO](https://docs.learnbittensor.org/resources/glossary#tao),
[Glossary: Transfer](https://docs.learnbittensor.org/resources/glossary#transfer)

## Relationship to Extrinsics

Transfer and extrinsics are related but different parts of Bittensor chain action vocabulary.
Extrinsics name signed transactions and calls submitted to Subtensor, while transfer names the
wallet-to-wallet TAO movement carried out through those state-changing submissions. The
[Glossary: Extrinsics](https://docs.learnbittensor.org/resources/glossary#extrinsics) describes
signed transactions submitted to the chain, and the
[Glossary: Transfer](https://docs.learnbittensor.org/resources/glossary#transfer) describes transfer
as sending TAO tokens between wallet addresses.

For readers, extrinsics name submitted chain actions, while transfer names the TAO movement action
among those state-changing wallet operations.

References: [Glossary: Extrinsics](https://docs.learnbittensor.org/resources/glossary#extrinsics),
[Glossary: Transfer](https://docs.learnbittensor.org/resources/glossary#transfer)

## Relationship to Existential Deposit

Transfer and existential deposit are related but different parts of Bittensor account vocabulary.
Existential deposit names the minimum TAO balance threshold for retaining an account, while transfer
names the act of moving TAO between wallet addresses. The
[Glossary: Existential Deposit](https://docs.learnbittensor.org/resources/glossary#existential-deposit)
describes the minimum balance required for an account to exist, and the
[Glossary: Transfer](https://docs.learnbittensor.org/resources/glossary#transfer) describes transfer
as sending TAO tokens between wallet addresses.

For readers, transfer names the movement action, while existential deposit names the minimum balance
boundary that movement must respect so an account can remain represented on chain.

References:
[Glossary: Existential Deposit](https://docs.learnbittensor.org/resources/glossary#existential-deposit),
[Glossary: Transfer](https://docs.learnbittensor.org/resources/glossary#transfer)
