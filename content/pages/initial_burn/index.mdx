# Initial Burn

Initial Burn is a subtensorModule runtime constant, listed in the chain's constants metadata as
initialBurn, with the value 100000000 and the summary "Initial Burn"
([Subtensor API Constants: initialBurn](https://docs.learnbittensor.org/subtensor-api/constants#initialburn-u64)).
It supplies the default value a subnet's Burn uses.

## What It Means

Burn is held per subnet and sets the current TAO cost of registering a neuron through the burn path.
Initial Burn is the default this per-subnet value falls back to before a different value applies for
a subnet
([Subtensor API Constants: initialBurn](https://docs.learnbittensor.org/subtensor-api/constants#initialburn-u64)).
The Burn in force on a subnet such as netuid 1 is that subnet's own chain state and can differ from
this default.

## Distinction from Min and Max Burn

Initial Burn is the default starting registration burn, while initialMinBurn, valued at 500000, is
the floor the burn may not fall below; initialMaxBurn, valued at 100000000000, is the ceiling the
burn may not exceed
([Subtensor API Constants: initialMinBurn](https://docs.learnbittensor.org/subtensor-api/constants#initialminburn-u64),
[Subtensor API Constants: initialMaxBurn](https://docs.learnbittensor.org/subtensor-api/constants#initialmaxburn-u64)).

## Reader Boundary

Initial Burn is a default constant, not the live per-subnet Burn, and it reflects the current
runtime configuration rather than a fixed protocol rule
([Subtensor API Constants: initialBurn](https://docs.learnbittensor.org/subtensor-api/constants#initialburn-u64)).
