# Contract Trapped

`ContractTrapped` is a contracts pallet error raised when a contract call traps during execution.
The API errors reference summarizes it as "Contract trapped during execution"
([Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped)).

## What It Means

`ContractTrapped` means the contract did not finish its call in the normal way. Execution hit a trap
condition during the run, so the call stops without the intended completion outcome
([Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped)).

This is a trap-during-execution failure. It does not, by itself, mean the contract finished and
deliberately reverted its storage changes, that execution exhausted its gas limit, or that input
failed to decode before the call could proceed.

## Why It Appears

This error appears when contract execution traps before completing normally
([Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped)).

For a reader, the practical meaning is narrow: the contract call failed during execution rather than
returning a clean completion or an intentional revert.

## Distinction from Contract Reverted

`ContractTrapped` and `ContractReverted` both stop a contracts operation from succeeding, but they
describe different outcomes. `ContractTrapped` means execution trapped before completing normally.
`ContractReverted` means execution finished and then discarded its storage changes
([Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped),
[Subtensor API Errors: ContractReverted](https://docs.learnbittensor.org/subtensor-api/errors#contractreverted)).

- **ContractTrapped** — execution traps before completing normally.
- **ContractReverted** — execution completes, but the storage changes are discarded.

## Distinction from Out Of Gas

`ContractTrapped` and `OutOfGas` both leave a contract call without the intended result, but they
fail for different reasons. `ContractTrapped` means execution trapped during the run. `OutOfGas`
means execution exhausted the gas limit before finishing
([Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped),
[Subtensor API Errors: OutOfGas](https://docs.learnbittensor.org/subtensor-api/errors#outofgas)).

- **ContractTrapped** — execution traps during the call.
- **OutOfGas** — execution cannot finish because the gas limit is exhausted.

## Distinction from Decoding Failed

`ContractTrapped` and `DecodingFailed` both block a contracts call, but at different points.
`DecodingFailed` means input passed to a contract API function failed to decode as the expected
type. `ContractTrapped` means execution began and then trapped during the run
([Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped),
[Subtensor API Errors: DecodingFailed](https://docs.learnbittensor.org/subtensor-api/errors#decodingfailed)).

- **ContractTrapped** — execution traps during the call.
- **DecodingFailed** — input fails to decode before execution proceeds as expected.
