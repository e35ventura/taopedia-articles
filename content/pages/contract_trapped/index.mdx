# Contract Trapped

`ContractTrapped` is a contracts pallet error raised when contract execution traps. The API errors
reference summarizes it as "Contract trapped during execution"
([Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped)).

## What It Means

Bittensor runs an Ethereum-compatible execution layer on Subtensor for smart contracts
([Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials)). In that execution
environment, a trap halts the contract call during execution rather than letting it finish normally
([EVM vs PVM](https://docs.polkadot.com/smart-contracts/for-eth-devs/evm-vs-pvm/)).

`ContractTrapped` means the runtime reached that trapped outcome on a contracts call: execution
started, but the call was halted before normal completion
([Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped)).

This is a mid-execution halt. It does not, by itself, mean no code exists at the supplied code hash
or that the executed contract exhausted its gas limit.

## Why It Appears

This error appears when contract execution traps during a call
([Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped)).

The practical meaning is narrow: the call began executing contract code, but the runtime stopped it
with a trap instead of returning a normal result.

## Distinction from Out Of Gas

`ContractTrapped` and `OutOfGas` are different contracts pallet errors with different API summaries.
`ContractTrapped` is summarized as "Contract trapped during execution." `OutOfGas` is summarized as
"The executed contract exhausted its gas limit."
([Subtensor API Errors: OutOfGas](https://docs.learnbittensor.org/subtensor-api/errors#outofgas),
[Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped)).

- **ContractTrapped** — execution trapped before normal completion.
- **OutOfGas** — the executed contract exhausted its gas limit.

## Distinction from Code Not Found

`ContractTrapped` and `CodeNotFound` fail at different stages. `CodeNotFound` is summarized as "No
code could be found at the supplied code hash," so the runtime cannot start execution from that
hash. `ContractTrapped` is summarized as "Contract trapped during execution," so execution began but
halted abnormally
([Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound),
[Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped)).

- **CodeNotFound** — no code at the supplied code hash.
- **ContractTrapped** — execution trapped during the call.

## Reader Boundary

This page defines the meaning of the error label and the trapped-execution outcome it names. It does
not diagnose which contract instruction or host call caused a specific trap on chain
([Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
