# Named

`Named` is a scheduler pallet error raised when a non-named function is used on a task that was
scheduled with a name. The API errors reference describes it as "Attempt to use a non-named function
on a named task."
([Subtensor API Errors: Named](https://docs.learnbittensor.org/subtensor-api/errors#named)).

## What It Means

The scheduler pallet distinguishes between named and anonymous scheduled tasks. `Named` fires when
an operation that does not support named tasks is applied to a task that was scheduled with a name
([Subtensor API Errors: Named](https://docs.learnbittensor.org/subtensor-api/errors#named)).

This is a named-task compatibility check. It does not mean scheduling itself failed, that the target
block number is in the past, or that rescheduling would produce no change.

## Why It Appears

This error appears when a scheduler call that is not designed for named tasks is directed at a task
that carries a name
([Subtensor API Errors: Named](https://docs.learnbittensor.org/subtensor-api/errors#named)).

## Distinction from Failed To Schedule

`Named` and `FailedToSchedule` both block scheduler operations, but at different points.
`FailedToSchedule` fires when the runtime cannot queue a call for future dispatch at all. `Named`
fires when queuing or a related operation fails specifically because of a named-task compatibility
mismatch
([Subtensor API Errors: FailedToSchedule](https://docs.learnbittensor.org/subtensor-api/errors#failedtoschedule),
[Subtensor API Errors: Named](https://docs.learnbittensor.org/subtensor-api/errors#named)).

- **Named** — operation is rejected because the function does not support named tasks.
- **FailedToSchedule** — scheduling fails because the runtime cannot queue the call.

## Distinction from Reschedule No Change

`Named` and `RescheduleNoChange` both appear on scheduler operation paths, but they block for
different reasons. `RescheduleNoChange` fires when a reschedule would leave the call at the same
target block as before. `Named` fires when a non-named function is directed at a named task
([Subtensor API Errors: RescheduleNoChange](https://docs.learnbittensor.org/subtensor-api/errors#reschedulenochange),
[Subtensor API Errors: Named](https://docs.learnbittensor.org/subtensor-api/errors#named)).

- **Named** — function and task are incompatible because of the task's named status.
- **RescheduleNoChange** — reschedule is rejected because the target block is unchanged.
