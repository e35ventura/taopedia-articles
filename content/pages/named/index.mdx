# Named

`Named` is a scheduler pallet error raised when a non-named scheduler operation targets a task that
was originally created with a name. The API docs describe it as "Attempt to use a non-named function
on a named task"
([Subtensor API Errors: Named](https://docs.learnbittensor.org/subtensor-api/errors#named)).

## What It Means

The scheduler distinguishes between named and unnamed tasks. A task created with a name must be
managed using operations that accept that name. When a non-named operation is applied to a named
task, the scheduler rejects it with `Named` — this is a task-type mismatch, not a scheduling failure
or a missing-task failure
([Subtensor API Errors: Named](https://docs.learnbittensor.org/subtensor-api/errors#named)).

## Distinction from Scheduled Call Not Found

`Named` and the scheduler `NotFound` error both block scheduler management operations, but they
represent different failures. `NotFound` fires when the targeted task cannot be found. `Named` fires
when the task is found but the operation is incompatible with how the task was originally created
([Subtensor API Errors: Named](https://docs.learnbittensor.org/subtensor-api/errors#named),
[Subtensor API Errors: NotFound](https://docs.learnbittensor.org/subtensor-api/errors#notfound)).

- **NotFound** — the task does not exist.
- **Named** — the task exists but the operation requires an unnamed task.
