# Proposal Hash

A proposal hash is the identifier used to refer to a proposal in Bittensor governance. The
[Proposal Hash glossary entry](https://docs.learnbittensor.org/resources/glossary#proposal-hash)
places the term in the Senate voting process, where a compact reference is needed for a proposal
under review.

The phrase is governance reference vocabulary. It names the identifier attached to a proposal, not
the proposal body, the voting outcome, or the governance authority that reviews it.

## Identifier Role

The proposal hash gives governance readers and interfaces a stable way to point at the same proposal
during review. The
[Proposal Hash glossary entry](https://docs.learnbittensor.org/resources/glossary#proposal-hash)
anchors that identifier meaning, while the broader
[Governance Overview](https://docs.learnbittensor.org/governance) supplies the proposal-review
setting.

That role is intentionally narrow. A proposal hash identifies a governance item; it does not explain
why the item exists, whether it should pass, or what change it contains.

## Proposal Relationship

A proposal and a proposal hash answer different questions. A
[proposal](https://docs.learnbittensor.org/resources/glossary#proposal) is the governance item put
forward for review, while the proposal hash is the identifier used to refer to that item during
governance discussion and voting.

Keeping the terms separate prevents an identifier from being mistaken for the proposal itself. The
proposal carries the substance; the proposal hash is the reference label attached to that substance.

## Senate Review Context

The Senate is the governance body that reviews proposals in Bittensor's governance structure. The
[Senate documentation](https://docs.learnbittensor.org/governance/senate) places proposal review and
voting inside that body, so proposal hash belongs near Senate vocabulary as a reference term.

This does not make the proposal hash a vote or a Senate decision. It is the identifier used while a
proposal moves through review.

## Triumvirate Context

The governance overview separates proposal creation from Senate approval. In that structure, the
Triumvirate can put proposals forward and the Senate reviews them
([Governance Overview](https://docs.learnbittensor.org/governance),
[Senate](https://docs.learnbittensor.org/governance/senate)).

Proposal hashes sit between those concepts as references to the proposal under consideration. The
hash does not rename the Triumvirate, the Senate, or the approval process.

## Record Boundary

Proposal hash should not be treated as a complete governance record. It can identify which proposal
is being discussed, but a reader still needs the surrounding governance source to understand the
proposal's subject, review stage, and decision context
([Governance Overview](https://docs.learnbittensor.org/governance)).

That boundary matters because short identifiers are easy to quote without context. The article-level
meaning is identification, not interpretation.

## Reader Boundary

Proposal hash should be read as identifier vocabulary for Bittensor governance. It does not list
pending proposals, predict outcomes, describe voter reasoning, or replace the governance and Senate
references that explain the process.

For Taopedia readers, the stable concept is simple: a proposal hash is the reference identifier used
to point at a Bittensor governance proposal during Senate review and voting.
