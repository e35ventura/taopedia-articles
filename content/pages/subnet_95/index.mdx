# Subnet 95: Actual

Actual is Bittensor Subnet 95, operated by [Actual Computer Inc.](https://actual.inc). The subnet's
registered on-chain description identifies it as a "Heterogeneous inference network by Actual
Computer Inc." Actual Computer Inc. describes its mission as building AI infrastructure at the
intersection of systems engineering and artificial intelligence.
([actual.inc/company](https://actual.inc/company))

A heterogeneous inference network routes AI inference requests across a pool of compute providers
running different hardware configurations and model backends. Rather than requiring uniform
infrastructure, the network can direct each request to whichever node best satisfies its
requirements, improving utilization and availability across the fleet.

## How the Mechanism Works

Based on the on-chain description and the operator's stated focus on inference infrastructure, the
subnet is structured around distributing inference workloads: miners serve AI inference requests
from their hardware, and validators measure the quality, latency, and accuracy of those responses to
produce a score. Rewards flow to miners whose inference results meet the validators' standards.

Because the subnet's GitHub repository
([actual-computer/actual-subnet-95](https://github.com/actual-computer/actual-subnet-95)) was not
publicly accessible at the time this article was prepared, the specific scoring formula, supported
model types, and request routing protocol should be verified against current operator documentation
before relying on any description here.

## Participating as a Miner

Miners on Subnet 95 provide compute for AI inference. Prospective miners should register on
Bittensor netuid 95, configure their hardware to serve the request format the subnet defines, and
consult the operator's current documentation at [actual.inc](https://actual.inc) and the subnet's
GitHub repository for setup instructions specific to the Actual inference protocol.

## Participating as a Validator

Validators score miners based on the quality and responsiveness of their inference output.
Validators must hold a validator permit on Subnet 95 and follow the scoring protocol published by
Actual Computer Inc. The current validator permit threshold and scoring weights are visible in live
chain state.
