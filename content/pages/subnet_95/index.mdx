# Subnet 95: Actual

Actual is Bittensor Subnet 95, operated by Actual Computer Inc. The operator's website is
[actual.inc](https://actual.inc).

The on-chain identity lists
[actual-computer/actual-subnet-95](https://github.com/actual-computer/actual-subnet-95) as the
GitHub repository, but that repository is not publicly accessible at this time.

## On-Chain Identity

Subnet 95 is registered on-chain under the name Actual, operated by Actual Computer Inc. The
operator's public GitHub organization is [actual-computer](https://github.com/actual-computer). Live
SN95 data is available on [TaoStats](https://taostats.io/subnets/95).
