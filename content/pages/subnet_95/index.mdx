# Subnet 95: Actual

Actual is Bittensor Subnet 95.

## On-Chain Identity

The on-chain identity for netuid 95 registers the name Actual with the description "Heterogeneous
inference network by Actual Computer Inc." and the website actual.inc. The identity also lists
`actual-computer/actual-subnet-95` as the GitHub repository, but that path is not publicly
accessible. Live SN95 data is available on [TaoStats](https://taostats.io/subnets/95).
