Actual is Bittensor Subnet 95, operated by [Actual Computer Inc.](https://actual.inc). The on-chain
identity description registered by the operator characterizes it as a heterogeneous inference
network. The designation "heterogeneous" refers to inference across hardware or model types that
differ in architecture or capability — a pattern where miners handle varied workload profiles rather
than a single uniform task.

The codebase is listed in the on-chain identity as
[actual-computer/actual-subnet-95](https://github.com/actual-computer/actual-subnet-95), though that
repository was not publicly accessible at the time of review. The operator's website at
[actual.inc](https://actual.inc) is authentication-gated. This article therefore describes the
subnet at an identity level, based on what the on-chain record exposes.

## How the Mechanism Works

The on-chain description positions Actual as an inference network. In a heterogeneous inference
subnet, miners typically receive inference requests and return results, with validators scoring
quality, latency, or both. Because the repository is private and the website requires login, the
specific scoring function, request format, and reward calculation are not publicly documented.

The general structure of the Bittensor incentive layer still applies: miners register under a
hotkey, validators submit weight vectors into [[Yuma Consensus]], and emissions flow proportionally
to stake-weighted scores. What distinguishes Actual from other inference subnets is the emphasis on
heterogeneous hardware, suggesting that the scoring model accommodates a range of GPU and CPU
configurations rather than targeting a single hardware class.

## Participating as a Miner

Miners on Actual register a hotkey on Subnet 95 and provide inference capacity. The specific
hardware requirements, client setup, and performance benchmarks are not publicly documented from the
sources available. Prospective miners should consult the current operator documentation and the
[actual-computer](https://github.com/actual-computer) GitHub organization for any publicly released
miner tooling.

## Participating as a Validator

Validators on Actual score miners on inference quality and submit those scores to the Bittensor
chain as weight vectors. The precise scoring logic — including how validators send requests,
evaluate responses, and compose the final weight vector — is not publicly documented from the
current available sources. Validator permits on Subnet 95 are subject to the standard Bittensor
[[Validator Permit]] requirements.
