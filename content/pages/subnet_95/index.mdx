Actual is Bittensor Subnet 95, operated by Actual Computer Inc. Its on-chain description reads
"Heterogeneous inference network by Actual Computer Inc." The project website is
[actual.inc](https://actual.inc) and the subnet GitHub repository is registered on-chain as
`actual-computer/actual-subnet-95`.

Actual Computer describes itself as building AI infrastructure at the intersection of systems
engineering and artificial intelligence, with a focus on inference. Its public job listings cite
roles in core ML inference engineering and infrastructure engineering.
([actual.inc/company](https://actual.inc/company))

## How the Mechanism Works

The on-chain identity describes SN95 as a heterogeneous inference network. Heterogeneous inference
refers to serving AI model inference across varied hardware, model types, or execution backends
rather than a single uniform stack. Bittensor's incentive layer ties miner rewards to the quality
and usefulness of the inference they serve, with validator-assigned weights fed through
[[Yuma Consensus]].

Because the subnet's GitHub repository is not publicly accessible, the specific scoring criteria,
challenge format, and reward formula are not described here. Readers should consult the operator's
published documentation or the on-chain identity record for current details.

## Participating as a Miner

Miner participation requires serving inference under the subnet's protocol. Because the repository
is private, setup requirements and node configuration are not publicly documented from this source.
Prospective miners should contact the Actual Computer team through [actual.inc](https://actual.inc)
or monitor the on-chain identity for updated public documentation.

## Participating as a Validator

Validators score miners against the subnet's inference quality criteria. The general validator
workflow for Bittensor subnets is described in [[Mining and Validating]]. Subnet-specific scoring
criteria depend on operator documentation, which is not currently publicly available for SN95.

## On-Chain Identity

Live SN95 data is available on [TaoStats](https://taostats.io/subnets/95). The registered identity
lists the subnet name as Actual, the operator as Actual Computer Inc., and the URL as
[actual.inc](https://actual.inc). The GitHub field points to
[actual-computer/actual-subnet-95](https://github.com/actual-computer/actual-subnet-95), which is
not publicly accessible. Subnet 95 has 256 active neurons.
