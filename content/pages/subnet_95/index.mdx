Actual is Bittensor Subnet 95. Its on-chain identity describes the subnet as a heterogeneous
inference network operated by Actual Computer Inc., lists [actual.inc](https://actual.inc) as the
subnet URL, and lists
[actual-computer/actual-subnet-95](https://github.com/actual-computer/actual-subnet-95) as the
subnet's GitHub repository. The referenced GitHub repository is not publicly accessible at this
time.

## What Actual Provides

The on-chain description identifies Actual as a heterogeneous inference network. The
[Actual Computer website](https://actual.inc) describes the company as building the future of AI
infrastructure, specifically at the intersection of systems engineering and artificial intelligence.
The operator's public GitHub organization, [actual-computer](https://github.com/actual-computer),
hosts a fork of [llama.cpp](https://github.com/actual-computer/llama.cpp), which suggests the
subnet's inference work involves efficient local large language model execution.

The term "heterogeneous" in the on-chain description indicates that the network is designed to
coordinate inference across different hardware types or model backends rather than requiring a
uniform compute environment. Without a public subnet repository, the specific miner task, scoring
function, and reward design for SN95 cannot be independently verified from published operator
documentation at this time.

## On-Chain Identity

Live SN95 data is available on [TaoStats](https://taostats.io/subnets/95). Readers can reproduce the
subnet's registered identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 95 --network finney`.

That Finney identity reports the subnet name as Actual, the subnet URL as actual.inc, the GitHub
repo as actual-computer/actual-subnet-95, and the description as a heterogeneous inference network
by Actual Computer Inc. The subnet has 256 registered neurons.
