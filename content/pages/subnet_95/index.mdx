Actual is Bittensor Subnet 95, operated by Actual Computer Inc. The on-chain identity registers the
subnet under the name Actual, describes it as a heterogeneous inference network, and lists
[actual.inc](https://actual.inc) as the project website and
[actual-computer/actual-subnet-95](https://github.com/actual-computer/actual-subnet-95) as the
subnet repository.

The repository named in the on-chain identity is not publicly accessible at the time of this
writing. This article relies on on-chain identity fields rather than repository documentation.
Readers should verify the latest state at [TaoStats](https://taostats.io/subnets/95) and the project
website before making participation decisions.

## How the Mechanism Works

The on-chain description frames Actual as a heterogeneous inference network. In the Bittensor
incentive model, a heterogeneous inference subnet typically directs miners toward running inference
workloads across diverse hardware configurations. Validators score miners on inference quality or
throughput and set weights via [[Yuma Consensus]] accordingly.

Because no public documentation is available from the repository, the specific task definition,
scoring function, and reward curve cannot be described in detail here. Participants should consult
current operator documentation before committing resources.

## Participating as a Miner

Miners on a heterogeneous inference subnet are generally expected to run inference endpoints that
satisfy validator challenges. The exact hardware requirements, model requirements, and performance
thresholds for SN95 are defined by the operator and should be obtained from current project
documentation or the [actual.inc](https://actual.inc) website.

## Participating as a Validator

Validators on SN95 issue inference challenges to registered miners and score results, then submit
weight vectors that feed into [[Yuma Consensus]]. The specific scoring rubric, query protocol, and
weight-setting schedule are defined by the subnet operator.

[actual-computer/actual-subnet-95](https://github.com/actual-computer/actual-subnet-95) and the
