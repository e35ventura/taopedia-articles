Byzantium is Bittensor Subnet 76. Its on-chain identity describes the subnet as "Leverage marketing
with AI Swarm" and lists [byzantiumai.net](https://www.byzantiumai.net) as the project website. No
GitHub repository is registered in the live Finney identity.

## What Byzantium Provides

The on-chain description positions Byzantium as an AI swarm applied to marketing work. The subnet
name and description together suggest a model in which a coordinated network of AI agents performs
marketing tasks — such as content generation, outreach, or campaign optimization — and the Bittensor
incentive layer rewards those agents for useful output.

Because no public GitHub repository or technical documentation is linked in the registered identity,
readers should verify the current mechanism directly with the project before relying on any
third-party description of how miners and validators operate on SN76.

## On-Chain Identity

Live SN76 data is available on [TaoStats](https://taostats.io/subnets/76). Readers can reproduce the
subnet's registered identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 76 --network finney`.

That Finney identity reports the subnet name as Byzantium, the description as "Leverage marketing
with AI Swarm," and the subnet website as byzantiumai.net. No GitHub source repository is
registered.
