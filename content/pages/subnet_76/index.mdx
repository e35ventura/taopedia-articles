Subnet 76 is a Bittensor subnet slot whose current on-chain identity is registered as Byzantium. The
live identity now lists [byzantiumai.net](https://www.byzantiumai.net) as the subnet URL and gives
the description "Leverage marketing with AI Swarm." No public GitHub repository is registered for
this netuid.

Because the identity does not include a public GitHub source, this article does not reproduce a
specific miner task, scoring function, or validator workflow. Readers should consult the Byzantium
website directly for current operator documentation, and should verify the live Finney identity
before relying on any third-party descriptions of the subnet.

## Current Status

The registered on-chain identity for Subnet 76 includes the subnet name Byzantium, the project URL
https://www.byzantiumai.net, and the description "Leverage marketing with AI Swarm." The GitHub
field is blank. Without a public repository, a detailed miner and validator mechanism description
cannot be sourced from the registered identity alone.

## On-Chain Identity

Live SN76 data is available on [TaoStats](https://taostats.io/subnets/76). Readers can reproduce the
subnet's registered identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 76 --network finney`.

The current Finney identity reports the subnet name as Byzantium, the subnet URL as
https://www.byzantiumai.net, and the description "Leverage marketing with AI Swarm." No GitHub
source, contact field, or logo URL is registered.
