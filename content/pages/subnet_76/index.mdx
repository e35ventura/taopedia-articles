# Subnet 76: Byzantium

Byzantium is Bittensor Subnet 76. The on-chain identity for netuid 76 registers the name Byzantium,
the description "Leverage marketing with AI Swarm," and the website
[byzantiumai.net](https://www.byzantiumai.net). No GitHub repository is registered in the on-chain
identity fields.

The project website is a marketing page and does not currently publish technical documentation,
source code, or operator guides. Because no public codebase is available, this article describes
only what the on-chain identity fields directly state.

## On-Chain Identity

The on-chain identity for netuid 76 is the source for the name, URL, description, and absence of
GitHub. Live SN76 data is available on [TaoStats](https://taostats.io/subnets/76).
