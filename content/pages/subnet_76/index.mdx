Byzantium is Bittensor Subnet 76. Its on-chain identity describes the subnet as leveraging marketing
with an AI swarm and lists [byzantiumai.net](https://www.byzantiumai.net/) as the subnet URL. No
public GitHub repository is currently registered in the on-chain identity.

The Byzantium website describes the project as building the largest decentralized AI marketing
agency on Bittensor, coordinated across X/Twitter, Farcaster, and Bittensor itself. At the subnet
level, Byzantium maps that coordination into a miner-and-validator incentive structure.

## What Byzantium Provides

The Byzantium website positions the subnet as a swarm of AI marketing agents coordinated through
Bittensor's incentive layer. According to the public project description, participating agents
handle marketing work across social platforms, with Bittensor providing the trust and reward
infrastructure that allocates emissions to the strongest performers.

Because the project has not yet published a public technical repository through its on-chain
identity, the mechanism details below are based on the public website description. Readers should
check the live Finney identity and official project channels for current miner and validator
specifications before participating.

## Participating as a Miner

The public project materials describe miners as AI marketing agents that produce outputs across
platforms such as X/Twitter and Farcaster. The specific task definition, scoring criteria, and
registration process are not yet documented in a public repository linked from the on-chain
identity. Prospective miners should consult the
[Byzantium Discord](https://discord.com/channels/799672011265015819/1474042162877300776) for current
participation guidance.

## Participating as a Validator

Validators on Byzantium evaluate miner marketing outputs and set weights through [[Yuma Consensus]].
Because no public validator repository is currently linked from the on-chain identity, the scoring
rubric and validator setup process are not documented here. Validators should follow the project's
Discord channel for setup instructions as the network approaches launch.

## On-Chain Identity

Live SN76 data is available on [TaoStats](https://taostats.io/subnets/76). The live Finney identity
registers the subnet name as Byzantium, the description as "Leverage marketing with AI Swarm," and
the subnet URL as [byzantiumai.net](https://www.byzantiumai.net/). No GitHub repository or contact
address is registered in the on-chain identity.
