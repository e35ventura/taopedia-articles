Byzantium is Bittensor Subnet 76. Its live on-chain identity describes the subnet as "Leverage
marketing with AI Swarm" and lists [byzantiumai.net](https://www.byzantiumai.net/) as the project
website. The subnet does not currently list a public GitHub repository in its identity record.

The project website describes Byzantium as the largest decentralized AI marketing agency,
coordinated on Bittensor. It presents the subnet as a swarm of AI marketers that operates across
X/Twitter, Farcaster, and Bittensor. The site was in a coming-soon state at the time of this
article's preparation.

## What Byzantium Provides

Based on its on-chain description and website, Byzantium uses Bittensor's incentive mechanism to
coordinate AI agents that perform marketing work across social platforms. The subnet's registered
description — "Leverage marketing with AI Swarm" — matches the website's framing of the subnet as a
coordination layer for decentralized AI-driven marketing activity.

Because Byzantium has not published a public implementation repository in its identity record, the
specific miner task, validator scoring method, and operator workflow cannot be described from a
reproducible source. Operators and participants should use the website and any current documentation
published by the subnet team as the authoritative guide.

## Miner and Validator Roles

Without a public source repository defining the mechanism, the miner task and validator scoring
criteria for Subnet 76 cannot be described from a verifiable source. At the Bittensor level, miners
compete for incentive and validators submit weights that feed into [[Yuma Consensus]], but the
specific task that distinguishes Byzantium has not been documented in a source this article can
reproduce.

Participants should consult the [Byzantium website](https://www.byzantiumai.net/) and the project's
Discord for current onboarding guidance.

## On-Chain Identity

Live SN76 data is available on [TaoStats](https://taostats.io/subnets/76). The current Finney
identity reports the subnet name as Byzantium, description as "Leverage marketing with AI Swarm,"
and website as [byzantiumai.net](https://www.byzantiumai.net/). A Discord channel is also linked in
the identity record. No GitHub repository is currently registered in the on-chain identity.
