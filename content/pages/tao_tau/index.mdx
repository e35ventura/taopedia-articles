# TAO (τ)

TAO (τ) is the cryptocurrency of the Bittensor network. The official
[Glossary: TAO (τ)](https://docs.learnbittensor.org/resources/glossary#tao-tau) describes TAO as the
network token used to incentivize participation in mining, validation, subnet creation and
management, and related staking activity.

## Name and Symbol Context

Bittensor documentation uses both the label TAO and the tau symbol τ when referring to the network
token. For readers, TAO (τ) is the combined vocabulary entry: TAO names the asset in prose, while τ
marks the symbol used in official glossary and tokenomics references. It is not a separate token
from TAO; it is the same network cryptocurrency described with its conventional symbol.

References: [Glossary: TAO (τ)](https://docs.learnbittensor.org/resources/glossary#tao-tau),
[Introduction to Bittensor](https://docs.learnbittensor.org/learn/introduction)

## Incentive and Participation Context

TAO participates in the incentive layer that connects subnet work to network rewards. The
[Introduction to Bittensor](https://docs.learnbittensor.org/learn/introduction) frames TAO as the
incentive for subnet activity, while the
[Glossary: Emission](https://docs.learnbittensor.org/resources/glossary#emission) describes how
newly created currency is injected into subnets and later allocated to miners, validators, stakers,
and subnet creators.

For readers, TAO (τ) should be read as the network-token side of that incentive picture. Subnet
alpha tokens remain subnet-local assets in Dynamic TAO vocabulary and are not interchangeable with
the TAO label itself.

## Minting and Emission Boundary

Official glossary material also places TAO in block-level emission context. The
[Glossary: TAO (τ)](https://docs.learnbittensor.org/resources/glossary#tao-tau) entry notes that TAO
is minted on a recurring block schedule on the Bittensor blockchain as part of network emission.

This article does not forecast supply, quote live balances, or describe wallet transfer steps. Those
details belong in official emission references and live chain data.

References: [Emission](https://docs.learnbittensor.org/learn/emissions),
[Glossary: Emission](https://docs.learnbittensor.org/resources/glossary#emission)

## Contrast with Subnet Alpha

Dynamic TAO tokenomics also uses subnet-specific alpha tokens. The
[Glossary: Stake](https://docs.learnbittensor.org/resources/glossary#stake) and alpha-token
references describe stake and emissions in subnet markets separately from network-wide TAO usage.

TAO (τ) therefore names the network cryptocurrency, while alpha names subnet-local token context.
Statements about TAO staking on the Root Subnet should not be read as statements about subnet alpha
balances without an explicit subnet market reference.

## Wallet and Staking Context

TAO is held and moved through Bittensor wallet and staking vocabulary. The
[Glossary: Wallets](https://docs.learnbittensor.org/resources/glossary#wallets) entry places TAO
inside wallet ownership context, and staking documentation describes how TAO holders delegate
support to validators.

For readers, TAO (τ) is the asset label in those relationships. It does not name a wallet file, a
hotkey, or a validator UID by itself.

References:
[Staking and delegation overview](https://docs.learnbittensor.org/staking-and-delegation/delegation),
[Glossary: Wallets](https://docs.learnbittensor.org/resources/glossary#wallets)

## Relationship to Multiple Mechanisms

TAO incentives operate across subnets that may run more than one incentive mechanism. The
[Glossary](https://docs.learnbittensor.org/resources/glossary#multiple-incentive-mechanisms) notes
that mechanism count is a subnet design property.

For readers, TAO (τ) still names the network cryptocurrency. Multiple-mechanism context belongs with
subnet incentive design, not with the token name itself.

References:
[Multiple Incentive Mechanisms Within Subnets](https://docs.learnbittensor.org/subnets/understanding-multiple-mech-subnets),
[Glossary: Multiple Incentive Mechanisms](https://docs.learnbittensor.org/resources/glossary#multiple-incentive-mechanisms)

## Reader Boundary

TAO (τ) should not be read as investment advice, a price forecast, or a command to stake with any
particular validator. It is the official network-token vocabulary entry for Bittensor's
cryptocurrency and its τ symbol.
