# Invalid Tick Range

`InvalidTickRange` is a swap pallet error raised when the submitted tick range is not valid. The API
errors reference describes it as "The provided tick range is invalid"
([Subtensor API Errors: InvalidTickRange](https://docs.learnbittensor.org/subtensor-api/errors#invalidtickrange)).

## What It Means

`InvalidTickRange` means the tick range provided to the call was not accepted as a valid parameter
for the operation
([Subtensor API Errors: InvalidTickRange](https://docs.learnbittensor.org/subtensor-api/errors#invalidtickrange)).

This is a parameter-validation check on the tick range. It does not mean the pool has insufficient
reserves.

## Why It Appears

This error appears when a swap pallet call is submitted with a tick range that is not valid for the
operation
([Subtensor API Errors: InvalidTickRange](https://docs.learnbittensor.org/subtensor-api/errors#invalidtickrange)).

## Distinction from Invalid Liquidity Value

`InvalidTickRange` is documented as "The provided tick range is invalid." `InvalidLiquidityValue` is
documented as "Provided liquidity parameter is invalid (likely too small)." Both block a swap pallet
call due to an invalid submitted parameter, but their documented conditions describe different
parameters
([Subtensor API Errors: InvalidTickRange](https://docs.learnbittensor.org/subtensor-api/errors#invalidtickrange),
[Subtensor API Errors: InvalidLiquidityValue](https://docs.learnbittensor.org/subtensor-api/errors#invalidliquidityvalue)).

- **InvalidTickRange** -- the submitted tick range is invalid.
- **InvalidLiquidityValue** -- the submitted liquidity parameter is invalid.

## Distinction from Reserves Too Low

`InvalidTickRange` is documented as "The provided tick range is invalid." `ReservesTooLow` is
documented as "Reserves too low for operation." Both can block a swap pallet operation, but their
documented conditions describe different problems
([Subtensor API Errors: InvalidTickRange](https://docs.learnbittensor.org/subtensor-api/errors#invalidtickrange),
[Subtensor API Errors: ReservesTooLow](https://docs.learnbittensor.org/subtensor-api/errors#reservestoolow)).

- **InvalidTickRange** -- the provided tick range itself is invalid.
- **ReservesTooLow** -- the pool reserves are too low for the operation.
