# Migration In Progress

`MigrationInProgress` is a contracts pallet error raised while a pending migration still needs to
complete. The API errors reference summarizes it as "A pending migration needs to complete before
the extrinsic can be called"
([Subtensor API Errors: MigrationInProgress](https://docs.learnbittensor.org/subtensor-api/errors#migrationinprogress)).

## What It Means

Subtensor includes a contracts pallet for on-chain smart contracts. The runtime can run migrations
that update stored contract state over one or more blocks. `MigrationInProgress` means a migration
is still pending, so the runtime rejects the current operation until that migration finishes
([Subtensor API Errors: MigrationInProgress](https://docs.learnbittensor.org/subtensor-api/errors#migrationinprogress)).

This is a migration-completion gate. It does not, by itself, mean a migrate call found nothing to
update, that no contract exists at the targeted address, or that no code exists at a supplied hash.

## Why It Appears

This error appears when a contracts operation is submitted while a pending migration has not yet
completed
([Subtensor API Errors: MigrationInProgress](https://docs.learnbittensor.org/subtensor-api/errors#migrationinprogress)).

## Distinction from No Migration Performed

`MigrationInProgress` and `NoMigrationPerformed` both involve contracts migrations, but at different
stages. `MigrationInProgress` blocks other operations because a migration is still pending.
`NoMigrationPerformed` is summarized as "Migrate dispatch call was attempted but no migration was
performed."
([Subtensor API Errors: MigrationInProgress](https://docs.learnbittensor.org/subtensor-api/errors#migrationinprogress),
[Subtensor API Errors: NoMigrationPerformed](https://docs.learnbittensor.org/subtensor-api/errors#nomigrationperformed)).

- **MigrationInProgress** — a pending migration still needs to complete.
- **NoMigrationPerformed** — a migrate call did not perform any migration.

## Distinction from Contract Not Found

`MigrationInProgress` and `ContractNotFound` are different contracts pallet errors with different
API summaries. `MigrationInProgress` means a pending migration must finish first. `ContractNotFound`
is summarized as "Contract not found at the specified address."
([Subtensor API Errors: MigrationInProgress](https://docs.learnbittensor.org/subtensor-api/errors#migrationinprogress),
[Subtensor API Errors: ContractNotFound](https://docs.learnbittensor.org/subtensor-api/errors#contractnotfound)).

- **MigrationInProgress** — a pending migration still needs to complete.
- **ContractNotFound** — no live contract exists at the targeted address.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not report whether
a migration is currently pending on a network or estimate when it will finish
([Subtensor API Errors: MigrationInProgress](https://docs.learnbittensor.org/subtensor-api/errors#migrationinprogress),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
