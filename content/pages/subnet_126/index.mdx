Poker44 is Bittensor Subnet 126. The live Finney identity lists its subnet name as Poker44, its
GitHub repository as Poker44/Poker44-subnet, its subnet URL as poker44.net, and its description as
"Decentralized Poker Platform with Bot Dection."

The Poker44 repository describes the subnet as a poker bot-detection network. Miners return bot-risk
predictions for poker-behavior payloads, while validators score those predictions against canonical
evaluation batches. The README also emphasizes that Poker44 is security infrastructure, not a poker
room.

## What Poker44 Provides

Poker44 provides an evaluation loop for identifying bot-like behavior in online poker data. Its
README says validators query miners with poker-behavior chunk payloads, score predictions, and set
weights on chain. The miner and validator guides describe a current production path where platform
infrastructure prepares canonical evaluation batches from live benchmark-table hands, and validators
consume those batches through a central evaluation API.

At the article level, the subnet turns poker-behavior classification into a Bittensor task: miners
produce risk scores, validators compare those scores with hidden labels, and the resulting weights
flow through [[Yuma Consensus]].

## Miner and Validator Roles

Miners receive `DetectionSynapse(chunks=...)` requests. The miner guide says each chunk may contain
one or many hands, and the current contract expects one `risk_score` for each received chunk. The
practical miner task is to score each chunk independently and return probability-like bot-risk
scores.

Validators run the scoring side of the subnet. The validator guide says validators fetch active
canonical batch sets, convert those batches into miner requests, query miners, score responses chunk
by chunk against hidden validator-side labels, and update weights on chain. This is the
subnet-specific form of the broader [[Mining and Validating]] pattern in Bittensor.

## On-Chain Identity

Live SN126 data is available on [TaoStats](https://taostats.io/subnets/126). Readers can also
reproduce the chain identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 126 --network finney`.

That Finney identity reports the subnet name as Poker44, the subnet URL as poker44.net, and the
GitHub repo as Poker44/Poker44-subnet.
