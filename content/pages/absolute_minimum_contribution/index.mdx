# Absolute Minimum Contribution

Absolute minimum contribution is a crowdloan pallet runtime constant, listed in the chain's
constants metadata as absoluteMinimumContribution, with the value 100000000 and the summary "The
absolute minimum contribution required to contribute to a crowdloan"
([Subtensor API Constants: absoluteMinimumContribution](https://docs.learnbittensor.org/subtensor-api/constants#absoluteminimumcontribution-u64)).
The value is denominated in rao, the base unit where one TAO is 1,000,000,000 rao, so the floor is
0.1 TAO.

## What It Means

A crowdloan pools TAO from many contributors toward a shared funding goal
([Crowdloans](https://docs.learnbittensor.org/subnets/crowdloans)). Absolute minimum contribution is
the smallest amount any single contribution may be: a contribution below 0.1 TAO does not meet the
requirement
([Subtensor API Constants: absoluteMinimumContribution](https://docs.learnbittensor.org/subtensor-api/constants#absoluteminimumcontribution-u64)).
The floor applies to each individual contribution, not to the running total a crowdloan has raised.

## A Network-Wide Floor

The word absolute marks this as the hard lower limit that applies across the network. A crowdloan
may set its own minimum contribution to suit its goal, but it cannot ask for less than this floor,
so 0.1 TAO is the smallest contribution any crowdloan can accept
([Crowdloans](https://docs.learnbittensor.org/subnets/crowdloans)). The constant fixes the lowest
point a crowdloan's own minimum is allowed to reach.

## Distinction from the Creation Deposit

Absolute minimum contribution governs joining a crowdloan, while a separate threshold governs
opening one. The minimum deposit, valued at 10000000000 rao, or 10 TAO, is what the creator must put
up to start a crowdloan
([Subtensor API Constants: minimumDeposit](https://docs.learnbittensor.org/subtensor-api/constants#minimumdeposit-u64)).
One is the floor for each contributor's payment; the other is the up-front deposit for the creator.
The creation deposit is the larger figure, and the two apply to different roles.

## Distinction from the Contributor Cap

Absolute minimum contribution bounds the size of each contribution, while a separate constant bounds
how many contributors there may be. The maximum number of contributors, valued at 500, caps how many
distinct accounts may join one crowdloan
([Subtensor API Constants: maxContributors](https://docs.learnbittensor.org/subtensor-api/constants#maxcontributors-u32)).
One limit is about how small a single contribution may be; the other is about how many contributors
there can be. A crowdloan is shaped by both at once: a floor on each payment and a ceiling on the
number of payers.

## Reader Boundary

Absolute minimum contribution is a single network-wide constant expressed in rao, not a per-subnet
value, and it reflects the current runtime configuration rather than a fixed protocol rule; the
value could change in a future runtime upgrade. It names the floor for one contribution and does not
describe a crowdloan's goal, its total raised, or how contributions are returned
([Subtensor API Constants: absoluteMinimumContribution](https://docs.learnbittensor.org/subtensor-api/constants#absoluteminimumcontribution-u64)).
