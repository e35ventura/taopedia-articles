# Invalid Liquidity Value

`InvalidLiquidityValue` is a swap pallet error raised when the submitted liquidity parameter is not
valid. The API errors reference describes it as "Provided liquidity parameter is invalid (likely too
small)"
([Subtensor API Errors: InvalidLiquidityValue](https://docs.learnbittensor.org/subtensor-api/errors#invalidliquidityvalue)).

## What It Means

`InvalidLiquidityValue` means the liquidity amount provided to the call was not accepted as a valid
parameter for the operation
([Subtensor API Errors: InvalidLiquidityValue](https://docs.learnbittensor.org/subtensor-api/errors#invalidliquidityvalue)).

This is a parameter-validation check on the liquidity value. It does not mean the pool has
insufficient reserves.

## Why It Appears

This error appears when a swap pallet call is submitted with a liquidity parameter that is invalid,
for example because it is too small
([Subtensor API Errors: InvalidLiquidityValue](https://docs.learnbittensor.org/subtensor-api/errors#invalidliquidityvalue)).

## Distinction from Invalid Tick Range

`InvalidLiquidityValue` is documented as "Provided liquidity parameter is invalid (likely too
small)." `InvalidTickRange` is documented as "The provided tick range is invalid." Both block a swap
pallet call due to an invalid submitted parameter, but their documented conditions describe different
parameters
([Subtensor API Errors: InvalidLiquidityValue](https://docs.learnbittensor.org/subtensor-api/errors#invalidliquidityvalue),
[Subtensor API Errors: InvalidTickRange](https://docs.learnbittensor.org/subtensor-api/errors#invalidtickrange)).

- **InvalidLiquidityValue** -- the submitted liquidity parameter is invalid.
- **InvalidTickRange** -- the submitted tick range is invalid.

## Distinction from Reserves Too Low

`InvalidLiquidityValue` is documented as "Provided liquidity parameter is invalid (likely too
small)." `ReservesTooLow` is documented as "Reserves too low for operation." Both can block a swap
pallet operation, but their documented conditions describe different problems
([Subtensor API Errors: InvalidLiquidityValue](https://docs.learnbittensor.org/subtensor-api/errors#invalidliquidityvalue),
[Subtensor API Errors: ReservesTooLow](https://docs.learnbittensor.org/subtensor-api/errors#reservestoolow)).

- **InvalidLiquidityValue** -- the provided liquidity parameter itself is invalid.
- **ReservesTooLow** -- the pool reserves are too low for the operation.
