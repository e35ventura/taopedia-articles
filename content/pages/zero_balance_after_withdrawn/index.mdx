# Zero Balance After Withdrawn

`ZeroBalanceAfterWithdrawn` is a subtensor pallet error raised when a withdrawal cannot complete
because the amount requested would leave the account with a zero balance. The API errors reference
describes it as "Unsuccessfully withdraw, balance could be zero (can not make account exist) after
withdrawal"
([Subtensor API Errors: ZeroBalanceAfterWithdrawn](https://docs.learnbittensor.org/subtensor-api/errors#zerobalanceafterwithdrawn)).

## What It Means

`ZeroBalanceAfterWithdrawn` means the withdrawal was blocked because completing it would reduce the
account's remaining balance to zero, which does not satisfy the requirement that an account maintain
a non-zero balance to exist
([Subtensor API Errors: ZeroBalanceAfterWithdrawn](https://docs.learnbittensor.org/subtensor-api/errors#zerobalanceafterwithdrawn)).

This is a post-withdrawal balance check. It does not mean the account lacks the requested funds.

## Why It Appears

This error appears when a withdrawal call is submitted with an amount that would bring the account's
remaining balance to zero
([Subtensor API Errors: ZeroBalanceAfterWithdrawn](https://docs.learnbittensor.org/subtensor-api/errors#zerobalanceafterwithdrawn)).

## Distinction from Insufficient Balance

`ZeroBalanceAfterWithdrawn` is documented as "Unsuccessfully withdraw, balance could be zero (can
not make account exist) after withdrawal." `InsufficientBalance` is documented as "The caller does
not have enough balance for the operation." Both block a balance operation, but their documented
conditions describe different problems
([Subtensor API Errors: ZeroBalanceAfterWithdrawn](https://docs.learnbittensor.org/subtensor-api/errors#zerobalanceafterwithdrawn),
[Subtensor Standard Errors: InsufficientBalance](https://docs.learnbittensor.org/errors/subtensor#insufficientbalance)).

- **ZeroBalanceAfterWithdrawn** — the withdrawal would leave zero balance, preventing account
  existence.
- **InsufficientBalance** — the account does not have enough balance to fund the operation.
