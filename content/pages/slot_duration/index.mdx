# Slot Duration

Slot duration is an aura pallet runtime constant, listed in the chain's constants metadata as
slotDuration, with the value 12000 and the summary "The slot duration Aura should run with,
expressed in milliseconds. The effective value of this type should not change while the chain is
running"
([Subtensor API Constants: slotDuration](https://docs.learnbittensor.org/subtensor-api/constants#slotduration-u64)).
The runtime sets this constant via
`type SlotDuration = pallet_aura::MinimumPeriodTimesTwo<Runtime>;`
([runtime/src/lib.rs](https://github.com/opentensor/subtensor/blob/14bc6f9f964b9cc362e9635dd110a487fa5d15a0/runtime/src/lib.rs#L366)).

## What It Means

Aura is the block-production consensus for Subtensor. The `slotDuration` constant sets the length of
each slot in milliseconds, which defines how often the runtime expects a new block. When
`slotDuration` is 12000, the chain aims for a 12-second slot cadence
([Subtensor API Constants: slotDuration](https://docs.learnbittensor.org/subtensor-api/constants#slotduration-u64)).

The `MinimumPeriodTimesTwo` wrapper means the actual slot duration is double the timestamp
`MinimumPeriod`, which is set to half of the slot duration
([runtime/src/lib.rs](https://github.com/opentensor/subtensor/blob/14bc6f9f964b9cc362e9635dd110a487fa5d15a0/runtime/src/lib.rs#L411)).
