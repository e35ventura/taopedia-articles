# Vesting Balance

`VestingBalance` is a balances pallet error raised when an account's locked vesting balance is too
high to allow a transfer
([Subtensor API Errors: VestingBalance](https://docs.learnbittensor.org/subtensor-api/errors#vestingbalance)).

## What It Means

A vesting schedule locks part of an account's balance until a schedule-dependent unlock time. When
the locked amount is too high relative to what the transfer would leave behind, the pallet rejects
the transfer to protect the vesting lock. This is distinct from the account simply not having enough
total balance — the funds exist but are locked
([Subtensor API Errors: VestingBalance](https://docs.learnbittensor.org/subtensor-api/errors#vestingbalance)).

## Distinction from Insufficient Balance

`VestingBalance` fires when the locked vesting portion blocks the transfer even though the total
balance may be sufficient. `InsufficientBalance` fires when the total balance itself is too low
([Subtensor API Errors: VestingBalance](https://docs.learnbittensor.org/subtensor-api/errors#vestingbalance),
[Subtensor API Errors: InsufficientBalance](https://docs.learnbittensor.org/subtensor-api/errors#insufficientbalance)).

- **VestingBalance** — funds exist but are locked by vesting.
- **InsufficientBalance** — total balance is too low.

## Distinction from Existing Vesting Schedule

`VestingBalance` fires on a transfer path when an existing schedule's locked amount blocks the
operation. `ExistingVestingSchedule` fires on the schedule-creation path when an account already has
a schedule and a second one is submitted
([Subtensor API Errors: VestingBalance](https://docs.learnbittensor.org/subtensor-api/errors#vestingbalance),
[Subtensor API Errors: ExistingVestingSchedule](https://docs.learnbittensor.org/subtensor-api/errors#existingvestingschedule)).

- **VestingBalance** — a transfer is blocked by vesting locks.
- **ExistingVestingSchedule** — a new schedule is rejected because one already exists.

## Reader Boundary

This page defines the error label and the vesting-balance guard on the transfer path. It does not
report the account's current locked amount or describe the vesting schedule's unlock timeline
([Subtensor API Errors: VestingBalance](https://docs.learnbittensor.org/subtensor-api/errors#vestingbalance)).
