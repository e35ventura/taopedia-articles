# XCM Decode Failed

`XCMDecodeFailed` is a contracts pallet error raised when the submitted XCM program cannot be
decoded. The API errors reference describes it as "Failed to decode the XCM program"
([Subtensor API Errors: XCMDecodeFailed](https://docs.learnbittensor.org/subtensor-api/errors#xcmdecodefailed)).

## What It Means

`XCMDecodeFailed` means the contracts call was blocked because the XCM program provided could not be
decoded by the runtime
([Subtensor API Errors: XCMDecodeFailed](https://docs.learnbittensor.org/subtensor-api/errors#xcmdecodefailed)).

This is a decode check on the XCM program. It does not mean the contract itself is invalid.

## Why It Appears

This error appears when a contracts call is submitted with an XCM program that fails to decode
([Subtensor API Errors: XCMDecodeFailed](https://docs.learnbittensor.org/subtensor-api/errors#xcmdecodefailed)).

## Distinction from Decoding Failed

`XCMDecodeFailed` is documented as "Failed to decode the XCM program." `DecodingFailed` is
documented as input that "failed to decode as expected type." Both are contracts pallet errors that
block a call due to a decoding failure, but their documented conditions describe different decoding
targets
([Subtensor API Errors: XCMDecodeFailed](https://docs.learnbittensor.org/subtensor-api/errors#xcmdecodefailed),
[Subtensor API Errors: DecodingFailed](https://docs.learnbittensor.org/subtensor-api/errors#decodingfailed)).

- **XCMDecodeFailed** -- the submitted XCM program failed to decode.
- **DecodingFailed** -- the call input failed to decode as the expected type.

## Distinction from Code Not Found

`XCMDecodeFailed` is documented as "Failed to decode the XCM program." `CodeNotFound` is documented
as "No code could be found at the supplied code hash." Both block a contracts call, but their
documented conditions describe different problems
([Subtensor API Errors: XCMDecodeFailed](https://docs.learnbittensor.org/subtensor-api/errors#xcmdecodefailed),
[Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound)).

- **XCMDecodeFailed** -- the XCM program provided could not be decoded.
- **CodeNotFound** -- no code exists at the supplied code hash.
