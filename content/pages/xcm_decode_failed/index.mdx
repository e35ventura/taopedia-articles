# XCM Decode Failed

`XCMDecodeFailed` is a contracts pallet error raised when the runtime cannot decode a supplied XCM
program. The API errors reference summarizes it as "Failed to decode the XCM program"
([Subtensor API Errors: XCMDecodeFailed](https://docs.learnbittensor.org/subtensor-api/errors#xcmdecodefailed)).

## What It Means

Some contracts operations can supply an XCM program to the contracts runtime. `XCMDecodeFailed`
means the runtime could not interpret that XCM program in the format it expected, so the operation
stops before it can use the program
([Subtensor API Errors: XCMDecodeFailed](https://docs.learnbittensor.org/subtensor-api/errors#xcmdecodefailed)).

## Why It Appears

This error appears when a contracts operation reaches the point where an XCM program must be decoded
and that decode step fails
([Subtensor API Errors: XCMDecodeFailed](https://docs.learnbittensor.org/subtensor-api/errors#xcmdecodefailed)).

## Distinction from Decoding Failed

`XCMDecodeFailed` and `DecodingFailed` both involve decoding, but the API summaries name different
inputs. `XCMDecodeFailed` is summarized as "Failed to decode the XCM program." `DecodingFailed` is
summarized as "Input passed to a contract API function failed to decode as expected type."
([Subtensor API Errors: XCMDecodeFailed](https://docs.learnbittensor.org/subtensor-api/errors#xcmdecodefailed),
[Subtensor API Errors: DecodingFailed](https://docs.learnbittensor.org/subtensor-api/errors#decodingfailed)).

- **XCMDecodeFailed** — the XCM program could not be decoded.
- **DecodingFailed** — contract API input could not be decoded as the expected type.

## Distinction from Contract Trapped

`XCMDecodeFailed` and `ContractTrapped` both stop a contracts operation, but they describe different
failure points. `XCMDecodeFailed` means the runtime could not decode the supplied XCM program.
`ContractTrapped` is summarized as "Contract trapped during execution."
([Subtensor API Errors: XCMDecodeFailed](https://docs.learnbittensor.org/subtensor-api/errors#xcmdecodefailed),
[Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped)).

- **XCMDecodeFailed** — the XCM program fails at decode time.
- **ContractTrapped** — the contract traps during execution.
