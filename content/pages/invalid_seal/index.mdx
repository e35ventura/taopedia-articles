# Invalid Seal

`InvalidSeal` is a documented Subtensor standard error. The standard-errors reference describes it
as "PoW hash seal does not match work"
([Subtensor Standard Errors](https://docs.learnbittensor.org/subtensor-api/errors#invalidseal)).

## What It Means

This error means the faucet request included a `work` value, but that value did not match the seal
the chain reconstructed from the submitted block number, nonce, and coldkey, so the request was
rejected instead of minting faucet balance
([Subtensor Standard Errors](https://docs.learnbittensor.org/subtensor-api/errors#invalidseal),
[Subtensor source: registration.rs](https://github.com/opentensor/subtensor/blob/main/pallets/subtensor/src/subnets/registration.rs)).

In `registration.rs`, `do_faucet` computes
`seal = Self::create_seal_hash(block_number, nonce, &coldkey)` and returns `InvalidSeal` when that
reconstructed seal is not equal to the submitted `work_hash`
([Subtensor source: registration.rs](https://github.com/opentensor/subtensor/blob/main/pallets/subtensor/src/subnets/registration.rs)).

## Why It Appears

The faucet path checks whether the submitted block number is acceptable, whether the submitted work
meets the required difficulty, and whether the reconstructed seal equals the submitted work.
`InvalidSeal` is the final mismatch failure: the request reached the seal-comparison step, but the
submitted work value was not the one implied by the accompanying inputs
([Subtensor Standard Errors: InvalidWorkBlock](https://docs.learnbittensor.org/subtensor-api/errors#invalidworkblock),
[Subtensor Standard Errors: InvalidDifficulty](https://docs.learnbittensor.org/subtensor-api/errors#invaliddifficulty),
[Subtensor source: registration.rs](https://github.com/opentensor/subtensor/blob/main/pallets/subtensor/src/subnets/registration.rs)).

For a reader, the practical meaning is narrow: the problem is not simply that the work was too weak.
It is that the work value does not line up with the block number, nonce, and coldkey that were
submitted alongside it
([Subtensor Standard Errors](https://docs.learnbittensor.org/subtensor-api/errors#invalidseal),
[Subtensor Standard Errors: InvalidDifficulty](https://docs.learnbittensor.org/subtensor-api/errors#invaliddifficulty)).

## Distinction from Invalid Difficulty

`InvalidSeal` and `InvalidDifficulty` reject different faucet proof-of-work defects. `InvalidSeal`
means the submitted work does not match the seal implied by the accompanying inputs.
`InvalidDifficulty` means the submitted work hash is real but still fails the required threshold
([Subtensor Standard Errors](https://docs.learnbittensor.org/subtensor-api/errors#invalidseal),
[Subtensor Standard Errors: InvalidDifficulty](https://docs.learnbittensor.org/subtensor-api/errors#invaliddifficulty),
[Subtensor source: registration.rs](https://github.com/opentensor/subtensor/blob/main/pallets/subtensor/src/subnets/registration.rs)).

- **InvalidSeal** — the submitted work does not match the reconstructed seal.
- **InvalidDifficulty** — the submitted work is below the required difficulty.

## Reader Boundary

This page defines the meaning of the `InvalidSeal` label in the faucet proof-of-work path. It does
not explain the stale-block check behind `InvalidWorkBlock`, the separate threshold check behind
`InvalidDifficulty`, or the broader faucet policy beyond this one rejection condition
([Subtensor source: registration.rs](https://github.com/opentensor/subtensor/blob/main/pallets/subtensor/src/subnets/registration.rs)).
