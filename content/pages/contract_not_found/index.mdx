# Contract Not Found

`ContractNotFound` is a contracts pallet error raised when no live contract exists at the targeted
address. The API errors reference summarizes it as "Contract not found at the specified address"
([Subtensor API Errors: ContractNotFound](https://docs.learnbittensor.org/subtensor-api/errors#contractnotfound)).

## What It Means

Bittensor supports an Ethereum-compatible smart-contract environment on Subtensor
([Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials)). In that setting,
some operations expect the supplied address to resolve to an already deployed contract.
`ContractNotFound` means the runtime could not find a contract at that address, so the contract-side
operation cannot continue
([Subtensor API Errors: ContractNotFound](https://docs.learnbittensor.org/subtensor-api/errors#contractnotfound)).

This is an address-to-contract lookup failure. It does not, by itself, mean the contract code at a
known code hash is missing, and it does not mean execution started and then trapped.

## Why It Appears

This error appears when a contracts operation points at an address that does not currently resolve
to a live contract
([Subtensor API Errors: ContractNotFound](https://docs.learnbittensor.org/subtensor-api/errors#contractnotfound)).

## Distinction from Code Not Found

`ContractNotFound` and `CodeNotFound` both concern missing contract-related state, but they fail on
different lookups. `ContractNotFound` means the targeted address does not resolve to a live
contract. `CodeNotFound` means a supplied code hash does not resolve to stored contract code
([Subtensor API Errors: ContractNotFound](https://docs.learnbittensor.org/subtensor-api/errors#contractnotfound),
[Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound)).

- **ContractNotFound** — no live contract exists at the targeted address.
- **CodeNotFound** — no stored code exists at the supplied code hash.

## Distinction from Contract Terminated

`ContractNotFound` and `ContractTerminated` both describe contracts that are not available for the
attempted operation, but they say different things. `ContractNotFound` means the runtime cannot find
a live contract at the given address. `ContractTerminated` means a contract was terminated and is no
longer available after that termination event
([Subtensor API Errors: ContractNotFound](https://docs.learnbittensor.org/subtensor-api/errors#contractnotfound),
[Subtensor API Errors: ContractTerminated](https://docs.learnbittensor.org/subtensor-api/errors#contractterminated)).

- **ContractNotFound** — the target address does not resolve to a live contract.
- **ContractTerminated** — the contract was terminated and is no longer available.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not report whether
a specific address currently hosts a contract on a live network
([Subtensor API Errors: ContractNotFound](https://docs.learnbittensor.org/subtensor-api/errors#contractnotfound),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
