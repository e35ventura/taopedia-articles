# Subtoken Enabled

Subtoken enabled is a per-subnet hyperparameter, listed in the documentation as `SubtokenEnabled`,
that gates whether subtoken trading is active for a subnet. The reference describes it as enabling
or disabling subtoken trading for a given subnet, with a default of true
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

## What It Controls

The hyperparameter is the trading gate for a subnet's alpha subtoken, not the subnet's task,
emission formula, or validator weight rules. When enabled, the subnet's alpha token can trade
through the subtoken market paths the protocol exposes; when disabled, that trading path is turned
off for the selected netuid
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters),
[Dynamic TAO](https://docs.learnbittensor.org/learn/dynamic-tao)).

It does not set alpha price, pool depth, or staking yields. It only decides whether subtoken trading
is permitted on the subnet, leaving pricing and liquidity to the market mechanisms that operate when
trading is on
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

The flag is set at root permission rather than by the subnet owner alone, so changes reflect
network-level policy for subtoken markets. The live value on netuid 1 can differ from the documented
default and from another subnet's setting
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

## Documented Type and Default

The [Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)
reference lists `SubtokenEnabled` as a `Bool` with a default of true and marks the permission
required to change it as root
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

Because each subnet carries its own hyperparameters, the trading gate on one netuid can differ from
the documented default and from the flag on another subnet
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

## Reading the Live Value for netuid 1

Subtoken enabled is per-subnet chain state, so any live claim is tied to a specific netuid. For the
documented example netuid 1 on Finney mainnet, the flag appears in that subnet's hyperparameter
table, which the reference describes under viewing a subnet's hyperparameters
([Subnet Hyperparameters: View hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters#view-hyperparameters)).
The infobox uses netuid 1 only as an example label; other subnets expose their own values
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

## Distinction from Dynamic TAO

Dynamic TAO is the broader economic model for subnet alpha tokens, pools, and staking. Subtoken
enabled is the per-subnet hyperparameter that turns subtoken trading on or off within that model
([Dynamic TAO](https://docs.learnbittensor.org/learn/dynamic-tao),
[Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

- **Dynamic TAO** — subnet alpha token economics and market structure.
- **Subtoken enabled** — whether subtoken trading is active on one subnet.
