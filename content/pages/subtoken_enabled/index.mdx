# Subtoken Enabled

Subtoken enabled is a per-subnet hyperparameter, listed in the documentation as `SubtokenEnabled`,
that controls whether subtoken trading is turned on for a subnet
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

## What It Controls

A subnet's subtoken is its alpha. While the flag is true, the staking paths that trade TAO and the
subnet's alpha through its pool are available; while it is false, those paths are rejected. The flag
governs subtoken trading on the subnet, not who holds stake or how weights and emissions are scored
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

The reference lists `SubtokenEnabled` as a `Bool`, described as "Enables or disables subtoken
trading for a given subnet," changed through the `sudo_set_subtoken_enabled` extrinsic with the
permission to set it marked as root. Because it is per-subnet, one subnet can have subtoken trading
on while another has it off
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

## Distinction from Subtoken Disabled

Subtoken enabled is the hyperparameter; `SubtokenDisabled` is the error raised when a call depends
on subtoken trading that the flag has turned off. The flag is the setting; the error is the
rejection returned to a staking or stake-move call while the setting is false
([Subtensor Standard Errors: SubtokenDisabled](https://docs.learnbittensor.org/subtensor-api/errors#subtokendisabled)).

- **Subtoken enabled** — the per-subnet flag for subtoken trading.
- **Subtoken disabled** — the error returned when a call needs trading the flag has switched off.

## Chain Reads for netuid 1

Readers can verify the live value for a subnet with
`btcli subnet hyperparameters --netuid 1 --network finney`, which lists the per-subnet
hyperparameter values, including this flag, for the documented example netuid. Because the value is
per-subnet chain state, the flag read for one netuid applies only to that subnet and can differ from
another's
([Subnet Hyperparameters: View hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters#view-hyperparameters),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

## Reader Boundary

This page defines the subtoken enabled hyperparameter and what its switch turns on. It does not
document the internals of subtoken trading or the live value set on any particular subnet
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).
