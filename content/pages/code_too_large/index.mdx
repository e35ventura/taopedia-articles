# Code Too Large

`CodeTooLarge` is a contracts pallet error raised when supplied instantiation code exceeds the
current schedule limit. The API errors reference summarizes it as "The code supplied to
`instantiate_with_code` exceeds the limit specified in the current schedule"
([Subtensor API Errors: CodeTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#codetoolarge)).

## What It Means

Bittensor runs an Ethereum-compatible execution layer on Subtensor for smart contracts
([Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials)). `CodeTooLarge`
means the bytecode submitted through `instantiate_with_code` is larger than the contracts schedule
allows, so instantiation stops before the code is stored
([Subtensor API Errors: CodeTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#codetoolarge)).

This is a code-size rejection on instantiation. It does not, by itself, mean no code exists at a
named hash or that execution trapped during a later call.

## Why It Appears

This error appears when `instantiate_with_code` is called with bytecode that exceeds the limit named
in the current contracts schedule
([Subtensor API Errors: CodeTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#codetoolarge)).

## Distinction from Code Not Found

`CodeTooLarge` and `CodeNotFound` both involve contract code, but at different checks.
`CodeNotFound` is summarized as "No code could be found at the supplied code hash." `CodeTooLarge`
is summarized as "The code supplied to `instantiate_with_code` exceeds the limit specified in the
current schedule."
([Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound),
[Subtensor API Errors: CodeTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#codetoolarge)).

- **CodeTooLarge** — supplied instantiate code exceeds the current schedule limit.
- **CodeNotFound** — no code at the supplied code hash.

## Distinction from Contract Trapped

`CodeTooLarge` and `ContractTrapped` are different contracts pallet errors with different API
summaries. `CodeTooLarge` is summarized as "The code supplied to `instantiate_with_code` exceeds the
limit specified in the current schedule." `ContractTrapped` is summarized as "Contract trapped
during execution."
([Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped),
[Subtensor API Errors: CodeTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#codetoolarge)).

- **CodeTooLarge** — supplied instantiate code exceeds the current schedule limit.
- **ContractTrapped** — contract trapped during execution.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not report the live
instantiate code limit configured on a network
([Subtensor API Errors: CodeTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#codetoolarge),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
