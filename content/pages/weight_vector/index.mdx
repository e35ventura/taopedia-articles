# Weight Vector

A weight vector is the per-validator signal at the base of Bittensor consensus. The Bittensor
glossary describes it as a vector maintained by each subnet validator, where each element is the
weight that validator assigns to a subnet miner based on the miner's performance.

References: [Weight Vector](https://docs.learnbittensor.org/resources/glossary#weight-vector),
[Yuma Consensus](https://docs.learnbittensor.org/learn/yuma-consensus)

## What the Vector Represents

Each element of a weight vector is one validator's relative evaluation of a single miner inside a
subnet. Taken together, the vector is that validator's complete view of how the subnet's miners
compare on the task being scored. It is a single participant's signal, not a finished consensus
result, so a claim about one weight vector describes one validator's opinion rather than the
subnet's collective outcome.

References: [Weight Vector](https://docs.learnbittensor.org/resources/glossary#weight-vector),
[Consensus Score](https://docs.learnbittensor.org/resources/glossary#consensus-score)

## Relationship to the Weight Matrix

The glossary describes the ranking weight vectors for a subnet as combining to form the weight
matrix. In other words, a weight vector is one row of input and the weight matrix is the collection
of those rows arranged for the subnet's consensus step. This distinction matters because the matrix
result, after every validator's vector is included, can differ from any single vector on its own.

References: [Weight Vector](https://docs.learnbittensor.org/resources/glossary#weight-vector),
[Weight Matrix](https://docs.learnbittensor.org/resources/glossary#weight-matrix)

## Multiple Mechanisms

The glossary notes that when a subnet uses multiple incentive mechanisms, each validator maintains a
separate weight vector for each mechanism. A weight vector should therefore be read in the context
of a particular subnet mechanism, not as a single ranking that spans every task a subnet may run.

References: [Weight Vector](https://docs.learnbittensor.org/resources/glossary#weight-vector),
[Yuma Consensus](https://docs.learnbittensor.org/learn/yuma-consensus)

## Reader Boundary

A weight vector is a validator's input signal, not an operating instruction, a guaranteed outcome,
or a live value to read from the chain. It names a consensus term: the per-validator, per-miner
evaluation that Yuma Consensus aggregates together with the validator weights and weight matrix it
feeds into. Exact weights and current values belong in the official references and chain data, while
Taopedia's role is to explain what the term means rather than mirror a live number.

References: [Weight Vector](https://docs.learnbittensor.org/resources/glossary#weight-vector),
[Weight Matrix](https://docs.learnbittensor.org/resources/glossary#weight-matrix)
