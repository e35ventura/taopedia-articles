# Storage Deposit Limit Exhausted

`StorageDepositLimitExhausted` is a contracts pallet error raised when more storage is created than
the storage deposit limit allows. The API errors reference summarizes it as "More storage was
created than allowed by the storage deposit limit"
([Subtensor API Errors: StorageDepositLimitExhausted](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositlimitexhausted)).

## What It Means

Subtensor includes a contracts pallet for on-chain smart contracts. Contract storage growth is
capped by a storage deposit limit tied to reserved balance. `StorageDepositLimitExhausted` means an
operation would create more storage than that limit permits, so the runtime rejects it
([Subtensor API Errors: StorageDepositLimitExhausted](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositlimitexhausted)).

This is a storage-deposit limit rejection. It does not, by itself, mean the origin cannot fund the
required deposits, that no contract exists at the targeted address, or that no code exists at a
supplied hash.

## Why It Appears

This error appears when a contracts operation would add storage beyond the allowed deposit limit
([Subtensor API Errors: StorageDepositLimitExhausted](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositlimitexhausted)).

## Distinction from Storage Deposit Not Enough Funds

`StorageDepositLimitExhausted` and `StorageDepositNotEnoughFunds` both involve contracts storage
deposits, but the API summaries name different problems. `StorageDepositLimitExhausted` means more
storage was created than the limit allows. `StorageDepositNotEnoughFunds` is summarized as "Origin
doesn't have enough balance to pay the required storage deposits."
([Subtensor API Errors: StorageDepositLimitExhausted](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositlimitexhausted),
[Subtensor API Errors: StorageDepositNotEnoughFunds](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositnotenoughfunds)).

- **StorageDepositLimitExhausted** — more storage was created than the deposit limit allows.
- **StorageDepositNotEnoughFunds** — the origin cannot fund the required storage deposits.

## Distinction from Contract Not Found

`StorageDepositLimitExhausted` and `ContractNotFound` are different contracts pallet errors with
different API summaries. `StorageDepositLimitExhausted` means storage would exceed the deposit
limit. `ContractNotFound` is summarized as "Contract not found at the specified address."
([Subtensor API Errors: StorageDepositLimitExhausted](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositlimitexhausted),
[Subtensor API Errors: ContractNotFound](https://docs.learnbittensor.org/subtensor-api/errors#contractnotfound)).

- **StorageDepositLimitExhausted** — more storage was created than the deposit limit allows.
- **ContractNotFound** — no live contract exists at the targeted address.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not report the
storage deposit limit configured on a network or measure storage use for a specific contract
([Subtensor API Errors: StorageDepositLimitExhausted](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositlimitexhausted),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
