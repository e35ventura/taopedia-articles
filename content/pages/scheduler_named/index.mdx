# Scheduler Named

`Named` is a scheduler pallet error raised when a non-named function is used on a named scheduled
task. The API errors reference summarizes it as "Attempt to use a non-named function on a named
task" ([Subtensor API Errors: Named](https://docs.learnbittensor.org/subtensor-api/errors#named)).

## What It Means

Subtensor uses the scheduler pallet to queue calls for dispatch at a specified future block. Some
scheduler entries are stored as named tasks. `Named` means the submitted operation uses a non-named
function against one of those named tasks, so the runtime rejects it
([Subtensor API Errors: Named](https://docs.learnbittensor.org/subtensor-api/errors#named)).

This is a named-task function mismatch. It does not, by itself, mean the scheduler failed to queue a
new call, that the referenced scheduled call was not found, or that the submitted target block is in
the past.

## Why It Appears

This error appears when a scheduler operation targets a named task but supplies a non-named function
for that path
([Subtensor API Errors: Named](https://docs.learnbittensor.org/subtensor-api/errors#named)).

## Distinction from Failed To Schedule

`Named` and `FailedToSchedule` both stop scheduler operations, but with different API summaries.
`Named` is summarized as "Attempt to use a non-named function on a named task." `FailedToSchedule`
is summarized as "Failed to schedule a call."
([Subtensor API Errors: Named](https://docs.learnbittensor.org/subtensor-api/errors#named),
[Subtensor API Errors: FailedToSchedule](https://docs.learnbittensor.org/subtensor-api/errors#failedtoschedule)).

- **Named** — a non-named function was used on a named task.
- **FailedToSchedule** — the scheduler failed to schedule the call.

## Distinction from Scheduled Call Not Found

`Named` and scheduler `NotFound` are different scheduler pallet errors with different API summaries.
`Named` concerns the function type used on a named task. `NotFound` is summarized as "Cannot find
the scheduled call."
([Subtensor API Errors: Named](https://docs.learnbittensor.org/subtensor-api/errors#named),
[Subtensor API Errors: NotFound](https://docs.learnbittensor.org/subtensor-api/errors#notfound)).

- **Named** — a non-named function was used on a named task.
- **NotFound** — the referenced scheduled call was not found.

## Reader Boundary

This page defines the meaning of the scheduler `Named` error label from the API reference. It does
not report which scheduler tasks are named on a network
([Subtensor API Errors: Named](https://docs.learnbittensor.org/subtensor-api/errors#named),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
