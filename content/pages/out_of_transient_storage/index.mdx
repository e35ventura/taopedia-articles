# Out Of Transient Storage

`OutOfTransientStorage` is a contracts pallet error raised when no more data can be added to
transient storage. The API errors reference summarizes it as "Can not add more data to transient
storage"
([Subtensor API Errors: OutOfTransientStorage](https://docs.learnbittensor.org/subtensor-api/errors#outoftransientstorage)).

## What It Means

Some contracts operations write to transient storage during a call. `OutOfTransientStorage` means
that temporary storage is already full, so the operation cannot add more data
([Subtensor API Errors: OutOfTransientStorage](https://docs.learnbittensor.org/subtensor-api/errors#outoftransientstorage)).

This is a transient-storage capacity failure. It does not, by itself, mean the origin cannot fund
required storage deposits, that execution exhausted its gas limit, or that a buffer outside sandbox
memory was passed to a contract API function.

## Why It Appears

This error appears when a contracts operation would add data beyond the transient storage limit for
the current call
([Subtensor API Errors: OutOfTransientStorage](https://docs.learnbittensor.org/subtensor-api/errors#outoftransientstorage)).

## Distinction from Storage Deposit Limit Exhausted

`OutOfTransientStorage` and `StorageDepositLimitExhausted` both involve storage limits, but the API
summaries name different boundaries. `OutOfTransientStorage` is summarized as "Can not add more data
to transient storage." `StorageDepositLimitExhausted` is summarized as "More storage was created
than allowed by the storage deposit limit."
([Subtensor API Errors: OutOfTransientStorage](https://docs.learnbittensor.org/subtensor-api/errors#outoftransientstorage),
[Subtensor API Errors: StorageDepositLimitExhausted](https://docs.learnbittensor.org/subtensor-api/errors#storagedepositlimitexhausted)).

- **OutOfTransientStorage** — transient storage cannot accept more data.
- **StorageDepositLimitExhausted** — more storage was created than the deposit limit allows.

## Distinction from Out Of Gas

`OutOfTransientStorage` and `OutOfGas` both stop contract execution, but with different API
summaries. `OutOfTransientStorage` concerns transient storage capacity. `OutOfGas` is summarized as
"The executed contract exhausted its gas limit."
([Subtensor API Errors: OutOfTransientStorage](https://docs.learnbittensor.org/subtensor-api/errors#outoftransientstorage),
[Subtensor API Errors: OutOfGas](https://docs.learnbittensor.org/subtensor-api/errors#outofgas)).

- **OutOfTransientStorage** — transient storage cannot accept more data.
- **OutOfGas** — the executed contract exhausted its gas limit.
