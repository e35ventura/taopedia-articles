# Code Rejected

`CodeRejected` is a contracts pallet error raised when the supplied contract code is found to be
invalid during validation. The API errors reference describes it as "The contract's code was found
to be invalid during validation. The most likely cause of this is that an API was used which is not
supported by the node."
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

## What It Means

Before contract code is stored on chain, the contracts pallet validates it. `CodeRejected` fires
when that validation step rejects the code — most commonly because the code uses an API that the
node does not support
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

This is a code-validation rejection at upload time. It does not mean the code hash is already in
use, that the code exceeds the size limit, or that no code was found at a given hash.

## Why It Appears

This error appears when code being uploaded to the contracts pallet does not pass the validation
check. The practical meaning is narrow: the code itself must be corrected — typically by removing or
replacing any use of an API that the target node does not support — before reattempting the upload
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

## Distinction from Code Too Large

`CodeRejected` and `CodeTooLarge` both block contract code upload, but they fail for different
reasons. `CodeTooLarge` fires when the submitted code exceeds the size limit in the current
contracts schedule. `CodeRejected` fires when the code fails the validation check, regardless of its
size
([Subtensor API Errors: CodeTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#codetoolarge),
[Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

- **CodeRejected** — code is invalid during validation (e.g., unsupported API used).
- **CodeTooLarge** — code exceeds the allowed size limit.

## Distinction from Code Not Found

`CodeRejected` and `CodeNotFound` both block contracts operations involving code, but at different
points and for different reasons. `CodeNotFound` fires when an operation references a code hash that
has no code stored at it. `CodeRejected` fires when code is being uploaded but fails validation
before it can be stored
([Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound),
[Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

- **CodeRejected** — upload attempt rejected because the code is invalid.
- **CodeNotFound** — operation references a code hash with no stored code.
