# Code Rejected

`CodeRejected` is a contracts pallet error raised when contract code is found to be invalid during
validation. The API errors reference describes it as code that "was found to be invalid during
validation" and notes the most likely cause is "an API was used which is not supported by the node"
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

## What It Means

Bittensor runs an Ethereum-compatible execution layer on Subtensor for smart contracts
([Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials)). When contract code
is uploaded, the runtime validates it before storing it on chain. `CodeRejected` means that
validation failed, typically because the code uses an API the node does not support — for example,
when an older node version is paired with a newer contract toolchain
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

## Distinction from Code Too Large

`CodeRejected` and `CodeTooLarge` both block a contract upload, but at different checks.
`CodeRejected` fires when the code fails validation. `CodeTooLarge` fires when the code exceeds the
size limit before validation runs
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected),
[Subtensor API Errors: CodeTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#codetoolarge)).

- **CodeRejected** — the code is invalid during validation.
- **CodeTooLarge** — the code exceeds the size limit.

## Distinction from Decoding Failed

`CodeRejected` and `DecodingFailed` are both contracts pallet errors that stop a contract operation
early, but they involve different inputs. `CodeRejected` fires when the contract code itself fails
validation at upload. `DecodingFailed` fires when the input attached to a contract call cannot be
decoded into the expected format
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected),
[Subtensor API Errors: DecodingFailed](https://docs.learnbittensor.org/subtensor-api/errors#decodingfailed)).

- **CodeRejected** — the contract code is invalid.
- **DecodingFailed** — the call input cannot be decoded.
