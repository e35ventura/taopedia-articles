# Code Rejected

`CodeRejected` is a contracts pallet error raised when supplied contract code is rejected by the
runtime. The API errors reference summarizes it as "The code was rejected by the execution engine"
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

## What It Means

Bittensor supports an Ethereum-compatible smart-contract environment on Subtensor
([Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials)). In that setting,
uploaded or instantiated contract code has to pass the runtime's validation rules before it can be
accepted. `CodeRejected` means that validation step rejected the supplied code, so the runtime does
not accept it for execution
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

This is a code-validation rejection. It does not, by itself, mean the code is missing from storage,
that a contract address could not be found, or that execution began and then ran out of gas.

## Why It Appears

This error appears when a contracts operation supplies code that the runtime's execution engine will
not accept
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

## Distinction from Code Too Large

`CodeRejected` and `CodeTooLarge` both stop contract code before successful use, but they reject
different problems. `CodeRejected` means the runtime refused the code during validation.
`CodeTooLarge` means the submitted instantiate code exceeds the current schedule limit
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected),
[Subtensor API Errors: CodeTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#codetoolarge)).

- **CodeRejected** — the runtime rejects the supplied code during validation.
- **CodeTooLarge** — the supplied code exceeds the allowed size limit.

## Distinction from Code Not Found

`CodeRejected` and `CodeNotFound` both concern contract code, but at different stages.
`CodeRejected` means the supplied code was examined and refused. `CodeNotFound` means a later lookup
could not find code at a supplied code hash
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected),
[Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound)).

- **CodeRejected** — supplied code fails validation.
- **CodeNotFound** — stored code cannot be found by code hash.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not diagnose which
specific validation rule rejected a given contract or report whether a different code version would
be accepted on a live network
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
