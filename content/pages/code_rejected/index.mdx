# Code Rejected

`CodeRejected` is a contracts pallet error raised when submitted contract code fails validation. The
API errors reference describes it as "The contract's code was found to be invalid during validation.
The most likely cause of this is that an API was used which is not supported by the node. This
happens if an older node is used with a new version of ink!"
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

## What It Means

`CodeRejected` means the contracts call was blocked because the submitted code did not pass the
pallet's validation check
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

The API errors reference identifies the most likely cause as an API used in the code that the node
does not support, which the reference notes occurs when an older node is used with a newer version
of ink!
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

This is a code validation failure. It does not mean the code hash is absent from storage or that the
code exceeds the size limit.

## Why It Appears

This error appears when a contracts call submits code that the pallet's validation check rejects
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected)).

## Distinction from Code Not Found

`CodeRejected` is documented as code that "was found to be invalid during validation."
`CodeNotFound` is documented as "No code could be found at the supplied code hash." Both are
contracts pallet errors that block a call involving code, but their documented conditions describe
different problems
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected),
[Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound)).

- **CodeRejected** -- submitted code exists but fails the validation check.
- **CodeNotFound** -- no code exists at the supplied code hash.

## Distinction from Code Too Large

`CodeRejected` is documented as code that "was found to be invalid during validation."
`CodeTooLarge` is documented as "The code supplied to `instantiate_with_code` exceeds the limit
specified in the current schedule." Both block a contracts operation involving code upload, but
their documented conditions describe different checks
([Subtensor API Errors: CodeRejected](https://docs.learnbittensor.org/subtensor-api/errors#coderejected),
[Subtensor API Errors: CodeTooLarge](https://docs.learnbittensor.org/subtensor-api/errors#codetoolarge)).

- **CodeRejected** -- code fails the validation check.
- **CodeTooLarge** -- code exceeds the size limit in the current schedule.
