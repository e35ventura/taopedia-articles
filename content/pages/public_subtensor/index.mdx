# Public Subtensor

Public Subtensor is a publicly accessible node in the Bittensor network that provides public access
to the Subtensor chain layer, not a separate blockchain
([Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)).

The term belongs to network-access vocabulary. It names a node anyone can reach to observe shared
chain state, rather than a new runtime, a wallet, or a consensus mechanism.

## Distinction from Subtensor

Subtensor is Bittensor's layer-one blockchain and system of record that stores state and processes
extrinsics, while Public Subtensor is a publicly accessible node that reaches that chain. Subtensor
is the chain itself; Public Subtensor is one public point of access to it
([Glossary: Subtensor](https://docs.learnbittensor.org/resources/glossary#subtensor),
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)).

- **Subtensor** — the layer-one blockchain and system of record.
- **Public Subtensor** — a publicly accessible node that reaches that chain.

## Distinction from Local Blockchain

A local blockchain is a private, isolated chain used for development and testing, while Public
Subtensor is a publicly accessible node on the shared network. One is private and local; the other
is public and shared
([Glossary: Local Blockchain](https://docs.learnbittensor.org/resources/glossary#local-blockchain),
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)).

- **Local blockchain** — a private chain for development and testing.
- **Public Subtensor** — a publicly accessible node on the shared network.

## Distinction from Mainchain

Mainchain is Bittensor's primary production network, while Public Subtensor is a publicly accessible
node that connects participants to a chain. A public node can serve the mainchain, but it is the
access point rather than the production network itself
([Glossary: Mainchain](https://docs.learnbittensor.org/resources/glossary#mainchain),
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)).

- **Mainchain** — the primary production network.
- **Public Subtensor** — a publicly accessible node reaching that network.

## Public Access Does Not Grant Signing Authority

Reaching a public node lets a reader observe shared chain state, but it does not by itself authorize
changes to that state. Submitting an extrinsic still depends on the required wallet keys, role, and
fees, so public access and signing authority remain separate
([Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)).

A public node therefore answers where chain state can be observed, not who is allowed to change it.

## Reader Boundary

Public Subtensor names a public-access node, not private key custody, wallet authority, or a
guarantee about any particular operator. It identifies public access to the Subtensor chain layer
rather than a separate network or runtime
([Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)).
