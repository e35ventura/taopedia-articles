# Public Subtensor

Public Subtensor refers to publicly reachable Bittensor chain access. Official Bittensor
documentation uses Subtensor to describe the blockchain layer that supports Bittensor network state.

References:
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor),
[Subtensor](https://docs.learnbittensor.org/subtensor-nodes)

## Network Context

The term is useful when distinguishing public chain access from local development context. Public
Subtensor belongs to the live network side of that distinction, while local blockchain context is
private and development-oriented.

References:
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)

## Relationship to Subtensor

Public Subtensor and Subtensor are related but name different layers of the same picture. The
[Glossary: Subtensor](https://docs.learnbittensor.org/resources/glossary#subtensor) describes
Bittensor's layer 1 blockchain and the system of record for transactions and rankings, while the
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)
describes publicly reachable access to that chain layer.

For readers, Subtensor is the chain layer itself, while Public Subtensor names live public access to
it. The term does not rename Subtensor and should not be read as a separate blockchain.

References: [Glossary: Subtensor](https://docs.learnbittensor.org/resources/glossary#subtensor),
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)

## Relationship to Local Blockchain

Public Subtensor and local blockchain name opposite sides of Bittensor chain access. The
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)
describes publicly reachable chain access, while the
[Glossary: Local Blockchain](https://docs.learnbittensor.org/resources/glossary#local-blockchain)
describes a private chain used for development and testing.

For readers, Public Subtensor belongs to live network access context, while local blockchain belongs
to isolated development context. The two terms should not be read as interchangeable network labels.

References:
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor),
[Glossary: Local Blockchain](https://docs.learnbittensor.org/resources/glossary#local-blockchain)

## Relationship to Bittensor Networks

Public Subtensor and Bittensor Networks name related but different parts of live chain context. The
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks) reference groups
mainnet, testnet, and localnet, while the
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)
describes publicly reachable access to the Subtensor chain layer.

For readers, Bittensor Networks is the environment label, while Public Subtensor names public access
to Subtensor inside mainnet and testnet context. It does not describe private local blockchain
development.

References: [Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks),
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)

## Reader Boundary

This page defines the term. It does not provide endpoint recommendations, connection steps, or
node-operation guidance. Readers should use current official Bittensor documentation when they need
operational details.

## Relationship to Extrinsics

Public Subtensor and extrinsics are related but different parts of Bittensor chain vocabulary.
Extrinsics name signed transactions and calls submitted to Subtensor, while Public Subtensor names
publicly reachable access to the chain layer where those submissions are processed. The
[Glossary: Extrinsics](https://docs.learnbittensor.org/resources/glossary#extrinsics) describes
signed transactions submitted to the chain, and the
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)
describes publicly reachable access to that chain layer.

For readers, extrinsics name submitted chain actions, while Public Subtensor names the public access
context for interacting with the chain that receives them.

References: [Glossary: Extrinsics](https://docs.learnbittensor.org/resources/glossary#extrinsics),
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)

## Relationship to Block

Public Subtensor and a block are related but different parts of Bittensor chain timing vocabulary. A
block names one unit of chain progression on Subtensor, while Public Subtensor names publicly
reachable access to the chain layer where those blocks are produced. The
[Glossary: Block](https://docs.learnbittensor.org/resources/glossary#block) describes a block as a
unit of chain data, and the
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)
describes publicly reachable access to that chain layer.

For readers, a block marks chain progression, while Public Subtensor names public access to the
chain history where those blocks are recorded.

References: [Glossary: Block](https://docs.learnbittensor.org/resources/glossary#block),
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)

## Relationship to Mempool

Public Subtensor and the mempool are related but different parts of Bittensor chain activity. The
mempool names pending transactions before block inclusion, while Public Subtensor names publicly
reachable access to the chain layer where those pending submissions eventually arrive. The
[Glossary: Mempool](https://docs.learnbittensor.org/resources/glossary#mempool) describes the
pending-transaction context, and the
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)
describes publicly reachable access to Subtensor.

For readers, the mempool belongs to the pre-inclusion waiting stage, while Public Subtensor names
public access to the chain layer that processes included submissions.

References: [Glossary: Mempool](https://docs.learnbittensor.org/resources/glossary#mempool),
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)

## Relationship to Netuid

Public Subtensor and a netuid are related but different parts of Bittensor vocabulary. A netuid
identifies a subnet on the network, while Public Subtensor names publicly reachable access to the
chain layer that records subnet-scoped state tied to that identifier. The
[Glossary: Netuid](https://docs.learnbittensor.org/resources/glossary#netuid) places netuid at the
subnet level, and the
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)
describes publicly reachable access to Subtensor.

For readers, a netuid selects which subnet context is in scope, while Public Subtensor names public
access to the chain layer that holds subnet-related state.

References: [Glossary: Netuid](https://docs.learnbittensor.org/resources/glossary#netuid),
[Glossary: Public Subtensor](https://docs.learnbittensor.org/resources/glossary#public-subtensor)
