# Staking Swap Fee

The staking swap fee is the amount-based charge Bittensor applies when a staking operation converts
value through a subnet's liquidity pool. The fee documentation describes staking and unstaking
operations as incurring an amount-based swap fee on the transacted liquidity, charged in addition to
the base transaction fee
([Transaction Fees in Bittensor](https://docs.learnbittensor.org/learn/fees),
[Understanding Slippage](https://docs.learnbittensor.org/learn/slippage)).

## What It Means

A staking swap fee is tied to the conversion side of a staking action, not to the chain work of
submitting it. When stake is added, removed, or moved across subnets, value passes through a
subnet's pool that exchanges TAO and the subnet's alpha. The fee documentation describes this as an
amount-based swap fee, expressed as a percentage of the transacted liquidity, rather than a flat or
compute-based charge ([Transaction Fees in Bittensor](https://docs.learnbittensor.org/learn/fees),
[Understanding Slippage](https://docs.learnbittensor.org/learn/slippage)).

So when this fee applies, its size scales with the amount being staked or unstaked, because it is a
percentage of the liquidity that moves through the pool. It is a separate cost from the base
weight-and-length transaction fee that the chain charges for processing the extrinsic
([Transaction Fees in Bittensor](https://docs.learnbittensor.org/learn/fees),
[Glossary: Stake](https://docs.learnbittensor.org/resources/glossary#stake)).

## How It Works

The fee documentation states that staking and unstaking operations incur the base transaction fee as
well as amount-based swap fees on the transacted liquidity, and gives the documented swap-fee rate
as a small fixed percentage. Because the charge is a share of the amount, larger staking conversions
carry a proportionally larger swap fee than smaller ones
([Transaction Fees in Bittensor](https://docs.learnbittensor.org/learn/fees)).

The fee documentation also extends the swap fee to cross-subnet stake movement: when stake is moved
between subnets through a transfer, swap, or move, the same amount-based swap fee is applied. The
staking documentation describes moving stake as a single atomic operation that relocates stake
between validators or subnets without first withdrawing to the coldkey, and the swap fee attaches to
that liquidity movement
([Transaction Fees in Bittensor](https://docs.learnbittensor.org/learn/fees),
[Staking and Delegation](https://docs.learnbittensor.org/staking-and-delegation/delegation)).

There is a documented exception for same-subnet movement. The fee documentation states that when
stake is moved between hotkeys within the same subnet, no staking swap fee is applied and only the
weight-based transaction fee is charged. So the swap fee tracks whether the action actually crosses
a pool conversion, not merely whether stake changed hands
([Transaction Fees in Bittensor](https://docs.learnbittensor.org/learn/fees)).

## What It Does Not Mean

This fee should not be read as the base transaction fee. The fee documentation describes the base
transaction fee as having weight and length components tied to compute time and encoded size, while
the staking swap fee is an amount-based percentage of the transacted liquidity. The two are charged
separately, and a staking operation can carry both at once
([Transaction Fees in Bittensor](https://docs.learnbittensor.org/learn/fees)).

It also should not be read as slippage. The slippage documentation describes slippage as the
difference between the tokens actually received and the amount expected at the static spot price,
arising because the trade changes the pool's reserves and therefore the price. The swap fee is a
separate percentage charge on the amount, not the price-impact gap that slippage names
([Understanding Slippage](https://docs.learnbittensor.org/learn/slippage),
[Glossary: Slippage](https://docs.learnbittensor.org/resources/glossary#slippage)).

## Distinction from Slippage

The staking swap fee and slippage are two different effects on a staking conversion. The swap fee is
a percentage charge on the transacted liquidity that the protocol applies, while slippage is the
difference between the expected and received amount that arises because the trade itself shifts the
pool's reserves and price. Both can reduce the output of the same staking action, but for different
reasons ([Transaction Fees in Bittensor](https://docs.learnbittensor.org/learn/fees),
[Understanding Slippage](https://docs.learnbittensor.org/learn/slippage)).

- **Staking swap fee** — a percentage of the amount, charged by the protocol on the conversion.
- **Slippage** — the price-impact gap caused by the trade changing pool reserves.

## Distinction from Transaction Fee

The staking swap fee and the base transaction fee differ in what they are charged on. The fee
documentation describes the base transaction fee through weight and length, tied to compute and
encoded size, while the swap fee is an amount-based percentage of transacted liquidity. A staking
operation can incur both, so they are added together rather than substituted
([Transaction Fees in Bittensor](https://docs.learnbittensor.org/learn/fees)).

- **Staking swap fee** — amount-based percentage on the pool conversion.
- **Transaction fee** — weight-and-length cost of processing the extrinsic.

## Distinction from Same-Subnet Hotkey Movement

The staking swap fee separates conversions that pass through the pool from movements that do not.
The fee documentation states that moving stake between hotkeys within the same subnet incurs no
staking swap fee and only the weight-based transaction fee, whereas moving stake across subnets is
charged the amount-based swap fee. The presence of the swap fee therefore depends on whether the
action crosses a pool conversion
([Transaction Fees in Bittensor](https://docs.learnbittensor.org/learn/fees),
[Staking and Delegation](https://docs.learnbittensor.org/staking-and-delegation/delegation)).

- **Cross-subnet stake move** — charged the amount-based staking swap fee.
- **Same-subnet hotkey move** — no swap fee, only the base transaction fee.

## Reader Boundary

This page defines what the staking swap fee is and which staking actions it attaches to. It does not
tell a reader the exact fee amount their next staking action will cost on a live network; that
depends on the amount being transacted and the documented swap-fee rate applied to it. The
documented place to read the fee itself is the Bittensor fee reference
([Transaction Fees in Bittensor](https://docs.learnbittensor.org/learn/fees),
[Glossary: Unstaking](https://docs.learnbittensor.org/resources/glossary#unstaking)).
