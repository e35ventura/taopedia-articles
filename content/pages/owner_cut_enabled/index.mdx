# Owner Cut Enabled

Owner cut enabled is a per-subnet hyperparameter, listed in the documentation as `OwnerCutEnabled`,
that gates whether the subnet owner receives their cut of emissions at all. The reference describes
it as controlling owner-cut distribution, with a default of true so owners ordinarily receive their
share unless the flag is turned off
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

## What It Controls

The hyperparameter is the on-off switch for owner-cut distribution, not the percentage of the cut.
When it is true, the owner receives the configured
[subnet owner cut](https://docs.learnbittensor.org/subnets/subnet-hyperparameters#subnetownercut)
share of emissions; when it is false, that owner allocation is not distributed
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters),
[Emission](https://docs.learnbittensor.org/learn/emissions)).

It does not change how miner incentives or validator dividends are calculated inside Yuma Consensus.
It only decides whether the owner slice of the emission envelope is paid out on the selected netuid
([Yuma Consensus](https://docs.learnbittensor.org/learn/yuma-consensus)).

The flag is owner-tunable per subnet and is exposed in the canonical hyperparameter API, so netuid 1
can keep the default while another netuid disables owner-cut payout, and the live value is chain
state rather than a network constant
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

## Documented Type and Default

The [Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)
reference lists `OwnerCutEnabled` as a `Bool` with a default of true and marks the permission
required to change it as subnet owner
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

Because each subnet carries its own hyperparameters, the owner-cut gate on one netuid can differ
from the documented default and from the flag on another subnet
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

## Reading the Live Value for netuid 1

Owner cut enabled is per-subnet chain state, so any live claim is tied to a specific netuid. For the
documented example netuid 1 on Finney mainnet, the flag appears in that subnet's hyperparameter
table, which the reference describes under viewing a subnet's hyperparameters
([Subnet Hyperparameters: View hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters#view-hyperparameters)).
The infobox uses netuid 1 only as an example label; other subnets expose their own values
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

## Distinction from Subnet Owner Cut

Subnet owner cut sets the percentage share allocated to the owner when a cut is distributed. Owner
cut enabled decides whether that distribution happens at all
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

- **Subnet owner cut** — percentage of emissions allocated to the owner.
- **Owner cut enabled** — whether that owner allocation is distributed.
