# Root Staker

A root staker is a TAO holder who stakes through the Root Subnet, also called Subnet Zero. The
official [Emission: Distribution](https://docs.learnbittensor.org/learn/emissions#distribution)
documentation describes emissions to stakers on the Root Subnet separately from emissions to stakers
holding subnet alpha in a mining subnet. Root staker names the Root Subnet side of that distinction.

## Root Subnet Context

The
[Glossary: Root Subnet/Subnet Zero](https://docs.learnbittensor.org/resources/glossary#root-subnetsubnet-zero)
describes a special subnet where miners cannot register and no validation work is performed, while
validators can register and TAO holders can stake in a subnet-agnostic way. Root staker language
belongs to that TAO staking path rather than to subnet-local alpha markets.

For readers, root staker should be read as a role tied to Root Subnet participation, not as a wallet
label or a guarantee of any particular dividend outcome.

## Contrast with Alpha Staker

Bittensor staking prose distinguishes Root Subnet TAO staking from subnet-local alpha staking. An
[[Alpha Staker]] holds subnet alpha through staking in a specific mining subnet, while a root staker
participates through TAO staked to validators on the Root Subnet.

This keeps two ideas separate: root staker names TAO staked through Root Subnet validators, while
alpha staker names participation through subnet alpha in a specific subnet.

References:
[Glossary: Root Subnet/Subnet Zero](https://docs.learnbittensor.org/resources/glossary#root-subnetsubnet-zero),
[Emission: Distribution](https://docs.learnbittensor.org/learn/emissions#distribution)

## Dividends and Root Claims Context

Root staking can produce alpha dividends from active subnets. The
[Root Claim Overview](https://docs.learnbittensor.org/staking-and-delegation/root-claims) describes
how those dividends can be swapped to TAO and restaked on root or kept as the subnet alpha that
generated them. Root staker names the staking role; root claims name the dividend-handling layer for
stake placed through Root.

This article does not describe claim modes, live balances, or staking steps. Those details belong in
official staking documentation and live chain data.

References:
[Root Claim Overview](https://docs.learnbittensor.org/staking-and-delegation/root-claims),
[Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets)

## Relationship to Root Proportion

Root stakers participate in subnet dividend context through TAO routed via Root. The
[Glossary: Root Proportion](https://docs.learnbittensor.org/resources/glossary#root-proportion)
measures how much of a subnet's dividend context is attributed to that root-routed TAO stake. Root
staker names the participant role, while root proportion names a subnet-level measure of how much
dividend context belongs to root stakers rather than alpha stakers.

References:
[Glossary: Root Proportion](https://docs.learnbittensor.org/resources/glossary#root-proportion),
[Emission](https://docs.learnbittensor.org/learn/emissions)

## Relationship to Multiple Mechanisms

Root staking is subnet-agnostic at the Root Subnet level. The
[Glossary](https://docs.learnbittensor.org/resources/glossary#multiple-incentive-mechanisms) notes
that ordinary subnets may run more than one incentive mechanism with separate evaluation contexts.

For readers, root staker still names TAO staking through Root Subnet validators. Alpha dividends
from active subnets may still connect to subnet markets that run multiple mechanisms, but the root
staker role itself remains part of Root Subnet vocabulary rather than a per-mechanism miner label.

References:
[Multiple Incentive Mechanisms Within Subnets](https://docs.learnbittensor.org/subnets/understanding-multiple-mech-subnets),
[Glossary: Multiple Incentive Mechanisms](https://docs.learnbittensor.org/resources/glossary#multiple-incentive-mechanisms)

## Reader Boundary

Root staker should not be read as a validator recommendation, a live portfolio report, or a synonym
for nominator in every context. It is a role term for Root Subnet TAO staking participation. Exact
balances, fees, and subnet-specific behavior belong in current official staking references.
