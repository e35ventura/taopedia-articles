# Root Staker

A root staker is a TAO holder who stakes through validators on the Root Subnet, also called Subnet
Zero
([Glossary: Root Subnet/Subnet Zero](https://docs.learnbittensor.org/resources/glossary#root-subnetsubnet-zero),
[Staking and delegation overview](https://docs.learnbittensor.org/staking-and-delegation/delegation)).

The term names the TAO-holder role in Bittensor's subnet-agnostic staking context. It should be read
separately from alpha-side staking inside an ordinary subnet.

## Root Subnet Context

The Root Subnet is the special subnet where TAO holders can stake to validators in a subnet-agnostic
way. It is distinct from ordinary subnet miner and validator work
([Glossary: Root Subnet/Subnet Zero](https://docs.learnbittensor.org/resources/glossary#root-subnetsubnet-zero),
[Emission: Distribution](https://docs.learnbittensor.org/learn/emissions#distribution)).

Root staker therefore names the TAO holder supplying stake through that context, not the validator
role and not a subnet-local alpha position.

## Root Staker and Alpha Staker

Bittensor staking prose separates root-side TAO staking from subnet-local alpha staking. Emissions
to stakers on the Root Subnet are described separately from emissions to stakers holding subnet
alpha in a mining subnet
([Emission: Distribution](https://docs.learnbittensor.org/learn/emissions#distribution),
[Glossary: Root Subnet/Subnet Zero](https://docs.learnbittensor.org/resources/glossary#root-subnetsubnet-zero)).

For readers, the useful boundary is asset and context. Root staker describes TAO staked through Root
Subnet validators; alpha staker language belongs to a subnet's alpha context.

## Delegation Boundary

A root staker commits TAO by delegating to a validator on the Root Subnet. The staking and
delegation overview covers TAO holders staking through validators, while the Root Subnet glossary
places that relationship on Subnet Zero
([Staking and delegation overview](https://docs.learnbittensor.org/staking-and-delegation/delegation),
[Glossary: Root Subnet/Subnet Zero](https://docs.learnbittensor.org/resources/glossary#root-subnetsubnet-zero)).

This article keeps the role definition separate from validator selection. Root staker names who
supplies TAO through Root Subnet staking; it does not rank validators or explain staking steps.

## Dividends and Root Claims

Root-routed stake can earn alpha dividends that are later handled through the root-claim process.
Root claims define Keep and Swap handling for accumulated dividends from Root Subnet stake
([Root Claim Overview](https://docs.learnbittensor.org/staking-and-delegation/root-claims),
[Emission: Distribution](https://docs.learnbittensor.org/learn/emissions#distribution)).

Root staker names the staking role before that dividend-handling layer. Root claims and root claim
type describe what happens when accumulated dividends are processed.

## Root Claim Type Boundary

Root claim type is adjacent vocabulary because it controls Keep or Swap handling for dividends. A
root staker is the TAO-holder role; root claim type is the dividend-handling preference used when
claimable dividends are processed
([Root Claim Overview](https://docs.learnbittensor.org/staking-and-delegation/root-claims),
[Glossary: Root Staker](https://docs.learnbittensor.org/resources/glossary#root-staker)).

This distinction keeps the role separate from the dividend setting. A root staker can be discussed
without turning the article into a claim-type guide.

## TAO-Weight Context

Root staker also sits near TAO-weight vocabulary because Root Subnet staking uses TAO. TAO weight
describes how TAO stake contributes relative to alpha stake in stake-weight interpretation, while
root staker names the TAO holder using Root Subnet staking
([Glossary: TAO Weight](https://docs.learnbittensor.org/resources/glossary#tao-weight),
[Glossary: Root Subnet/Subnet Zero](https://docs.learnbittensor.org/resources/glossary#root-subnetsubnet-zero)).

That keeps role vocabulary separate from weighting vocabulary. Root staker names who stakes; TAO
weight helps explain how TAO stake is interpreted in consensus context.

## Relationship to Root Proportion

Root staker and root proportion describe different levels of the same staking context. Root staker
names the TAO-holder role, while root proportion measures how much of a subnet's dividend context is
attributed to root-routed TAO
([Glossary: Root Proportion](https://docs.learnbittensor.org/resources/glossary#root-proportion),
[Glossary: Root Subnet/Subnet Zero](https://docs.learnbittensor.org/resources/glossary#root-subnetsubnet-zero)).

One term names who is staking through the Root Subnet. The other names a subnet-level proportion
that reflects root-side stake in that subnet's dividend context.

## Reader Boundary

Root staker should be read as a concept article term. It is not a balance report, validator
recommendation, staking guide, or synonym for every staker in every Bittensor context
([Staking and delegation overview](https://docs.learnbittensor.org/staking-and-delegation/delegation),
[Glossary: Root Subnet/Subnet Zero](https://docs.learnbittensor.org/resources/glossary#root-subnetsubnet-zero)).

The stable article-level point is that root staker names a TAO holder using the Root Subnet staking
context.
