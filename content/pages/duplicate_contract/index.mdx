# Duplicate Contract

`DuplicateContract` is a contracts pallet error raised when a contract with the same account already
exists. The API errors reference summarizes it as "A contract with the same AccountId already
exists"
([Subtensor API Errors: DuplicateContract](https://docs.learnbittensor.org/subtensor-api/errors#duplicatecontract)).

## What It Means

Subtensor includes a contracts pallet for on-chain smart contracts. Each live contract is tied to an
account on chain. `DuplicateContract` means the operation targets an account that already has a live
contract, so the runtime rejects the creation attempt
([Subtensor API Errors: DuplicateContract](https://docs.learnbittensor.org/subtensor-api/errors#duplicatecontract)).

This is an account-occupancy rejection. It does not, by itself, mean no contract exists at the
address, that no code exists at a supplied hash, or that supplied instantiate code exceeded the
schedule size limit.

## Why It Appears

This error appears when a contracts operation would create a contract at an account that already has
one
([Subtensor API Errors: DuplicateContract](https://docs.learnbittensor.org/subtensor-api/errors#duplicatecontract)).

## Distinction from Contract Not Found

`DuplicateContract` and `ContractNotFound` point in opposite directions at the contract-address
lookup. `DuplicateContract` is summarized as "A contract with the same AccountId already exists."
`ContractNotFound` is summarized as "Contract not found at the specified address."
([Subtensor API Errors: DuplicateContract](https://docs.learnbittensor.org/subtensor-api/errors#duplicatecontract),
[Subtensor API Errors: ContractNotFound](https://docs.learnbittensor.org/subtensor-api/errors#contractnotfound)).

- **DuplicateContract** — a live contract already exists at the targeted account.
- **ContractNotFound** — no live contract exists at the targeted address.

## Distinction from Code Not Found

`DuplicateContract` and `CodeNotFound` both involve contract state, but the API summaries name
different missing or conflicting records. `DuplicateContract` means the targeted account is already
occupied by a live contract. `CodeNotFound` is summarized as "No code could be found at the supplied
code hash."
([Subtensor API Errors: DuplicateContract](https://docs.learnbittensor.org/subtensor-api/errors#duplicatecontract),
[Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound)).

- **DuplicateContract** — a live contract already exists at the targeted account.
- **CodeNotFound** — no code exists at the supplied hash.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not report whether
a specific account already has a live contract on a network
([Subtensor API Errors: DuplicateContract](https://docs.learnbittensor.org/subtensor-api/errors#duplicatecontract),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
