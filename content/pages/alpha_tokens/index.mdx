# Alpha Tokens

Alpha tokens are subnet-specific assets in Bittensor. Each subnet has its own alpha token, separate
from TAO, giving each subnet its own tokenomics context for emissions, staking, and liquidity pools
([Emission](https://docs.learnbittensor.org/learn/emissions)).

## Subnet Asset Scope

An alpha token represents value inside a specific subnet rather than across the Bittensor network.
TAO remains the network-wide asset; alpha tokens belong to subnet-level tokenomics
([Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets)).

This scope keeps TAO and alpha-token claims separate. A statement about TAO supply or network
emission is not automatically a statement about a subnet's alpha-token context.

## Emission Role

Bittensor emission uses both TAO and subnet-specific alpha tokens. The
[Emission](https://docs.learnbittensor.org/learn/emissions) documentation describes TAO entering
subnet contexts and alpha tokens appearing in subnet-level reward and reserve flows.

The useful point is asset scope. TAO is network-scoped; alpha tokens are subnet-scoped assets used
inside each subnet's emission and staking context.

## Pool Context

Subnets use paired TAO and alpha reserve structures. The
[Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets) documentation
describes each subnet as an automated market maker with TAO and subnet-specific alpha reserves. The
[Emission](https://docs.learnbittensor.org/learn/emissions#alpha-reserve-injection) documentation
describes alpha reserve injection on the alpha side.

Alpha tokens are therefore not only reward vocabulary. They are part of the subnet pool design that
underlies Dynamic TAO tokenomics.

## Staking Scope

Outside the root subnet, stake can be represented in a subnet's alpha units. The
[Delegation](https://docs.learnbittensor.org/staking-and-delegation/delegation) documentation places
subnet alpha in staking and delegation context, while
[Slippage](https://docs.learnbittensor.org/learn/slippage) explains why pool conditions matter when
TAO and alpha interact through the AMM.

Alpha-token staking language is subnet-denominated stake context, not a general claim about TAO
itself.

## Halving Scope

Alpha tokens have subnet-level halving context. The
[Halving Mechanisms](https://docs.learnbittensor.org/concepts/halving) documentation distinguishes
network-level TAO halving from subnet-level alpha halving.

The word "halving" applies at different asset scopes. A TAO halving claim and an alpha halving claim
should name the asset and subnet context being discussed.

## Reader Boundary

Alpha tokens are the right term when the focus is a subnet-specific asset. If the focus is
network-scoped TAO, TAO is more precise. If the focus is the pool-held side,
[alpha reserve](https://docs.learnbittensor.org/learn/emissions#alpha-reserve-injection) is more
precise. If the focus is cross-subnet emission share,
[subnet weights](https://docs.learnbittensor.org/resources/glossary#subnet-weights) is more precise.

These boundaries keep alpha tokens focused on subnet asset vocabulary, not a staking walkthrough,
pool calculation, or complete account of Dynamic TAO.

## Development Stage Context

The
[Introduction to Bittensor](https://docs.learnbittensor.org/learn/introduction#subnet-development)
describes subnet development as moving from localnet to testnet and then mainnet. For alpha tokens,
that sequence changes how readers should interpret examples of subnet-specific token behavior and
staking outcomes.

In localnet, alpha token mechanics can be observed in an isolated environment. Localnet alpha token
balances and emission outcomes reflect local chain settings and do not represent production subnet
token state.

On testnet, alpha token behavior can be observed in a shared, non-production network. Testnet alpha
token balances and staking outcomes are separate from mainnet subnet token state.

On mainnet, alpha tokens are live subnet-specific assets that represent staked positions and carry
economic weight within a production Bittensor subnet. The
[Understanding Subnets](https://docs.learnbittensor.org/subnets/understanding-subnets) documentation
describes the subnet alpha token context that applies on the production network.

The [Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks) reference
separates mainnet, testnet, and localnet. An alpha token example from one environment should not be
read as representing staking balances or emission outcomes in another environment.
