# Subnet 19: Blockmachine

Blockmachine is Bittensor Subnet 19 (SN19), operated by [taostat](https://blockmachine.io). The
subnet runs a decentralized marketplace for blockchain RPC and archive node services, replacing
centralized API providers with a competitive network of independent node operators. Miners earn
emissions by serving valid blockchain data requests routed through a protocol-owned gateway;
validators audit correctness and performance, and the network rewards efficient, accurate service
while penalizing poor performers.

References: [taostat/blockmachine (GitHub)](https://github.com/taostat/blockmachine/),
[blockmachine.io](https://blockmachine.io)

## How the Mechanism Works

The subnet operates a protocol-owned gateway that routes incoming JSON-RPC requests to registered
miners. Response correctness is verified in real-time using cryptographic proofs against trusted
block roots before results are returned to customers. Miners declare pricing bids per region each
epoch, and the gateway routes requests accordingly. Only successful responses — those that return
valid results — generate billable compute units and miner earnings. Failed requests produce neither
payment nor penalty.

Pricing is denominated in USD per compute unit rather than in token terms, decoupling infrastructure
costs from token price volatility and making the service predictable for customers.

After serving requests, validators audit gateway logs by replaying sampled requests against
reference nodes to verify that miners returned correct data. Confirmed data mismatches result in
permanent bans. Quality scores combining latency, success rate, and long-term reliability feed into
weight vectors submitted to [[Yuma Consensus]], which distributes emissions via [[Dynamic TAO]].

The subnet also uses a Protocol Stability Reserve: for each alpha token earned by miners, the
protocol makes an equivalent on-chain purchase, neutralizing miner sell pressure and keeping token
economics aligned with actual service delivery.

References: [taostat/blockmachine (GitHub)](https://github.com/taostat/blockmachine/)

## Participating as a Miner

Miners on Blockmachine operate full RPC and archive nodes for one or more blockchain networks. Their
economic role is to serve accurate, low-latency responses to routed JSON-RPC requests. Miners who
deliver fast, reliable responses across their registered regions attract more request volume and
earn proportionally more emissions. Because only successful responses generate earnings, reliability
and data correctness are the primary competitive levers — a miner returning incorrect data risks a
permanent ban.

References: [taostat/blockmachine (GitHub)](https://github.com/taostat/blockmachine/)

## Participating as a Validator

Validators on Blockmachine audit the accuracy and performance of miners by downloading gateway logs
and replaying sampled requests against independent reference nodes. They measure each miner's
95th-percentile response latency, per-epoch success rate, and rolling long-term reliability score.
These metrics are combined into per-miner quality scores, and validators submit the resulting weight
vectors to [[Yuma Consensus]]. Validators also flag confirmed data mismatches, which trigger
permanent miner bans.

References: [taostat/blockmachine (GitHub)](https://github.com/taostat/blockmachine/)
