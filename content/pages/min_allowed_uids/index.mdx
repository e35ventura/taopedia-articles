# Min Allowed UIDs

Min allowed UIDs is a per-subnet hyperparameter, listed in the documentation as `MinAllowedUids`,
that sets the minimum allowed number of
[UIDs](https://docs.learnbittensor.org/resources/glossary#uid-slot) for a subnet. The reference
describes it as the minimum allowed UIDs for a subnet, callable only by the root account
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

## What It Controls

The hyperparameter names the lower bound on a subnet's UID count, not which neurons hold those UIDs
or how registration is priced. Each registered neuron occupies one
[UID slot](https://docs.learnbittensor.org/resources/glossary#uid-slot), and this value is the
documented minimum for how many such slots a subnet is allowed
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

It is root-callable rather than owner-set, reflecting network-level control over the minimum. The
live value on netuid 1 is per-subnet chain state and can differ from the documented default and from
another subnet's value
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

## Documented Type, Default, and Setter

The [Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)
reference lists `MinAllowedUids` as a `u16` with a default of 64. It is changed through the
`sudo_set_min_allowed_uids` extrinsic and is callable only by the root account
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

## Reading the Live Value for netuid 1

Min allowed UIDs is per-subnet chain state, so any live claim is tied to a specific netuid. For the
documented example netuid 1 on Finney mainnet, the value appears in that subnet's hyperparameter
table, which the reference describes under viewing a subnet's hyperparameters
([Subnet Hyperparameters: View hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters#view-hyperparameters)).
The infobox uses netuid 1 only as an example label; other subnets expose their own values
([Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).

## Distinction from Max Allowed UIDs

Max allowed UIDs sets the maximum number of UIDs a subnet can hold, while min allowed UIDs names the
documented minimum allowed UID count for a subnet. The two name opposite ends of a subnet's
UID-count bounds
([Subnet Hyperparameters](https://docs.learnbittensor.org/subnets/subnet-hyperparameters)).

- **Max allowed UIDs** — maximum UID count a subnet can hold.
- **Min allowed UIDs** — minimum allowed UID count for a subnet.
