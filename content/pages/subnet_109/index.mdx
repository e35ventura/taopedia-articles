Academia is Bittensor Subnet 109. The live Finney identity lists its subnet name as Academia, its
GitHub repository as fx-integral/academia, no subnet URL, and its description as "Academia: where
builders become subnet owners."

The Academia README describes the project as a Bittensor subnet incubation academy. Its stated goal
is to develop promising subnet ideas in-house on mainnet, evaluate them through structured
mechanisms, and graduate the strongest projects into dedicated subnets.

## What Academia Provides

Academia provides an incubator model for subnet creation. The README frames the subnet around
scouting, evaluating, and developing subnet concepts inside a single Bittensor subnet, with
selection based on demonstrated performance rather than proposals alone.

The README names two initial mechanism tracks: Research & Design for subnet theses, incentive
designs, benchmark suites, and exploit analysis; and Prototype & Arena for working implementations,
benchmark competition, and mainnet-tested prototypes. It also describes an AI agent evaluation
system for intake, scoring, and candidate ranking using transparent rubrics and auditable scores.

## Miner and Validator Roles

Academia's public README frames the work around builders and candidate projects rather than a fully
documented miner protocol. It says miner and validator onboarding documentation is still to be
published, so Taopedia should not yet assert detailed submission commands, validator prompts, or
scoring cadence.

At the mechanism level, the README lists work products such as subnet concepts, research artifacts,
benchmark suites, and prototypes. Validators generally evaluate subnet work and submit weights
through Bittensor; once Academia publishes detailed operator docs, those details can be mapped to
the broader Bittensor mining and validating pattern.

## On-Chain Identity

Readers can reproduce the live identity fields with the Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 109 --network finney`.

That Finney identity reports the subnet name as Academia, the GitHub repo as fx-integral/academia,
no subnet URL, and the description "Academia: where builders become subnet owners."
