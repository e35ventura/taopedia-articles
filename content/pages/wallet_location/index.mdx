# Wallet Location

Wallet location is Bittensor wallet-file terminology for where generated Bittensor wallet files are
stored on a user's machine. The official
[Wallet Location glossary](https://docs.learnbittensor.org/resources/glossary#wallet-location)
describes it as the directory path where generated Bittensor wallets are stored locally.

## File-Storage Context

Wallet location is storage-location vocabulary, not a wallet role, address format, or key type. It
describes where wallet files live on a local machine, while separate wallet and key terms describe
the wallet material itself.

## Wallet Context

Official [wallet documentation](https://docs.learnbittensor.org/keys/wallets) is the surrounding
context for Bittensor wallet concepts. In Taopedia prose, wallet location should be read as a file
storage concept rather than an account-status claim or a security procedure.

## Key Material Storage Context

The [Glossary: Wallet Location](https://docs.learnbittensor.org/resources/glossary#wallet-location)
identifies wallet location as where generated Bittensor wallets are stored on a local machine.
Official [wallet documentation](https://docs.learnbittensor.org/keys/wallets) treats that storage as
holding local coldkey and hotkey file material. Wallet location therefore names a filesystem context
for wallet keys, not an on-chain address or subnet participant role.

References:
[Glossary: Wallet Location](https://docs.learnbittensor.org/resources/glossary#wallet-location),
[Bittensor wallet documentation](https://docs.learnbittensor.org/keys/wallets)

## Reading the Term

This article is a concept boundary. It does not provide file paths, recovery steps, or wallet
operation guidance. For a reader, the useful point is that wallet location names the local storage
context for Bittensor wallet files.

## Local Path Versus On-Chain Identity

Wallet location names where generated wallet files are stored on a local machine. It does not name
the on-chain coldkey identity, SS58 destination address, or subnet participation status associated
with those keys. The glossary describes wallet location as a directory path for locally generated
wallet files, while wallet and key terms describe the cryptographic material and authority those
files represent when used to sign. The directory path does not replace reading balances or stake on
chain.

Readers should keep filesystem context separate from chain context. Knowing where wallet files live
helps with backup and workstation planning, but it does not by itself describe balances, stake, or
registrations visible on chain. Backup policy and file permissions belong in operational wallet
guides rather than in a storage-path concept article.

References:
[Glossary: Wallet Location](https://docs.learnbittensor.org/resources/glossary#wallet-location),
[Bittensor wallet documentation](https://docs.learnbittensor.org/keys/wallets)

## Multiple Key Files in One Location

Official wallet documentation allows multiple coldkeys and hotkeys to exist under the wallet storage
layout on a machine. Wallet location therefore describes a directory context that can hold more than
one key file, not a one-to-one mapping between a folder and a single network identity.

That matters when reading custody discussions. A participant may store several operational hotkeys
and one or more coldkey files in the same wallet directory structure described by official tooling.
Wallet location names the storage area; individual key files inside it still map to separate roles
described in coldkey and hotkey vocabulary. Tooling labels inside that directory identify which file
serves which role.

References:
[Glossary: Wallet Location](https://docs.learnbittensor.org/resources/glossary#wallet-location),
[Wallets, Coldkeys and Hotkeys](https://docs.learnbittensor.org/keys/wallets)

## Workstation Security and File Location

The workstation security guide treats where keys live as part of wallet risk, not only which device
is online. Wallet location vocabulary helps readers discuss local file storage without turning a
directory path into a security checklist or a substitute for coldkey custody guidance.

Local wallet files on an internet-connected machine carry different risk than read-only observation
or offline signing environments described in the security documentation. Wallet location names the
filesystem context for generated files; workstation security names how much authority those files
should expose in daily use. Operational hardening steps belong in official security references
rather than in this concept article. Moving files without understanding key roles can break signing
setup.

References:
[Glossary: Wallet Location](https://docs.learnbittensor.org/resources/glossary#wallet-location),
[Coldkey and Hotkey Workstation Security](https://docs.learnbittensor.org/keys/coldkey-hotkey-security)

## Relationship to Wallets

Wallet location and wallets are related but different parts of Bittensor wallet vocabulary. A wallet
is the cryptographic identity formed by coldkey and hotkey pairs used to access TAO and sign
transactions, while wallet location describes the filesystem directory where the generated wallet
files are stored locally on a user's machine. The
[Bittensor wallet documentation](https://docs.learnbittensor.org/keys/wallets) describes wallets as
the key-pair identity that proves control and accesses on-chain state, while the
[Glossary: Wallet Location](https://docs.learnbittensor.org/resources/glossary#wallet-location)
describes wallet location as the local storage path for those generated wallet files.

For readers, the wallet names the cryptographic identity and on-chain control, while wallet location
names where the local key files representing that identity are stored on disk.

References: [Bittensor wallet documentation](https://docs.learnbittensor.org/keys/wallets),
[Glossary: Wallet Location](https://docs.learnbittensor.org/resources/glossary#wallet-location)

## Relationship to Coldkeys

Wallet location and coldkeys are related but different scopes in Bittensor wallet vocabulary. A
coldkey is the security-sensitive cryptographic key that holds TAO balances and owns hotkeys, while
wallet location describes the filesystem directory where generated coldkey files (and hotkey files)
are stored on the local machine. The
[Wallets, Coldkeys and Hotkeys](https://docs.learnbittensor.org/keys/wallets) documentation treats
coldkeys as the custody anchor that should be protected offline when possible, and the
[Glossary: Wallet Location](https://docs.learnbittensor.org/resources/glossary#wallet-location)
describes wallet location as the local storage context for those wallet files.

For readers, the coldkey names the key material and on-chain identity, while wallet location names
the local filesystem path where that key material is stored when generated on a machine.

References: [Wallets, Coldkeys and Hotkeys](https://docs.learnbittensor.org/keys/wallets),
[Glossary: Wallet Location](https://docs.learnbittensor.org/resources/glossary#wallet-location)
