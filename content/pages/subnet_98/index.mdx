ForeverMoney is Bittensor Subnet 98, a subnet that turns automated liquidity management into a
rewarded competition. The project site is [forevermoney.ai](https://forevermoney.ai), and its
on-chain description is "Decentralized intelligence for advanced liquidity management." The codebase
for the subnet is the `SN98-ForeverMoney/forever-money` repository.

## What ForeverMoney Rewards

Providing liquidity to a modern decentralized exchange is not a one-time deposit: concentrated
liquidity pools, such as those used by Uniswap V3 and Aerodrome, only earn fees while the pool price
stays inside the range a provider has chosen, so positions need to be adjusted as prices move.
ForeverMoney treats this ongoing decision — when and how to move a position — as the work the subnet
rewards.

The network runs as a set of independent jobs, where each job is a specific liquidity pool or
trading pair being managed. For each job, miners compete to propose the rebalancing decision they
think will perform best, and the subnet rewards strategies that grow the value of the position,
through price appreciation and trading fees, while protecting the underlying holdings from loss.
Strategies that consistently perform well across many rounds earn more than ones that do well only
occasionally.

## Miner and Validator Roles

Miners are the strategists. For a given job, a miner decides whether to keep the current position or
rebalance it, and submits that decision to the network. Because the subnet manages many pools at
once, miners build up a per-job track record and tend to specialize in the pairs they understand
best.

Validators run the competition and decide what gets used. In evaluation rounds, all participating
miners compete and their proposed strategies are tested through forward simulations that start from
the current on-chain state, so submissions are judged on expected performance rather than on claims.
Validators score the results, maintain each miner's reputation over time, and set weights on the
network accordingly, which is how reward flows through [[Yuma Consensus]]. Miners that have taken
part consistently for long enough become eligible for live rounds, where the winning strategy for a
job is actually executed on-chain on the Base network. At the article level the split is
straightforward: miners propose how to manage liquidity, while validators measure how well each
proposal would do and weight it.

## On-Chain Identity

Live SN98 subnet data is available on [TaoStats](https://taostats.io/subnets/98), which identifies
the subnet as ForeverMoney. Readers can reproduce the subnet identity fields directly with the
Bittensor CLI command documented in the
[btcli reference](https://docs.learnbittensor.org/btcli/#btcli-subnets-get-identity):
`btcli subnets get-identity --netuid 98 --network finney`. That Finney identity is the source of
truth for the subnet name and the GitHub repository associated with the subnet.
