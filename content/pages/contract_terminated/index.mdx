# Contract Terminated

`ContractTerminated` is a contracts pallet error raised when an operation targets a contract that is
no longer available after termination. The API errors reference summarizes it as "The contract has
been terminated"
([Subtensor API Errors: ContractTerminated](https://docs.learnbittensor.org/subtensor-api/errors#contractterminated)).

## What It Means

Some contracts-pallet operations expect the supplied address to resolve to a live contract.
`ContractTerminated` means that the contract is no longer available because it has already been
terminated, so the attempted operation cannot continue
([Subtensor API Errors: ContractTerminated](https://docs.learnbittensor.org/subtensor-api/errors#contractterminated)).

This is a post-termination availability failure. It does not, by itself, mean the runtime never had
a contract at the address, that a code hash lookup failed, or that execution started and then
trapped.

## Why It Appears

This error appears when a contracts operation points at a contract that has already been terminated
and is no longer available for the requested action
([Subtensor API Errors: ContractTerminated](https://docs.learnbittensor.org/subtensor-api/errors#contractterminated)).

## Distinction from Contract Not Found

`ContractTerminated` and `ContractNotFound` both mean a requested contracts operation cannot proceed
at the supplied address, but they say different things. `ContractTerminated` means the contract was
terminated and is no longer available. `ContractNotFound` means the runtime cannot find a live
contract at the specified address
([Subtensor API Errors: ContractTerminated](https://docs.learnbittensor.org/subtensor-api/errors#contractterminated),
[Subtensor API Errors: ContractNotFound](https://docs.learnbittensor.org/subtensor-api/errors#contractnotfound)).

- **ContractTerminated** — the contract was terminated and is no longer available.
- **ContractNotFound** — no live contract exists at the targeted address.

## Distinction from Contract Trapped

`ContractTerminated` and `ContractTrapped` both involve unavailable contract outcomes, but at
different stages. `ContractTerminated` means the contract is already unavailable because termination
has happened. `ContractTrapped` means execution reached the contract and then trapped during the
call
([Subtensor API Errors: ContractTerminated](https://docs.learnbittensor.org/subtensor-api/errors#contractterminated),
[Subtensor API Errors: ContractTrapped](https://docs.learnbittensor.org/subtensor-api/errors#contracttrapped)).

- **ContractTerminated** — the contract is unavailable after termination.
- **ContractTrapped** — execution reached the contract and trapped during the call.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not identify which
specific contract addresses are currently terminated on a live network
([Subtensor API Errors: ContractTerminated](https://docs.learnbittensor.org/subtensor-api/errors#contractterminated),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
