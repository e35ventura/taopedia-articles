# Initial Max Registrations Per Block

Initial Max Registrations Per Block is a subtensorModule runtime constant, listed in the chain's
constants metadata as initialMaxRegistrationsPerBlock, with the value 1 and the summary "Initial max
registrations per block"
([Subtensor API Constants: initialMaxRegistrationsPerBlock](https://docs.learnbittensor.org/subtensor-api/constants#initialmaxregistrationsperblock-u16)).
It supplies the default value a subnet's MaxRegistrationsPerBlock uses.

## What It Means

MaxRegistrationsPerBlock is held per subnet and caps how many neuron registrations the subnet
accepts within a single block. Initial Max Registrations Per Block is the default this per-subnet
value falls back to before a different value applies for a subnet
([Subtensor API Constants: initialMaxRegistrationsPerBlock](https://docs.learnbittensor.org/subtensor-api/constants#initialmaxregistrationsperblock-u16)).
The MaxRegistrationsPerBlock in force on a subnet such as netuid 1 is that subnet's own chain state
and can differ from this default.

## Distinction from Related Registration Defaults

Initial Max Registrations Per Block is the default value, while
initialTargetRegistrationsPerInterval, valued at 2, is the target number of registrations per
adjustment interval; initialAdjustmentInterval, valued at 100, is the number of blocks between
registration-cost recalibrations
([Subtensor API Constants: initialTargetRegistrationsPerInterval](https://docs.learnbittensor.org/subtensor-api/constants#initialtargetregistrationsperinterval-u16),
[Subtensor API Constants: initialAdjustmentInterval](https://docs.learnbittensor.org/subtensor-api/constants#initialadjustmentinterval-u16)).
This constant supplies the seed a subnet begins from, which is separate from those related values.

## Reader Boundary

Initial Max Registrations Per Block is a default constant, not the live per-subnet
MaxRegistrationsPerBlock, and it reflects the current runtime configuration rather than a fixed
protocol rule
([Subtensor API Constants: initialMaxRegistrationsPerBlock](https://docs.learnbittensor.org/subtensor-api/constants#initialmaxregistrationsperblock-u16)).
