# No Such Code

`NoSuchCode` is a contracts pallet error raised when a named contracts code record does not exist in
storage. The API errors reference summarizes it as "No code info could be found for the supplied
code hash"
([Subtensor API Errors: NoSuchCode](https://docs.learnbittensor.org/subtensor-api/errors#nosuchcode)).

## What It Means

Some contracts-pallet operations need stored code information for a supplied code hash before they
can continue. `NoSuchCode` means the runtime could not find that code record, so the requested
operation cannot proceed
([Subtensor API Errors: NoSuchCode](https://docs.learnbittensor.org/subtensor-api/errors#nosuchcode)).

This is a stored code-record lookup failure. It does not, by itself, mean a live contract address
was missing, that stored code is still in use by another contract, or that execution reached a
contract and then trapped.

## Why It Appears

This error appears when a contracts operation supplies a code hash whose code information is not
present in storage
([Subtensor API Errors: NoSuchCode](https://docs.learnbittensor.org/subtensor-api/errors#nosuchcode)).

## Distinction from Code Not Found

`NoSuchCode` and `CodeNotFound` both describe missing code-related state, but they name different
lookups. `NoSuchCode` means the runtime cannot find the stored code information for a supplied code
hash. `CodeNotFound` means no code could be found at the supplied code hash
([Subtensor API Errors: NoSuchCode](https://docs.learnbittensor.org/subtensor-api/errors#nosuchcode),
[Subtensor API Errors: CodeNotFound](https://docs.learnbittensor.org/subtensor-api/errors#codenotfound)).

- **NoSuchCode** — the stored code record is missing.
- **CodeNotFound** — no code could be found at the supplied code hash.

## Distinction from Code In Use

`NoSuchCode` and `CodeInUse` both involve stored code state, but they fail on opposite conditions.
`NoSuchCode` means the runtime cannot find the code record at all. `CodeInUse` means the code does
exist, but the runtime refuses removal because at least one contract still references it
([Subtensor API Errors: NoSuchCode](https://docs.learnbittensor.org/subtensor-api/errors#nosuchcode),
[Subtensor API Errors: CodeInUse](https://docs.learnbittensor.org/subtensor-api/errors#codeinuse)).

- **NoSuchCode** — no stored code record exists for the supplied hash.
- **CodeInUse** — the stored code exists but is still referenced.

## Reader Boundary

This page defines the meaning of the error label from the API reference. It does not report which
code hashes currently exist on a live network
([Subtensor API Errors: NoSuchCode](https://docs.learnbittensor.org/subtensor-api/errors#nosuchcode),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
