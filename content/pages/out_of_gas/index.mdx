# Out Of Gas

`OutOfGas` is a contracts pallet error raised when executed contract code exhausts its gas limit.
The API errors reference summarizes it as "The executed contract exhausted its gas limit"
([Subtensor API Errors: OutOfGas](https://docs.learnbittensor.org/subtensor-api/errors#outofgas)).

## What It Means

Bittensor's EVM layer runs Ethereum-compatible smart contracts on Subtensor. Each execution is
metered by gas, and the call stops when that budget is used up. `OutOfGas` means the contract ran
out of gas before finishing, so execution halts without completing the intended logic
([Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials),
[Subtensor API Errors: OutOfGas](https://docs.learnbittensor.org/subtensor-api/errors#outofgas)).

This is a runtime gas-exhaustion outcome during execution. It does not, by itself, mean the
submitted gas limit was below the runtime minimum before the call started or that the gas limit
exceeded the allowed maximum at submission time.

## Why It Appears

This error appears when a contract call or deployment uses more gas during execution than the
allotted limit allows. The practical meaning is narrow: raise the gas limit, reduce the work the
contract performs in one call, or optimize the contract path before retrying
([Subtensor API Errors: OutOfGas](https://docs.learnbittensor.org/subtensor-api/errors#outofgas),
[Token Bridging](https://docs.learnbittensor.org/evm-tutorials/bridge-vtao)).

## Distinction from Gas Limit Too Low

`OutOfGas` and `GasLimitTooLow` both involve gas limits, but at different stages. `GasLimitTooLow`
is an EVM pallet rejection when the submitted gas limit is below the runtime minimum before
execution starts. `OutOfGas` means execution began and then exhausted the gas budget
([Subtensor API Errors: GasLimitTooLow](https://docs.learnbittensor.org/subtensor-api/errors#gaslimittoolow),
[Subtensor API Errors: OutOfGas](https://docs.learnbittensor.org/subtensor-api/errors#outofgas)).

- **OutOfGas** — execution exhausted the allotted gas limit.
- **GasLimitTooLow** — the submitted gas limit is below the required minimum.

## Distinction from Gas Limit Too High

`OutOfGas` and `GasLimitTooHigh` both relate to gas limits, but they indicate different failures.
`GasLimitTooHigh` rejects a transaction when the submitted gas limit exceeds the runtime maximum
before execution. `OutOfGas` means the call was allowed to run but consumed its gas budget during
execution
([Subtensor API Errors: GasLimitTooHigh](https://docs.learnbittensor.org/subtensor-api/errors#gaslimittoohigh),
[Subtensor API Errors: OutOfGas](https://docs.learnbittensor.org/subtensor-api/errors#outofgas)).

- **OutOfGas** — execution exhausted the allotted gas limit.
- **GasLimitTooHigh** — the submitted gas limit exceeds the allowed maximum.

## Reader Boundary

This page defines the meaning of the error label and the gas-exhaustion outcome it represents during
contract execution. It does not estimate gas for a specific contract call or report live gas
settings on a network; those depend on contract logic and runtime parameters at submission time
([Bittensor EVM Smart Contracts](https://docs.learnbittensor.org/evm-tutorials),
[Bittensor Networks](https://docs.learnbittensor.org/concepts/bittensor-networks)).
